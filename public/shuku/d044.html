题1 顺序表循环左移 p 位（2010真题模型）

【题】将长度 n 的顺序表 R 循环左移 p（0<p<n）位，要求 O(n) 时间、O(1) 空间。 【思路】三次逆置：逆前 p 个 → 逆后 n−p 个 → 逆全部。

void Reverse(int R[], int l, int r) {
    int t;
    while (l < r) { t = R[l]; R[l++] = R[r]; R[r--] = t; }
}
void LeftShift(int R[], int n, int p) {
    p = p % n;
    Reverse(R, 0, p-1);
    Reverse(R, p, n-1);
    Reverse(R, 0, n-1);
}

【考点】逆置法是 O(1) 空间重排的万能钥匙；p≥n 时取模。

题2 寻找主元素（2013真题模型）

【题】找出现次数超过 n/2 的元素（不存在返回−1），时间 O(n)、空间 O(1)。 【思路】摩尔投票：候选计数加减，最后再验一遍。

int Majority(int A[], int n) {
    int cand = A[0], cnt = 1, i, c = 0;
    for (i = 1; i < n; i++) {
        if (A[i] == cand) cnt++;
        else if (--cnt == 0) { cand = A[i]; cnt = 1; }
    }
    if (cnt > 0)
        for (i = 0; i < n; i++) if (A[i] == cand) c++;
    return c > n/2 ? cand : -1;
}

【考点】投票法两阶段（选候选+验证），漏验证是常见扣分点。

题3 两递增序列合并为递减（头插法模型）

【题】La、Lb 均为递增单链表（带头结点），归并到 Lc 且 Lc 递减，用原结点，不开新空间。 【思路】比较两表较小者，头插进 Lc ——小的先插到头，最后小的在最后 → 自然递减。

void MergeDec(LinkList La, LinkList Lb, LinkList Lc) {
    LNode *pa = La->next, *pb = Lb->next, *t;
    Lc->next = NULL;
    while (pa && pb) {
        if (pa->data <= pb->data) { t = pa; pa = pa->next; }
        else                      { t = pb; pb = pb->next; }
        t->next = Lc->next; Lc->next = t;   // 头插
    }
    while (pa) { t = pa; pa = pa->next; t->next = Lc->next; Lc->next = t; }
    while (pb) { t = pb; pb = pb->next; t->next = Lc->next; Lc->next = t; }
}

【考点】头插法自动逆序——"递增表→递减表"秒变头插题；时间 O(m+n)。

题4 单链表原地逆置（迭代+递归双版本）

/* 迭代：三指针 */
LNode* Reverse(LinkList L) {          // 无头结点版
    LNode *pre = NULL, *p = L, *nxt;
    while (p) { nxt = p->next; p->next = pre; pre = p; p = nxt; }
    return pre;
}
/* 递归版 */
LNode* RevRec(LNode *p) {
    if (p == NULL || p->next == NULL) return p;
    LNode *newHead = RevRec(p->next);
    p->next->next = p;                // 后继指向自己
    p->next = NULL;
    return newHead;
}

【考点】递归版"假设后面已逆好"；带伪代码扣分少、缺复杂度说明扣分多。

题5 快慢指针找中间结点

LNode* Middle(LinkList L) {           // 奇数返回正中，偶数返回前一个中间
    LNode *slow = L, *fast = L;
    while (fast->next && fast->next->next) {
        slow = slow->next;
        fast = fast->next->next;
    }
    return slow;
}

【考点】快慢指针三连用：中点、判环（相遇即有环）、回文判定（配栈）。

题6 合法出栈序列判定（栈模拟）

【题】给定入栈序列与某出栈序列，判定其是否可能。

int Valid(int push[], int pop[], int n) {
    int stack[MaxSize], top = -1, i = 0, j = 0, x;
    for (i = 0; i < n; i++) {
        stack[++top] = push[i];                 // 依次入栈
        while (top >= 0 && stack[top] == pop[j]) // 能弹则弹
            { top--; j++; }
    }
    return j == n;                              // 全部弹出即合法
}

【考点】模拟贪心：入栈后"能弹就弹"；时间 O(n)。

题7 循环队列（牺牲单元法）完整实现

#define MAXQSIZE 100
typedef struct { int data[MAXQSIZE]; int front, rear; } SqQueue;
int QueueEmpty(SqQueue Q){ return Q.front == Q.rear; }
int QueueFull (SqQueue Q){ return (Q.rear+1) % MAXQSIZE == Q.front; }
int EnQueue(SqQueue *Q, int x){
    if (QueueFull(*Q)) return 0;
    Q->data[Q->rear] = x;  Q->rear = (Q->rear+1) % MAXQSIZE;  return 1;
}
int DeQueue(SqQueue *Q, int *x){
    if (QueueEmpty(*Q)) return 0;
    *x = Q->data[Q->front];  Q->front = (Q->front+1) % MAXQSIZE;  return 1;
}

【考点】牺牲一单元判满：(rear+1)%M==front；元素数 (rear-front+M)%M。

题8 二叉树三件套（高/总结点/叶子）

int Height(BiTree T){
    if (!T) return 0;
    int l = Height(T->lchild), r = Height(T->rchild);
    return (l > r ? l : r) + 1;
}
int Count(BiTree T){ return T ? 1 + Count(T->lchild) + Count(T->rchild) : 0; }
int Leaves(BiTree T){
    if (!T) return 0;
    if (!T->lchild && !T->rchild) return 1;
    return Leaves(T->lchild) + Leaves(T->rchild);
}

【考点】递归三行模板："空返回、叶特殊、左右合并"。

题9 二叉排序树的非递归插入

int BSTInsert(BiTree *T, int k) {
    BiTree p = *T, *pre = NULL, *s;
    while (p && p->data != k) {        // 找插入位置
        pre = p;
        p = (k < p->data) ? p->lchild : p->rchild;
    }
    if (p) return 0;                   // 已存在
    s = (BiTNode*)malloc(sizeof(BiTNode));
    s->data = k; s->lchild = s->rchild = NULL;
    if (pre == NULL) *T = s;           // 空树
    else if (k < pre->data) pre->lchild = s;
    else pre->rchild = s;
    return 1;
}

【考点】记 pre 双指针；BST 插入必插在叶子位置。

题11 快速选择找第 k 小（快排 partition 应用）

int QuickSelect(int A[], int low, int high, int k) {   // k从1计
    int pivot = A[low], l = low, h = high;
    while (l < h) {
        while (l < h && A[h] >= pivot) h--;
        A[l] = A[h];
        while (l < h && A[l] <= pivot) l++;
        A[h] = A[l];
    }
    A[l] = pivot;
    int rank = l - low + 1;
    if (rank == k) return A[l];
    return (rank > k) ? QuickSelect(A, low, l-1, k)
                      : QuickSelect(A, l+1, high, k-rank);
}

【考点】partition 是快排核心——写快排=写它；平均 O(n)，只递归一侧。

题12 堆的插入（上浮调整）

void HeapInsert(int H[], int *n, int x) {   // 大根堆，H[1..n]
    int i = ++(*n);                          // 新元素放末尾
    while (i > 1 && H[i/2] < x) {            // 与双亲比较
        H[i] = H[i/2];                       // 双亲下移
        i = i/2;
    }
    H[i] = x;
}

【考点】上浮 O(log n)；对照建堆的"下沉"；删除=末尾换顶+下沉。

题13 判断二叉树是否二叉排序树（中序递增）

int pre = INT_MIN, ok = 1;                // pre记录中序前驱
void Check(BiTree T) {
    if (!T || !ok) return;
    Check(T->lchild);
    if (T->data <= pre) ok = 0;           // 中序必须严格递增
    else pre = T->data;
    Check(T->rchild);
}

【考点】"BST⇔中序严格递增"；全局前驱变量法优于逐结点判断（后者会重复比较）。

题14 邻接矩阵 BFS 最短路径（无权图）

void BFS_MIN_Dist(MGraph G, int v, int dist[]) {   // dist[i]: v到i最短边数
    int queue[MaxV], front = 0, rear = 0, i, visited[MaxV] = {0};
    for (i = 0; i < G.vexnum; i++) dist[i] = INT_MAX;
    dist[v] = 0; visited[v] = 1;
    queue[rear++] = v;
    while (front < rear) {
        int u = queue[front++];
        for (i = 0; i < G.vexnum; i++)
            if (G.edges[u][i] == 1 && !visited[i]) {
                visited[i] = 1;
                dist[i] = dist[u] + 1;     // BFS首达即最短
                queue[rear++] = i;
            }
    }
}

【考点】BFS 求无权图单源最短路径——为什么首达即最短（按层扩展），证明一句话要会写。

题15 散列表删除的正确姿势（惰性删除）

【题】开放定址法散列表中为什么不能直接物理删除元素？如何实现删除？ 【答】直接删除会截断探测链：位于同义词后方的元素将无法被查到（探测遇到空位即判定失败）。做法：

typedef enum { EMPTY, USED, DELETED } SlotState;
/* 删除：state[i] = DELETED（惰性删除，占据但不存有效值） */
/* 查找：遇 EMPTY 才停止；遇 DELETED 继续探测 */
/* 插入：可复用 DELETED 槽位（但查找时须继续确认后方无同义词） */

【考点】删除、查找、插入三者规则不同——是选择题与简答题双料考点。

大题代码规范（阅卷习惯）

  1. 先写算法思想（2-3行），再写代码，最后写时间/空间复杂度——三段缺一不可；
  2. 伪代码可接受，但变量含义要注释；链表题说明是否有头结点；
  3. 边界条件明写：空表、单结点、p≥n、满/空队；
  4. 允许调用基本操作（如 DestroyList），但核心逻辑必须自己写。
