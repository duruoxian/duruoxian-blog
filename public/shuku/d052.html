408 全真模拟卷（自编·第六套）

结构同真题：40×2' 选择 + 7道综合题共70分 = 150分，180分钟。答案解析在卷末（选择题答案随题给出）。

一、单项选择题（每题2分）

数据结构（1~11）

1. 在带头结点的双向链表中，在 p 所指结点之后插入 s 结点（s->next 已置为 p->next），下列哪条语句必须最后执行： A. s->prior=p　B. p->next->prior=s　C. p->next=s　D. s->next=p->next

C。p->next 一旦修改，原后继结点就"丢"了，故必须在借用完 p->next 的语句之后执行。

2. 入栈序列为 1,2,3,4,5，下列不可能的出栈序列是： A. 4,3,2,1,5　B. 3,5,4,2,1　C. 5,4,1,3,2　D. 2,3,4,5,1

C。弹出5、4后栈顶必为3，不可能先出1（模拟法逐一排除）。

3. 用单链表作队列的存储结构，为使出队、入队均为 O(1)，需要保存： A. 仅头指针　B. 仅尾指针　C. 头指针和尾指针　D. 头结点数据域存队长即可

C。出队在头、入队在尾，两端都要 O(1) 定位。

4. KMP 算法相比朴素模式匹配算法的主要改进是： A. 匹配更快需要更多空间　B. 主串指针不回溯　C. 模式串可以任意缩短　D. 无需预处理模式串

B。KMP 利用 next 数组只回退模式串指针，主串指针从不回溯；预处理 O(m)。

5. 一棵树有 2 个度为 3 的结点、1 个度为 2 的结点、2 个度为 1 的结点，则叶子结点数为： A. 4　B. 5　C. 6　D. 7

C。n₀ = 1 + Σ(i-1)·nᵢ = 1 + 1×1 + 2×2 = 6。

6. 已知二叉树先序序列 ABDEC、中序序列 DBEAC，其后序序列为： A. DEBCA　B. DBECA　C. EDBCA　D. DEABC

A。根A→左子树{D,B,E}（先序BDE/中序DBE：根B、左D右E）→右子树{C}→后序 DEBCA。

7. n 个顶点的强连通有向图至少有多少条边： A. n−1　B. n　C. n(n−1)/2　D. n²

B。n个顶点构成一个有向环即可强连通，恰 n 条边。

8. 关于 Dijkstra 算法，正确的是： A. 可处理带负权边的图　B. 按路径长度递增次序依次确定各顶点最短路径　C. 适用于求多源最短路径　D. 时间复杂度与存储结构无关

B。Dijkstra 贪心逐点确定，不能处理负权边；多源用 Floyd。

9. 序列基本有序（接近正序）时，效率最高的排序算法是： A. 快速排序　B. 直接插入排序　C. 简单选择排序　D. 堆排序

B。基本有序时直接插入/冒泡近似 O(n)；快排反而退化为 O(n²)。

10. 3 阶 B 树中，除根结点外，任一结点至少含有的关键字个数为： A. 0　B. 1　C. 2　D. 3

B。⌈m/2⌉−1 = ⌈3/2⌉−1 = 1（根至少1个关键字、至少2棵子树）。

11. 散列表表长7（地址0~6），散列函数 H(k)=k mod 7，线性探测。依次插入 15、22、29 后，29 的存放地址是： A. 1　B. 2　C. 3　D. 4

C。15→1；22 冲突→2；29 冲突（1、2被占）→3。

计算机组成原理（12~22）

12. 8位补码 1000 0000 表示的十进制数是： A. 0　B. −127　C. −128　D. 128

C。补码多表示一个最小负数 −2⁷。

13. 定点小数 [x]补 = 1.0110，则 x = ? A. −0.0110　B. −0.1010　C. −0.0101　D. 0.1010

B。负数：取反加一还原数值位 0.0110→0.1010，符号为负。

14. IEEE 754 单精度数 1.5×2³，其阶码字段（含偏置127）的值为： A. 3　B. 127　C. 130　D. 131

C。阶码真值3 + 127 = 130（二进制 1000 0010）。

15. 信息位 n=8 的海明码，至少需要的校验位数 k 为： A. 3　B. 4　C. 5　D. 8

B。2^k ≥ n+k+1：16 ≥ 8+4+1=13 ✓。

16. Cache 有 16 行、块大小 8B，主存容量 4096B，直接映射下主存地址的标记字段位数为： A. 4　B. 5　C. 7　D. 9

B。主存块数=512=2⁹，行号4位，块内3位 → 标记=9−4=5位。

17. 虚拟地址 16 位、页大小 4KB，则虚页总数为： A. 4　B. 12　C. 16（即2⁴）　D. 4096

C。页内偏移12位，页号4位 → 2⁴=16个虚页。

18. 转移指令位于地址 2000H，指令长 2B，相对寻址偏移量为 −4H，则转移目标地址为： A. 1FFCH　B. 1FFEH　C. 2002H　D. 2004H

B。指令取出后 PC=2002H，目标 = PC + 偏移 = 2002H + (−4H) = 1FFEH。

19. 下列不属于 RISC 特征的是： A. 指令定长、格式少　B. 只有 Load/Store 指令访存　C. 寻址方式丰富、指令系统庞大　D. 设置大量通用寄存器

C。这是 CISC 特征。

20. 5 段指令流水线，每段耗时 1ns，连续执行 12 条指令的总时间为： A. 12ns　B. 15ns　C. 16ns　D. 17ns

C。(k+n−1)Δt = (5+12−1)×1 = 16ns。

21. CPU 响应（可屏蔽）中断请求的时间通常是： A. 任一机器周期结束　B. 一条指令执行周期结束　C. 取指周期结束　D. 随时

B。中断采样在每条指令执行末进行，保证指令原子性。

22. 同步总线，数据线 32 位，工作频率 100MHz，每个时钟周期传送一次数据，总线带宽为： A. 100MB/s　B. 400MB/s　C. 800MB/s　D. 3200MB/s

B。4B × 100M = 400MB/s。

操作系统（23~32）

23. 进程从"运行态"转为"阻塞态"的原因是： A. 时间片用完　B. 被高优先级进程抢占　C. 等待某事件（如I/O完成）而主动让出CPU　D. 所等待的事件已发生

C。时间片到/抢占是运行→就绪；事件发生是阻塞→就绪。

24. 同一进程内的多个线程不共享的资源是： A. 地址空间　B. 全局变量　C. 栈与寄存器组　D. 打开的文件

C。栈和寄存器（含PC）是线程私有。

25. 时间片轮转调度中，若时间片设置过大，算法将退化为： A. 短作业优先　B. 优先级调度　C. 先来先服务　D. 多级反馈队列

C。时间片≥所有进程运行时间时，等效FCFS。

26. 信号量 S 初值为3，进程执行了 5 次 P(S) 和 2 次 V(S)，则 S 的值为： A. 2　B. 1　C. 0　D. −2

C。3−5+2=0；此时等待进程数为 0（S<0 才有等待者）。

27. 3 个进程，每个进程最多需要 2 台打印机，系统不发生死锁至少需要打印机台数为： A. 3　B. 4　C. 5　D. 6

B。n(k−1)+1 = 3×1+1 = 4（最坏每进程持有1台时仍剩1台可分配）。

28. 银行家算法在死锁处理策略中属于： A. 死锁预防　B. 死锁避免　C. 死锁检测与解除　D. 鸵鸟策略

B。分配前判断是否处于安全状态，是典型的"避免"。

29. 页大小 1KB，逻辑地址 2500（十进制），页号2对应物理块号7，则物理地址为： A. 7156　B. 7620　C. 2500　D. 904

B。2500=2×1024+452 → 物理地址 = 7×1024+452 = 7620。

30. 访问序列 1,2,3,4,1,2,5,1,2,3,4,5，分配3个物理块，FIFO 置换的缺页次数为： A. 7　B. 8　C. 9　D. 10

C。逐页模拟：缺页9次；该序列下FIFO还有Belady现象（4块时缺10次）。

31. UNIX 混合索引：块大小 4KB、地址项 4B，则一次间接地址可表示的文件大小上限为： A. 4KB　B. 4MB　C. 4GB　D. 1KB

B。一次间接块含 1024 个地址 → 1024×4KB = 4MB。

32. 磁盘转速 6000 转/分钟，其平均旋转延迟约为： A. 2.5ms　B. 5ms　C. 10ms　D. 20ms

B。转一圈 10ms，平均半圈 5ms。

计算机网络（33~40）

33. OSI 参考模型中，负责数据加密/压缩与语法表示转换的是： A. 应用层　B. 会话层　C. 表示层　D. 传输层

C。表示层：语法表示、加密压缩。

34. 在 100Mbps 链路上发送一个 1000B 的分组，发送时延为： A. 8μs　B. 80μs　C. 100μs　D. 10ms

B。8000bit / 10⁸bps = 80μs。

35. 序号字段 3 位，GBN 协议发送窗口的最大尺寸为： A. 3　B. 4　C. 7　D. 8

C。W ≤ 2ⁿ−1 = 7。

36. 以太网规定最小帧长 64B，其目的是： A. 提高传输效率　B. 保证发送站在发送完成前能检测到冲突（争用期）　C. 与MAC地址对齐　D. 便于差错校验

B。64B=512bit ≥ 2τ×带宽。

37. 子网掩码为 255.255.255.192，每个子网的可用主机数为： A. 64　B. 62　C. 30　D. 126

B。/26 → 主机位6位 → 2⁶−2=62。

38. RIP 协议中，"不可达"的跳数表示为： A. 15　B. 16　C. 255　D. ∞（无定义值）

B。最大合法跳数15，16=不可达（限制计数到无穷）。

39. TCP 三次握手中，第三次握手报文的标志与序号为： A. SYN=1, seq=x　B. SYN=1, ACK=1, seq=y, ack=x+1　C. ACK=1, seq=x+1, ack=y+1　D. FIN=1, seq=x

C。第三次握手只置 ACK=1，消耗序号：seq=x+1，确认号 ack=y+1。

40. 用户代理（如Outlook）向邮件服务器发送邮件使用的协议是： A. POP3　B. IMAP　C. SMTP　D. SNMP

C。"推"用SMTP；收信才用POP3/IMAP。

二、综合应用题（共70分）

41.（13分）已知带头结点的单链表 L，结点值为整数（|值|≤n，n为给定正整数），设计一个时间复杂度尽可能高效的算法，删除链表中绝对值相等的冗余结点（每个绝对值只保留首次出现的结点），并说明算法的时间与空间复杂度。

答案：空间换时间。设辅助标记数组 flag[0..n] 初始化为0。 c void RemoveDup(LinkList L, int n) { int *flag = (int*)calloc(n+1, sizeof(int)); LNode *p = L->next, *pre = L; while (p != NULL) { int v = abs(p->data); if (flag[v] == 0) { flag[v] = 1; pre = p; p = p->next; } else { pre->next = p->next; free(p); p = pre->next; } } free(flag); } 时间 O(m)（m为表长），空间 O(n)。若不用辅助数组，双循环 O(m²) 时间 O(1) 空间，效率低——本题按"尽可能高效"给 O(n) 版本满分。

42.（10分）将关键字 50,30,70,20,40,80 依次插入初始为空的 AVL 树，再插入 10。画出插入 10 后失衡的最小子树的旋转过程，给出最终树形，并指出旋转类型。

答案：插入前6个关键字后树为：根50，左30（左20右40），右70（右80）。 插入10：沿 50→30→20→10 路径，结点30的平衡因子变为2（左子树高2、右子树高0），是最小失衡子树的根。 插入位置在 30 的左孩子的左子树 → LL型，对30进行右旋：20 升为该子树根，左孩子10、右孩子30。 最终树形：根50；左子树20（左10、右30）；右子树70（右80）。全树平衡，高度3。

43.（13分）某页式虚拟存储系统：虚拟地址24位，物理内存64MB，页大小4KB。求： (1) 虚页号与页内偏移各多少位； (2) 物理地址位数与页表项中页框号至少多少位； (3) 若单级页表每项占4B，页表最大占多少存储空间； (4) 虚地址 5000（十进制），已知虚页1存放在物理块3，求物理地址。

答案： (1) 页内偏移 = 12位（4KB=2¹²）；虚页号 = 24−12 = 12位。 (2) 物理地址 = 26位（64MB=2²⁶）；页框号 = 26−12 = 14位（页表项还需存取控制等标志位，题问"至少"为14位）。 (3) 页表项数 = 2¹²，页表大小 = 2¹²×4B = 16KB。 (4) 5000 = 1×4096 + 904 → 页号1、页内偏移904；物理地址 = 3×4096+904 = 13192。

44.（10分）某计算机 Cache 共 4 行，块大小 16B，采用直接映射。CPU 依次访问主存地址（十进制）：0, 4, 8, 16, 132, 8, 4。求每次访问后 Cache 的命中情况（命中/缺失），并给出总命中次数与命中率。

答案：块大小16B → 块号=⌊地址/16⌋；行号=块号 mod 4。 - 0：块0→行0，缺失（装入块0） - 4：块0→行0，命中 - 8：块0→行0，命中 - 16：块1→行1，缺失 - 132：块8→行0（8 mod 4=0），缺失（换出块0） - 8：块0→行0，缺失（重新装入） - 4：块0→行0，缺失 总命中 2次，命中率 2/7 ≈ 28.6%。（本题体现直接映射的"颠簸"现象：行0被块0、块8反复抢占。）

45.（8分）桌上有一个盘子，每次只能放一个水果。父亲专放苹果，母亲专放橘子；女儿只吃苹果，儿子只吃橘子。盘满时不能放，盘空时不能取。试用信号量机制实现父亲、母亲、女儿、儿子四个进程的同步，给出伪代码并说明每个信号量的意义与初值。

答案： semaphore plate = 1; // 盘子空位（互斥+容量） semaphore apple = 0; // 盘中苹果数 semaphore orange = 0; // 盘中橘子数 父亲: while(true){ 准备苹果; P(plate); 放苹果; V(apple); } 母亲: while(true){ 准备橘子; P(plate); 放橘子; V(orange); } 女儿: while(true){ P(apple); 取苹果; V(plate); 吃苹果; } 儿子: while(true){ P(orange); 取橘子; V(plate); 吃橘子; } plate 初值1保证盘中最多一个水果；apple/orange 初值0表示 initially 无水果。因为 plate 已保证互斥放取，无需额外 mutex。

46.（7分）某系统访问页面序列为 4,3,2,1,4,3,5,4,3,2,1,5，分配3个物理块。计算 LRU 置换算法的缺页次数，并写出每次淘汰的页面。

答案：逐页模拟（栈式）： 4F、3F、2F、1F(淘汰4)、4F(淘汰3)、3F(淘汰2)、5F(淘汰1)、4H、3H、2F(淘汰5)、1F(淘汰4)、5F(淘汰3)。 缺页 10次，命中2次。淘汰序列：4,3,2,1,5,4,3。（LRU 是堆栈类算法，无Belady异常。）

47.（9分）某单位分得网络 192.168.60.0/24，需划分为4个大小相等的子网。写出：(1) 每个子网的子网掩码；(2) 各子网的网络地址与可用主机地址范围；(3) 每个子网的可用主机数。

答案：4个子网 → 借2位 → /26，掩码 255.255.255.192。 | 子网 | 网络地址 | 可用主机范围 | 广播地址 | |---|---|---|---| | 1 | 192.168.60.0/26 | .1 ~ .62 | .63 | | 2 | 192.168.60.64/26 | .65 ~ .126 | .127 | | 3 | 192.168.60.128/26 | .129 ~ .190 | .191 | | 4 | 192.168.60.192/26 | .193 ~ .254 | .255 | 每子网可用主机 2⁶−2 = 62 台。
