综合题解析

综合1：三次逆置法（2010真题）：先逆置前 p 个，再逆置后 n−p 个，最后整体逆置。

void Reverse(int a[], int l, int r){
    int t;
    while(l<r){ t=a[l]; a[l]=a[r]; a[r]=t; l++; r--; }
}
void LeftShift(int a[], int n, int p){
    Reverse(a,0,p-1); Reverse(a,p,n-1); Reverse(a,0,n-1);
}   /* 三次调用共 O(n)，空间 O(1) */

示例：abcdefg 左移2：ba cdefg → ba gfedc → cdefgab ✓。

综合2：思想——比较 A、B 的中位数：相等即为所求；a中位<b中位 ⇒ 丢弃 A 的前半与 B 的后半（保持等长）；反之对称。每次规模减半 ⇒ O(logn)。 执行：n=5：A中位5 < B中位6 → 保留 A{5,7,9} 与 B{2,4,6}； n=3：A中位7 > B中位4 → 保留 A{5,7} 与 B{4,6}； n=2：A中位5 > B中位4 → 保留 A{5} 与 B{6}； n=1：中位数 = min(5,6) = 5（合并序列 1..10 的下中位）。

综合3： (1) [x]补=11.01000（−0.75：11.01000），[y]补=11.10000（−0.5）； 和 = 11.01000+11.10000 = 110.11000 → 丢弃模4进位 = 10.11000，双符号位10 ⇒ 负溢出（真值和=−1.25<−1，合理）。 (2) [x]补=11.01011，[y]补=00.11001； 和 = 11.01011+00.11001 = 100.00100 → 模4丢弃进位 = 00.00100，双符号位00 ⇒ 无溢出，真值 +0.00100₂ = +0.125 ✓。
