第一部分 代数结构

一、二元运算与代数系统

D1 二元运算：A×A→A 的函数（封闭性是定义的一部分）。 D2 运算五性质（运算表怎么看）： | 性质 | 运算表特征 | |---|---| | 封闭 | 表里全是A的元素 | | 交换 | 表关于主对角线对称 | | 结合 | 表上看不出，需验证 (ab)c=a(bc) | | 单位元 e | e行=e列=原排列（横竖都照抄） | | 零元 θ | θ行θ列全是θ | | 逆元 | a*b=e 的位置：a行b列与b行a列是e | 【要点】单位元若存在必唯一；零元无逆元（除非单元素系统）；逆元在群中唯一。

考题1（运算表判群） A={a,b,c}，运算表：a为单位元（a行=a列=abc）；bb=c，bc=a，cb=a，cc=b。问 ⟨A,·⟩ 是否群？ 【解】封闭✓（表内全是abc）；交换✓（表对称）；单位元a✓；逆元：a⁻¹=a，b⁻¹=c（b·c=a），c⁻¹=b✓。 结合性：本表实为"三元群"（同构于Z₃加群：b↔1,c↔2），结合✓。是群（且是交换群/阿贝尔群）。∎ （考试技巧：3元素群只有一种（Z₃），4元素群有两种（Z₄与Klein四元群）——记结构比硬验结合律快。）

二、群论核心

D3 层级链（记牢顺序）： 半群（结合）→ 独异点/含幺半群（+单位元）→ 群（+每个元素可逆）→ 阿贝尔群（+交换）。 【例】⟨Z,+⟩ 阿贝尔群；⟨Z,×⟩ 只到独异点（2无逆元）；⟨Zₙ,+ₙ⟩ 群；⟨Zₙ,×ₙ⟩ 一般只到独异点（0不可逆）。 T1 群的基本性质：①消去律成立；②逆元唯一且 (ab)⁻¹=b⁻¹a⁻¹；③群中无零元（除非平凡群）。 D4 子群判定：H非空且 ∀a,b∈H 有 ab⁻¹∈H ⇒ H≤G。 T2 拉格朗日定理：有限群G，子群H的阶整除|G|（|H| | |G|）。 【推论】元素阶整除群阶；素数阶群必是循环群（同构于Zₚ）。 D5 循环群与置换群（概念级）：⟨g⟩={gᵏ}；n阶循环群≅Zₙ；置换群Sₙ（|Sₙ|=n!）——定理证明的思想源头（历史谈资：伽罗瓦）。

考题2（拉格朗日应用） 6阶群可能的子群阶数？元素可能的阶？ 【解】子群阶 ∈ {1,2,3,6}（6的因子）；元素阶 ∈ {1,2,3,6}，且素数阶群无非平凡子群。∎

三、环与域

D6 环 ⟨R,+,×⟩：⟨R,+⟩阿贝尔群 + ⟨R,×⟩半群 + ×对+分配。 - 交换环（×交换）、含幺环、无零因子环（ab=0→a=0或b=0）→ 三者兼备=整环； - 域：交换、含幺、每个非零元可逆 → 域必是整环。 【判定题钉子】 | 结构 | 例子 | |---|---| | 环但非整环 | Z₄（2×2=0 零因子）、Z₆（2×3=0） | | 整环但非域 | Z（2无乘法逆元） | | 域 | Q、R、C、Zₚ（p素数） | T3 Zₙ是域 ⇔ n是素数：n=ab合数 → a·b≡0 (mod n) 出零因子；素数p时费马小定理保证每个非零元有逆。∎ 【连接】这一定理是密码学RSA的理论地基（模运算下的逆元与欧拉定理）——AI安全的谈资。

四、格与布尔代数（本部分高潮）

D7 格：偏序集任意两元素都有上确界与下确界（代数等价：∧=glb、∨=lub 满足交换/结合/吸收律）。 【判定】哈斯图里任两点都有"共同上面的最小点"与"共同下面的最大点"；钻石图是格、五边形图不是分配格。 D8 分配格、有界格、有补格：分配律 a∧(b∨c)=(a∧b)∨(a∧c)；全下界0全上界1；每元有补元。 D9 布尔代数 = 有补分配格：每个元素的补元唯一；满足德摩根。 【核心统一（本系列三次呼应的闭环）】： - 命题逻辑代数 ⟨{0,1},∧,∨,¬⟩（第1册的等值式）； - 集合代数 ⟨P(A),∪,∩,^c⟩（第2册的恒等式）； - 开关代数（0/1电路，计组的与或非门） ——三个都是布尔代数的具体模型，同一套定律（德摩根、分配、吸收在第1、2册各背一遍，在此合流）。这就是"布尔代数"在课程体系中的地位：数字电路与数理逻辑的公共数学基础（计组精讲第1册的与或非门在此找到户口）。 【斯通定理（谈资）】有限布尔代数都同构于某个 ⟨P(A)⟩，其元素个数必为 2的幂。

第二部分 组合计数

一、鸽巢原理

T4 简单版：n+1个物体放入n个盒子 → 必有盒子≥2个。 T5 加强版：n个物体放入k个盒子 → 必有盒子 ≥ ⌈n/k⌉。 考题3（经典应用） 任取13个人，证明至少有两人同月生日；任取多少学生才能保证至少3人选同一门课（5门课）？ 【解】①13>12=12个月 → 鸽巢。②需 ⌈n/5⌉≥3 → n≥11（10人时可能每门恰2人）。∎ 【408连接】哈希冲突的必然性（装填因子>1必碰撞）、生日悖论（23人两两同生日概率>50%——哈希攻击原理，AI安全谈资）。

二、排列组合加强版

T6 四类计数模型（对照表）： | 模型 | 公式 | 例 | |---|---|---| | 无重排列 | P(n,k)=n!/(n−k)! | 排名次 | | 无重组合 | C(n,k) | 选人 | | 重集组合（可重复选） | C(n+k−1, k) | 3种饮料买5杯=C(7,5)=21 | | 重集全排列（各元素重复nᵢ次） | k!/(n₁!n₂!…) | MISSISSIPPI字母排列 | 【环排列】n元环排列数=(n−1)!/2（n≥3，翻转同构）。 T7 错排公式：Dₙ=n!·Σ(−1)ᵏ/k!≈n!/e。信封装错问题。 考题4（错排演算） 4封信全装错信封的方式数？ 【解】D₄=4!(1−1+1/2−1/6+1/24)=24×(12/24−4/24+1/24)=24×9/24=9。 （记忆链：D₁=0，D₂=1，D₃=2，D₄=9，D₅=44。）∎ T8 Catalan数（第三次会师）：Cₙ=C(2n,n)/(n+1)—— ① n个元素出栈序列数（DS线性结构册递推推导）； ② n对括号合法匹配数； ③ 凸n+2边形三角剖分数。 【一句总结】"凡是'左括号随时≥右括号'类约束的计数，都是Catalan"——这是组合结构里最深刻的普适性之一（谈资级）。

三、生成函数与递推（算法分析的桥）

D10 母函数：a₀,a₁,… 的母函数 G(x)=Σaₙxⁿ。 【常用三件（必背）】： - 1/(1−x)=Σxⁿ（序列全1）； - 1/(1−x)²=Σ(n+1)xⁿ（自然数序列）； - 1/(1−kx)=Σkⁿxⁿ（等比）。 T9 母函数解递推（Fibonacci全程）：Fₙ=Fₙ₋₁+Fₙ₋₂，F₀=0,F₁=1： G(x)−x=xG(x)+x²G(x) → G(x)=x/(1−x−x²)。 部分分式后展开：Fₙ=(φⁿ−ψⁿ)/√5（φ=(1+√5)/2黄金比）。∎ 【要点】母函数把"递推"变成"代数解方程"——组合恒等式的机器。 T10 常系数线性齐次递推：aₙ=c₁aₙ₋₁+c₂aₙ₋₂ → 特征方程 r²=c₁r+c₂，根 r₁,r₂（互异）→ aₙ=Ar₁ⁿ+Br₂ⁿ（初值定A、B）——与DS的 T(n)=2T(n−1)+1=2ⁿ−1（汉诺塔）同法。 【DS大连接】复杂度递推两类解法在此归位：常系数线性→特征根法（本节）；分治型T(n)=aT(n/b)+f(n)→主定理思想（DS精讲第1册展开法）。
