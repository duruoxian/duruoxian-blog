第2章 物理层

  • 奈奎斯特（无噪声）：极限速率 = 2W·log₂V (b/s)，V=码元离散电平数。
  • 香农（有噪声）：C = W·log₂(1+S/N)；信噪比dB = 10·lg(S/N)。
  • 两公式对比：奈氏限制码元速率（波特率上限），香农限制比特速率；受两者同时约束取小者。
  • 编码：不归零NRZ、归零RZ、曼彻斯特（每比特中间跳变，数据率=波特率/2）、差分曼彻斯特（看起始有无跳变）。
  • 复用：FDM/TDM/统计TDM/WDM/CDMA（码片正交计算：规格化内积=0为不同站）。
  • 宽带接入：ADSL（电话线，频分，上行<下行）、HFC、FTTx。

第3章 数据链路层（计算重镇）

三大功能

  • 封装成帧；透明传输：字节填充（帧定界符前插ESC）/比特填充（5个1后插0，HDLC）；差错检测：奇偶、CRC（模2除法，考计算）、海明（纠1位）。

可靠传输三协议（滑动窗口，计算高频）

协议 发送窗口 特点
停止-等待 1 信道利用率 = T_D/(T_D+RTT+T_A)
回退N帧GBN W≤2ⁿ−1（n位编号） 接收窗口1，出错重传之后全部
选择重传SR W≤2^(n−1)（收发各半） 接收窗口=发送窗口，逐帧确认

介质访问控制

  • 随机接入：ALOHA（纯/时隙）、CSMA/CD（以太网）：
  • 最小帧长 = 2τ × 数据率（τ=单程端到端传播时延；争用期=2τ）。例：10Mb/s、争用期51.2μs → 最小帧64B。
  • 二进制指数退避：第i次冲突从 {0..2^min(i,10)−1} 随机选k，等 k×争用期；16次失败放弃。
  • CSMA/CA（802.11无线，因无线无法"边发边听"）。
  • 轮询/令牌（令牌环，确定性，重负载优）。
  • 信道划分：FDM/TDM/CDMA（复习第2章）。

局域网与设备

  • 以太网V2 MAC帧：目的6+源6+类型2+数据(46-1500)+FCS4；数据字段46~1500B（不足46填充）。
  • VLAN（802.1Q）：在源地址后插4字节标签，隔离广播域。
  • PPP：面向字节、无纠错只检错、支持多协议（帧格式：7E定界）。
  • 交换机自学习：查表转发；表无此项→泛洪；同端口→丢弃。冲突域与广播域：集线器1个冲突域；交换机隔离冲突域不隔离广播域；路由器两者都隔离。

无线局域网 802.11（WLAN）【选择概念】

  • MAC 方式：CSMA/CA——无线无法"边发边听"（自身信号远强于远端），故不能用 CD；靠ACK确认在链路层保可靠。
  • RTS/CTS 预约机制：解决隐藏站问题（A、C 都听不到 B 发送）。
  • 帧间间隔：SIFS（最短，高优先如ACK）< DIFS（数据帧）。
  • 结构：BSS（含 AP 的基础结构网络）+ SSID；AP 之间漫游；帧内三/四个地址字段（经 AP 转发时区分源/目的/AP）。
  • 与以太网对比：802.11 帧也有 MAC 地址与 FCS，但引入第4地址与序号控制（重传去重）。

第4章 网络层（计算重镇：子网划分）

IPv4

  • 数据报首部20B固定：版本、首部长(×4B)、总长度、TTL(过路由器−1，=0丢弃)、协议(6=TCP,17=UDP)、首部校验和。
  • 分类地址：A(1-126)/B(128-191)/C(192-223)；私有地址：10/8、172.16/12、192.168/16。
  • 子网划分五步法（模板）： ①主机位 k=log₂(需主机数+2)（+2是网络地址与广播地址）；②掩码=32−k位全1；③块大小=2^k；④各子网网络地址=块整数倍；⑤可用主机=2^k−2。
  • 例：192.168.1.0/24 划4个子网 → k=6 → 掩码/26（255.255.255.192），块64：0、64、128、192，各62台。
  • CIDR聚合：取地址二进制公共前缀。例：194.24.0.0 与 194.24.1.0 → /23聚合194.24.0.0/23。
  • 最长前缀匹配：路由表多条匹配取前缀最长者。

其他协议

  • ARP：IP→MAC，同网段直接ARP，跨网段对默认网关ARP；ARP请求广播、响应单播。
  • ICMP：差错报告（终点不可达/超时/参数问题）+ 询问（回送请求/回答→ping）；ICMP不是传输层协议。
  • DHCP：UDP、C/S、Discover(广播)→Offer→Request(广播)→ACK 四步，自动配置IP。
  • NAT：私网地址转换，改IP+端口（NAPT）。
  • 路由协议：RIP（距离向量，跳数≤15，坏消息传得慢）、OSPF（链路状态，Dijkstra，区域，直接封装IP）、BGP（AS间，路径向量，策略优先）。
  • IPv6：128位、首部固定40B、无校验和、只在源节点分片、即插即用；从IPv4过渡：双协议栈+隧道。

路由器的结构与转发流程（综合题模板）

路由器 = 路由选择部分（路由选择处理机，运行RIP/OSPF/BGP，维护路由表）+ 分组转发部分（交换结构 + 一组输入端口 + 一组输出端口）。 转发流程：①输入端口收帧、剥离链路层封装 → ②按目的IP查路由表（最长前缀匹配） → ③交换结构送往输出端口（端口忙则排队，溢出丢包） → ④TTL减1、重算首部校验和 → ⑤输出端口重新封装链路层帧（每跳重写二层头）。 考点：路由器隔离广播域；直接交付（同网段）vs 间接交付（跨网段经网关）；默认路由 0.0.0.0/0 兜底。

IPv6 / 移动IP / SDN（了解级清单）

  • IPv6：地址128位、首部固定40B、取消首部校验和、只在源结点分片、支持地址自动配置；过渡：双协议栈 + 隧道。
  • 移动IP：移动结点 = 永久地址（归属地址）+ 转交地址；归属代理截获发往永久地址的分组并经隧道转发至外地代理。
  • SDN：数据平面与控制平面分离，控制器集中计算并下发流表（OpenFlow协议），设备只负责按流表转发。

第5章 传输层（综合题大户：TCP）

  • UDP：无连接、8B首部、不保证可靠、支持一对多；适合实时（DNS/ DHCP/ RTP）。
  • TCP：面向连接、全双工、点对点、可靠有序、流量/拥塞控制。
  • 三次握手：SYN(seq=x) → SYN+ACK(seq=y, ack=x+1) → ACK(ack=y+1)；为什么三次：防已失效的连接请求到达造成资源浪费 + 双方确认收发能力。
  • 四次挥手：FIN→ACK→FIN→ACK；主动方TIME_WAIT等2MSL：保证最后一个ACK到达+旧报文消逝。
  • 可靠机制：序号+确认（累积确认）、超时重传（RTTs加权，RTO）、快重传（3个冗余ACK立即重传）。
  • 流量控制：接收窗口rwnd通告；持续计时器防死锁（零窗口探测）。
  • 拥塞控制四件套（必考画图/计算）：
  • 慢启动：cwnd从1MSS起每RTT翻倍（指数）→ 到阈值ssthresh转拥塞避免；
  • 拥塞避免：每RTT +1MSS（线性）；
  • 超时：ssthresh=当前cwnd/2，cwnd=1 重新慢启动；
  • 快重传+快恢复：3冗余ACK → ssthresh=cwnd/2，cwnd=新阈值（快恢复）继续线性增。
  • 发送窗口 = min(rwnd, cwnd)。

第6章 应用层

  • C/S（服务器常开）vs P2P（对等，扩展性强）。
  • DNS：层次域名树；递归查询（主机→本地）+ 迭代查询（本地→根/顶级/权限）；UDP 53（区域传送用TCP）；资源记录：A、NS、CNAME、MX、PTR。
  • FTP：控制21 / 数据20 两个TCP连接，控制全程保持。
  • 邮件：SMTP推（25）+ POP3拉（110）/IMAP；邮件网关间用SMTP。
  • HTTP：TCP 80；HTTP1.0非持续（每对象2×RTT）；1.1持续连接（流水线方式1×RTT+所有对象传输）；无状态（Cookie补状态）；HTTPS=HTTP+TLS(443)。
  • DHCP、WWW、CDN概念级。

计算机网络 · 难点专攻

1. 子网划分/聚合计算五步法（408年年考，背模板）

①按主机需求定 k=log₂(N+2)；②掩码/前缀=32−k；③块大小=2^k；④子网网络地址按块对齐；⑤聚合：转二进制找公共前缀。口算器：/26=每块64台，/27=32，/28=16，/25=128。

2. 最小帧长/争用期（CSMA-CD）

最小帧长 = 2τ×R。反向题：给帧长和速率求最大网段距离 → τ=帧长/(2R)，距离=τ×v。以太网帧不足64B须填充。

3. 滑动窗口+信道利用率组合题

停止等待利用率 = T_D/(T_D+RTT+T_A)；连续ARQ利用率 = min(1, W×T_D/(T_D+RTT))。窗口编号位数反推：GBN W≤2ⁿ−1，SR W≤2ⁿ⁻¹。

4. TCP拥塞窗口演化（画表题）

逐RTT列 cwnd：慢启动 1→2→4→8（到ssthresh止）→线性 9→10…；遇超时：ssthresh=cwnd/2、cwnd=1；遇3冗余ACK：ssthresh=cwnd/2、cwnd=ssthresh（快恢复）。横轴用RTT不用拍。

5. 各层协议归属速记（判断题秒杀）

属于网络层：IP、ICMP、ARP、IGMP、路由协议（RIP/OSPF/BGP是"协议"其报文载体不同：RIP走UDP 520，OSPF直接走IP，BGP走TCP 179）；应用层全走TCP：HTTP/FTP/SMTP/BGP；走UDP：DNS/DHCP/RIP/TFTP/SNMP。

6. 报文发送综合题模板

"主机A发一个2KB文件给B，经路由器R，链路速率与传播时延给定"：总时间=各段发送时延+各段传播时延（分组化后按"流水线"算：首组全程+其余组每段发送时延）。分组交换：总时间=首组传播全程 + 所有组的发送时延之和（分段叠加）。
