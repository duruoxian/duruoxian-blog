第1章 绪论

一、定义精讲

D1 数据结构三要素： ① 逻辑结构：数据元素之间的逻辑关系（与存储无关）——线性结构（线性表/栈/队列/串）与非线性结构（树/图/集合）； ② 存储结构（物理结构）：顺序存储、链式存储、索引存储、散列存储； ③ 数据的运算：运算的定义针对逻辑结构、实现针对存储结构。 【985面试金句】"逻辑结构独立于存储结构；同一个逻辑结构可以有多种存储实现；运算的定义在逻辑结构上，实现在存储结构上。"

D2 算法五特性：有穷性、确定性、可行性、输入（≥0个）、输出（≥1个）。 【辨析】程序可以不满足有穷性（操作系统），算法必须满足——"算法是程序的灵魂"。

D3 时间复杂度的严格定义（大O）：T(n)=O(f(n)) ⇔ 存在正常数 c 与 n₀，使 n≥n₀ 时恒有 T(n)≤c·f(n)。 【配套记号】Ω（下界，≥c·f(n)）、Θ（上下界夹住）。"O"只给上界——说 O(n²) 的算法也可能实际是 O(n)，严谨表述要说 Θ(n²)。 【要点】① 常数c与n₀的存在性是定义核心——"忽略常数与低阶项"的合法依据；② 最坏时间复杂度是考研默认口径（给出上界保证），有时问平均复杂度（对输入分布求期望）。

D4 常见复杂度阶（从快到慢）： O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!) 【直觉】log n = "折半才见底"；n log n = "每层折半、共n个元素"（归并/快排/堆）；2ⁿ = "每步两种选择全枚举"。

二、分析范式精讲

A1 单层循环→O(n)，嵌套→乘积，折半→log。典型模式：

i = 1;
while (i <= n) i = i * 3;      /* 执行次数k满足 3^k ≥ n → O(log₃n) */

A2 递归式展开法： T(n)=T(n/2)+1 → 每层1次操作、共log₂n层 → O(log n)（二分查找）。 T(n)=2T(n/2)+n → 每层合计n、共log₂n层 → O(n log n)（归并/快排平均）。 T(n)=T(n−1)+1 → O(n)；T(n)=2T(n−1)+1 → 2ⁿ−1 → O(2ⁿ)（汉诺塔）。 A3 双指针不嵌套：i、j 各自从两端向中间走，合计至多 n 步 → O(n) 而非 O(n²)。

三、本章考题（4题）

题1（用定义证明） 证明 2n²+3n+1 = O(n²)。 【证】n≥1 时，2n²+3n+1 ≤ 2n²+3n²+n² = 6n²。取 c=6，n₀=1 即满足定义。∎ （同时可证 =Θ(n²)：下界 2n²≤2n²+3n+1 对 n≥1 成立，取 c=2。）

题2（嵌套含依赖·易错） 求：

int sum = 0;
for (i = 1; i <= n; i++)
    for (j = 1; j <= i; j++)
        sum++;

【解】内层次数=1+2+…+n=n(n+1)/2 → O(n²)。变体：j<=ii? → Σi²=O(n³)；j = 2 → 内层O(log i)，总Σlog i=O(n log n)? Σ_{i≤n}log i = log(n!)≈n log n ✓。∎

题3（递归式） 设 T(n)=2T(n/2)+n，T(1)=1，求 T(n)。 【解】展开：T(n)=n+2[n/2+2T(n/4)]=2n+4T(n/4)=…=kn+2^k T(n/2^k)。取 k=log₂n：T(n)=n·log₂n+n → O(n log₂n)。∎

题4（概念辨析） 判断：①数据的存储结构是逻辑结构在计算机中的映像；②同一逻辑结构只能有一种存储结构；③算法的时间复杂度与所用的存储结构无关。 【答】①对；②错（线性表可顺序可链式）；③错（例：顺序表按位查找O(1) vs 链表O(n)——存储结构直接影响运算的实现效率）。∎

第2章 线性表

一、定义精讲

D1 线性表：n（n≥0）个数据类型相同的元素的有限序列（a₁,a₂,…,aₙ）；元素个数 n 为表长；位序从1开始（数组下标从0开始——位序i对应下标i−1）。 【要点】"相同类型"+"有序（逻辑序）"+"有限"——三者缺一不可；栈、队列、串都是受限的线性表。

D2 顺序表：逻辑相邻⇒物理相邻。地址公式（0基）：LOC(aᵢ)=LOC(a₀)+i×L。 D3 链表族谱：单链表（带头结点）、双链表、循环单/双链表、静态链表（数组+游标，无指针环境用）。 【头结点的作用】①首位置插入/删除与别处统一（不需改头指针）；②空表与非空表处理统一（判空=L->next==NULL）。

二、定理与公式推导（不背结论背推导）

T1 顺序表插入/删除的平均移动次数（完整推导）： - 插入到第 i 个位置（i=1..n+1，等概率 p=1/(n+1)）需移动 n−i+1 个元素（第i到第n个后移）： E插入=Σ_{i=1}^{n+1} (n−i+1)/(n+1) = (n+(n−1)+…+0)/(n+1) = n/2。 - 删除第 i 个元素（i=1..n，p=1/n）需移动 n−i 个： E删除=Σ_{i=1}^n (n−i)/n = (n−1)/2。∎ （插入移动一半、删除移动一半差1——选择题爱考精确值。）

T2 双链表插入的语句次序（985面试经典）：在 p 之后插入 s：

s->prior = p;          /* ① */
s->next  = p->next;    /* ② */
p->next->prior = s;    /* ③ */
p->next = s;           /* ④ 必须最后——p->next 一改，原后继就"丢"了 */

【剖析】任何访问旧 p->next 的语句（②③）都必须在 ④ 之前；删除结点同理（先摘链后free）。

T3 循环单链表+仅设尾指针 rear： 头 = rear->next->next（头结点的下一个）；头插、尾插、两表合并都 O(1)——合并两个循环链表只需交换指针，这是它相对单链表+头指针的核心优势。

T4 顺序表 vs 链表（决策表）： | 维度 | 顺序表 | 链表 | |---|---|---| | 按位存取 | O(1) | O(n) | | 插入/删除（已定位） | O(n)移动 | O(1)改指针 | | 存储 | 连续、无指针开销、可随机存取 | 分散、指针开销、缓存不友好 | | 适用 | 查多改少、长度可预估 | 频繁插删、长度动态 |

三、本章考题（5题）

题1（设计·原地划分） 设计算法将顺序表的所有奇数移到所有偶数之前，时间O(n)、空间O(1)。 【解】双指针相向扫（快排 partition 思想）：

void OddBeforeEven(int A[], int n) {
    int i = 0, j = n - 1, t;
    while (i < j) {
        while (i < j && A[i] % 2 != 0) i++;   /* 左找偶 */
        while (i < j && A[j] % 2 == 0) j--;   /* 右找奇 */
        if (i < j) { t = A[i]; A[i] = A[j]; A[j] = t; }
    }
}

时间O(n)（每元素至多被扫一次），空间O(1)。∎ （不要求稳定时用 partition；要求稳定→另开辅助数组O(n)空间。两问对比是985出题套路。）

题2（设计·有序合并） 两个递增单链表（带头结点）La、Lb，合并为递增链表 Lc（复用结点）。 【解】尾插版（与《算法代码题精练》题3的头插递减版对照记忆）：

void MergeAsc(LinkList La, LinkList Lb, LinkList Lc) {
    LNode *pa = La->next, *pb = Lb->next, *t, *tail = Lc;
    while (pa && pb) {
        if (pa->data <= pb->data) { t = pa; pa = pa->next; }
        else                      { t = pb; pb = pb->next; }
        tail->next = t; tail = t;          /* 尾插 */
    }
    tail->next = pa ? pa : pb;
}

时间O(m+n)，空间O(1)。∎

题3（次序陷阱·判断改错） 在双链表中 p 结点之前插入 s，以下次序是否正确： s->next=p; p->prior=s; s->prior=p->prior; p->prior->next=s;？ 【答】错误：第二句执行后 p->prior 已指向 s，第四句变成 s->next=s 自环。正确次序必须保证用到旧 p->prior 的语句在前：s->prior=p->prior; s->next=p; p->prior->next=s; p->prior=s;。∎ （记忆："改指针前先备份"——谁会被覆盖，谁就要先被使用。）

题4（仅设尾指针的循环单链表） 证明：用带尾指针 rear 的循环单链表作队列，入队/出队均可 O(1)。 【证】rear->next 即头结点（循环），出队删 rear->next->next（O(1)改两个指针）；入队在 rear 后插并 rear=rear->next（O(1)）。另：合并两个此类链表只需交换 rear->next 与 rear->next->next 的指向，O(1) 完成——这是普通单链表做不到的。∎

题5（静态链表概念） 静态链表中，"游标"存储的是什么？如何判空、判尾？ 【答】游标=后继元素在数组中的下标（逻辑链）。判尾：游标==−1（或约定值）；判空：头游标指向的仍是空闲区标志。插入/删除只需修改游标，无需 malloc/free。∎

第3章 栈、队列和数组

一、定义精讲

D1 栈：只允许在一端（栈顶）插入删除的线性表，LIFO。 D2 队列：只允许一端（队尾）插入、另一端（队头）删除，FIFO。 【要点】栈和队列都是操作受限的线性表——受限带来"序列合法性"这类独有题型。 D3 循环队列（牺牲一个单元法）： - 队满：(rear+1)%M == front；队空：front==rear；元素数=(rear−front+M)%M。 D4 双端队列：两端都可插入删除。变体：输入受限（插入只许一端）、输出受限（删除只许一端）。

二、定理与公式推导

T1 n个元素进栈的出栈序列个数=卡特兰数 Cₙ=C(2n,n)/(n+1)。 【推导（必会）】设 f(n)=以 n 个元素入栈为前提的出栈序列数。固定第1个出栈的是原第 i 个入栈元素：其前恰有 i−1 个元素先入栈且须全部先出（f(i−1) 种），其后 n−i 个后入栈（f(n−i) 种）。递推： f(n)=Σ_{i=1}^{n} f(i−1)·f(n−i)，f(0)=1 → 即卡特兰递推，f(n)=C(2n,n)/(n+1)。 验证：f(3)=5，f(4)=14。∎ T2 循环队列判满的三种方案：①牺牲单元（(rear+1)%M==front，元素数≤M−1）；②设尺寸变量 size（满：size==M）；③设标志位 tag（进队置1出队置0，front==rear且tag==1为满）。计算元素个数题先看清是哪种方案。 T3 数组存储地址公式（推导）： - 行优先（0基，n列）：LOC(aᵢⱼ)=LOC(a₀₀)+(i·n+j)·L； - 列优先：LOC(aᵢⱼ)=LOC(a₀₀)+(j·m+i)·L。 【推导】行优先=先存满一行：aᵢⱼ 之前有 i 个整行（i·n个元素）+本行 j 个。 T4 对称矩阵压缩（下三角，1基位序）：aᵢⱼ（i≥j）存入 B[k]，k=i(i−1)/2+(j−1)（0基数组）。 【推导】aᵢⱼ 之前存了第1~(i−1)行的全部（1+2+…+(i−1)=i(i−1)/2个）+本行 (j−1) 个。上三角部分 aᵢⱼ(i<j) 取对称元素 a_{ji}。 T5 三对角矩阵压缩：|i−j|≤1 的 aᵢⱼ 存入 B[k]（0基），k=2i+j−3（1基行列）。 【验证】a₁₁→0，a₁₂→1，a₂₁→2，a₂₂→3，a₃₂→5（第3行从5起）✓。

三、本章考题（6题）

题1（出栈序列合法性判定·算法+手算） 判断序列 4,3,5,1,2 是否为入栈序 1,2,3,4,5 的合法出栈序列。 【手算】入1，入2，入3，入4 → 弹4；弹3；入5 → 弹5；弹1？栈中是[1,2]，栈顶2≠1 → 非法。 【判定算法】辅助栈模拟：按出栈序逐个"把元素压到栈顶等于目标为止"，目标弹不出即非法，时间O(n)。∎

题2（卡特兰数计算） 4个不同元素依次进栈，出栈序列共有多少种？ 【解】C₄=C(8,4)/5=70/5=14种。∎ （对照：f(1)=1, f(2)=2, f(3)=5, f(4)=14——递推 f(n)=Σf(i−1)f(n−i) 现场可算。）

题3（循环队列·参数计算） 循环队列数组 Q[0..59]（容量60，牺牲单元法），front=20，rear=15。求元素个数、队满条件、再入队3个后的 front/rear。 【解】元素数=(15−20+60)%60=55；队满：(rear+1)%60==front → 16==20? 队满条件此刻不成立（55=59−4? 55≤58可用）→ 未满。 再入队3个：rear=(15+3)%60=18，front不变=20（元素58，仍<59可用上限）。∎ （若采用 size 方案，容量可达60无牺牲——两种方案的容量差1是选择题陷阱。）

题4（双端队列合法性·985易错） 输入序 a,b,c,d（必须依次进队/栈）。判断输出序列 4,2,1,3（对应 d,b,a? 按字母即 d,b,a,c? ——设 a=1,b=2,c=3,d=4，即输出 4,2,1,3）能否由：①输入受限双端队列（插入只能尾端，删除两端皆可）②输出受限双端队列（删除只能头端，插入两端皆可）得到。 【解】①输入受限：只能尾插、两端删。想先出4：1,2,3尾插、4尾插 → 队列[1,2,3,4]；删尾得4✓；队列[1,2,3]，下一目标2：头=1、尾=3，2在中间取不到 → 非法。 ②输出受限：只能头删、两端插。1头插→[1]；2头插→[2,1]；3头插→[3,2,1]；4头插→[4,3,2,1]；依次头删：4,3,2,1——但目标是4,2,1,3：得4后头=3≠2。换策略：1尾插[1]；2头插[2,1]；3尾插[2,1,3]；4头插[4,2,1,3] → 头删4✓、2✓、1✓、3✓ → 合法。∎ （此类题的唯一解法：穷举两端插入/删除策略+逐步模拟，不存在通用公式。）

题5（压缩存储下标） 6阶对称矩阵 A（aᵢⱼ=aⱼᵢ）按行优先存下三角于 B[0..20]。求 a₆₃ 存放位置与 B 的总长。 【解】a₆₃（i=6≥j=3）：k=6×5/2+(3−1)=15+2=17（B[17]，0基）。 总长=n(n+1)/2=6×7/2=21。∎ （上三角元素如 a₃₆ 取 a₆₃ 同位置。）

题6（三对角矩阵下标） n 阶三对角矩阵按行优先存 |i−j|≤1 的元素于 B（0基）。求 a₄₅ 的位置。 【解】k=2i+j−3=2×4+5−3=10。验证：前三行存 3+3+3=9 个（第1行2个、第2行3个、第3行3个=8? ——第1行2个（a₁₁,a₁₂），第2、3行各3个，共2+3+3=8，a₄₅是第4行第2个 → 8+2=10 ✓）。∎
