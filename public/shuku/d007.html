数学 · 多元微积分专项（120题带详解）

§1 多元极限、连续与偏导（U1–U25）

U1.★ 求 z=√(1−x²) + √(y²−1) 的定义域。

1−x²≥0 且 y²−1≥0 ⇒ x∈[−1,1]，|y|≥1（两块无穷长条区域）。

U2.★★ 判断 lim(x,y)→(0,0) xy/(x²+y²) 是否存在。

沿 y=kx：kx²/(x²+k²x²) = k/(1+k²)，随 k 变化 ⇒ 不存在。 沿不同路径极限不同是"极限不存在"的最快证法。

U3.★★ 求 lim(x,y)→(0,0) x²y/(x²+y²)。

|x²y|/(x²+y²) ≤ |y|·[x²/(x²+y²)] ≤ |y| → 0 ⇒ 极限 0。 分母是二次齐次，分子凑出更高阶——夹逼比极坐标更快。

U4.★ 判断 lim(x,y)→(0,0) (x+y)/(x−y) 是否存在。

沿 y=0 得 1；沿 x=0 得 −1 ⇒ 不存在。

U5.★ 求 lim(x,y)→(0,0) sin(xy)/y。

= x·[sin(xy)/(xy)] → x·1 → 0（把 y 看成"一元极限里的分母"）。

U6.★ 求 lim(x,y)→(0,0) √(x²+y²)·sin(1/√(x²+y²))。

有界 × 无穷小 ⇒ 0。与一元 x·sin(1/x) 同构，r=√(x²+y²) 当成"一元变量"用。

U7.★ 求 lim(x,y)→(0,0) e^{−1/(x²+y²)}。

令 r²=x²+y²→0⁺：e^{−1/r²} = 1/e^{1/r²} → 0。

U8.★★ 默写二元连续的定义，并说明与"沿任何直线极限存在"的关系。

f 在 (P₀) 连续 ⟺ lim(P→P₀) f(P) = f(P₀)。 沿所有直线极限存在且相等推不出二元极限存在（还要沿曲线，如抛物线）——二元极限要求全路径一致。

U9.★★ f(x,y)=(x²−y²)/(x²+y²)（(x,y)≠(0,0)），f(0,0)=0。求 fx(0,0) 与 fy(0,0)。

f(h,0) ≡ 1 ⇒ fx(0,0)=lim 1/h 不存在；f(0,h) ≡ −1 ⇒ fy(0,0) 不存在。 两个偏导都不存在——尽管沿坐标轴 f 是常数，这函数在原点附近仍然剧烈变化。

U10.★★★ f(x,y)=√|xy|，f(0,0)=0。讨论在 (0,0) 的连续性、偏导存在性与可微性。

连续：|√|xy|| ≤ √[(x²+y²)/2] → 0 ✓。 偏导：f(h,0)=0 ⇒ fx(0,0)=fy(0,0)=0，都存在。 可微：需 √|xy|/√(x²+y²) → 0；沿 y=x 得 1/√2 ⇒ 不可微。 结论钉死：偏导存在 + 连续 ⇏ 可微。

U11.★ z=e^{xy}，求 zx、zy。

zx = y·e^{xy}；zy = x·e^{xy}（对谁求导，另一个变量就是系数/因子）。

U12.★ z=x^y（x>0），求 zx、zy。

zx = y·x^{y−1}；zy = x^y·lnx。底数变量与指数变量分开对待。

U13.★★ z=ln(x+√(x²+y²))，求 zx。

zx = [1 + x/√(x²+y²)]/[x+√(x²+y²)] = 1/√(x²+y²)（分子有理化后奇迹般简洁）。

U14.★★ z=x²y + e^{xy}，求 zxy。

zx = 2xy + y·e^{xy} ⇒ zxy = 2x + e^{xy} + xy·e^{xy}（先对 x 再对 y，中间结果别丢项）。

U15.★★ 以 z=x^y 为例验证 zxy = zyx。

zxy = x^{y−1} + y·x^{y−1}lnx；zyx = y·x^{y−1}lnx + x^{y−1}。相等 ✓。 克莱罗定理：二阶偏导连续时混合偏导与次序无关。

U16.★★ z=f(u,v)，u=x²+y，v=xy。求 zx、zy。

链式：zx = 2x·fu + y·fv；zy = fu + x·fv（画"树形图"逐枝相乘）。

U17.★★ z=f(x²−y², e^{xy})，用 f₁、f₂ 记号求 zx、zy。

zx = 2x·f₁ + y·e^{xy}·f₂；zy = −2y·f₁ + x·e^{xy}·f₂。 抽象函数链式的标准记法，考题默认你会。

U18.★★ u=f(x²y, y/x)，求 ux、uy。

ux = 2xy·f₁ − (y/x²)·f₂；uy = x²·f₁ + (1/x)·f₂。

U19.★★ 由 e^z = xyz 确定 z=z(x,y)，求 zx。

F = e^z − xyz：Fx = −yz，Fz = e^z − xy。 zx = −Fx/Fz = yz/(e^z − xy)。

U20.★★ 设 z=z(x,y) 由 x²+y²+z² = 3xyz 确定，求 zx 在点 (1,1,1) 的值。

Fx = 2x−3yz = 2−3 = −1；Fz = 2z−3xy = −1。 zx = −Fx/Fz = −(−1)/(−1) = −1。

U21.★★ z=z(x,y) 由 x²+y²+z²=1（z>0）确定，求 zxx。

zx = −x/z。zxx = −1/z + (x/z²)·zx = −1/z − x²/z³ = −(z²+x²)/z³。

U22.★★ z=e^{x/y}，求全微分 dz。

dz = e^{x/y}·(dx/y − x·dy/y²)。全微分=两枝偏导各配自己的增量。

U23.★★★ f(x,y)=(x²+y²)·sin(1/(x²+y²))（(x,y)≠0），f(0,0)=0。判断在 (0,0) 的可微性。

fx(0,0)=lim x·sin(1/x²)=0，同理 fy(0,0)=0。 [f−0]/r = r·sin(1/r²) → 0 ⇒ 可微（尽管偏导函数在原点不连续）。 可微判定永远回到定义：Δf − (fxΔx+fyΔy) 是 ρ=√(Δx²+Δy²) 的高阶无穷小。

U24.★★ 用全微分近似计算 (1.02)^{3.01}。

f=x^y，(1,3) 处：f=1，fx=3，fy=x^y·lnx=0。 Δf ≈ 3(0.02) + 0(0.01) = 0.06 ⇒ ≈ 1.06。

U25.★★★ 圆柱半径 r=2 cm（误差 ±0.01），高 h=5 cm（误差 ±0.02），求体积最大绝对误差。

V=πr²h：dV = 2πrh·dr + πr²·dh。 最坏情形：2π·2·5(0.01) + π·4(0.02) = 0.2π+0.08π = 0.28π ≈ 0.88 cm³。

§2 方向导数、梯度与极值（U26–U45）

U26.★ 默写方向导数与梯度的关系。

D_l f = fx·cosα + fy·cosβ = grad f · e_l（e_l 是单位方向向量）。 三元同理加 cosγ 项。前提：f 可微。

U27.★★ z=x²+y² 在点 (1,2) 处沿方向 l=(1,1) 的方向导数。

grad z = (2x,2y) = (2,4)；e_l = (1,1)/√2。 D = (2+4)/√2 = 3√2。

U28.★★ f=xy+yz+zx 在点 (1,1,2) 处沿 l=(1,2,2) 的方向导数。

grad f = (y+z, x+z, y+x) = (3,3,2)；|l|=3。 D = (3+6+4)/3 = 13/3。

U29.★★ f=ln(x²+y²) 在 (1,1) 处，沿什么方向增长最快？最快速率是多少？

grad f = (2x,2y)/(x²+y²) = (1,1)。 沿 (1,1)/√2 方向最快，速率 = |grad f| = √2。梯度方向=最速上升，这是梯度的定义性事实。

U30.★ 说明"梯度与等值线（面）垂直"。

等值线 f=c 上取方向 t：df=grad f·dt = 0 ⇒ grad f ⊥ t。 例：f=x²+y² 的等值线是圆，梯度沿半径向外，处处垂直。梯度指向 f 增大最陡的方向，等值线是它的"横截面"。

U31.★★★ 求 z=x³−y³+3x²+3y²−9x 的极值。

zx=3x²+6x−9=3(x+3)(x−1)=0 ⇒ x=1,−3；zy=−3y²+6y=−3y(y−2)=0 ⇒ y=0,2。 四个驻点：A=zxx=6x+6，B=zxy=0，C=zyy=−6y+6。 (1,0)：A=12>0，AC=72>0 ⇒ 极小 −5；(−3,2)：A=−12<0，AC=72>0 ⇒ 极大 31； (1,2) 与 (−3,0)：AC<0 ⇒ 非极值。

U32.★★ 求 z=x³+8y³−xy 的极值。

zx=3x²−y=0，zy=24y²−x=0 ⇒ x=24y²，3(576y⁴)=y ⇒ y=1/12（y=0 舍，代回 x=0 检验 AC=0 不定，沿 y=x³? 实际 y=0,x=0 时 z=0 且 z=x³+8y³−xy 在附近变号，非极值）。 驻点 (1/6, 1/12)：A=6x=1，B=−1，C=48y=4 ⇒ AC−B²=3>0，A>0 ⇒ 极小 −1/216。

U33.★★ 求 z=e^{2x}(x+y²+2y) 的极值。

zy = 2e^{2x}(y+1)=0 ⇒ y=−1；zx = e^{2x}(2x+2y²+4y+1)=0 ⇒ 2x+2−4+1=0 ⇒ x=1/2。 A=e^{2x}(4x+4y²+8y+4)=e(2+4−8+4)=2e>0；B=e^{2x}(4y+4)=0；C=2e^{2x}=2e。 AC−B²=4e²>0 ⇒ 极小 f(1/2,−1) = e(1/2+1−2) = −e/2。

U34.★★ 求 z=x⁴+y⁴−x²−y² 的所有极值点。

zx=4x³−2x=2x(2x²−1)=0 ⇒ x=0, ±1/√2（y 同）。 (0,0)：A=C=−2，AC=4>0，A<0 ⇒ 极大（值 0）。 (±1/√2, ±1/√2)：A=C=6(½)−2=1>0，AC=1>0 ⇒ 四个极小点，值均为 −1/2。

U35.★★★ 求 z=x²y(4−x−y) 在闭区域 D（x 轴、y 轴与直线 x+y=6 围成）上的最大值与最小值。

驻点：zx=xy(8−3x−2y)=0，zy=x²(4−x−2y)=0 ⇒ 内部驻点 (2,1)：z=4。 边界：x=0 或 y=0 ⇒ z=0；x+y=6 ⇒ z=−2x²(6−x)，在 x=4 取最小 −64。 比较：最大 4（内部点 (2,1)），最小 −64（边界点 (4,2)）。 闭区域最值=内部驻点+边界逐段讨论，一个都不能漏。

U36.★★ 用拉格朗日乘数法求 f=xy 在约束 x+y=1 下的最大值。

L=xy+λ(1−x−y)：Ly=x−λ=0，Lx=y−λ=0 ⇒ x=y=1/2。 最大值 1/4（对称约束的最优解常在对称点）。

U37.★★ 求内接于椭圆 x²/a²+y²/b²=1（第一象限顶点）的矩形最大面积。

S=4xy，约束 g=x²/a²+y²/b²−1=0。 拉格朗日：y = λ·2x/a²，x = λ·2y/b² ⇒ 相乘得 λ=ab/2 ⇒ x=a/√2，y=b/√2。 S_max = 4·(ab/2) = 2ab。

U38.★★ 求椭球 x²/a²+y²/b²+z²/c²=1 的内接长方体（各面平行坐标面）最大体积。

V=8xyz，约束 g=x²/a²+y²/b²+z²/c²−1=0。 由对称性（或拉格朗日解方程组）得 x=a/√3，y=b/√3，z=c/√3，V_max=8abc/(3√3)。

U39.★ 默写拉格朗日乘数法的方程组结构。

求 f 在 φ=0 约束下的极值：令 L = f + λφ，解 ∇f = −λ∇φ 与 φ=0 的联立。 多个约束就配多个 λ；k 个变量 m 个约束 ⇒ 方程组 k+m 个。

U40.★★ 求 z=xy 在约束 x²+y²=1 上的最大值与最小值。

L=xy+λ(1−x²−y²)：y=2λx，x=2λy ⇒ x=y 或 λ=1/2、x=−y。 x=y=±1/√2 ⇒ z=1/2；x=−y=±1/√2 ⇒ z=−1/2。 最大 1/2，最小 −1/2。

U41.★★★ 求 f=x²−y²+2 在闭区域 D: x²+y²/4 ≤ 1 上的最值。

内部：fx=2x=0，fy=−2y=0 ⇒ (0,0)，f=2。 边界参数化 x=cost，y=2sint：f = 5cos²t−2 ∈ [−2, 3]。 比较：最大 3（点 (±1,0)），最小 −2（点 (0,±2)）。

U42.★★ 默写二元极值二阶充分条件，并说明 B²<AC 为何能定号。

驻点处 A=fxx，B=fxy，C=fyy：AC−B²>0 且 A>0 ⇒ 极小；AC−B²>0 且 A<0 ⇒ 极大；AC−B²<0 ⇒ 非极值；=0 失效。 原理：泰勒二阶项 Ax²+2Bxy+Cy² 是二次型，判别式决定正定/负定/不定。

U43.★★ 体积为 4 的长方体，表面积最小时尺寸是多少？

约束 xyz=4，最小化 S=2(xy+yz+zx)。 由均值不等式（或拉格朗日对称性）：x=y=z=4^{1/3}，S_min = 6·4^{2/3}。 "对称约束+对称目标 ⇒ 对称解"是最快判据，但写过程仍要拉格朗日。

U44.★★★ f=√(x²+y²) 在原点处方向导数都存在吗？它与可微性矛盾吗？

沿单位方向 (cosα,sinα)：[f(hcosα,hsinα)−0]/h = |h|/h 分 h>0、h<0——单侧方向差商 = 1，各方向的方向导数都存在且为 1。 但 fx(0,0)=lim|h|/h 不存在 ⇒ 偏导不存在 ⇒ 不可微。 方向导数存在 ⇏ 可微（与 U10 合起来：偏导存在、方向导数存在都不够，必须按定义验证）。

U45.★★ u=ln(x²+y²+z²)，求在点 (1,2,−2) 处梯度的模。

grad u = 2(x,y,z)/(x²+y²+z²) = 2(1,2,−2)/9。 |grad u| = 2·3/9 = 2/3（也是该点最大方向导数）。

§3 二重积分（U46–U70）

U46.★ ∫∫_D (1+x+y)dA，D=[0,1]×[0,1]。

∫∫1=1，∫∫x=½，∫∫y=½ ⇒ 2。常数与单变量积分直接分开算。

U47.★★ D 由 y=x、y=0、x=1 围成，求 ∫∫_D xy dA。

∫₀¹ dx ∫₀ˣ xy dy = ∫₀¹ x·(x²/2)dx = 1/8。

U48.★★ 交换 ∫₀¹dx∫ₓ^{√x} f(x,y)dy 的积分次序。

区域：x ≤ y ≤ √x（0≤x≤1）⇒ 视 y 为主：y² ≤ x ≤ y（0≤y≤1）。 ∫₀¹dy ∫_{y²}^{y} f(x,y)dx。画出区域是唯一可靠的办法。

U49.★★ 计算 ∫₀¹dx ∫ₓ¹ e^{y²}dy。

e^{y²} 对 y 积不出 ⇒ 必换序：= ∫₀¹ e^{y²}dy ∫₀^y dx = ∫₀¹ y·e^{y²}dy = (e−1)/2。 "积不出的函数"是换序题的标志性信号。

U50.★★ 求 ∫∫_{x²+y²≤a²} e^{−x²−y²} dA。

极坐标：2π∫₀ᵃ r·e^{−r²}dr = π(1−e^{−a²})。 令 a→+∞ 得 ∫∫_{R²}e^{−r²}dA=π——概率论高斯积分的来源。

U51.★★ 求 ∫∫_{x²+y²≤4} √(4−x²−y²) dA。

被积函数是半径 2 的上半球面高度 ⇒ 体积 = 16π/3（半球 V=(2/3)π·2³）。

U52.★★ D: 1≤x²+y²≤4，x≥0，y≥0。求 ∫∫_D arctan(y/x) dA。

极坐标下被积函数=θ：∫₀^{π/2}θdθ · ∫₁²r dr = (π²/8)(3/2) = 3π²/16。

U53.★★★ 求 ∫∫_{x²+y²≤9} |x²+y²−4| dA。

按圆环拆：r<2 被积 4−r²，2<r<3 被积 r²−4。 2π∫₀²(4r−r³)dr = 2π(8−4)=8π；2π∫₂³(r³−4r)dr = 2π(25/4)=25π/2。 合计 41π/2。绝对值必须找零等值线（r=2）分块。

U54.★ D: x²+y²≤1。求 ∫∫_D (x+y³+1) dA。

x、y³ 都是奇函数且区域对称 ⇒ 归零，=π。对称性先行，省一半计算。

U55.★★ D: x²+y²≤a²。求 ∫∫_D x² dA。

轮换对称：∫∫x² = ∫∫y² = ½∫∫(x²+y²) = ½·2π∫₀ᵃr³dr = πa⁴/4。

U56.★ 求 z=1−x−y 与三坐标面围成的立体体积。

= ∫∫_{三角形} (1−x−y)dA = 三棱锥体积 = 1/6（∫₀¹∫₀^{1−x}(1−x−y)dydx）。

U57.★★ 求 ∫∫_{x²+y²≤x} √(x²+y²) dA。

极坐标：r ≤ cosθ，θ∈(−π/2,π/2)。 ∫θ∫₀^{cosθ} r·r dr = (1/3)∫_{−π/2}^{π/2}cos³θdθ = (1/3)(4/3) = 4/9。

U58.★★ 求 y²=x 与 x=2−y² 围成区域面积。

交点 y=±1：∫_{−1}^{1}[(2−y²)−y²]dy = ∫(2−2y²) = 8/3。

U59.★★ 计算 ∫₀¹dx ∫_{x²}¹ e^{−y²}dy。

e^{−y²} 对 y 积不出 ⇒ 必换序。区域：x²≤y≤1，0≤x≤1 ⇒ 0≤x≤√y： I = ∫₀¹ e^{−y²}·√y dy，令 t=√y（dy=2t dt）：= 2∫₀¹ t²e^{−t⁴}dt。 与 U49 对照：下限是 x（线性）时才能凑出 y·e^{−y²}；下限是 x² 时就只剩"写成定积分形式"这一条路。 结论：I = 2∫₀¹ t²e^{−t⁴}dt（无法用初等函数表示，考试写到此即得分）。

U60.★★ 求 ∫∫_{|x|+|y|≤1} (|x|+|y|) dA。

四个象限对称，每块：∫₀¹∫₀^{1−x}(x+y)dydx = ∫₀¹[(1−x)(1+x)/2]dx = 2/3·? = 1/3·? 逐块 = 1/3，共 4/3。

U61.★★ 求 ∫∫_{整个平面} e^{−(x²+y²)} dA。

极坐标：2π∫₀^{+∞}re^{−r²}dr = π（高斯积分，概率论与热传导的地基）。

U62.★ (X,Y) 在单位圆盘上均匀分布（密度 1/π）。求 P(X²+Y²≤1/4)。

面积比：π(1/4)/π·? 小圆面积 π/4 ⇒ 1/4。均匀分布的概率=面积比。

U63.★★★ 设 f 连续，F(t)=∫∫_{x²+y²≤t²} f(√(x²+y²))dA（t>0）。求 F′(t)。

极坐标：F=2π∫₀ᵗ f(r)r dr ⇒ F′(t) = 2πt·f(t)。 "圆盘上对称被积函数 ⇒ 化为一次积分再求导"，含参二重积分的标准处理。

U64.★★★ 默写二重积分中值定理，并指出 f=x²+y² 在单位圆盘上的平均值。

f 在有界闭区域 D 连续 ⇒ ∃(ξ,η)∈D：∫∫_D f = f(ξ,η)·S_D。 平均值 = ∫∫(x²+y²)/π = (π/2)/π = 1/2 ⇒ 存在点使 ξ²+η²=1/2（半径 1/√2 的圆上）。

U65.★★ 证明 ∫∫_{x²+y²≤1} e^{x²+y²} dA ≤ π(e−1)，并说明等号情形。

极坐标精确计算：2π∫₀¹re^{r²}dr = π(e−1) ⇒ 恰好相等（此"不等式"实为等式）。 教训：能用单调性直接算的别硬估。

U66.★ 说出极坐标曲线 r=2sinθ 是什么图形。

两边乘 r：r²=2rsinθ ⇒ x²+y²=2y ⇒ 圆心 (0,1)、半径 1 的圆。r=a·sinθ/cosθ 一族都这样翻译。

U67.★★ 求 ∫∫_D (x+y)dA，D: x²+y² ≤ x+y。

配方：(x−½)²+(y−½)² ≤ ½。平移 u=x−½，v=y−½： ∫∫(u+v+1)dA = 0+0+π(1/2) = π/2。平移消一次项是对称性的活用。

U68.★★ 计算 ∫₀¹dy ∫_{√y}^1 √(x³+1) dx。

区域：√y≤x≤1，0≤y≤1 ⇒ y≤x²。换序：∫₀¹√(x³+1)dx∫₀^{x²}dy = ∫₀¹x²√(x³+1)dx。 = (1/3)·(2/3)(x³+1)^{3/2}|₀¹ = (2/9)(2√2−1)。

U69.★★ 求由 z=1−x²−y² 与 z=0 围成立体的体积。

V = ∫∫_{r≤1}(1−r²)dA = 2π∫₀¹(r−r³)dr = 2π(1/4) = π/2。

U70.★★ 求 ∫∫_D (x²+y²)dA，D: 1≤x²+y²≤4 且 x≥0，y≥0。

极坐标：∫₀^{π/2}dθ·∫₁²r³dr = (π/2)(15/4) = 15π/8。

§4 三重积分（U71–U90）

U71.★ 求 Ω（x≥0,y≥0,z≥0 且 x+y+z≤1）的体积，用三重积分。

投影到 xy 面（三角形 x+y≤1）：V=∫∫ z 上限 1−x−y = ∫∫(1−x−y)dA = 1/6（四面体）。

U72.★★ 求 Ω（z=x²+y² 与 z=1 围成）的体积。

投影 r≤1：V=∫∫_{r≤1}(1−r²)dA = 2π∫₀¹(r−r³)dr = π/2（旋转抛物面碗）。

U73.★★ 用"先二后一"求球 x²+y²+z²≤R² 的体积。

高度 z 处截面是半径 √(R²−z²) 的圆：V=∫_{−R}^R π(R²−z²)dz = π(2R³−2R³/3) = 4πR³/3。 被积函数只含 z ⇒ 截面法通常完胜。

U74.★★ 求 ∫∫∫_Ω z dV，Ω 为上半球 r≤1，z≥0。

球坐标：z=r·cosφ，dV=r²sinφ dr dφ dθ。 ∫₀^{2π}dθ ∫₀^{π/2}sinφcosφdφ ∫₀¹r³dr = 2π·(1/2)·(1/4) = π/4。

U75.★ 均匀球体 r≤R 的质心在哪？

对称性：球心 (0,0,0)。任何对称区域+对称密度，质心在对称中心，先答这个再算别的。

U76.★★ 求 ∫∫∫_Ω (x²+y²)dV，Ω：锥 z=√(x²+y²) 与 z=1 围成。

柱坐标：0≤z≤r≤1。∫₀^{2π}∫₀¹∫₀^r r²·r dz dr dθ = 2π∫₀¹r⁴dr = 2π/5。

U77.★★ 圆柱 x²+y²≤1，0≤z≤1，密度 ρ=z。求质量与质心的 z 坐标。

M=∫∫∫z dV = 2π·(∫₀¹r dr)(∫₀¹z dz) = 2π·(1/2)(1/2) = π/2。 z̄ = ∫∫∫z²dV / M = (2π·½·⅓)/(π/2) = (π/3)/(π/2) = 2/3。

U78.★★★ 推导均匀球体（密度 ρ、半径 R）绕直径的转动惯量。

I_z = ρ∫∫∫(x²+y²)dV = ρ·(2/3)∫∫∫r²dV（轮换对称）。 ∫∫∫r²dV = ∫₀^{2π}∫₀^π∫₀^R r⁴sinφ drdφdθ = 2π·2·R⁵/5 = 4πR⁵/5。 I = 8πρR⁵/15 = (2/5)MR²（M=4πρR³/3）。物理必背结论，积分可现场推。

U79.★★ 用先二后一求 Ω（z=x²+y² 与 z=4 围成）的体积。

高度 z 处截面 r=√z：V=∫₀⁴ πz dz = 8π。

U80.★ 求 ∫∫∫_{r≤R} r² dV。

球坐标：2π∫₀^π sinφdφ ∫₀^R r⁴dr = 2π·2·R⁵/5 = 4πR⁵/5。

U81.★★ 求 ∫∫∫_{x²+y²+z²≤1} (x+y+z)² dV。

展开：x²+y²+z² + 2(xy+yz+zx)。交叉项由对称性归零。 ∫∫∫r²dV = 4π/5 ⇒ = 4π/5。

U82.★★ Ω: x²+y²≤z，0≤z≤1（倒锥）。求 ∫∫∫_Ω f(z)dV 的截面法表达，并取 f(z)=z 计算。

高度 z 处截面是半径 √z 的圆（x²+y²≤z）：∫∫∫f(z)dV = ∫₀¹ f(z)·πz dz。 f=z：∫₀¹πz²dz = π/3。

U83.★ 用三重积分求锥 z=√(x²+y²)（z≤1）的体积，验证圆锥公式。

V=∫₀¹πz²dz = π/3 ✓（与初等几何 (1/3)πR²h 一致）。

U84.★ 求椭球 x²/a²+y²/b²+z²/c²≤1 的体积。

广义球坐标 x=au,y=bv,z=cw，雅可比 abc： V = abc·(4π/3)（单位球体积）。= 4πabc/3。

U85.★★ 求 ∫∫∫_{r≤R} z² dV。

对称：∫z² = ∫x² = ∫y² = ⅓∫r²dV = ⅓·4πR⁵/5 = 4πR⁵/15。

U86.★★★ 计算 ∫∫∫_Ω dV/(1+x+y+z)³，Ω: x+y+z≤1，x,y,z≥0。

先二后一：高度 u=x+y+z 处截面是面积 u²/2 的三角形。 I = ½∫₀¹ u²/(1+u)³du，令 w=1+u：= ½∫₁² (w−1)²/w³ dw = ½∫₁²(1/w − 2/w² + 1/w³)dw。 = ½[lnw + 2/w − 1/(2w²)]₁² = ½[(ln2+1−1/8)−(0+2−1/2)] = (1/2)ln2 − 5/16。 （即 ½(ln2 − 5/8)。截面面积函数是这类题的钥匙。）

U87.★★ 求 ∫∫∫_{x²+y²+z²≤4, z≥0} z² dV。

上半球 = 全球值的一半：4πR⁵/15（R=2）= 4π·32/15 = 128π/15 ⇒ 64π/15。

U88.★★ 求 ∫∫∫_{r≤1} |z| dV。

= 2×上半球 ∫z dV = 2×(π/4)（U74）= π/2。

U89.★★★ 求 Ω（z=x²+y² 与 z=1 围成）均匀物体的质心 z 坐标。

对称 ⇒ x̄=ȳ=0。∫∫∫z dV = ∫∫{r≤1}∫{r²}^1 z dz·r dr dθ = 2π∫₀¹ r(1−r⁴)/2 dr = π(1/2−1/6) = π/3。 V=π/2（U72）⇒ z̄ = (π/3)/(π/2) = 2/3（比 1/2 靠上——碗形状上重下轻，合理）。

U90.★★★ 求"冰激凌"（球 x²+y²+z²=2z 内部与锥 z=√(x²+y²) 内部的公共部分）体积。

球坐标：球面 r=2cosφ；锥 φ=π/4。 V = ∫₀^{2π}dθ∫₀^{π/4}sinφdφ∫₀^{2cosφ}r²dr = (2π/3)∫₀^{π/4}8cos³φ·sinφdφ = (16π/3)·[−cos⁴φ/4]₀^{π/4}·(−1) = (16π/3)(1/4)(1−1/4) = π。

§5 曲线曲面积分与三大定理（U91–U120）

U91.★ 求 ∫_L (x+y)ds，L: y=x 从 (0,0) 到 (1,1)。

ds=√2 dx：(x+y)=2x ⇒ ∫₀¹2x·√2dx = √2。

U92.★ 求 ∫_L x ds，L 为上半圆 x²+y²=1（y≥0）。

曲线关于 y 轴对称，x 是奇函数 ⇒ 0（第一类曲线积分不认方向，只认对称）。

U93.★★ 求 ∫_L x² ds，L: x²+y²=a²（整圆）。

对称：∫x²ds = ½∫(x²+y²)ds = ½a²·2πa = πa³。

U94.★★ 求螺旋线 x=acost，y=asint，z=bt（0≤t≤2π）上 ∫_L (x²+y²+z²)ds。

ds=√(a²+b²)dt；被积 = a²+b²t²。 = √(a²+b²)[2πa² + b²·(8π³/3)] = √(a²+b²)(2πa² + 8π³b²/3)。

U95.★★ 求 ∬_S (x+y+z)dS，S 为平面 x+y+z=1 在第一卦限的部分。

在 S 上被积函数恒为 1 ⇒ = S 的面积 = 等边直角三角形放大 √3 倍 = √3/2。

U96.★★ 求 ∬_S z dS，S: z=√(x²+y²)（0≤z≤1 的锥面）。

z=r，dS=√2 r dr dθ：= √2∫₀^{2π}dθ∫₀¹r²dr = 2√2π/3。

U97.★★ 求 ∬_S (x²+y²)dS，S: x²+y²+z²=R²。

轮换：= (2/3)∬(x²+y²+z²)dS = (2/3)R²·4πR² = 8πR⁴/3。

U98.★ 默写第二类曲线积分的方向性。

∫_L Pdx+Qdy：L 反向则积分变号。与第一类（ds 恒正）的本质区别。

U99.★★ 用格林公式求 ∮_L (x−y)dx + (x+y)dy，L: x²+y²=1 取正向。

∂Q/∂x − ∂P/∂y = 1 − (−1) = 2 ⇒ ∮ = ∬_D 2dA = 2π。

U100.★★★ 求 ∫_L (eˣsiny − y)dx + (eˣcosy − 1)dy，L: 上半圆 x²+y²=1 从 (1,0) 到 (−1,0)。

∂Q/∂x − ∂P/∂y = eˣcosy − (eˣcosy − 1) = 1。 补 x 轴线段（y=0，dx 段被积 P=0）从 (−1,0) 回 (1,0)：闭路 = ∬1·dA = π/2。 L 方向是顺时针（从 (1,0) 到 (−1,0) 经上半圆）⇒ 闭路取负向：−I + 0 = π/2 ⇒ I = π/2。

U101.★★ 验证 (2xy)dx + x²dy 与路径无关，并求原函数。

∂P/∂y=2x=∂Q/∂x ✓（全平面单连通）。 u = ∫0^x 0·dx + ∫₀^y x²dy = x²y + C（折线法）。

U102.★★ 求 u 使 du = (x²+2xy−y²)dx + (x²−2xy−y²)dy。

∂P/∂y=2x−2y=∂Q/∂x ✓。 逐项积分拼凑：u = x³/3 + x²y − xy² − y³/3 + C（验证：ux=x²+2xy−y² ✓，uy=x²−2xy−y² ✓）。

U103.★ 默写两类曲线积分的联系。

∫_L Pdx+Qdy = ∫_L (Pcosα + Qcosβ)ds，(cosα,cosβ) 是 L 沿指定方向的单位切向量。三元多一项 cosγ。

U104.★★ 求 ∮_L xdx + ydy，L: x²+y²=1 正向。

P=x，Q=y：∂Q/∂x−∂P/∂y = 0 ⇒ 0（也是势函数 (x²+y²)/2 沿闭路为零的直接体现）。

U105.★ 默写第二类曲面积分的记号与方向意义。

∬_Σ Pdydz + Qdzdx + Rdxdy：dydz 等是有向面积微元投影，外侧/内侧差正负号。高斯公式要求外侧。

U106.★★ 用高斯公式求 ∬_Σ x·dydz + y·dzdx + z·dxdy，Σ: 球面 r=R 外侧。

div = 3 ⇒ = 3·(4/3)πR³ = 4πR³。

U107.★★ 求 ∬_Σ x·dydz + y·dzdx + z·dxdy，Σ: 立方体 [0,1]³ 表面外侧。

div=3，体积 1 ⇒ 3。

U108.★★★ 求 ∬_Σ x·dydz + y·dzdx + z·dxdy，Σ 为锥面 z=√(x²+y²)（0≤z≤1）的下侧（不含底面）。

补底面 z=1（下侧朝 −z）成闭合外侧：div=3，锥体体积 π/3 ⇒ 闭合积分 = π。 底面（下侧）：R=1，法向 −z ⇒ ∬z·dxdy 取 −∬dxdy = −π。 锥面部分 = π − (−π) = 2π。"补面"是高斯公式的标准用法，方向要配对。

U109.★★★ 用斯托克斯公式求 ∮_Γ ydx + zdy + xdz，Γ: x²+y²+z²=a² 与 x+y+z=0 的交线（从 z 轴正向看为逆时针）。

rot F = (0−1, 0−1, 0−1) = (−1,−1,−1)（P=y,Q=z,R=x）。 平面法向 n=(1,1,1)/√3：∮ = ∬(rot F·n)dS = −√3·S_disk = −√3πa²（圆盘半径 a）。

U110.★ 默写旋度公式。

rot F = |i j k; ∂/∂x ∂/∂y ∂/∂z; P Q R| = (R_y−Q_z, P_z−R_x, Q_x−P_y)。

U111.★ 求 div(x³, y³, z³)。

3(x²+y²+z²)。散度=各分量的偏导之和。

U112.★ F=(y,−x,0)，求 rot F 并解释物理意义。

rot F = (0,0,−2)。刚体绕 z 轴旋转场，旋度沿 −z，模 2=2ω（角速度 ω=1）。

U113.★ 默写两类曲面积分的联系。

∬_Σ R dxdy = ±∬_Σ R·cosγ·dS（±由曲面侧定，cosγ 是法向量与 z 轴夹角余弦）。P、Q 两项同理。

U114.★★ 流速场 F=(x,y,z) 通过球面 r=R 外侧的流量。

div=3：流量 = 3·(4/3)πR³ = 4πR³（球内每点源强 3，物理意义与 U106 相同）。

U115.★★ 求星形线 x=acos³t，y=asin³t 的全长。

第一象限 ds = 3a·sint·cost·dt（√(x′²+y′²)=3a sint cost）。 ∫₀^{π/2}3a sint cost dt = 3a/2 ⇒ 全长 = 4×3a/2 = 6a。

U116.★ 用第一类曲面积分表示圆柱 x²+y²=R²（0≤z≤h）的侧面面积并计算。

∬dS，参数化 dS = R dθdz：= R·2π·h = 2πRh（初中公式，积分一遍确认参数化能力）。

U117.★★★ 求 ∬_S (x+y+z)² dS，S: x²+y²+z²=R²。

展开 = x²+y²+z² + 2(xy+yz+zx)。交叉项在球面上由对称性归零。 = ∬R²dS = 4πR⁴。

U118.★★ 用格林公式的面积公式 A=½∮(xdy−ydx) 推导椭圆面积。

x=acost，y=bsint：xdy−ydx = ab(cos²t+sin²t)dt = ab·dt。 A = ½∫₀^{2π}ab·dt = πab。

U119.★★★ 求 ∫_L (x²−y)dx − (x+sin²y)dy，L: y=√(2x−x²) 从 (0,0) 到 (1,1)。

∂Q/∂x−∂P/∂y = −1−(−1) = 0 ⇒ 路径无关（单连通域内）。 原函数 u = x³/3 − xy − y/2 + sin2y/4（−∫sin²y dy = −y/2+sin2y/4）。 I = u(1,1) − u(0,0) = 1/3 − 1 − 1/2 + sin2/4 = sin2/4 − 7/6。 先验路径无关再换折线，是第二类曲线积分的最优策略。

U120.★★★ 求 ∬_Σ (x²cosα + y²cosβ + z²cosγ)dS，Σ: 球面 x²+y²+z²=a² 外侧。

化为第二类后用高斯：div(x²,y²,z²) = 2(x+y+z)。 ∫∫∫2(x+y+z)dV：球对称下 x、y、z 各自归零 ⇒ 0。

完结：U1–U120。使用节奏：①§1–§2 两天（可微性判别按定义、极值先驻点后判别式）→②§3 两天（先画区域再动手；换序题先练 U48–U49/U68）→③§4 一天半（三种坐标按"被积函数+区域"选，选择困难就背 U76/U74 两个模板）→④§5 两天半（格林/高斯/斯托克斯各配一道"补线/补面"题，U100/U108/U109 是必会三件套）。数一大题里曲线曲面积分几乎必出一道，这里 30 题就是主粮。
