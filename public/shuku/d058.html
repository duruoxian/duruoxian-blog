第3章 内存管理

一、装入与保护精讲

L1 三种装入方式： - 绝对装入：编译时确定地址（单道批处理早期）； - 静态重定位：装入时一次性转换（地址变换在装入时完成，装入后不能移动）； - 动态重定位：运行时随时转换（重定位寄存器/基址寄存器+逻辑地址）——现代OS标配，配合进程换入换出与紧凑。 L2 内存保护两法：上下限寄存器法；重定位寄存器（基址）+界地址寄存器（限长）法——越界即产生越界异常。 【辨析】重定位寄存器/界地址寄存器的修改是特权指令（核心态）。 L3 覆盖与交换：覆盖=程序内部段间复用同一内存区（程序员声明覆盖结构，已淘汰）；交换=内存紧张时把整个进程换出到外存（对换区，中级调度的实现）。

二、连续分配（碎片与算法演算）

C1 两种碎片： - 固定分区/页式 → 内部碎片（分配给进程但用不到的部分）； - 动态分区/段式 → 外部碎片（分区之间的零头）——解决：紧凑（需动态重定位支持）。 C2 动态分区分配算法（四兄弟）： | 算法 | 规则 | 优点 | 缺点 | |---|---|---|---| | 首次适应 First | 从低地址找第一个够用的 | 简单、开销小、高地址留大区 | 低端碎屑多 | | 邻近适应 Next | 从上次结束位置继续找 | 检索开销更小 | 高地址大区被分割 | | 最佳适应 Best | 找最小的够用分区 | 大区保得住 | 产生最多微小碎片 | | 最坏适应 Worst | 找最大的分区 | 残留区仍可用 | 大区迅速耗尽 |

考题1（四算法同题演算） 空闲分区按地址序为 100K、500K、200K、300K、600K。作业依次申请 212K、417K、112K。分别用四种算法，写出最终空闲分区表。 【解】 - 首次：212→500K(剩288)；417→600K(剩183)；112→288K(剩176)。最终：100, 176, 200, 300, 183。 - 最佳：212→300K(剩88)；417→500K(剩83)；112→200K(剩88)。最终：100, 88, 88, 300, 183（两个88K碎屑——最佳适应的"最佳"是单次最佳）。 - 最坏：212→600K(剩388)；417→500K(剩83)；112→388K(剩276)。最终：100, 276, 200, 300, 83。 - 邻近：本次与首次相同（未发生回绕）→ 100, 176, 200, 300, 183。∎ （结论可背：首次综合最优；最佳碎片最多；最坏大区先没。）

三、页式存储（地址变换推导）

P1 分页原理：物理内存分页框，进程地址空间分页（等大，如4KB）；页表记录页号→页框号。 【地址拆分】逻辑地址 A（页大小 2ᵏ）→ 页号 = A ÷ 页长（高位段），页内偏移 = A mod 页长（低位段）——拆位运算即可，无需除法：页大小4KB=2¹² → 低12位是偏移。 物理地址 = 页框号×页长 + 页内偏移。

考题2（一级页表变换） 页大小1KB，页表{0→5, 1→10, 2→4, 3→8}。逻辑地址3500的物理地址？ 【解】页号=3500/1024=3，偏移=3500−3×1024=428。 物理地址=8×1024+428=8620。 二进制视角：3500=11 0110101100₂（低10位偏移=0110101100=428，高位页号=11=3）→ 物理地址=1000 0110101100₂=8620。∎ （两种算法等价：除法拆分=二进制拆位；页大小为2的幂时永远用拆位。）

P2 二级页表（解决页表太大）：32位、页4KB、页表项4B → 单级页表 2²⁰ 项 = 4MB（又占1K个页框！）→ 二级：页目录(10位) + 页表(10位) + 页内偏移(12位)。 【推导】每页表项4B → 一页装 4KB/4B=1024=2¹⁰ 项 → 页表本身也要分页 → 页目录再索引页表。 【要点】①二级页表页目录常驻内存、页表可换出；②无TLB时访存3次（查页目录、查页表、取数据）；③地址位数计算：二级页表下"单进程最多页表空间"=页目录1页+1024页表页。

考题3（二级页表拆位） 32位系统、页4KB、二级页表（10-10-12）。虚拟地址 0x00403004 的页目录索引、页表索引、页内偏移各是多少？ 【解】0x00403004 = 0000 0000 01 0000 0000 11 0000 0000 0100₂。 页目录索引（高10位）=1；页表索引（中10位）=3；页内偏移（低12位）=4。∎ （模板：页大小4KB→偏移12位；页表项4B→每页表1024项→中间10位；剩余=页目录。）

四、TLB 与有效访存时间（必考计算）

T1 快表TLB：页表项的高速缓存（相联存储器），命中则免查页表。 EAT公式（TLB命中时1次访存取数，未命中2次）： EAT = h·(T_tlb + T_m) + (1−h)·(T_tlb + 2·T_m)

考题4（EAT计算） TLB访问20ns，内存访问100ns，TLB命中率80%。求有效访存时间。 【解】EAT=0.8×(20+100)+0.2×(20+100+100)=96+44=140ns。∎ （若TLB与查页表并行访问：命中=100，未命中=220 → EAT=0.8×100+0.2×220=124ns——题干"并行/串行"决定公式，看清再算。）

五、虚拟内存（请求分页）

V1 传统存储管理的两大缺陷：一次性（全装才跑）、驻留性（跑完才走）→ 虚拟内存：部分装入+请求调页+置换。 V2 局部性原理（虚拟内存可行的理论根基）：时间局部性（刚访问过 soon 再访）+ 空间局部性（相邻地址 soon 被访）。 V3 缺页中断：缺页是内中断（故障），一条指令执行期间可产生并处理多次缺页；处理流程：保留现场→查页表定位→外存调入（无帧则先置换，脏页写回）→更新页表→重新执行被中断指令。 V4 抖动（颠簸）：刚换出的页马上又要访问 → 频繁缺页，CPU大部分时间在换页。原因：分配的页框数 < 工作集；解决：工作集模型（分配≥工作集）、降低多道程序度。

六、置换算法（四大逐页模拟·统一访问串）

访问串：1, 2, 3, 4, 1, 2, 5, 1, 2, 3, 4, 5（3个页框）。

考题5（OPT·理想算法） 淘汰"未来最久不使用"的页。 【解】1F, 2F, 3F, 1F(淘汰未来最不用的3? 未来：4,1,2,5,1,2,3,4,5——3最远) → 帧{1,3,4}? 逐步： - 1F、2F、3F；4：淘汰3（未来最迟用3? 未来访问：4(当前),1,2,5,…，2在位置10、3在位置10? 未来串（4之后）：1,2,5,1,2,3,4,5——3首次出现在第7位，1在第1位，2在第2位 → 淘汰3）→ {4,1,2}； - 1H、2H；5：帧{4,1,2}，未来（5之后）：1,2,3,4,5——4在第4位、1第1位、2第2位 → 淘汰4 → {5,1,2}； - 1H、2H；3F淘汰5（5已用过且最后）→ {3,1,2}? 淘汰5：{1,2,3}；4F淘汰1 → {4,2,3}；5F淘汰2 → {4,3,5}。 缺页=7（3+1+1+1+1），命中5。∎（OPT无法实现，作评价基准。）

考题6（FIFO·Belady异常） 同串、3帧。 【解】队列演变：1,2,3 → 4挤1 → {2,3,4} → 1挤2 → {3,4,1} → 2挤3 → {4,1,2} → 5挤4 → {1,2,5} → 1H、2H → 3挤1 → {2,5,3} → 4挤2 → {5,3,4} → 5H。 缺页=9。 【Belady异常】同串改用4帧：缺页反而变为 10（异常：帧增多缺页增多）——FIFO专属，LRU/OPT无此现象。∎

考题7（LRU·堆栈法演算） 同串、3帧。LRU淘汰"最近最久未使用"。 【解】用栈（栈顶=最近）：1F[1]；2F[2,1]；3F[3,2,1]；4F挤1→[4,3,2]；1F挤2→[1,4,3]；2F挤3→[2,1,4]；5F挤4→[5,2,1]；1H；2H；3F挤5→[3,2,1]；4F挤1→[4,3,2]；5F挤2→[5,4,3]。 缺页=10。∎ （LRU是堆栈算法（栈内容包含关系），无Belady异常——这就是它优于FIFO的理论原因。）

考题8（Clock改进时钟·逐位演算） 同串、3帧、访问位初0、指针从0开始；装入/命中置访问位1；淘汰时扫到访问位0的帧。求缺页数。 【解】指针逐页推进（装入或命中均置1；淘汰后指针指向下一帧）： 1F(f0=1,ref1)、2F(f1=2,ref1)、3F(f2=3,ref1)，指针0； 4：指针扫三帧都ref1→清0回指f0，ref0=0 → 淘汰f0装4(ref1)，指针1；{4,2,3} 1：f1 ref0 → 淘汰f1装1，指针2；{4,1,3} 2：f2 ref0 → 淘汰f2装2，指针0；{4,1,2} 5：扫一圈全1清0 → 回f0 ref0 → 淘汰f0装5，指针1；{5,1,2} 1H（f1 ref置1）、2H（f2 ref置1）； 3：f0 ref0 → 淘汰f0装3，指针1；{3,1,2} 4：f1 ref0 → 淘汰f1装4，指针2；{3,4,2} 5：f2 ref0 → 淘汰f2装5，指针0；{3,4,5} 缺页=10。∎ （Clock是FIFO的改良（给第二次机会），本串下与LRU同为10；改进Clock再引入修改位：优先淘汰（未访问且未修改）页。）

七、考题补遗（2题）

题9（段式与段页式访存次数） 不采用快表时：段式、页式、段页式各需几次访存？ 【答】页式2次（页表+数据）；段式2次（段表+数据）；段页式3次（段表→页表→数据）。快表命中均可降为1次。∎

题10（页表项位数计算） 32位系统、页大小4KB、物理内存4GB。页表项至少多少位？ 【解】页内偏移12位 → 物理页框号=32−12=20位；页表项除页框号还需存取控制位、修改位等（考试答"至少20位"）。单级页表共 2²⁰ 项 → 占 2²⁰×4B=4MB——这正是引入二级页表的原因。∎
