01 行列式与矩阵【数一·数二】

知识点摘要

  • 行列式定义（不同行不同列乘积的代数和）、性质（换行变号、某行乘k、拆分、倍加不变）。
  • 展开定理：按行/列展开；代数余子式（带符号 Aᵢⱼ=(-1)^(i+j)Mᵢⱼ）。
  • 特殊行列式：上三角=对角乘积、范德蒙德、分块行列式 |A 0; C B|=|A||B|。
  • 矩阵运算：加法、数乘、乘法（不交换、无消去律）、转置、幂。
  • 逆矩阵：定义 AB=E；可逆⇔|A|≠0；(AB)⁻¹=B⁻¹A⁻¹；(Aᵀ)⁻¹=(A⁻¹)ᵀ。
  • 伴随矩阵 A：AA=|A|E；A⁻¹=A/|A|；|A|=|A|^(n-1)；r(A*) 规律。
  • 初等变换与初等矩阵；等价标准形；矩阵的秩（子式/行简化定义）。
  • 分块矩阵运算（高频技巧：分块求逆、按行/列分块）。

公式定理

  • |kA|=kⁿ|A|；|AB|=|A||B|；|Aᵀ|=|A|。
  • (A) = |A|^(n-2) A；|A|=|A|^(n-1)；A=|A|A⁻¹（A可逆时）。
  • r(A+B)≤r(A)+r(B)；r(AB)≤min(r(A),r(B))；A列满秩⇒r(AB)=r(B)。
  • 秩1矩阵：A=αβᵀ ⇒ Aⁿ=(βᵀα)^(n-1)A。

常见题型

  1. 数值/抽象行列式计算（性质化简、展开、加边法、递推）。
  2. 代数余子式求和（构造新行列式：把某行/列换成全1等）。
  3. 求逆矩阵（初等行变换 [A|E]→[E|A⁻¹]；或 A* 公式；或定义 AB=E）。
  4. 解矩阵方程 AX=B（注意 A 可逆才可除；左乘右乘方向）。
  5. 求秩/参数问题（初等变换化行最简）。
  6. Aⁿ 计算（秩1公式、对角化预告、递推、拆分 A=B+λE）。

易错点

  • 乘法不可交换：BA≠AB；(A+B)² ≠ A²+2AB+B²（除非可交换）。
  • |A+B| ≠ |A|+|B|。
  • A=伴随：元素是"代数余子式"且转置摆放（Aᵢⱼ=Aⱼᵢ）。
  • 行变换求逆只能用行变换（列变换会错位）。
  • r(AB) 相关等式有前提（如 A 列满秩），乱用会错。
  • 奇数阶正交矩阵 |A|=±1 之类结论记住条件。

自测题（3道）

  1. 设 A 为3阶，|A|=2，求 |2A⁻¹-A|。（提示 A=|A|A⁻¹）
  2. A²-A=E，证明 A 可逆并求 A⁻¹。
  3. 求 |A|：A=[[1,1,1],[1,2,3],[1,3,6]]。

答案 1. |2A⁻¹-A|=|2A⁻¹-2A⁻¹|=0？——注意 A=2A⁻¹ ⇒ 原式=|2A⁻¹-2A⁻¹|=|0|=0。 2. A²-A=E ⇒ A(A-E)=E ⇒ A⁻¹=A-E。 3. R2←R2-R1、R3←R3-R1 化为上三角 [[1,1,1],[0,1,2],[0,2,5]] ⇒ |A| = 1×(1×5-2×2) = 1。

02 向量组与线性方程组【数一·数二】

知识点摘要

  • n维向量：线性组合、线性表示；向量组线性相关/无关的定义与判定。
  • 相关性结论：向量组部分相关⇒整体相关；整体无关⇒部分无关；n+1个n维向量必相关。
  • 极大线性无关组与向量组的秩；等价向量组。
  • 齐次方程组 Ax=0：基础解系；解空间维数 = n - r(A)。
  • 非齐次 Ax=b：有解⇔r(A)=r(A|b)；通解=特解+齐次通解。
  • 解的性质：齐次解的和/倍仍是解；非齐次两解之差是齐次解。
  • 【数一】向量空间：基、维数、坐标、过渡矩阵；施密特正交化、正交矩阵。

公式定理

  • 线性相关 ⇔ r(α₁,…,αₛ) < s ⇔ 存在不全为零的系数使 Σkᵢαᵢ=0。
  • 向量组Ⅰ可由Ⅱ线性表示 ⇒ r(Ⅰ)≤r(Ⅱ)。
  • 克拉默法则（方阵且|A|≠0）：xᵢ=|Aᵢ|/|A|。
  • Ax=0 仅有零解 ⇔ r(A)=n（方阵时 ⇔ |A|≠0）。
  • r(A|b)=r(A)=n 唯一解；=r(A)<n 无穷多解；r(A)<r(A|b) 无解。

常见题型

  1. 抽象向量组线性相关性证明（定义法、秩、反证）。
  2. 含参数向量组求极大无关组并把其余向量表示出来（行变换 AX=0）。
  3. 含参数方程组解的讨论（三种情形：无解/唯一/无穷）。
  4. 两个方程组公共解、同解问题（r 相等 + 解代入）。
  5. 解的结构：由 Aξᵢ=b 的解信息求通解（解的差=齐次解）。
  6. 【数一】过渡矩阵与坐标变换、正交化。

易错点

  • "α₁,…,αₛ 线性相关" 与 "任一向量可由其余表示"：前者⇒"存在"某个向量可表示，不是"任意"。
  • 方程组有解的判定用增广矩阵秩，别只算 r(A)。
  • 基础解系要求：线性无关 + 每个都是解 + 个数 n-r(A)（个数写全）。
  • 行变换后向量组的对应关系要按列跟踪（解 X=0 时的系数）。
  • 同解⇒解空间相同⇒r(A)=r(B)=r(A|B)（齐次情形 r(A)=r(B)=n-r解空间）。

自测题（3道）

  1. α₁=(1,2,3), α₂=(2,4,6), α₃=(1,1,1)：判断相关性并求极大无关组。
  2. 设 A 为4×3矩阵，r(A)=2，η₁,η₂ 是 Ax=0 的两个无关解，ξ 是 Ax=b 的解，写出通解结构（b有解时）。
  3. a 为何值时方程组 x+y+z=1, ax+y+z=1, x+y+az=1 无解/唯一解/无穷解？

答案 1. α₂=2α₁ 相关；极大无关组 {α₁,α₃}，α₂=2α₁+0·α₃（r=2）。 2. 先校验：n-r(A)=3-2=1，基础解系只有1个向量，题设“两个无关解”不成立。正确通解：ξ + k·η（k∈R）。考点=先算 n-r 再写通解结构。 3. 系数行列式 = (a-1)(a-1)；a≠1 唯一解（x=y=z=1/3 另算）；a=1 时三方程同为 x+y+z=1 ⇒ 无穷多解；无解情形不存在（增广恒一致）。结论：a≠1唯一，a=1无穷，不存在无解。

03 特征值、特征向量与二次型【数一·数二】

知识点摘要

  • 特征值/特征向量定义 Aξ=λξ（ξ≠0）；特征方程 |λE-A|=0。
  • 特征值性质：Σλᵢ=tr(A)；Πλᵢ=|A|；kA、Aᵐ、A⁻¹、A*、f(A) 的特征值；A 与 Aᵀ 特征值相同。
  • 不同特征值的特征向量线性无关；k重特征值的无关特征向量个数 ≤ k。
  • 相似定义 P⁻¹AP=B；相似的必要条件（秩、行列式、迹、特征多项式、秩r(λE-A)全同）。
  • 可对角化条件：n阶A有n个线性无关特征向量 ⇔ 每个 kᵢ 重特征值有 kᵢ 个无关特征向量；实对称矩阵必可对角化且可用正交矩阵。
  • 实对称：不同特征值的特征向量自动正交。
  • 二次型：矩阵表示（对称矩阵）、合同变换、标准形（配方/正交变换）、规范形。
  • 惯性定理；正定判定（顺序主子式全正 / 特征值全正 / 正惯性指数=n / 与E合同）。

公式定理

  • f(A) 的特征值 = f(λ)（多项式情形）；A⁻¹ 的特征值 = 1/λ；A* 的 = |A|/λ。
  • 正交相似对角化：QᵀAQ=Λ，Q 的第 i 列 = λᵢ 的单位化特征向量。
  • A~B 且可对角化 ⇒ Aᵐ = PΛᵐP⁻¹（求 Aⁿ 的标准方法）。
  • 合同：CᵀAC；正交变换既是相似又是合同。

常见题型

  1. 求数值矩阵/含参矩阵的特征值与特征向量（先算特征多项式；重根时小心无关个数）。
  2. 由特征值/特征向量反求矩阵 A 或参数（用 Aξ=λξ 联立）。
  3. 判定/证明可对角化；求 P 使 P⁻¹AP=Λ。
  4. 求正交矩阵 Q 化 A 为对角形（施密特正交化重根向量）。
  5. 用相似求 Aⁿ、|A+E| 等。
  6. 二次型化标准形/规范形；判定正定；由正定反求参数范围。

易错点

  • 特征向量 ξ≠0：λ=0 只要有非零特征向量就合法（|A|=0 ⇒ 0是特征值）。
  • 不同特征值的特征向量线性无关，但同一特征值的不同特征向量的线性组合仍是该值的特征向量（≠0时）。
  • 相似的必要条件可以用来"排除"，但要证相似还得找 P（或同为实对称且特征值相同）。
  • 正交化顺序：先对重特征值内部的向量正交化，再单位化；不同特征值间天然正交（实对称）。
  • 二次型的矩阵必须是对称矩阵（先把交叉项系数折半放对角外）。
  • 正定前提：二次型矩阵对称；顺序主子式判别法适用于对称矩阵。

自测题（3道）

  1. A=[[2,0,0],[0,3,1],[0,1,3]]，求特征值。
  2. 设 Aξ=2ξ（ξ≠0），求 A²-3A+2E 的特征值，判断 A 是否可逆。
  3. 判定 f=x₁²+2x₂²+x₃²+2x₁x₂ 的正定性。

答案 1. 块结构：λ=2；2×2块 [[3,1],[1,3]] 特征值 4, 2 ⇒ λ=2,2,4。 2. f(2)=4-6+2=0；且0是特征值⇒|A|=0⇒A不可逆。 3. 矩阵 [[1,1,0],[1,2,0],[0,0,1]]：顺序主子式 1, 1, 1 全正 ⇒ 正定。

线代 · 难点专攻

1. 含参方程组讨论流程

方阵先算 |A|：|A|≠0 → 唯一解；|A|=0 → 代回逐值讨论 r(A) 与 r(A|b)。非方阵不能算行列式，只能初等行变换讨论秩。参数是字母时，行变换除以含参式前必须“讨论该式是否为零”。

2. 可对角化判定流程图

n 个互异特征值 → 必可对角化。有重根 λ₀（k重）→ 算 n−r(λ₀E−A) 是否等于 k（等于才可对角化）。实对称矩阵 → 必可对角化，且可正交对角化（重根内部先施密特正交化）。

3. 由相似反求参数

用两条方程：tr(A)=tr(B) 与 |A|=|B| 联立解参数；解出的参数必须回验全部特征值一致（tr/|A| 只是必要条件）。

4. 正定型含参题

先把二次型写成对称矩阵（交叉项系数折半放对称位置）→ 顺序主子式全>0 → 从一阶主子式开始逐级解参数范围（不等式组取交集）。

5. 求 Aⁿ 的四种武器

秩1公式 (βᵀα)ⁿ⁻¹A；对角化 A=PΛP⁻¹；拆分 A=B+λE 用二项式（B²=0 型）；递推 A²=cA+dE。
