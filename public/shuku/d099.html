英语一 · 熟词僻义与固定搭配

阅读读不懂，一半是长难句，另一半就是熟词僻义——认识的词用了不认识的意思。本文件收录真题高频熟词僻义（附语境例句）、固定搭配、易混词辨析。每天20个，两周过一轮，配合《考研核心单词》。 例句均为真题风格自编句（非真题原文），展示用法即可。

04 易混词辨析（20组）

  1. comprise / compose：A comprises B（A包含B，不用of）；B be composed of A? —— A consist of B = A be composed of B = B make up A；comprise主动：The committee comprises seven members.
  2. affect / effect：affect（v.影响）；effect（n.影响）；effect做动词="实现"（effect change）。
  3. adapt / adopt / adept：适应 / 采纳收养 / 熟练的。
  4. principal / principle：主要的；本金 / 原则。
  5. complement / compliment：补充 / 赞美。
  6. stationary / stationery：静止的 / 文具。
  7. disinterested / uninterested：公正无私的 / 不感兴趣的。
  8. economic / economical：经济的 / 节俭的。
  9. historic / historical：具有历史意义的 / 与历史有关的。
  10. considerable / considerate：相当大的 / 体贴的。
  11. imaginable / imaginary / imaginative：可想象的 / 想象中的 / 富于想象力的。
  12. intelligent / intelligible：聪明的 / 可理解的。
  13. approve of（赞成）/ approve（批准）。
  14. assure（使人确信，assure sb.）/ ensure / insure：确保（事实）/ 投保。
  15. attribute to（归因于）/ contribute to（贡献；导致）/ distribute（分配）。
  16. inflation（通胀）/ deflation（通缩）/ recession（衰退）/ depression（萧条）——阅读经济类常客。
  17. immune to（免疫于）/ immune from（免除于，法律）。
  18. liable to（易于）/ liable for（对…负责）。
  19. speculation（投机；推测）/ manipulation（操纵）/ regulation（监管）。
  20. disinterested party（公正方）/ third party（第三方）/ stakeholders（利益相关者）。

  1. 熟词僻义只在语境里记得住：把例句读出声，用"僻义"造一个自己的句子。
  2. 每次做阅读遇到"认识但读不通"的词→立刻查本文件→没有则补录（标注出处年份）。
