一、选择题（每题只选一个正确项）

C1. 下列程序段的时间复杂度：i=1; while(i<=n) i=i*2; A. O(n) B. O(logn) C. O(nlogn) D. O(√n)

B。i 每次翻倍，执行 ⌈log₂n⌉ 次。

C2. 入栈序列 1,2,3,4，不可能的出栈序列是： A. 1234 B. 4321 C. 3142 D. 4132

D。4 先出说明 1,2,3 都在栈内且从上到下为 3,2,1，之后只能出 3——出 1 不可能。

C3. 循环队列数组大小 M=8（牺牲一格判满），front=5，元素个数 3，则 rear=？最多还能入队几个？ A. 0，4 B. 0，3 C. 2，4 D. 8，5

A。rear=(5+3)%8=0；最多存 M−1=7 个，还可入 7−3=4 个。

C4. 一棵二叉树有 10 个度为 2 的结点，则叶结点数为： A. 9 B. 10 C. 11 D. 12

C。n₀=n₂+1=11。

C5. n 个顶点的无向强连通图最少有多少条边（有向图强连通最少边数）？ A. n B. n−1 C. n+1 D. 2n

A。n 条边构成一个有向环。

C6. 下列排序中不稳定且平均时间复杂度 O(nlogn) 的是： A. 冒泡排序 B. 归并排序 C. 快速排序 D. 直接插入排序

C。快排平均 O(nlogn) 且不稳定（另两个不稳定的是希尔、选择、堆排，平均不是 O(nlogn) 的只有希尔/选择）。

C7. 对 1000 个元素的有序表折半查找，最多比较次数： A. 8 B. 9 C. 10 D. 11

C。⌈log₂(1000+1)⌉=10。

C8. 哈希表长 13，已存 8 个元素，装填因子为： A. 8/13 B. 13/8 C. 0.5 D. 与冲突有关

A。α=8/13≈0.615，与冲突处理方式无关。

C9. 3阶B树中，非根非叶结点至少有： A. 1个关键字 B. 2个关键字 C. 2棵子树且2个关键字 D. 3个关键字

A。⌈3/2⌉−1=1 个关键字（即 2 棵子树）。注意问的是关键字数。

C10. 拓扑排序输出顶点数少于 n，说明： A. 图不连通 B. 图中有环 C. 图是完全图 D. 算法有误

B。AOV 网有环时拓扑排序无法输出全部顶点。

二、应用演算题（必须写过程）

A1.★ 关键字序列 {53, 27, 36, 15, 69, 42}（下标1起）： (1) 建大根堆（写出每步）；(2) 输出堆顶后重建堆的结果。

(1) 从 i=⌊6/2⌋=3 起：i=3（36）：孩子无 → 不动；i=2（27）：与较大孩子 69 交换 → [53,69,36,15,27,42]；i=1（53）：孩子 69 → 交换 → [69,53,36,15,27,42]，53 在位2与孩子 27,42 比：42 大 → 交换 → [69,42,36,15,27,53]。 (2) 堆顶69与末尾53交换并尺寸减1后，53 下沉：与 42? 53>42 → [53,42,36,15,27] 已是堆。

A2.★★ 频率 {a:5, b:3, c:2, d:1, e:1} 构造哈夫曼树，求 WPL 及各字符编码（左0右1）。

合并：1+1=2(d,e)，2+2=4(c,de)，4+3=7(b,·)，7+5=12。树高：a=1, b=2, c=3, d=e=4。 WPL=5×1+3×2+2×3+1×4+1×4=25（校验：非叶结点值之和 2+4+7+12=25 ✓）。编码（左0右1，一种）：a=0，b=10，c=110，d=1110，e=1111。

A3.★★ 模式串 "abaabc"：分别按严蔚敏口径（next[1]=0）和王道口径（next[1]=0 记最长相等前后缀）求 next 数组与 nextval。

严口径 next（j:1..6）：0 1 1 2 2 3。 逐位验证：j=3 时前2位"ab"无相等前后缀→1；j=4 前3位"aba"→"a"长度1→2；j=5 "abaa"→"a"→2；j=6 "abaab"→"ab"→3。 nextval：s= a b a a b c。j=1:0；j=2: s2=b vs s1=a 不同→1；j=3: s3=a vs s1=a 相同→nextval[1]=0；j=4: s4=a vs s2? next[4]=2→s2=b 不同→next[4]=2；j=5: next[5]=2→s2=b，s5=b 相同→nextval[2]=1；j=6: next[6]=3→s3=a，s6=c 不同→3。 nextval = 0 1 0 2 1 3。

A4.★★★ 有向图 V={A,B,C,D,E}，边权：A→B=2, A→C=5, B→C=1, B→D=4, C→D=1, C→E=7, D→E=3。用 Dijkstra 求 A 到各点最短路（写每轮表）。

初始：dist B=2, C=5, D=∞, E=∞。 第1轮定 B(2)：松弛 C=min(5,2+1)=3，D=2+4=6。 第2轮定 C(3)：松弛 D=min(6,3+1)=4，E=3+7=10。 第3轮定 D(4)：松弛 E=min(10,4+3)=7。 第4轮定 E(7)。 结果：B=2(A), C=3(A-B), D=4(A-B-C), E=7(A-B-C-D)。

A5.★★ 无向图边权 (A,B)=1, (B,C)=2, (A,C)=3, (C,D)=4, (B,D)=5, (D,E)=6, (A,E)=8： (1) Kruskal 求最小生成树；(2) 从 A 出发 Prim 的加边顺序。

(1) 排序选边：AB(1)✓, BC(2)✓, AC(3)✗(成环), CD(4)✓, BD(5)✗, DE(6)✓ → MST边 AB,BC,CD,DE，权13。 (2) Prim 从A：加B(1)→加C(2)→加D(4)→加E(6)（同树）。

A6.★★ 哈希 H(k)=k%7，表长7，线性探测。依次插入 14, 21, 28, 35。求成功 ASL 与失败 ASL。

14→0；21→0冲突→1；28→0,1冲突→2；35→0,1,2冲突→3。 成功 ASL=(1+2+3+4)/4=2.5。 失败 ASL：各地址探测到空位长度：H0→空在4（探0,1,2,3共4次）；H1→3；H2→2；H3→1；H4→1；H5→1；H6→1 → (4+3+2+1+1+1+1)/7=13/7≈1.86。

A7.★★ 序列 {49, 38, 65, 97, 76, 13, 27}：写出快速排序（首元素为基准）第一趟结果和堆排序建初始堆结果。

快排一趟：49 归位下标4 → [27,38,13,49,76,97,65]。 建堆（下标1起，从 i=⌊7/2⌋=3）：i=3(65)：孩子97 → 交换 → [49,38,97,76,76?] 逐步：…最终 [97,76,65,49,38,13,27]（大根堆，验证：97≥76,65；76≥49,38；65≥13,27）。

A8.★ 序列 4,7,2,1,5,3,6 依次入 BST：画出树，求成功 ASL。

根4；2左7右；1(2左)5(7左)3(2右)6(7右)。深度：4→1；2,7→2；1,3,5,6→3。 ASL=(1·1+2·2+3·4)/7=17/7≈2.43。

A9.★ 循环队列（牺牲单元，M=10）：front=3 时入队 5 个元素再出队 2 个，rear 与元素数？

rear=(3+5)%10=8；出队2个 front=5；元素数=(8−5+10)%10=3。

A10.★★ 对称矩阵（1-based，按行存下三角，i≥j）：a[4][3] 与 a[3][4] 存到一维数组第几位？

下三角只存 i≥j：a[4][3] → k=4·3/2+3−1=8；a[3][4]（上三角元素）与 a[4][3] 对称同值 → 也存于8。

A11.★★★ 依次插入 1,2,3,4,5 到空 3阶B树，写出每次分裂后的树。

1,2 → [1,2]；插3：[1,2,3]溢出 → 中点2上移：根[2]，叶[1],[3]；插4：右叶[3,4]；插5：[3,4,5]溢出 → 中点4上移：根[2,4]，叶[1],[3],[5]。 最终：根[2,4]，三个叶[1],[3],[5]。

A12.★ AOV 网边：1→2, 1→3, 2→4, 3→4, 4→5。写出所有拓扑序列并判断唯一性。

三、算法设计题（C语言，按"思想→代码→复杂度"给分）

S1.★★ 将带头结点单链表 L 就地逆置。

void Reverse(LinkList L){
    LNode *p=L->next, *q;
    L->next=NULL;                 /* 摘下首结点当空表 */
    while(p){ q=p->next;          /* 保存后继 */
        p->next=L->next; L->next=p; p=q; }  /* 头插 */
}   /* O(n)，O(1) */

S2.★★ 合并两个有序单链表 A、B（带头结点）为有序表 C，不新建结点。

LNode* Merge(LinkList A, LinkList B){
    LNode *C=(LNode*)malloc(sizeof(LNode)), *r=C;
    LNode *p=A->next, *q=B->next;
    while(p&&q){
        if(p->data<=q->data){ r->next=p; r=p; p=p->next; }
        else { r->next=q; r=q; q=q->next; }
    }
    r->next = p?p:q;
    return C;
}   /* O(m+n) */

S3.★★ 求二叉树深度（递归）。

int Depth(TNode *t){
    if(!t) return 0;
    int l=Depth(t->lchild), r=Depth(t->rchild);
    return (l>r?l:r)+1;
}   /* O(n) */

S4.★★★ 判断二叉树是否为二叉排序树（利用中序递增）。

/* 全局或引用参数 prev 记中序前驱值 */
int Check(TNode *t, int *prev){
    if(!t) return 1;
    if(!Check(t->lchild, prev)) return 0;
    if(*prev!=-100000 && t->data<=*prev) return 0;  /* 需严格递增 */
    *prev=t->data;
    return Check(t->rchild, prev);
}
/* 调用：int prev=-100000; Check(root,&prev); */  /* O(n) */

第一章扩充题（15题，2026-10-28夜间）

  1. 写出大 O 记号的形式化定义。

    T(n) ≤ c·f(n)（n≥n₀，c>0）——O(f(n)) 是增长率的渐近上界，忽略常数与低阶项。

  2. 按增长率从小到大排序：O(1)、O(logn)、O(n)、O(nlogn)、O(n²)、O(n³)、O(2ⁿ)、O(n!)。

    O(1)<O(logn)<O(n)<O(nlogn)<O(n²)<O(n³)<O(2ⁿ)<O(n!)。对数 < 幂 < 指数 < 阶乘。

  3. 分析：i=0; while(i<n) i=i+3;

    循环 ⌈n/3⌉ 次 → O(n)。步长常数不影响阶。

  4. 分析：for(i=1;i<=n;i++) for(j=1;j<=2^i;j++) x++;

    Σ2ⁱ = 2^{n+1}−2 → O(2ⁿ)。内层次数指数增长。

  5. 分析递归 T(n)=T(n/2)+1。

    每层代价 O(1)、层数 log₂n → O(logn)（折半查找就是这个模型）。

  6. 分析递归 T(n)=2T(n/2)+n。

    递归树：每层 n、共 log₂n 层 → O(nlogn)（归并/快排的平衡情形）。

  7. 分析递归 T(n)=T(n−1)+n。

    Σn → O(n²)（递归版插入排序/选择）。

  8. 算法空间复杂度如何计？递归呢？

    额外辅助空间；递归计栈最大深度。原地算法=O(1)。

  9. 数据结构三要素？

    逻辑结构、存储结构、数据的运算（运算的定义在逻辑结构上，实现在存储结构上）。

  10. 逻辑结构分哪四类？

    集合、线性、树形（一对多）、图形（多对多）。

  11. 存储结构主要有哪些？

    顺序、链式、索引、散列。同一逻辑结构可用不同存储实现，效率不同。

  12. 算法的五个重要特性？

    有穷性、确定性、可行性、输入（≥0）、输出（≥1）。

  13. 好算法的目标？

    正确性、可读性、健壮性、高效率（时间+空间）。

  14. 判断：算法的时间复杂度与编程语言、编译器有关。

    错——大 O 只与问题规模和算法策略有关；同一算法用任何语言实现阶不变。

  15. 为什么复杂度要分最好/最坏/平均？举一例。

    基本操作次数随输入不同而变。例：快排平均 O(nlogn) 但基本有序时最坏 O(n²)；冒泡基本有序时最好 O(n)。

第二章扩充题（15题，2026-10-28夜间）

  1. 顺序表三种基本运算的复杂度：按位查找、插入、删除？

    O(1)、O(n)（平均移动 n/2）、O(n)（平均移动 (n-1)/2）。

  2. 什么场景选顺序表，什么场景选链表？

    频繁按位访问/长度稳定→顺序表；频繁插删/长度剧变/未知→链表。

  3. 单链表带头结点的三个好处？

    ①首元插删与中部统一，②空表非空表处理统一，③头指针永不指向数据结点（参数传递安全）。

  4. 设尾指针 rear 的循环单链表有什么优势？

    尾部插入 O(1)、首端插入 O(1)（rear->next 即头），两链表合并 O(1)（交换指针段）。

  5. 循环单链表判空、判尾的条件？

    判空 L->next==L；判尾 p->next==L。

  6. 双链表解决单链表什么缺陷？代价？

    找前驱 O(1)（单链表 O(n)）；代价：每结点多一个指针、插删各多维护两条链。

  7. 静态链表是什么？何时用？

    数组模拟链表：游标（下标）代替指针。不支持指针的语言/需要连续存储预分配的场景。

  8. 推导顺序表插入平均移动次数。

    插到第 i 位移动 n-i+1 个，i=1..n+1 等概率：(Σ(n-i+1))/(n+1) = n/2。

  9. 算法题：有序顺序表插入 x 保持有序（找不到则留原地）。

    从后往前找第一个 <x 的元素，其后整体右移一位再插入，O(n)。

  10. 算法题：无序顺序表删除所有值重复的元素（保留首个）。

    双层循环 O(n²)：外层锚定 a[i]，内层删后续与它相等的元素；或先排序 O(nlogn) 再有序去重 O(n)（会改变原顺序）。

  11. 算法题：单链表找最大值结点，并将该结点移到表头。

    一趟记录最大值及其前驱；摘下该结点，头插到头结点后，O(n)、O(1)。

  12. 算法题：将两个循环单链表（各带尾指针 ra、rb）合并为一个循环链表，要求 O(1)。

    暂存 ha=ra->next, hb=rb->next；ra->next=hb; rb->next=ha。两条链首尾相接，返回 rb。

  13. 算法题：将带头结点单链表按值划分为"值<0"与"值≥0"两段（相对次序不变）。

    见代码题 C24：原链串负数段，辅助链尾插非负段，O(n)、O(1)。

  14. 判断：顺序表支持随机存取，链表是顺序存取。

    对——顺序表 data[i] 直接 O(1)；链表必须从头沿指针走。

  15. 算法题：已知单链表中某结点指针 p（非尾结点），要求 O(1) 删除它。

    复制后继数据到 p（p->data = p->next->data），删除 p 的后继。"删除结点"实为"删除数据"。

B1.★★ 顺序表含 n 个整数，删除其中值在 [s,t]（s<t）区间的所有元素（s、t为给定参数）。要求 O(n)、O(1) 空间。

思想：一遍扫描，把不在区间内的元素前移覆盖。

int DelRange(SqList *L, int s, int t){
    int w=0;
    if(L->len==0 || s>=t) return 0;        /* 非法/空表 */
    for(int i=0;i<L->len;i++)
        if(L->data[i]<s || L->data[i]>t)   /* 保留区外元素 */
            L->data[w++]=L->data[i];
    L->len=w; return 1;
}   /* O(n), O(1) */

B2.★★ 带头结点单链表，按序号奇偶拆成两个链表（奇位元素保持相对次序留在A，偶位放入新表B）。

思想：遍历计数，尾插法分别接两个尾指针。

void Split(LinkList A){
    LinkList B=(LNode*)malloc(sizeof(LNode)); B->next=NULL;
    LNode *ra=A, *rb=B, *p=A->next;  int i=1;
    A->next=NULL;
    while(p){
        LNode *q=p->next;                 /* 摘下p */
        if(i%2==1){ ra->next=p; ra=p; }
        else      { rb->next=p; rb=p; }
        p=q; i++;
    }
    ra->next=rb->next=NULL;
}   /* O(n) */

B3.★★★（2015真题变体）带头结点单链表，删除表中绝对值相等的冗余结点（只保留首次出现），|data|≤m。要求尽量高效。

思想：辅助数组 flag[1..m] 标记已出现绝对值，一遍扫描。O(n) 时间、O(m) 空间。

void DelAbs(LinkList L, int m){
    int *flag=(int*)calloc(m+1,sizeof(int));
    LNode *p=L, *q;                        /* p指向待查结点的前驱 */
    while(p->next){
        int v=abs(p->next->data);
        if(flag[v]==0){ flag[v]=1; p=p->next; }
        else { q=p->next; p->next=q->next; free(q); }
    }
    free(flag);
}

B4.★★ 递增有序数组 A[0..n−1]，设计算法找出一对和为 x 的元素（存在则返回下标对）。

思想：双指针——i=0、j=n−1，和小于x则i++，大于则j−−。O(n)、O(1)。

int TwoSum(int A[], int n, int x, int *i, int *j){
    int l=0, r=n-1;
    while(l<r){
        long s=(long)A[l]+A[r];
        if(s==x){ *i=l; *j=r; return 1; }
        if(s<x) l++; else r--;
    }
    return 0;
}

B5.★★★（2014真题）二叉树结点含权值域 weight，计算所有叶结点带权路径长度之和 WPL（权×到根路径长度）。

思想：先序递归，参数 depth 记当前深度；到叶则累计 weight×depth。O(n)。

long WPL(BiTree T, int depth){          /* 调用 WPL(root,0) */
    if(!T) return 0;
    if(!T->lchild && !T->rchild)
        return (long)T->weight * depth;
    return WPL(T->lchild, depth+1) + WPL(T->rchild, depth+1);
}

B6.★★ 判断无向图 G(n个顶点，邻接表存储) 是否为一棵树。

思想：两个条件缺一不可——①边数恰为 n−1；②从顶点0出发 DFS/BFS 能访问全部 n 个顶点（连通）。

int visited[MAX], cnt=0;
void DFS(ALGraph *G,int v){ visited[v]=1; cnt++;
    for(ArcNode *p=G->adj[v].first;p;p=p->next)
        if(!visited[p->adjvex]) DFS(G,p->adjvex);
}
int IsTree(ALGraph *G){
    if(G->e != G->n-1) return 0;        /* 边数 */
    memset(visited,0,sizeof(visited)); cnt=0;
    DFS(G,0);
    return cnt==G->n;                    /* 连通 */
}

思想：栈保存 (结点, 右孩子是否已访问) 标志；或用"最后访问指针"法（下面采用）：仅当右孩子为空或刚被访问过时才访问本结点。

void PostOrder(BiTree T){
    BiTree stk[100]; int top=-1;
    BiTree p=T, last=NULL;
    while(p || top>=0){
        if(p){ stk[++top]=p; p=p->lchild; }      /* 左链入栈 */
        else{
            p=stk[top];
            if(p->rchild && p->rchild!=last)      /* 右子树未走 */
                p=p->rchild;
            else{
                visit(p); last=p; top--; p=NULL;  /* 访问并回溯 */
            }
        }
    }
}   /* O(n), O(h) */

B8.★★ 顺序表元素只含 0、1、2，设计一趟扫描的算法使全部0在前、2在后（荷兰国旗问题）。

思想：三指针——k0 指向0区末尾、k2 指向2区开头、cur 扫描；遇0与k0交换、遇2与k2交换（交换来的数再判一次，故cur不前进）。

void Flag(int a[], int n){
    int k0=0, k2=n-1, cur=0;
    while(cur<=k2){
        if(a[cur]==0)      swap(&a[cur++], &a[k0++]);
        else if(a[cur]==2) swap(&a[cur], &a[k2--]);   /* 换来的数需再看，cur不动 */
        else cur++;
    }
}   /* O(n), O(1) */

B9.★★ 在带头结点单链表中删除所有值为 x 的结点：(1) 递归版；(2) 非递归版。

/* (1) 递归（栈深O(n)） */
void DelX(LinkList L, int x){          /* L为当前结点的前驱 */
    if(!L->next) return;
    if(L->next->data==x){
        LNode *q=L->next; L->next=q->next; free(q);
        DelX(L,x);
    } else DelX(L->next,x);
}
/* (2) 非递归（前驱指针法，O(n)、O(1)） */
void DelX2(LinkList L, int x){
    LNode *p=L, *q;
    while(p->next){
        if(p->next->data==x){ q=p->next; p->next=q->next; free(q); }
        else p=p->next;
    }
}

B10.★★★ 求二叉树中两个结点 p、q 的最近公共祖先。

思想：后序递归——若当前结点为空/p/q 则返回之；左右子树各自返回结果，两侧都非空 ⇒ 当前结点即最近公共祖先；否则向上传递非空的一侧。O(n)。

BiTree LCA(BiTree T, BiTree p, BiTree q){
    if(!T || T==p || T==q) return T;
    BiTree L=LCA(T->lchild,p,q), R=LCA(T->rchild,p,q);
    if(L && R) return T;               /* 分居两侧 */
    return L ? L : R;
}
