§1 数项级数概念与性质（S1–S15）

S1.★ 级数收敛的定义。

部分和数列 Sₙ 的极限存在（有限）。判敛先想部分和。

S2.★ 收敛的必要条件与经典反例。

通项 uₙ→0。反之不成立：调和级数 Σ1/n 通项→0 但发散。

S3.★ 增删有限项对敛散性的影响： A. 可能改变 B. 不改变敛散性（和可能变） C. 必发散 D. 和不变

B。前面有限项是常数；若收敛则和会变，发散依旧发散。

S4.★ 求 Σ 1/[n(n+1)]。

裂项：1/[n(n+1)] = 1/n − 1/(n+1)，部分和 = 1 − 1/(n+1) → 1。

S5.★ 求 Σ 1/[(2n−1)(2n+1)]。

裂项 ½[1/(2n−1) − 1/(2n+1)] ⇒ 部分和 = ½(1 − 1/(2n+1)) → 1/2。

S6.★ 等比级数 Σaq^{n−1} 的敛散与求和。

|q|<1 收敛，和 = a/(1−q)；|q|≥1 发散（q=1 时通项不趋0，q=−1 时部分和振荡）。

S7.★ 调和级数 Σ1/n 是否收敛？

发散（部分和超过 1+½+½+⋯，按 2^k 分组每组和 >½）。它是"通项趋0仍发散"的招牌。

S8.★ p-级数 Σ1/n^p 的敛散。

p>1 收敛，p≤1 发散。p=1 临界，p=2 与 p=1/2 是两大代表。

S9.★ Σ1/√n 敛散性。

p=1/2<1 ⇒ 发散（比较 1/n 知它比调和"略好"但不够）。

S10.★ 求 Σ (1/2ⁿ + 1/3ⁿ)（n≥1）。

两收敛级数逐项相加：1 + 1/2 = 3/2。

S11.★ 收敛级数加括号后： A. 可能发散 B. 仍收敛且和不变 C. 变 D. 无法判断

B。括号部分和是原部分和的子列。去括号则不然（(1−1)+(1−1) 收敛，去括号发散）。

S12.★ 通项中出现 n! 或 qⁿ 时优先想什么判别法？

比值判别法（阶乘/指数增长快）；幂形式 (aₙ)ⁿ 优先根值法。

S13.★ 通项 uₙ 有界能否保证收敛？

不能——uₙ=1 有界但级数发散。必要条件是"趋 0"，有界远弱于此。

S14.★ 判别 Σ n/(n³+1)。

~1/n²（抓主部）⇒ 收敛（比较判别法）。

S15.★ 两个收敛级数逐项相减得到： A. 发散 B. 收敛 C. 不定 D. 条件收敛

B。线性组合保持收敛。收敛−发散=发散才是要防的坑。

§2 正项级数判别（S16–S40）

S16.★ 比较判别法极限形式的内容。

aₙ,bₙ>0 且 lim aₙ/bₙ = c：0<c<+∞ ⇒ 同敛散；c=0 时 b 收敛⇒a 收敛；c=∞ 时 b 发散⇒a 发散。

S17.★ 判别 Σ sin(1/n)。

sin(1/n) ~ 1/n ⇒ 发散（与调和同敛散）。

S18.★ 判别 Σ 1/[n√(n+1)]。

~ 1/n^{3/2} ⇒ 收敛（p=3/2>1）。

S19.★★ 判别 Σ n!/nⁿ。

比值：aₙ₊₁/aₙ = [（n+1)!/（n+1)^{n+1}]·[nⁿ/n!] = (n/(n+1))ⁿ → 1/e < 1 ⇒ 收敛。

S20.★ 判别 Σ n!/10ⁿ。

比值 = (n+1)/10 → +∞ ⇒ 发散。

S21.★★ 判别 Σ (2n)!/(n!)²。

比值 = (2n+2)(2n+1)/(n+1)² → 4 > 1 ⇒ 发散（中心二项式系数级数）。

S22.★★ 判别 Σ [n/(2n+1)]ⁿ。

根值：aₙ^{1/n} = n/(2n+1) → 1/2 < 1 ⇒ 收敛。

S23.★★ 判别 Σ (1+1/n)^{−n²}。

根值：(1+1/n)^{−n} → 1/e < 1 ⇒ 收敛。

S24.★★ 判别 Σ 1/(ln n)ⁿ（n≥2）。

根值：1/lnn → 0 < 1 ⇒ 收敛（lnn 增长慢但指数位置上足够）。

S25.★★ 用积分判别法判 Σ 1/(n·ln²n)（n≥2）。

∫₂^{+∞} dx/(x·ln²x) = [−1/lnx]₂^{+∞} = 1/ln2 有限 ⇒ 收敛。

S26.★ 判别 Σ 1/(n·lnn)（n≥2）。

∫dx/(xlnx) = lnlnx → +∞ ⇒ 发散。与 S25 成对，只差一个平方。

S27.★★ 比值法对 Σ1/n² 的结果说明什么？

lim aₙ₊₁/aₙ = 1（失效）⇒ 比值法对 p-级数一律失效，此时换比较法。

S28.★★★ 判别 Σ nⁿ/(n!)²。

比值 = (1+1/n)ⁿ/(n+1) → e/(n+1) → 0 < 1 ⇒ 收敛（(n+1)² 的压制）。

S29.★★ 判别 Σ [1−cos(1/n)]。

1−cos(1/n) ~ 1/(2n²) ⇒ 收敛。

S30.★ 判别 Σ (e^{1/n} − 1)。

~ 1/n ⇒ 发散。

S31.★★ 判别 Σ [tan(1/n)]/n。

tan(1/n) ~ 1/n ⇒ 通项 ~ 1/n² ⇒ 收敛。

S32.★ 下列收敛的是：Σ1/n^{1.1}、Σ1/n、Σ1/√n、Σlnn/n。 A. 第一个 B. 第二个 C. 第三个 D. 第四个

A。p=1.1>1。第四个 ~lnn/n ≥ 1/n 发散（比较）。

S33.★ 正项级数收敛的充要条件（用部分和表述）。

部分和数列有界。正项级数部分和单调增，有界即收敛——这是比较判别法的根基。

S34.★ 求 Σ [1/n − 1/(n+1)]。

望远镜级数：部分和 = 1 − 1/(n+1) → 1。

S35.★★ 判别 Σ (√(n+1) − √n)。

部分和 = √(n+1) − 1 → +∞ ⇒ 发散（有理化后通项 ~ 1/(2√n)，也判发散）。

S36.★ 判别 Σ 1/(n²−n+1)。

分母 ~n² ⇒ 收敛（与 Σ1/n² 比较，比值极限 1）。

S37.★ 判别 Σ 1/[n(n+1)(n+2)]。

~1/n³ ⇒ 收敛（也可裂项 telescope）。

S38.★★ 判别 Σ (n!)²/(2n)!。

比值 = (n+1)²/[(2n+2)(2n+1)] → 1/4 < 1 ⇒ 收敛。

S39.★★ 判别 Σ 3ⁿ·n!/nⁿ。

比值 = 3/(1+1/n)ⁿ → 3/e > 1 ⇒ 发散（3 > e ≈ 2.718）。

S40.★★ 正项级数判别流程总结。

先看通项→0？否 ⇒ 发散。是 ⇒ 试等价无穷小化简 → 与 p-级数/几何级数比较；含 n!、指数用比值；含 n 次幂用根值；含 lnn 用积分判别。

§3 交错级数与绝对、条件收敛（S41–S55）

S41.★ 默写莱布尼茨判别法。

交错级数 Σ(−1)ⁿ⁻¹aₙ（aₙ>0）：若 aₙ 单调不增且 →0，则收敛，且余项 |Rₙ| ≤ aₙ₊₁。

S42.★ Σ(−1)ⁿ⁻¹/n 的敛散类型：

|aₙ|=1/n 调和发散，但单调减趋0 ⇒ 条件收敛。

S43.★ Σ(−1)ⁿ/n² 的敛散类型：

Σ1/n² 收敛 ⇒ 绝对收敛。

S44.★ Σ(−1)ⁿ(1+1/n)ⁿ 的敛散：

通项 →(−1)ⁿe ≠ 0 ⇒ 发散（必要条件不满足，别进莱布尼茨）。

S45.★ Σ(−1)ⁿ(1−1/n)ⁿ 的敛散：

(1−1/n)ⁿ → 1/e ≠ 0 ⇒ 发散。"−1/n"的负号骗不了极限。

S46.★★ 判别 Σ(−1)ⁿ sin(1/n)。

绝对值级数 ~1/n 发散；sin(1/n) 单调减趋0 ⇒ 条件收敛。

S47.★ 默写："绝对收敛 ⇒ 收敛"。

对。正项级数 Σ|aₙ| 收敛则 Σaₙ 收敛（|aₙ|≥aₙ 的部分部分）。逆不成立。

S48.★ 条件收敛级数加绝对值后： A. 仍收敛 B. 必发散 C. 不定 D. 变绝对收敛

B。条件收敛=收敛但 Σ|aₙ| 发散，这是定义。

S49.★★ 讨论 p 取值时 Σ(−1)ⁿ/n^p 的敛散。

p>1 绝对收敛；0<p≤1 条件收敛；p≤0 发散（通项不趋0）。

S50.★★ 判别 Σ(−1)ⁿ·ln(1+1/n)。

ln(1+1/n) 单调减趋0；绝对值 ~1/n 发散 ⇒ 条件收敛。

S51.★★ 判别 Σ(−1)ⁿ·√n/(n+1)。

aₙ=√n/(n+1)：递减趋0 ✓；绝对值 ~1/√n 发散 ⇒ 条件收敛。

S52.★ 交错级数取前 n 项和 Sₙ 估计真值，误差： A. ≤ aₙ B. ≤ aₙ₊₁（首弃项） C. 任意大 D. 精确

B。莱布尼茨余项估计，数值计算常用。

S53.★★ 条件收敛级数能否通过重排改变和？

能（黎曼重排定理）：条件收敛级数可重排成任意指定和或发散；绝对收敛级数重排不变。

S54.★ 判别 Σ(−1)ⁿ·n/(n+1)。

通项 →(−1)ⁿ ≠ 0 ⇒ 发散。

S55.★ 绝对收敛级数与条件收敛级数逐项相加，结果是：

条件收敛。（若和绝对收敛，减去绝对收敛项会推出另一个绝对收敛，矛盾。）

§4 幂级数收敛域与和函数（S56–S80）

S56.★ 收敛半径公式（不缺项幂级数 Σaₙxⁿ）。

R = 1/lim|aₙ₊₁/aₙ|（极限为0⇒R=∞；为∞⇒R=0）。端点必须单独验证。

S57.★★ 求 Σ xⁿ/n 的收敛域。

R=1。x=1：调和发散；x=−1：交错调和收敛。 收敛域 (−1, 1]。

S58.★★ 求 Σ xⁿ/n² 的收敛域。

R=1；x=±1 都收敛（p=2）⇒ [−1, 1]（处处绝对收敛）。

S59.★ 求 Σ xⁿ 的收敛域。

几何级数 ⇒ (−1,1)，和 = 1/(1−x)。

S60.★ 求 Σ n!·xⁿ 的收敛半径。

比值 |(n+1)x| → ∞（x≠0）⇒ R=0，只在 x=0 收敛。

S61.★ 求 Σ xⁿ/n! 的收敛域。

R=+∞ ⇒ (−∞,+∞)，和 = eˣ。

S62.★★ 求 Σ xⁿ/(n·2ⁿ) 的收敛域。

令 t=x/2：R 对 t 是 1 ⇒ |x|<2。x=−2：Σ(−1)ⁿ/n 收敛；x=2：Σ1/n 发散。 收敛域 [−2, 2)。

S63.★ 默写阿贝尔定理。

幂级数在 x₀≠0 收敛 ⇒ 对一切 |x|<|x₀| 绝对收敛；在 x₁ 发散 ⇒ |x|>|x₁| 全发散。收敛域是区间。

S64.★ 幂级数逐项求导/积分后，收敛半径：

不变（端点敛散可能改变，需重验）。

S65.★★★ 求 S(x)=Σ_{n≥0} xⁿ/(n+1) 的和函数（|x|<1）。

S = (1/x)Σ xⁿ⁺¹/(n+1) = (1/x)∫₀ˣ [Σtⁿ]dt = −ln(1−x)/x（x≠0）。 S(x) = −ln(1−x)/x（x≠0，|x|<1），S(0)=1（n=0 项）。

S66.★ 求 Σ n·xⁿ（|x|<1）。

Σxⁿ = 1/(1−x)，逐项求导：Σnxⁿ⁻¹ = 1/(1−x)² ⇒ Σnxⁿ = x/(1−x)²。

S67.★★ 求 Σ n²xⁿ（|x|<1）。

x·d/dx[x/(1−x)²] = x(1+x)/(1−x)³。

S68.★ Σ(−1)ⁿx^{2n}/(2n)! = ?

cosx（偶次项=余弦展开）。

S69.★ Σ(−1)ⁿx^{2n+1}/(2n+1)! = ?

sinx（奇次项=正弦展开）。

S70.★★ 求 Σ x^{2n}/(2n)（|x|<1）。

偶次调和：= ½[−ln(1−x) − ln(1+x)] = −½ln(1−x²)。

S71.★ 幂级数和函数在收敛区间内部是否连续？端点呢？

内部逐项连续可导可积；端点若收敛，和函数在端点也（左/右）连续（阿贝尔第二定理）——求 S(±1) 常用它。

S72.★★ 求 Σ (x−1)ⁿ/n 的收敛域。

|x−1|<1；x=0：Σ(−1)ⁿ/n 收敛；x=2：Σ1/n 发散 ⇒ [0, 2)。

S73.★★ 求 Σ (2x+1)ⁿ/n 的收敛域。

|2x+1|<1 ⇒ −1<x<0。x=−1：Σ(−1)ⁿ/n 收敛；x=0：Σ1/n 发散。 收敛域 [−1, 0)。

S74.★ 幂级数和函数的运算性质默写。

收敛区间内可逐项求导、逐项积分任意次；收敛半径不变。

S75.★ 幂级数 Σ(n+1)xⁿ 的和函数。

Σxⁿ⁺¹ = x/(1−x) 求导 ⇒ 1/(1−x)²（|x|<1）。

S76.★★★ 求 S(x)=Σ_{n≥1} xⁿ/[n(n+1)]（|x|<1）。

拆 1/[n(n+1)] = 1/n − 1/(n+1)： S = −ln(1−x) − (1/x)(−ln(1−x)−x) = 1 + (1−x)·ln(1−x)/x（x≠0），S(0)=0。

S77.★ 幂级数在收敛区间内可以求导多少次？

任意次，收敛半径不变——幂级数和函数是"无穷光滑"的。

S78.★★ 求 Σ (−1)ⁿ⁻¹xⁿ/n 的和函数与它在 x=1 的值。

逐项积分 1/(1+x)：S = ln(1+x)（−1<x≤1）；x=1 时 = ln2（阿贝尔第二定理）。

S79.★ 利用幂级数求 Σ(−1)ⁿ⁻¹/n 的和。

即 S78 在 x=1：ln2。"数值级数求和 = 找母函数代端点"。

S80.★★★ 求 Σ n(n+1)xⁿ（|x|<1）。

Σxⁿ⁺¹ = x²/(1−x)，二阶导 = 2/(1−x)³ ⇒ 原级数 = 2x/(1−x)³。

§5 函数幂级数展开与傅里叶级数（S81–S100）

S81.★ 写出 eˣ 的麦克劳林展开及收敛域。

eˣ = Σ xⁿ/n!，收敛域 (−∞,+∞)。

S82.★ 写出 sinx、cosx 的展开。

sinx = Σ(−1)ⁿx^{2n+1}/(2n+1)!；cosx = Σ(−1)ⁿx^{2n}/(2n)!，全域收敛。

S83.★ 写出 1/(1−x) 与 1/(1+x) 的展开。

1/(1−x) = Σxⁿ；1/(1+x) = Σ(−1)ⁿxⁿ，均 |x|<1。

S84.★★ 写出 ln(1+x) 的展开及收敛域。

逐项积分 1/(1+x)：ln(1+x) = Σ(−1)ⁿ⁻¹xⁿ/n，收敛域 (−1,1]。

S85.★★ 写出 arctanx 的展开及收敛域。

∫1/(1+t²)dt：arctanx = Σ(−1)ⁿx^{2n+1}/(2n+1)，收敛域 [−1,1]（端点交错收敛）。

S86.★ 写出 1/(1+x²) 的展开。

以 x² 代 x：Σ(−1)ⁿx^{2n}，|x|<1。

S87.★★ 将 1/x 展开为 (x−1) 的幂级数。

1/x = 1/[1+(x−1)] = Σ(−1)ⁿ(x−1)ⁿ，|x−1|<1（即 0<x<2）。

S88.★★ 将 eˣ 展开为 (x−1) 的幂级数。

eˣ = e·e^{x−1} = e·Σ(x−1)ⁿ/n!，全域。

S89.★★ 将 f(x)=x/(1+x) 展开为 x 的幂级数。

x/(1+x) = 1 − 1/(1+x) = Σ_{n≥1}(−1)ⁿ⁺¹xⁿ，|x|<1。

S90.★ 函数的幂级数展开唯一吗？

唯一（若能展开）：系数必为泰勒系数 aₙ=f⁽ⁿ⁾(x₀)/n!。这也证明"两个展开相等⇒对应系数相等"。

S91.★ 默写周期 2π 的傅里叶系数公式。

aₙ = (1/π)∫_{−π}^{π}f(x)cosnx dx；bₙ = (1/π)∫f(x)sinnx dx；a₀/2 是平均值项。

S92.★★★ 求 f(x)=x² 在 (−π,π) 上的傅里叶展开，并给出 x=π 处的值。

偶函数 ⇒ bₙ=0。计算得 a₀/2 = π²/3，aₙ = 4(−1)ⁿ/n²。 x² = π²/3 + 4Σ(−1)ⁿcos(nx)/n²。 x=π 处：π² = π²/3 + 4Σ1/n² ⇒ Σ1/n² = π²/6——傅里叶级数求数项级数和的招牌应用。

S93.★ 默写狄利克雷收敛定理。

f 分段单调/分段光滑：傅里叶级数收敛于 [f(x₋)+f(x₊)]/2；连续点=函数值；间断点=左右极限平均。

S94.★ [0,π] 上的函数展开成正弦级数需要什么延拓？

奇延拓到 (−π,π) ⇒ 只含 sin 项；偶延拓 ⇒ 余弦级数。

S95.★★ 将 f(x)=x（0<x<π）展开为正弦级数。

奇延拓（x 本身就是奇函数的自然延拓）：bₙ = (2/π)∫₀^π x·sinnx dx = 2(−1)ⁿ⁺¹/n。 x = 2Σ(−1)ⁿ⁺¹sin(nx)/n（0<x<π）。

S96.★ 周期 2l 的傅里叶系数与 2π 情形的关系。

换元 t=πx/l：aₙ=(1/l)∫_{−l}^{l}f·cos(nπx/l)dx，bₙ 同理带 sin(nπx/l)。

S97.★★ 利用 S92 求 Σ(−1)ⁿ⁻¹/n² 的和。

x=0 代入 x² 展开的右端：0 = π²/3 + 4Σ(−1)ⁿ/n² ⇒ Σ(−1)ⁿ/n² = −π²/12。 所以 Σ(−1)ⁿ⁻¹/n² = π²/12。

S98.★ 求 f(x)=x 在 (−π,π) 上的傅里叶级数。

奇函数 ⇒ aₙ=0；bₙ = (2/π)∫₀^π x·sinnx dx = 2(−1)ⁿ⁺¹/n。 x = 2Σ(−1)ⁿ⁺¹sin(nx)/n（x≠±π）。

S99.★★ f 定义在 (−π,π)，傅里叶级数在 x=±π 处收敛于： A. f(π) B. [f(π⁻)+f(−π⁺)]/2 C. 0 D. 不收敛

B。周期延拓下 ±π 是同一点，收敛于"周期缝合点"两侧极限的平均。

S100.★★ f(x)=|x| 在 (−π,π) 的傅里叶级数只含什么项？为什么？

偶函数 ⇒ 只含余弦项（bₙ=0）；结果 |x| = π/2 − (4/π)·Σcos((2k+1)x)/(2k+1)²。 奇偶性直接决定 sin/cos 项的有无——先判奇偶再动笔。
