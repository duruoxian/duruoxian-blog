卷 五

一、选择题

  1. lim_{x→∞} (3x²-x+1)/(2x²+3x-2) = ? A. 0　B. 3/2　C. 1　D. 不存在

  2. 设 f'(x)=f(x) 且 f(0)=2，则 f(x) = ? A. 2eˣ　B. e²ˣ　C. 2+x　D. 2x

  3. ∫_{-1}^{1} (x + √(1-x²)) dx = ? A. 0　B. π/4　C. π/2　D. π

  4. 曲线 y = x·e^{1/x²} 的渐近线共有？ A. 1条　B. 2条　C. 3条　D. 4条

  5. 级数 Σ_{n=1}^∞ (-1)ⁿ·n/(n²+1) 的收敛性？ A. 绝对收敛　B. 条件收敛　C. 发散　D. 收敛性无法判断

  6. 设 A 为3阶矩阵，|A|=1/2，则 |2A⁻¹ - A| = ? A. 3/4　B. 27/8　C. 27/4*　D. 9/4

  7. 设 α=(1,-1,2)ᵀ，A=ααᵀ，则 r(A) = ? A. 0　B. 1　C. 2　D. 3

  8. 向量 α₁=(1,a)ᵀ 与 α₂=(1,2)ᵀ 线性相关的充要条件是 a = ? A. 0　B. 2　C. 1　D. −2

  9. 设 X 的概率密度 f(x)=2x（0<x<1），则 P(X>1/2) = ? A. 1/4　B. 1/2　C. 3/4　D. 7/8

  10. X, Y 独立同服从 N(0,1)，则 D(X-2Y) = ? A. 1　B. 3　C. 4　D. 5

  2. 设 y = ln(x+√(1+x²))，则 y' = ______。
  3. ∫₀¹ x(1-x)¹⁰ dx = ______。
  4. 微分方程 y''-y'=0 的通解为 ______。

三、解答题

17.（10分）求 lim_{x→0} [(1+x)^{1/x} - e]/x。

18.（12分）曲线 { x = t - sin t, y = 1 - cos t }（摆线），求 t=π/2 处的 dy/dx 与 d²y/dx²。

19.（12分）计算曲线积分 I = ∫_L (eˣsiny - y)dx + (eˣcosy - x)dy，其中 L 为上半圆 x²+y²=1（y≥0），方向从 (-1,0) 到 (1,0)。

20.（12分）计算二重积分 I = ∬_D (x+y)² dσ，D: x²+y²≤1。

21.（12分）设 A=[[1,1,0],[0,1,1],[0,0,1]]，求 Aⁿ。

22.（12分）设 X~N(0,1)，求 Y=X² 的概率密度 f_Y(y) 与 E(Y)。

卷五答案与详解

选择：1B 2A 3C 4B 5B 6C 7B 8B 9C 10D

  1. 同阶齐次比系数 → 3/2。
  2. f=Ceˣ，f(0)=2。
  3. x 与 x³ 奇函数积分为0；√(1-x²) 为上半单位圆面积 π/2。
  4. x→∞：y=x·(1+1/x²+…)→斜渐近 y=x；x→0⁺：e^{1/x²}→∞ 故 y→∞ → 垂直渐近 x=0。共2条。
  5. n/(n²+1)单调减趋于0（莱布尼茨收敛）；|项|~1/n 发散 → 条件收敛。
  6. A=|A|A⁻¹=A⁻¹/2 → 2A⁻¹−A = (3/2)A⁻¹ → 行列式 = (3/2)³·2 = 27/4。
  7. A=ααᵀ，r(A)=r(ααᵀ)=1（α≠0；rank-1矩阵）。
  8. det[[1,1],[a,2]] = 2−a = 0。
  9. F(x)=x² → 1−1/4 = 3/4。
  10. D(X-2Y)=1+4·1=5（独立）。

填空：11. (1-cos2x)~2x²，x·sinx~x² → 2。 12. 1/√(1+x²)。 13. 换元u=1-x：∫₀¹(1-u)u¹⁰du = 1/11−1/12 = 1/132。 14. 特征根0,1 → y = C₁ + C₂eˣ。 15. (−1)³·(1/3) = −1/3。 16. 个位为2或4：2×4×3=24个偶三位数；总数 5×4×3=60 → 2/5。

17. (1+x)^{1/x} = e^{ln(1+x)/x} = e^{1 - x/2 + x²/3 + o(x²)} = e·e^{-x/2+o(x)} = e(1 - x/2 + o(x))。 原式 = [−e·x/2 + o(x)]/x → −e/2。

18. dx/dt = 1−cost，dy/dt = sint → dy/dx = sint/(1−cost)，t=π/2 时 = 1/(1−0) = 1。 d²y/dx² = [d/dt(sint/(1−cost))]/(1−cost)。 d/dt(sint/(1−cost)) = [cost(1−cost) − sin²t]/(1−cost)² = (cost−1)/(1−cost)² = −1/(1−cost)。 故 d²y/dx² = −1/(1−cost)²，t=π/2 时 = −1。

19. 补直线段 L₁: 从 (1,0) 沿 x 轴到 (−1,0)，构成闭曲线 L+L₁（顺时针，区域在上半平面）。 ∂P/∂y = eˣcosy−1，∂Q/∂x = eˣcosy−1 → 差为0。 格林公式（负向）：∮{L+L₁} = −∬0·dA = 0 → I = −∮{L₁}。 L₁ 上 y=0, dy=0：P = eˣ·0−0 = 0 → ∮_{L₁} = 0。故 I = 0。 （要点：路径无关判定 P_y=Q_x 全平面成立 → 曲线积分只取决于端点，可改走 x 轴直线段，直接得0。）

20. 展开 (x+y)² = x²+2xy+y²。由对称性 ∬xy=0，∬x²=∬y²（轮换对称）= (1/2)∬(x²+y²)dσ。 ∬(x²+y²)dσ = ∫₀^{2π}dθ∫₀¹ r³dr = 2π/4 = π/2 → ∬x² = π/4。 I = π/4 + 0 + π/4 = π/2。

21. A = E + N，N=[[0,1,0],[0,0,1],[0,0,0]]，N²=[[0,0,1],[0,0,0],[0,0,0]]，N³=O。 二项式：Aⁿ = E + nN + C(n,2)N² = [[1, n, n(n−1)/2],[0, 1, n],[0, 0, 1]]。

22. F_Y(y) = P(X²≤y) = P(−√y≤X≤√y) = 2Φ(√y)−1（y>0）。 f_Y(y) = dF/dy = 2φ(√y)·(1/(2√y)) = (1/√(2π))·y^{−1/2}·e^{−y/2}（y>0；y≤0时为0）。 E(Y) = E(X²) = D(X)+E²(X) = 1。

卷 六

一、选择题

  1. lim_{x→0⁺} (tanx)^{1/lnx} = ? A. 0　B. 1　C. e　D. e⁻¹

  2. 方程 x³-3x²+2 = 0 的不同实根个数为？ A. 1　B. 2　C. 3　D. 4

  3. 下列反常积分中收敛的是： A. ∫₀¹ dx/x^{1.1}　B. ∫₁^{+∞} dx/x^{0.9}　C. ∫₀¹ dx/x^{0.9}　D. ∫₁^{+∞} dx/x

  4. 设 F(x) = ∫₀^x x·f(t)dt（f(t)=t），则 F'(x) = ? A. x²/2　B. 3x²/2　C. x³/2　D. x·f(x)

  5. 幂级数 Σ_{n=0}^∞ n!·xⁿ 的收敛域为： A. (−1,1)　B. [−1,1)　C. (−1,1]　D. 仅 x=0

  6. 设 A=[[1,2],[3,4]]，A 为伴随矩阵，则 |A| = ? A. 1　B. −1　C. −2　D. −4

  7. 向量组 α₁=(1,0,0), α₂=(0,1,0), α₃=(1,1,a)，当 a=0 时该向量组的秩为： A. 1　B. 2　C. 3　D. 0

  8. 设 A 满足 A²=2A，则 A 的特征值只能是： A. 0　B. 2　C. 0 或 2　D. 任意实数

  9. A, B 独立，P(A)=0.5，P(B)=0.4，则 P(A∪B) = ? A. 0.9　B. 0.2　C. 0.7　D. 0.6

  10. (X,Y) 服从二维正态分布 N(μ₁,μ₂,σ₁²,σ₂²,ρ)，则"X 与 Y 相互独立"的充要条件是： A. ρ=0　B. Cov(X,Y)=0　C. E(XY)=E(X)·E(Y)　D. 以上都对

    D。二维正态下"不相关⇔独立"，而 ρ=0 ⇔ Cov=0 ⇔ E(XY)=EX·EY，三者等价。注意该结论仅对二维正态成立，一般分布不相关推不出独立。

三、解答题

17.（10分）设 f(x) = lim_{n→∞} x^{2n}/(1+x^{2n})，求 f(x) 的表达式，并指出其间断点及类型。

18.（12分）设 z = f(xy, x²+y²)，f 具有二阶连续偏导数，求 ∂²z/∂x∂y。

19.（12分）求曲线 y=1/x、直线 y=x 与 x=2 所围成图形（x≥1部分）的面积，及该图形绕 x 轴旋转一周所得旋转体的体积。

20.（12分）计算三重积分 I = ∭_Ω z² dV，其中 Ω: x²+y²+z²≤1。

21.（12分）设 A=[[1,2,2],[2,1,2],[2,2,1]]，求 A 的特征值，判断 A 是否正定，并计算 |A+2E|。

22.（12分）总体 X~N(μ, 4)，X₁,…,X₁₀₀ 为样本，求 P(|X̄−μ| < 0.4)。

卷六答案与详解

选择：1C 2C 3C 4B 5D 6C 7B 8C 9C 10D

  1. ln(tanx)/lnx = ln x(1+x²/3+…)/lnx → 1 → e。
  2. f(0)=2>0，f(1)=0，f(2)=−2<0，f(3)=2>0；f'=3x(x−2) 极大值2>0、极小值−2<0 → 三个根（一个负根、x=1、一个在(2,3)）。
  3. ∫₀¹ 1/xᵖ 收敛需 p<1（0.9 ✓）；∫₁^∞ 收敛需 p>1（0.9与1均发散）。
  4. F=x∫₀^x tdt = x³/2 → F' = 3x²/2。
  5. lim|a_{n+1}/aₙ| = lim(n+1) = ∞ → R=0，仅在 x=0 收敛。
  6. |A|=−2，|A*|=|A|^{n−1}=|A|¹=−2。
  7. a=0 时 α₃=(1,1,0)=α₁+α₂ → 秩2。
  8. λ²=2λ → λ(λ−2)=0。
  9. 0.5+0.4−0.2=0.7。
  10. 二维正态：不相关⇔独立；三个选项均与"ρ=0"等价 → 全对。

填空：11. 3^{1/n}−3^{1/(n+1)} = 3^{1/(n+1)}(3^{1/[n(n+1)]}−1) ~ ln3/[n(n+1)] → n²×(·) → ln3。 12. −1/(1+x²)（链式：1/(1+1/x²)·(−1/x²)）。 13. [x sinx]₀^{π/2} − ∫₀^{π/2}sinx dx = π/2 − 1。 14. y'=2, y''=2 → k = 2/(1+4)^{3/2} = 2/(5√5)（=2√5/25）。 15. |2A| = 2³|A| = 8|A|^{n−1} = 8×2² = 32。 16. 和为7的组合6种（(1,6)…(6,1)）→ 6/36 = 1/6。

17. |x|<1：x^{2n}→0 → f=0；|x|=1：f=1/2；|x|>1：f→1。 f(x) = 0（|x|<1），1/2（|x|=1），1（|x|>1）。 x=±1 处：左极限0、右极限1，跳跃（极限存在但≠函数值）→ x=±1 为第一类（跳跃）间断点。

18. z_x = y·f₁ + 2x·f₂。 再对 y 求导（f₁ 的 y 偏导 = x f₁₁ + 2y f₁₂；f₂ 的 y 偏导 = x f₂₁ + 2y f₂₂）： z_xy = f₁ + y(x f₁₁ + 2y f₁₂) + 2x(x f₂₁ + 2y f₂₂) = f₁ + xy f₁₁ + 2(x²+y²) f₁₂ + 4xy f₂₂。

19. 交点：y=x 与 y=1/x 交于 x=1。 面积 = ∫₁²(x − 1/x)dx = [x²/2 − lnx]₁² = 2−ln2−1/2 = 3/2 − ln2。 体积（绕x轴，外旋y=x、内挖y=1/x）： V = π∫₁²(x² − 1/x²)dx = π[x³/3 + 1/x]₁² = π(8/3+1/2 − 1/3−1) = π(7/3−1/2) = 11π/6。

20. 对称性：∭z² = (1/3)∭(x²+y²+z²)dV（三坐标平方地位相同）。 ∭(x²+y²+z²)dV = ∫₀^{2π}dθ∫₀^{π}sinφdφ∫₀¹ r⁴dr = 2π×2×(1/5) = 4π/5。 I = (1/3)×4π/5 = 4π/15。

21. A：对角1、非对角2（n=3）→ 特征值 1+2×2=5 与 1−2=−1（二重）。 特征值有负数 → 不正定。 |A+2E| = (5+2)(−1+2)(−1+2) = 7。

22. X̄~N(μ, 4/100) → σ_X̄ = 0.2。 P(|X̄−μ|<0.4) = P(|Z|<2) = 2Φ(2)−1 = 0.9544。
