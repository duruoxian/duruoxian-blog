00 C语言核心考点【408算法题的工具语言（C/C++）】

C/C++ 是 408 算法设计题的书写工具；本文件的 C 语言功底是写算法题与复试机试（C++）的地基。

知识点摘要

  • 数据类型与运算：int/float/double/char；类型转换规则（隐式向高转换）；运算符优先级、自增自减（前置/后置差异）。
  • 三大结构：顺序、选择（if/else、switch-case 与 break）、循环（while/for/do-while；break与continue区别）。
  • 数组：一维/二维初始化与遍历；数组名=首地址；越界不报错（C语言特性，常考找错）。
  • 函数：定义与声明、值传递 vs 地址传递、递归（条件：出口+递推式）、变量的作用域与生存期（auto/static/global）。
  • 指针：*与&、指针与数组（p+i 等价 a+i）、指针作参数（实现"引用传递"效果）、野指针/空指针。
  • 字符串：char数组与'\0'结尾；常用函数 strcpy/strcat/strcmp/strlen（能手写实现）。
  • 结构体：定义、成员访问（. 与 ->）、结构体数组/指针；typedef。
  • 文件（了解）：fopen/fclose 读写模式。

代码示例

/* 1. 指针交换：819算法题最常用地基 */
void swap(int *a, int *b){ int t=*a; *a=*b; *b=t; }

/* 2. 冒泡排序（循环结构+数组，考频极高） */
void bubble(int a[], int n){
    for(int i=0;i<n-1;i++)
        for(int j=0;j<n-1-i;j++)
            if(a[j]>a[j+1]) swap(&a[j],&a[j+1]);
}

/* 3. 递归：n!（出口+递推式） */
long fact(int n){ return n<=1 ? 1 : n*fact(n-1); }

/* 4. strlen 手写实现 */
int my_strlen(const char *s){
    int n=0; while(s[n]!='\0') n++;
    return n;
}

简答题（背诵要点）

  1. 值传递与地址传递的区别：值传递复制实参副本，形参改变不影响实参；地址（指针）传递传入地址，可通过解引用修改实参——函数要"改外面"必须传地址。
  2. static 局部变量的特点：初始化一次、函数调用结束后值保留、作用域仍限于本函数。
  3. 数组名与指针的区别：数组名是地址常量（不可自增），指针是变量；sizeof(数组名)=整个数组大小。

名词解释

  • 递归：函数直接或间接调用自身，须有终止条件与递推关系。
  • 指针：存放内存地址的变量。
  • 结构体：把不同类型数据组合成一个整体的构造类型。

常见题型与易错

  • 题型：读程序写结果（自增/循环边界/递归展开）、程序填空（排序/查找/字符串）、改错（越界/缺'\0'/漏break）。
  • 易错：i++与++i 在表达式中的值；switch 漏 break 的贯穿；二维数组按行存储 a[i][j] 地址计算；字符串比较用 strcmp 而不是 ==。
  • 真题映射：待拿到大纲原文与回忆版真题后补充。

自测题（3道）

  1. int a[5]={1,2,3}; 则 a[3]、a[5] 分别是多少？
  2. 写出 for(i=0;i<3;i++) for(j=0;j<=i;j++) printf("*"); 输出的 * 总数。
  3. char s[]="abc"; s[1]='B'; 合法吗？char *p="abc"; p[1]='B'; 呢？

答案 1. a[3]=0（部分初始化其余为0）；a[5] 越界（未定义行为，绝不能写）。 2. 1+2+3=6。 3. 数组版合法（s 在栈上可改）；指针版指向常量区，写入未定义（考试答"不合法"）。

01 绪论与算法分析

知识点摘要

  • 数据结构三元组：逻辑结构（集合/线性/树形/图状）、存储结构（顺序/链式/索引/散列）、数据的运算。
  • 算法五特性：有穷性、确定性、可行性、输入（≥0）、输出（≥1）。
  • 好算法目标：正确性、可读性、健壮性、高效性（时间+空间）。
  • 时间复杂度：基本操作重复执行次数 T(n) 的数量级 O(f(n))；大O规则（常数/低阶/系数省略）。
  • 常见复杂度阶：O(1)<O(log n)<O(n)<O(n log n)<O(n²)<O(n³)<O(2ⁿ)<O(n!)。
  • 空间复杂度：辅助空间量级；递归深度计入空间。

代码示例

/* O(n): 嵌套但有依赖的循环要按执行次数算，不能机械相乘 */
for(i=1;i<=n;i*=2)      /* 外层 log n 次 */
    for(j=1;j<=n;j++)   /* 内层 n 次 → O(n log n) */
        ;

简答题（背诵要点）

  1. 逻辑结构与存储结构的关系：逻辑结构是数据元素间关系的描述，与存储无关；存储结构是逻辑结构在内存中的映像；同一逻辑结构可有多种存储实现，运算效率不同。
  2. 时间复杂度定义：以基本操作重复次数的渐近上界刻画算法随问题规模增长的耗时趋势，与具体机器无关。
  3. 两层循环复杂度判定：外层控制总量时（如 while(i<n){i=i2}）为对数阶；双层独立循环相乘；循环变量非线性增长（i=2, i+=i）先解出执行次数再取阶。

名词解释

  • 数据项：数据不可分割的最小单位。数据元素：数据的基本单位，由若干数据项构成。
  • 算法：对特定问题求解步骤的一种描述，是指令的有限序列。
  • 渐近时间复杂度：问题规模 n 足够大时算法运行时间的数量级。

复杂度速查（后面章节反复引用）

结构/算法 查找 插入 删除
顺序表 O(n)/O(1)按位 O(n) O(n)
单链表（含头指针） O(n) O(1)（已给位置） O(1)（已给位置）

易错点

  • O(f) 是"上界"，O(1) 不代表一次执行完，而是"与n无关"。
  • 递归算法空间复杂度=递归深度×每层辅助空间。
  • 循环次数不是看循环变量初值，而是解不等式求次数。

自测题（3道）

  1. i=1; while(i<=n) i=i*3; 的时间复杂度？
  2. for(i=0;i<n;i++) for(j=i;j<n;j++) ; 的时间复杂度？
  3. 递归求 n! 的空间复杂度？

答案 1. O(log₃n) 即 O(log n)。 2. 内层次数 Σ(n-i)=n(n+1)/2 → O(n²)。 3. O(n)（递归深度 n）。

02 线性表【顺序表 / 单链表 / 双链表 / 循环链表】

知识点摘要

  • 线性表定义：n个相同类型元素的有限序列；位序从1计，下标从0计。
  • 顺序表：逻辑相邻物理相邻；按位 O(1) 随机存取；插入删除平均移动 n/2、(n-1)/2 个元素。
  • 单链表：结点=data+next；头结点的作用（统一首结点插入删除逻辑）；尾插法建表用尾指针。
  • 双链表：prior+next，可 O(1) 找前驱；循环链表：尾结点指回头（判空条件 p!=L / p->next!=L）。
  • 静态链表（了解）：数组模拟链表。

代码示例（必须默写级）

typedef struct LNode{
    int data;
    struct LNode *next;
} LNode, *LinkList;

/* 头插法建表（逆序） */
LinkList CreateH(int a[], int n){
    LinkList L=(LNode*)malloc(sizeof(LNode)); L->next=NULL;   /* 头结点 */
    for(int i=0;i<n;i++){
        LNode *s=(LNode*)malloc(sizeof(LNode));
        s->data=a[i]; s->next=L->next; L->next=s;
    }
    return L;
}

/* 顺序表插入：第i位(1≤i≤len+1)插x，返回1成功 */
int Insert(SqList *L,int i,int x){
    if(i<1||i>L->len+1) return 0;
    for(int j=L->len;j>=i;j--) L->data[j]=L->data[j-1]; /* 后移 */
    L->data[i-1]=x; L->len++;
    return 1;
}

简答题（背诵要点）

  1. 顺序表与链表比较：存取方式（随机 vs 顺序）、插入删除开销（移动元素 vs 改指针）、空间（静态分配连续 vs 动态离散有指针开销）、适用场景（频繁按位查/长度稳定→顺序表；频繁插删/长度未知→链表）。
  2. 头结点作用：使第一个位置的插入/删除与其他位置统一，空表与非空表处理统一。
  3. 循环双链表判空：L->next==L && L->prior==L。

名词解释

  • 顺序存储：用地址连续的存储单元依次存放线性表元素，逻辑与物理相邻一致。
  • 链式存储：结点含数据域与指针域，靠指针表达逻辑关系，存储空间不必连续。

复杂度表（必背）

操作 顺序表 单链表
按值查找 O(n) O(n)
按位存取 O(1) O(n)
插入/删除（已定位） O(n)（移动元素） O(1)（改指针）

易错点

  • 插入必须先移后插、删除先取值再前移；移动方向决定循环方向（插入从后往前）。
  • 链表删除结点：p->next=q->next 后才 free(q)；双链表操作先接后断，口算四步。
  • 循环条件：单链表判到尾用 p!=NULL，判尾结点用 p->next!=NULL，别混。
  • 顺序表位序 i 与下标 i-1 的转换，插入范围 [1, len+1]。

自测题（3道）

  1. 长度n的顺序表在第i位插入，平均移动多少个元素？
  2. 将单链表L原地逆置，写出核心循环（不建新表）。
  3. 带头结点单链表，删除所有值为x的结点，写核心代码。

答案 1. (n-i+1) 的平均 = n/2。 2. p=L->next->next; L->next->next=NULL; while(p){ q=p->next; p->next=L->next; L->next=p; p=q; }（头插法拆链重建）。 3. 前驱指针法：p=L; while(p->next){ if(p->next->data==x){ q=p->next; p->next=q->next; free(q);} else p=p->next; }

03 栈、队列与数组（含串与特殊矩阵压缩）

知识点摘要

  • 栈：后进先出 LIFO；顺序栈（top 指向栈顶或栈顶上一位，判空判满两种口径都要会）；共享栈（两端向中间）。
  • 出栈序列计数：卡特兰数 C(2n,n)/(n+1)；合法出栈序列判定（任意元素出栈时，比它后入栈的小元素必须已出完——312模式非法等技巧）。
  • 栈应用：括号匹配、表达式求值（中缀→后缀→求值）、递归、进制转换。
  • 队列：先进先出 FIFO；循环队列：front/rear，牺牲一格判满 (rear+1)%M==front，或设 size/tag；入队 (rear+1)%M。
  • 队列应用：层序遍历、缓冲区、页面置换（FIFO）。
  • 数组与压缩存储：对称矩阵（下三角按行存 a[i][j]→k= i(i-1)/2+j-1，i≥j，1-based）、三角矩阵、对角矩阵、稀疏矩阵（三元组/十字链表）。
  • 串：定长/堆分配/块链；KMP 的 next/nextval 数组【考试常考手工求 next】。

代码示例

#define M 100
typedef struct{ int data[M]; int front, rear; } CirQueue;
int EnQ(CirQueue *Q,int x){
    if((Q->rear+1)%M==Q->front) return 0;      /* 队满 */
    Q->data[Q->rear]=x; Q->rear=(Q->rear+1)%M; return 1;
}
int DeQ(CirQueue *Q,int *x){
    if(Q->rear==Q->front) return 0;            /* 队空 */
    *x=Q->data[Q->front]; Q->front=(Q->front+1)%M; return 1;
}

简答题（背诵要点）

  1. 栈与队列的区别与联系：都操作受限的线性表；栈一端进出（LIFO），队列一进一出（FIFO）；均可顺序/链式实现；栈用于递归/回溯/表达式，队列用于排队/层序。
  2. 循环队列判满的三种方案：牺牲一个单元 (rear+1)%M==front；增设 size==M；增设 tag（最后一次操作是入队且 front==rear）。
  3. 中缀转后缀规则（简答口径）：操作数直接输出；栈顶优先级≥当前运算符则弹栈；左括号入栈，右括号弹到左括号。

名词解释

  • 递归调用栈：系统为实现函数递归自动开辟的栈帧序列（保存返回地址、参数、局部变量）。
  • 稀疏矩阵：非零元个数远小于总数且分布无规律的矩阵，用三元组表压缩存储。
  • 模式匹配：在主串中找与模式串相同的子串；KMP 利用 next 数组避免主串指针回溯。

易错点

  • 卡特兰数：n=3 时出栈序列 5 种；合法判定别只数个数。
  • 循环队列元素个数 (rear-front+M)%M（不牺牲单元口径）；牺牲单元口径下容量 M-1。
  • 对称矩阵下标公式注意 1-based/0-based 与按行/按列，做题先写清约定。
  • KMP 求串 "ababaa" 的 next：next[1]=0 约定口径（人邮教材 vs 王道口径不同，以考纲教材为准，答题写清口径）。

自测题（3道）

  1. 序列 1,2,3 依次入栈，不可能的出栈序列是？（A.321 B.213 C.312 D.123）
  2. 循环队列 front=5, rear=0, M=8，元素个数？
  3. 对称矩阵按行压缩下三角（1-based），a[3][2] 存到一维数组第几位（i≥j）？

答案 1. C（312 非法：3出栈后1在2下面出不来）。 2. (0-5+8)%8=3 个。 3. k=3·2/2+2-1=4。

04 树与二叉树【408 重中之重】

知识点摘要

  • 树的基本概念：结点度、树的度、深度、森林；性质：n结点树 n-1 条边；度之和=边数=n-1。
  • 二叉树性质：i层最多 2^(i-1) 结点；深度k最多 2^k-1；n₀=n₂+1（叶=度2+1，必背推导：总度数=n-1）。
  • 完全二叉树：n 结点深度 ⌈log₂(n+1)⌉；编号 i：左孩 2i、右孩 2i+1、双亲 i/2（i≥2）。
  • 遍历：先序/中序/后序（递归与非递归）、层序；由中序+先序（或后序）唯一重建；先序+后序不能唯一确定。
  • 线索二叉树：利用空指针存前驱后继（n+1 个空指针），tag 区分孩子/线索。
  • 树/森林 ↔ 二叉树转换（左孩子右兄弟）；森林先序/中序对应关系。
  • 哈夫曼树：带权路径长度 WPL 最小的二叉树；哈夫曼编码（前缀码，左0右1约定）；n 个叶子的哈夫曼树共 2n-1 结点、无度1结点。
  • 平衡二叉树 AVL（了解概念+旋转判定）、B树/B+树（仅概念，视大纲）。

代码示例

typedef struct TNode{
    int data;
    struct TNode *lchild, *rchild;
} TNode;

/* 先序遍历（递归） */
void Pre(TNode *t){
    if(t){ printf("%d ",t->data); Pre(t->lchild); Pre(t->rchild); }
}

/* 中序非递归（栈）——链栈实现略，框架必会 */
void In(TNode *t){
    TNode *stk[100]; int top=-1;
    while(t||top!=-1){
        while(t){ stk[++top]=t; t=t->lchild; }   /* 左链入栈 */
        t=stk[top--]; printf("%d ",t->data);      /* 访问 */
        t=t->rchild;                               /* 转右 */
    }
}

简答题（背诵要点）

  1. 先序+中序确定二叉树过程：先序首根→在中序中定位分左右子树→递归；说明为什么后序+中序同理、先序+后序不行（无法区分单孩子是左还是右）。
  2. 哈夫曼编码为什么无歧义：任何编码都不是另一编码的前缀（字符只出现在叶结点），译码时走到叶即输出，天然分隔。
  3. n₀=n₂+1 证明：设度1结点n₁，边数=n-1=n₁+2n₂；结点数 n=n₀+n₁+n₂；联立得 n₀=n₂+1。

名词解释

  • 完全二叉树：深度k的二叉树前k-1层满，第k层结点从左到右连续排列。
  • 线索二叉树：n+1个空链域中，空左指前驱、空右指后继（加标志位）的二叉链表。
  • 带权路径长度 WPL：Σ(权×路径长)；哈夫曼树是 WPL 最小的二叉树。

易错点

  • n₀=n₂+1 对任意二叉树成立，与完全与否无关。
  • 重建二叉树必须含中序；写后序时先左右后根，画树慢但稳。
  • 哈夫曼编码长度=频率×深度求和；同一频率集 WPL 唯一但树形/编码不唯一（判断题考点）。
  • 完全二叉树 i 与 2i 越界判断：2i>n 则无左孩。
  • 层序建树/遍历用队列，不是栈。

自测题（3道）

  1. 某二叉树先序 ABDEC，中序 DBEAC，求后序。
  2. 一棵完全二叉树有 100 个结点，叶结点数？
  3. 字符频率 a:4, b:2, c:1, d:1，求 WPL 与 b 的编码（左0右1）。

答案 1. 后序 DEBCA（根A→左子树{B,D,E}先序BDE中序DBE→B为根，D左E右；右子树{C}）。 2. i=50：50号是叶（其孩子101,102>100），49号右孩99…结论：叶=⌈100/2⌉=50（i>n/2 全为叶）。 3. 合并1+1=2，2+2=4，4+4=8；深度 a=1、b=2、c=d=3：WPL=4×1+2×2+1×3+1×3=14（一种编码：a=0，b=10，c=110，d=111）。

05 图

知识点摘要

  • 图定义：顶点集V+边集E；有向/无向；完全图（无向n(n-1)/2条，有向n(n-1)条弧）；连通/强连通；生成树（n顶点n-1边）。
  • 度：无向=边关联数（Σ度=2|E|）；有向分入度/出度（Σ入=Σ出=|E|）。
  • 存储：邻接矩阵（O(n²)，稠密图）、邻接表（O(n+e)，稀疏图；求入度要逆邻接表）、十字链表/邻接多重表（了解）。
  • 遍历：DFS（栈/递归）与 BFS（队列）；邻接表遍历 O(n+e)，矩阵 O(n²)；同一图遍历序列不唯一（邻接矩阵唯一）。
  • 最小生成树 MST：Prim（加点，O(n²)，稠密友好）、Kruskal（加边，O(eloge)，稀疏友好）；MST不唯一但WPL唯一。
  • 最短路：Dijkstra（单源，不能有负权，O(n²)）、Floyd（多源，O(n³)，三重循环中转点k放最外层）。
  • 拓扑排序：AOV网，反复输出入度0顶点；唯一性⇏哈密顿路径；也可DFS逆序；检测环=输出顶点数<n。
  • 关键路径 AOE（了解）：关键活动=最早开始=最迟开始，路径长=工期。

代码示例（BFS 框架）

/* 邻接表BFS（vis[]初始化0，队列略） */
void BFS(ALGraph *G,int v){
    int q[100],h=0,t=0; vis[v]=1; q[t++]=v;
    while(h<t){
        int u=q[h++]; printf("%d ",u);
        ArcNode *p=G->adj[u].first;
        while(p){ if(!vis[p->adjvex]){ vis[p->adjvex]=1; q[t++]=p->adjvex;} p=p->next; }
    }
}

简答题（背诵要点）

  1. Prim 与 Kruskal 的思想与适用：Prim 从某顶点出发每次把"树外最近顶点"拉入树（顶点驱动，稠密图）；Kruskal 按权升序考察每条边，不构成回路才加入（边驱动，稀疏图）；都用贪心，正确性依赖 MST 性质（切分定理）。
  2. Dijkstra 为什么不能负权：算法基于"一旦确定最短路就不再更新"的贪心，负权边可能使后确定的路径经由负边更短，破坏贪心前提。
  3. 拓扑排序步骤：①找入度0顶点入栈/队②弹出输出并删除其所有出边（邻接点入度-1）③新的入度0顶点入栈④重复；输出个数<n ⇒ 有环。

名词解释

  • 连通图：无向图中任意两顶点间存在路径。
  • 生成树：包含图全部n个顶点的极小连通子图，恰有n-1条边。
  • AOV网：顶点表示活动、弧表示活动间优先关系的有向无环图（DAG）。

易错点

  • 无向完全图边数 n(n-1)/2；连通至少 n-1 边；n顶点生成树恰 n-1 边。
  • BFS 用队列、DFS 用栈/递归——队列换成栈就是 DFS，别写反。
  • Floyd 的 k（中转）必须最外层循环。
  • 邻接表存储时 BFS/DFS 序列依赖边表顺序 ⇒ 不唯一；矩阵则唯一。
  • Dijkstra 每轮"固定"一个顶点，n-1 轮结束；描表题按步骤写，别跳步。

自测题（3道）

AOE网：a(1→2)=3，b(1→3)=6，c(2→4)=4，d(3→4)=2，e(4→5)=3。 | 事件k | 1 | 2 | 3 | 4 | 5 | |---|---|---|---|---|---| | ve（最早，正向取max） | 0 | 3 | 6 | 8 | 11 | | vl（最迟，逆向取min） | 0 | 4 | 6 | 8 | 11 | | 活动 | a | b | c | d | e | |---|---|---|---|---|---| | e（=ve起点） | 0 | 0 | 3 | 6 | 8 | | l（=vl终点−时长） | 1 | 0 | 4 | 6 | 8 | | l−e（时间余量） | 1 | 0 | 1 | 0 | 0 | 关键路径 1→3→4→5（b,d,e），工期=11。 易错：ve正向取max、vl逆向取min；关键活动满足 l−e=0；缩短工期必须压缩所有关键路径上的公共活动。

06 查找

知识点摘要

  • 查找表、关键字、平均查找长度 ASL（Σ概率×比较次数）。
  • 顺序查找：ASL=(n+1)/2（成功）；折半查找：判定树，ASL≈log₂(n+1)-1，要求顺序存储+有序；元素 n 的判定树是平衡的，比较次数≤⌈log₂(n+1)⌉。
  • 分块查找（了解）：块间有序块内无序，ASL=索引查找+块内查找。
  • 二叉排序树 BST：左<根<右；中序遍历得递增序列；插入=查找失败处挂上；删除三分支（叶/单孩/双子用前驱或后继替换）；ASL 依赖树形（最坏O(n)斜树）。
  • 平衡二叉树 AVL：|bf|≤1；失衡四型 LL/RR/LR/RL（旋转口诀：LL右旋、RR左旋、LR先左后右、RL先右后左）。
  • 哈希表：散列函数（除留余数法 p 取≤m 的最大素数）、冲突处理：开放定址（线性探测/平方探测）、链地址；装填因子 α=元素数/表长，ASL 与 α 相关与表长无关。
  • 哈希查找失败/成功 ASL 手工计算（必考应用题）。

代码示例（BST 插入）

TNode* InsertBST(TNode *t,int k){
    if(!t){
        t=(TNode*)malloc(sizeof(TNode)); t->data=k;
        t->lchild=t->rchild=NULL; return t;
    }
    if(k<t->data)      t->lchild=InsertBST(t->lchild,k);
    else if(k>t->data) t->rchild=InsertBST(t->rchild,k);
    return t; /* 相等不插入（不允许重复关键字） */
}

简答题（背诵要点）

  1. 折半查找的前提与过程：顺序存储且按关键字有序；取 mid=(low+high)/2 比较，缩小一半区间，直到找到或 low>high 失败；画出判定树求 ASL。
  2. 哈希冲突定义与解决：不同关键字映到同一地址；开放定址法（线性探测易"堆积/聚集"，平方探测缓解）、链地址法（同义词挂链，删除方便）。
  3. BST 删除双子结点：用其中序前驱（左子树最右）或后继（右子树最左）替换关键值，再删那个替换结点。

名词解释

  • 平均查找长度 ASL：查找过程中关键字比较次数的期望值，衡量查找效率。
  • 装填因子：哈希表中已存元素数与表长之比，越大冲突越频繁。
  • 同义词：散列函数值相同的不同关键字。

易错点

  • 折半查找判定树手工构造：mid 向下/向上取整口径全卷统一，标注你的约定。
  • 线性探测删除不能物理删除（做标记），否则断链。
  • ASL 失败长度按"探测到空位"计，别按成功口径算。
  • AVL 旋转后子树挂接方向（新根的左右孩子重接）手画确认。
  • n=10 的折半查找最多比较 ⌈log₂11⌉=4 次。

07 排序【八大排序对比表必背】

知识点摘要

  • 插入类：直接插入（稳定，O(n²)，基本有序时O(n)）、折半插入（比较省移动不省）、希尔排序（增量序列，不稳定，约O(n^1.3)）。
  • 交换类：冒泡（稳定，O(n²)，可提前终止）、快速排序（不稳定，平均O(n log n)最坏O(n²)有序时，空间O(log n)递归栈，划分是核心）。
  • 选择类：简单选择（不稳定，比较O(n²)移动少）、堆排序（不稳定，建堆O(n)，调整O(n log n)，空间O(1)，大根堆升序）。
  • 归并排序：稳定，O(n log n)，空间O(n)，2路归并"排序树"手工画法。
  • 基数排序：稳定，O(d(n+r))，d位数r基数，队列分发收集。
  • 外部排序（了解）：多路归并、败者树、置换选择。

排序对比总表（背诵）

算法 平均 最坏 空间 稳定 备注
直接插入 O(n²) O(n²) O(1) ✔ 基本有序最快
希尔 ~O(n^1.3) — O(1) ✘ 依赖增量
冒泡 O(n²) O(n²) O(1) ✔ 一趟无交换即停
快速 O(n log n) O(n²) O(log n) ✘ 有序/逆序最坏
简单选择 O(n²) O(n²) O(1) ✘ 移动≤3(n-1)
堆排 O(n log n) O(n log n) O(1) ✘ 建堆O(n)
归并 O(n log n) O(n log n) O(n) ✔ 2路，画归并树
基数 O(d(n+r)) 同左 O(r) ✔ 多关键字

代码示例（快排划分——默写级）

int Partition(int a[],int low,int high){
    int pivot=a[low];                 /* 基准取首元素 */
    while(low<high){
        while(low<high && a[high]>=pivot) high--;
        a[low]=a[high];
        while(low<high && a[low]<=pivot) low++;
        a[high]=a[low];
    }
    a[low]=pivot; return low;         /* 基准落位 */
}
void QSort(int a[],int low,int high){
    if(low<high){ int p=Partition(a,low,high);
        QSort(a,low,p-1); QSort(a,p+1,high); }
}

简答题（背诵要点）

  1. 快排思想：取基准将序列划分为"≤基准"与"≥基准"两部分（partition），基准归位，再对两侧递归；平均 O(n log n)，基准选得差（有序）退化 O(n²)。
  2. 堆排序过程：建初始大根堆（从最后一个非叶结点 ⌊n/2⌋ 起向前 sift down）；每趟堆顶与末尾交换、堆尺寸-1、向下调整；升序用大根堆。
  3. 稳定性意义与举例：相等元素排序后相对次序不变；不稳定例：快排（4,4,3）、简单选择（3,3',1）、希尔、堆排。

名词解释

  • 稳定排序：排序后任意两个相等关键字的相对次序与排序前相同。
  • 大根堆：完全二叉树且每个结点≥其孩子（a[i]≥a[2i], a[2i+1]）。

易错点

  • 手工执行题：一趟定义各不相同（快排一趟=基准归位；冒泡一趟=从一端到另一端），答题先写清楚。
  • 建堆从 ⌊n/2⌋ 开始而不是从叶子； sift down 要与较大的孩子交换。
  • "排序趟数与初始序列有关"的只有：冒泡（可提前终止）、快排（递归深度）；其余趟数固定。
  • 基数排序 d 趟，每趟稳定收集（队列），LSD 从最低位开始。
  • 归并段手工题：注意"2路"与不足补空段。

自测题（3道）

  2. 对 {8,3,5,1} 建大根堆（数组从1开始），写最终数组。

答案 1. [27,38,13,49,76,97,65]（49落位下标4）。 2. 从 i=2 向前调整：[8,3,5,1]→i=2(3):孩子1; i=3(5):…；最终 [8,3,5,1] 已是堆？验证 a[1]=8≥a[2]=3,a[3]=5；a[2]=3≥a[4]=1 ⇒ 已是大根堆。 3. 希尔、快速、简单选择、堆排序。例：{3,3',1} 选择排序一轮后 1 与 3 交换 ⇒ 3 与 3' 逆序。

08 大纲冷门考点补充【大纲明确要求、主流笔记容易漏的部分】

依据 408 统考大纲（数据结构部分）补齐四块“大纲点名、复习易漏”的内容：广义表、并查集、B树/B+树、外部排序；另附 KMP next 数组的口径说明。学完打勾：☐广义表 ☐并查集 ☐B树 ☐外部排序 ☐KMP

一、广义表【大纲第4章】

知识点

  • 定义：LS=(a₁,a₂,…,aₙ)，元素可以是原子（小写）或子表（大写）；空表 ()；递归定义。
  • 两个基本操作（必考辨析）：
  • GetHead(L)=表头：第一个元素，可以是原子或子表。
  • GetTail(L)=表尾：除表头外其余元素组成的表——一定是表（哪怕只剩一个原子也要套括号）。
  • 长度=最外层元素个数；深度=括号最大嵌套层数（原子的深度为0，空表深度为1）。

例题

  • L=((a,b),c,d)：长度3，深度2；GetHead(L)=(a,b)，GetTail(L)=(c,d)。
  • A=(())：长度1（有一个元素——空表），深度2；GetHead(A)=()，GetTail(A)=()。
  • B=(a,(b,c))：长度2，深度2；GetHead(B)=a（原子！），GetTail(B)=((b,c))。

存储结构

  • 头尾链表表示法：表结点（tag=1, hp指针, tp指针）+ 原子结点（tag=0, atom）。
  • 扩展线性链表表示法：每个元素一个结点，子表结点指向子表。

自测

  1. ((a)) 的长度和深度？GetHead、GetTail？
  2. 已知 GetTail(L)=((b,c))，且 GetHead(L)=a，写出一个合法的 L。
  3. 广义表 ((a,b,c)) 的深度？

答案：1. 长度1、深度2；GetHead=(a)，GetTail=()。2. L=(a,(b,c))。3. 深度2。

二、并查集【大纲第5章"了解并查集及其应用"】

知识点

  • 用途：维护不相交集合的合并（Union）与查询（Find）；底层=双亲表示法（数组 parent[i] 存双亲，根指向自己）。
  • Find(x)：沿 parent 找根；Union(a,b)：把一棵树的根挂到另一棵根下。
  • 两大优化（答出=加分）：
  • 按秩/按大小合并：矮树挂到高树下，防止退化成长链。
  • 路径压缩：Find 时把沿途结点直接挂到根。
  • 两者结合后单次操作近似 O(α(n))（反阿克曼，工程上视为常数）。
  • 应用：求无向图连通分量个数；Kruskal 判环（两端点同根则加边成环，弃边）。

代码（C，默写级）

int parent[N];
void Init(int n){ for(int i=1;i<=n;i++) parent[i]=i; }
int Find(int x){                      /* 路径压缩版 */
    return parent[x]==x ? x : (parent[x]=Find(parent[x]));
}
void Union(int a,int b){ parent[Find(a)]=Find(b); }

自测

  1. 依次 Union(1,2), Union(3,4), Union(2,3) 后，Find(4) 返回？（无优化、挂左到右约定）
  2. n 个顶点全无边的图，每合并一条有效边（不成环）连通分量减几？
  3. Kruskal 中如何用并查集判环？

答案：1. 根为1（1←2←3←4 链，Find(4)=1）。2. 减1；连通分量初始=n，最小生成树完成时=1。3. 边(u,v)两端 Find 相同 ⇒ 成环，弃。

三、B树与B+树【大纲第7章"B+、B-树的概念与操作"】

m阶B树性质（必背5条）

  1. 每结点最多 m 棵子树、m-1 个关键字。
  2. 根至少 2 棵子树（≥1个关键字）。
  3. 非根非叶至少 ⌈m/2⌉ 棵子树（即 ⌈m/2⌉-1 个关键字）。
  4. 所有叶结点（失败结点）出现在同一层。
  5. 关键字在结点内有序，起"分界"作用。

操作要点

  • 插入：始终插在最底层的终端结点；关键字数超 m-1 → 从中点分裂，中点上移双亲，可能连锁分裂直到根（树高+1）。
  • 删除：叶层直接删；删非叶关键字用前驱/后继替换后转叶层删除；不足 ⌈m/2⌉-1 时向兄弟借 / 与兄弟+双亲合并。

B树 vs B+树（简答必背）

对比项 B树 B+树
关键字与子树 n个关键字 n+1棵子树 n个关键字 n棵子树
数据位置 分布在所有结点 全部在叶结点，非叶只作索引
叶结点 无链 叶结点链成有序链表
查找 可能不到叶就命中 稳定查到叶层，范围查询/遍历强
典型应用 文件系统 数据库索引（MySQL InnoDB）

自测

  1. 3阶B树中一个非根结点最多/最少几个关键字？
  2. 向3阶B树依次插入 1,2,3 会发生什么？
  3. 为什么数据库索引用B+树不用B树？

答案：1. 最多2个（m-1），最少1个（⌈3/2⌉-1=1）。2. 插入1,2后结点满，插3触发分裂：中点2上移成根，1、3分居两叶——树高变2。3. B+树所有查询稳定到叶、叶链支持高效范围扫描，非叶纯索引使单结点能存更多键（扇出更大树更矮，磁盘IO更少）。

四、外部排序【大纲第8章明确要求】

核心链条（简答按此线展开）

  1. 外存数据 ≫ 内存 → 分批读入内存用内排序生成初始归并段(run)写回外存。
  2. 多趟 k路平衡归并 直到 1 个有序段。归并趟数 S=⌈log_k r⌉（r=初始归并段数）→ 想少趟数：增大 k 或减少 r。
  3. k 路归并每选一个最小元素需比较 k-1 次 → 用败者树把每次选择降到 ⌈log₂k⌉ 次比较；再用缓冲区并行读写。
  4. 置换-选择排序（生成初始段）：内存工作区用"选最小且≥上次输出者"的置换法，平均段长可达内存容量2倍 → r 减半。
  5. 最佳归并树：段长不等时按哈夫曼思想安排归并顺序（短的先并），总IO最少。 - 补虚段公式：若 (r-1) mod (k-1) ≠ 0，补 u=(k-1)-(r-1) mod (k-1) 个长度0的虚段（使每次都能凑满k路）。

自测

  1. r=100 个初始归并段，4路平衡归并几趟？用置换-选择后若 r=55 呢？
  2. k=3, r=10，最佳归并树需补几个虚段？
  3. 败者树解决什么问题？

答案：1. ⌈log₄100⌉=4趟；⌈log₄55⌉=3趟（段少了省一趟）。2. (10-1) mod 2=1≠0 → 补 (3-1)-1=1 个虚段。3. k路归并时从k个候选中快速选最小，比较次数从k-1次降到⌈log₂k⌉次。

五、KMP next 数组口径说明【补第4章串】

  • 两种主流口径，答题必须先声明：
  • 严蔚敏/人邮教材口径：next[1]=0，next[j] = "第1~j-1位中最长相等前后缀长度+1"。
  • 王道口径：next[1]=-1（或记 next[0] 起点），数值=最长相等前后缀长度，整体比严口径小1。
  • nextval 优化：若 s[j] 与 s[next[j]] 相同，则 nextval[j]=nextval[next[j]]，避免重复无效比较。
  • 手算示范（严口径）：模式 "ababaa" → next = 0 1 2 3 2 2；再算 nextval = 0 1 0 3 2 2（第4位 a 的 next 指向第3位 a 相同 → 传递）。
  • 考试策略：求 next 手算题先写"采用严蔚敏口径，next[1]=0"，稳分。

简答题背诵版（按章，冲刺期每日过一遍）

格式：问题 → 要点句（首句必背，其余为展开逻辑）。

绪论

  1. 什么是数据结构？——数据结构是相互之间存在特定关系的数据元素的集合，研究数据的逻辑结构、存储结构及在其上定义的运算三个层面。
  2. 算法的五个重要特性？——有穷性、确定性、可行性、输入、输出。
  3. 衡量算法优劣的标准？——正确性、可读性、健壮性、高效性（时间与空间）。

线性表

  1. 顺序表与链表的优缺点及选用？——顺序表随机存取O(1)、存储密度高，但插删需移动O(n)、需预分配；链表插删改指针O(1)、动态分配，但只能顺序存取、有指针开销。频繁按位查找选顺序表，频繁插删或长度动态变化选链表。
  2. 头结点的作用？——使首位置插入删除与中间位置统一、空表与非空表统一，简化边界处理。

栈与队列

  1. 栈与队列的异同？——均为操作受限线性表；栈LIFO一端操作，队列FIFO一进一出；栈用于递归、回溯、表达式求值，队列用于缓冲、层序遍历、排队。
  2. 循环队列为何判满要牺牲一个单元？——front==rear 无法区分空与满；牺牲一格后判满为 (rear+1)%M==front，判空为 rear==front。

树

  1. 哈夫曼树与哈夫曼编码？——WPL最小的二叉树；对频率字符构造哈夫曼树，左0右1得到前缀码，任何编码非另一编码前缀，译码无歧义，总长最短。
  2. 为什么先序+后序不能唯一确定二叉树？——只有一个孩子的结点无法判断该孩子是左是右，树形不唯一；必须搭配中序。

图

  1. DFS与BFS的思想、数据结构、复杂度？——DFS沿一条路径走到底再回溯，用栈/递归；BFS逐层扩展，用队列；邻接表均O(n+e)，邻接矩阵均O(n²)。
  2. Prim与Kruskal？——同为MST贪心算法；Prim加点（树外最近点），适合稠密图；Kruskal加边（全图最小权边不构成环），适合稀疏图。
  3. 拓扑排序与环检测？——AOV网反复输出入度0顶点并删其出边；输出顶点数小于n说明存在环。

查找

  1. 折半查找的条件与效率？——顺序存储且有序；每次比较排除一半，ASL≈log₂(n+1)-1，判定树上查找长度≤⌈log₂(n+1)⌉。
  2. 哈希冲突及解决？——不同关键字映射同地址；开放定址（线性/平方探测）与链地址；ASL取决于装填因子α。

排序

  1. 快排的过程与复杂度？——基准划分两侧递归；平均O(n log n)空间O(log n)；基本有序时退化为O(n²)。
  2. 稳定性判别？——稳定：直接插入、冒泡、归并、基数；不稳定：希尔、快排、简单选择、堆排。
  3. 堆排序流程？——建初始堆（自⌊n/2⌋向前调整）→堆顶与堆尾交换→尺寸减1→向下调整→重复；O(n log n)，空间O(1)，不稳定。

名词解释（背诵卡片池）

每条已同步到 07_Anki卡片/专业课_名词解释.csv。

基础概念

  • 数据：能被计算机识别、存储和处理的符号总称。
  • 数据元素：数据的基本单位，通常作为一个整体进行处理。
  • 数据项：组成数据元素的、不可分割的最小单位。
  • 数据对象：性质相同的数据元素的集合。
  • 逻辑结构：数据元素之间逻辑关系的描述（集合、线性、树形、图状）。
  • 存储结构：数据结构在计算机中的映像（顺序、链式、索引、散列）。
  • 算法：求解特定问题的有限指令序列，具有有穷性、确定性、可行性、输入、输出。

线性结构

  • 顺序表：顺序存储的线性表，逻辑相邻则物理相邻。
  • 单链表：结点含数据域与指向后继的指针域的线性表。
  • 循环链表：尾结点指针指向头结点的链表。
  • 双向链表：结点含前后驱指针的链表。

栈队列

  • 栈：仅允许一端（栈顶）插入删除的LIFO线性表。
  • 队列：一端入队另一端出队的FIFO线性表。
  • 循环队列：用取模运算将顺序队列首尾相连，解决假溢出。

树

  • 二叉树：每结点至多两棵有序子树的树（左右不可颠倒）。
  • 满二叉树：深度k且有2^k-1个结点的二叉树。
  • 完全二叉树：与同深满二叉树编号一一对应（最下层靠左）的二叉树。
  • 线索二叉树：空指针改为指向前驱/后继的线索的二叉链表。
  • 哈夫曼树：带权路径长度WPL最小的二叉树（最优二叉树）。
  • 前缀码：任何字符编码都不是另一字符编码前缀的编码集。

图

  • 连通图：任意两顶点有路径相通的无向图。
  • 强连通图：任意两顶点相互可达的有向图。
  • 生成树：含全部顶点的极小连通子图（n-1条边）。
  • 最小生成树：各边权值和最小的生成树。
  • AOV网：顶点表活动、弧表优先关系的有向无环图。
  • AOE网：边表活动、顶点表事件的带权有向无环图（关键路径）。

查找与排序

  • 平均查找长度ASL：查找成功/失败时关键字比较次数的期望值。
  • 二叉排序树：左子树<根<右子树的二叉树，中序遍历递增。
  • 哈希（散列）：由关键字直接计算存储地址的查找技术。
  • 冲突与同义词：不同关键字得同一散列地址；互为同义词。
  • 装填因子：表中元素数/表长。
  • 稳定排序：相等关键字排序后相对次序不变的排序算法。
  • 堆：完全二叉树且任一结点不小于（或不大于）其孩子。

外部排序完整演算例题

①最佳归并树：初始段长 {2,3,6,9}，2路归并——按哈夫曼思想先并最小两段 2+3=5，再 5+6=11? （注意：归并树取最小两棵）→ {5,6,9} → 5+6=11 → {11,9} → 11+9=20。

总读+写记录数 = 2×WPL = 2×(2×2+2×3+1×6+1×9) = 50。 ②补虚段：8 个初始段做 3 路归并：(8−1) mod (3−1)=1≠0 → 补 u=(k−1)−1=1 个空段后再建树。 ③败者树：k=8 路归并中每选出一个最小记录，比较次数从 k−1=7 次降为 ⌈log₂8⌉=3 次。

数据结构 · 难点专攻

1. KMP next 手算固定流程（严蔚敏口径，答题先声明）

next[1]=0，next[2]=1；求 next[j] 时看前 j−1 位的“最长相等前后缀长度”，next[j]=该长度+1。nextval 传递规则：若 s[j]==s[next[j]]，nextval[j]=nextval[next[j]]。口算模板串 "ababaa"：next=0 1 2 3 2 2。

2. AVL 旋转：先找失衡点再对号入座

从插入点向上找第一个 |bf|>1 的结点；判断属 LL/RR/LR/RL（看失衡点→孩子→孙子的方向链）；LL 右旋、RR 左旋、LR 先左后右、RL 先右后左。旋转后原来孙子子树挂接位置最容易错——手画三层复演。

3. 哈夫曼手算两个校验

每次取权最小的两棵合并，和放回重排；n 个叶共 2n−1 个结点、无度1结点。WPL 两条算法互相校验：Σ权×路径长 = 所有非叶结点值之和。

4. 图算法手算模板

Dijkstra：每轮「确定一个未定点（dist最小）→ 用它松弛邻边 → 打标记」，n−1 轮，写表得分。Prim：维护“树内点集”，每轮选横跨边最小。Kruskal：边排序+并查集判环。拓扑：反复摘入度0结点，输出数<n 即有环。

5. 外部排序数字题公式

趟数 S=⌈log_k r⌉；补虚段：当 (r−1) mod (k−1)≠0，补 u=(k−1)−(r−1) mod (k−1) 个空段；置换-选择平均段长≈2×内存容量。
