第7章 查找

一、顺序查找与折半查找

S1 顺序查找：成功 ASL=(n+1)/2；失败 ASL=n+1（含哨兵后为 n+1? 无哨兵比较n次+1次判越界）。对存储无要求（顺序/链式皆可）。

S2 折半查找：仅适用于有序的顺序表（链表不行——无法O(1)取中点）。 判定树：mid=⌊(low+high)/2⌋；n个元素的判定树是平衡二叉树形态，比较次数≤⌈log₂(n+1)⌉；ASL≈log₂(n+1)−1。

考题1（折半查找全程演算+ASL） 有序表 (7,14,18,21,23,29,31,35,38,42,46,49,52)，共13个元素。①查找23的比较序列；②画判定树求成功ASL。 【解】①low=1,high=13：mid=7→31>23，high=6；mid=(1+6)/2=3→18<23，low=4；mid=(4+6)/2=5→A[5]=23 ✓ 3次比较（比较了31、18、23）。 ②判定树：根mid=7；左子树[1..6]根mid=3；右子树[8..13]根mid=10；……第4层6个叶子。 各层结点数：1、2、4、6 → ASL=(1×1+2×2+3×4+4×6)/13=(1+4+12+24)/13=41/13≈3.15。 【修正计算】比较次数按层：第1层1次(1个)、第2层2次(2个)、第3层3次(4个)、第4层4次(6个)：ASL=(1+4+12+24)/13=41/13≈3.15。∎

S3 分块查找：分块有序（块间有序、块内无序）+索引表。ASL=索引查找+块内查找；块大小 s=√n 时 ASL 最小=√n+1（对 (b+1)/2+(s+1)/2 求导，b=n/s）。

二、B树与B+树

B1 m阶B树定义（5条）：①每个结点至多 m 棵子树、m−1 个关键字；②根至少2棵子树、1个关键字；③非根非叶至少 ⌈m/2⌉ 棵子树、⌈m/2⌉−1 个关键字；④所有叶子（失败结点）同一层；⑤关键字有序。 B2 高度：n个关键字的m阶B树高度 ≤ log_{⌈m/2⌉}((n+1)/2)+1（含叶子层）。 B3 插入：插入到最底层叶子 → 超过 m−1 个关键字 → 从中间 ⌈m/2⌉ 处分裂，中间关键字上移。 B4 删除：删叶子关键字 → 低于下限 → 够借则借（兄弟转经双亲），不够则与兄弟+双亲关键字合并；删非叶关键字用前驱/后继替换后转为删叶子。 B5 B+树差异（必背四条）：①n棵子树含n个关键字；②叶子含全部关键字并链表相连（支持顺序查找）；③非叶结点只是索引；④m阶B+树根至少1个关键字? ——差异总结："查找速度"B+树稳定（都到叶子）、"支持范围查询"。

考题2（3阶B树插入演算） 依次插入 1,2,3,4,5（3阶：每结点至多2关键字、至少1个）。 【解】插1、2：根[1,2]。插3：溢出[1,2,3] → 中间2上移，分裂：根[2]，孩子[1]、[3]。 插4：进右叶[3,4]。插5：右叶[3,4,5]溢出 → 4上移：根[2,4]，孩子[1]、[3]、[5]。 最终：根[2,4]，三叶[1]、[3]、[5]。∎

考题3（B树删除演算） 在上题结果中删除1。 【解】删1后叶[ ]下溢（3阶至少1个关键字）。兄弟[3]、[5]：右兄弟[3]恰好1个（够借的下限=1，借后自己也下限? 3阶最少1个，借走后[3]变空 → 不够借）→ 合并：双亲关键字2下移与[ ]、[3]合并 → [2,3]；根变[4]。 结果：根[4]，两叶[2,3]、[5]。∎ （删除决策链：所在叶够→直删；不够→看兄弟能否借（旋转）；不能→合并，合并可能向上传播。）

三、散列（Hash）查找

H1 概念：散列函数 H(key) 建立直接映射；冲突=不同key映射同址；装填因子 α=表中元素数/表长——ASL只与α有关，与表长无关。 H2 冲突处理： - 开放定址：线性探测（±1，易"堆积"）、平方探测（±1²,±2²…，表长须为4k+3的素数）、双散列；删除只能惰性删除（标记DELETED）； - 拉链（链地址）：同义词链表，删除直接摘链。 H3 ASL计算模板： - 成功：每个元素"插入时的探测次数"的平均（按已入表元素算）； - 失败：从每个可能的散列地址出发探测到空的次数的平均（分母=散列函数值域大小）。

考题4（拉链法ASL） H(k)=k mod 5，依次插入 4,9,14,3,8,13。求成功与失败的ASL。 【解】链表：4%5=4→[4]；9%5=4→链尾[4,9]；14%5=4→[4,9,14]；3%5=3→[3]；8%5=3→[3,8]；13%5=3→[3,8,13]。 成功：4:1次、9:2、14:3、3:1、8:2、13:3 → ASL=(1+2+3+1+2+3)/6=2。 失败（5个地址，比较到链尾空）：地址0、1、2空→各1次；地址3链长3→4次；地址4链长3→4次。 ASL失败=(1+1+1+4+4)/5=11/5。∎ （对照：线性探测版的同型计算见《综合题精讲》题6（55/13≈4.23）——拉链无堆积现象，失败ASL显著更优。）

考题5（平方探测演算） H(k)=k mod 11，依次插入 22,41,53,46,30,13（平方探测，表长11）。给出最终表与成功ASL。 【解】22→0；41→8；53→9；46→2；30→8冲突：8+1²=9冲突→8−1²=7；13→2冲突：2+1²=3 → 插入3。 表：0:22，2:46，3:13，7:30，8:41，9:53。 成功：22:1、41:1、53:1、46:1、30:2（8→7）、13:2（2→3）→ ASL=8/6=4/3。∎ （平方探测避免线性堆积，但"表长=4k+3素数"才能探测全表——概念考点。）

四、B树相关概念对比

B树 B+树
子树与关键字 n棵子树、n−1个关键字 n棵子树、n个关键字
关键字位置 全树分布 全在叶子（非叶只作索引）
顺序查找 不支持（要中序遍历） 叶子链表直接支持

二、各排序精讲与演算

P1 直接插入：把第i个元素插入前面有序段。基本有序时接近O(n)（内层几乎不移动）——这也是它适合"小规模或基本有序"的原因。

P2 快速排序（挖坑法全程演算）：对 (52,49,80,36,14,58,61,23,97,75) 做一趟快排（枢轴52）： 坑=1（52挖出）。从high找<52：23（位8）→填坑1，坑=8； 从low找≥52：80（位3）→填坑8，坑=3； 从high：61、58≥52跳过；14（位5）<52 → 填坑3，坑=5； 从low：36、52? low扫到坑处重合 → 枢轴52入坑5。 一趟结果：(23,49,14,36, 52, 58,61,80,97,75)——52到达最终位置。∎ 【推导】最优（每次均分）：T(n)=2T(n/2)+O(n)=O(nlog₂n)；最坏（基本有序/枢轴总在最边）：T(n)=T(n−1)+O(n)=O(n²)；空间=递归栈O(log₂n)，最坏O(n)。 P3 堆排序演算：把 (45,78,11,65,33) 建成大根堆并输出前两个最大值。 建堆（自底向上，i=⌊5/2⌋=2起）：i=2(78)：孩子65,33 → 78最大，不动；i=1(45)：孩子78,11 → 45<78交换 → (78,45,11,65,33)，45落位2的孩子65,33 → 再换65 → 大根堆 (78,65,11,45,33)。 排序：78↔33 → 筛33（换65）→ (65,45,11|78)；65↔33 → 筛 → (45,33,11|65,78)。 前两大火已输出78、65。∎ （建堆自底向上O(n)；每次筛选O(log₂n)；取前k大只需k次输出——TopK题的标准答案。） P4 归并排序演算：对 (49,38,65,97,76,13,27,49′) 做2路归并： 第1趟：(38,49)(65,97)(13,76)(27,49′)；第2趟：(38,49,65,97)(13,27,49′,76)；第3趟：完整有序。 趟数=⌈log₂8⌉=3；稳定性：49始终在49′前 → ✔。∎ P5 基数排序演算：对 (278,109,063,930,589,184,505,269,008,083) 做3位LSD基数排序（r=10）： 按个位分配收集：930,063,083,505,278,008,109,589,269； 按十位：505,008,109,930,063,269,083,589； 按百位：008,063,083,109,269,505,589,930 → 有序。d=3趟，每趟O(n+r)，总O(d(n+r))，空间O(r)。∎ （LSD低位优先：必须用稳定排序收集——否则前趟成果作废。）

P6 外部排序： - 败者树：k路归并中O(log₂k)选最小；置换-选择生成平均2×内存容量的初始归并段； - 归并趟数=⌈log_k r⌉（r个初始段、k路）；最佳归并树（哈夫曼思想）安排归并顺序使I/O最少；补虚段：若(r−1)%(k−1)≠0，补 u=(k−1)−(r−1)%(k−1) 个空段。 【例】9个初始段4路归并：趟数=⌈log₄9⌉=2；(9−1)%3=2≠0 → 补1个虚段。

三、排序方法的选择逻辑（985面试）

  • n小（<50）：直接插入或简单选择（插入在基本有序时更优）；
  • n大且随机：快排；基本有序：插入/冒泡；要求稳定：归并；
  • 只求前k大：堆排序（O(n+klog n)）；
  • 关键字位数少且可分：基数；
  • 内存装不下：外部排序（置换选择+最佳归并树+败者树多路归并）。
