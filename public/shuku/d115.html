考研政治 · 只列框架

启动时间：2027年7月（现在完全不用碰）。满分100分：单选16×1' + 多选17×2' + 分析题5×10'。 五大模块按分值排序：毛中特≈30分 > 马原≈24分 > 思修≈16分 ≈ 时政16分 > 史纲≈14分。

模块一 马克思主义基本原理（马原，~24分）

  • 唯物论：物质与意识 / 世界的物质统一性
  • 辩证法：两大特征（联系、发展）/ 三大规律（对立统一、量变质变、否定之否定）/ 五对范畴
  • 认识论：实践与认识 / 真理与价值 / 认识过程
  • 唯物史观：社会基本矛盾 / 人民群众 / 社会形态
  • 政治经济学（选择题重点）：商品与劳动二重性 / 剩余价值 / 资本积累 / 利润与平均利润
  • 科学社会主义：两次飞跃 / 共产主义
  • 出题特点：选择题考"案例对原理"；分析题基本出自辩证法+认识论

模块二 毛泽东思想和中国特色社会主义理论体系（毛中特，~30分）

  • 毛泽东思想：形成发展 / 新民主主义革命理论 / 社会主义改造
  • 邓小平理论："什么是社会主义、怎样建设社会主义"
  • "三个代表"、科学发展观（选择级）
  • 习近平新时代中国特色社会主义思想（当代重点，分值大头）：十个明确 / 十四个坚持 / 五位一体 / 四个全面 / 新发展理念 / 高质量发展 / 全过程人民民主 / 共同富裕 / 中国式现代化 / 人类命运共同体
  • 出题特点：分析题主战场，与当年时政结合

模块三 中国近现代史纲要（史纲，~14分）

  • 时间轴：1840-1919 旧民主主义（鸦片战争→太平天国→洋务→维新→辛亥）
  • 1919-1949 新民主主义（五四→建党→大革命→土地革命→抗战→解放战争）
  • 1949-至今：社会主义改造 → 曲折探索 → 改革开放 → 新时代
  • 出题特点：选择题考周年纪念事件；分析题常与毛中特合流

模块四 思想道德与法治（思修，~16分）

  • 人生观：人生目的、态度、价值
  • 理想信念 / 中国精神（民族+时代）
  • 社会主义核心价值观
  • 道德：传统美德 / 社会公德 / 职业道德 / 家庭美德
  • 法治：宪法 / 民法典 / 权利义务 / 法治体系
  • 出题特点：分析题一题；选择题考细节表述

模块五 形势与政策及当代世界经济与政治（时政，~16分）

  • 当年1月-12月重大时政（选择2-3题）
  • 分析题第5题：中国与世界的重大议题
  • 来源：考前各名师年度总结（免费渠道见存档《免费资源清单.md》）
