短语与固定搭配 · 背诵版（与《六级6000词》配套）

结构：Part 1 动词短语（逐条编号 #001起，按主动词字母序）｜Part 2 介词短语（按介词打包）｜Part 3 名词/形容词+介词搭配｜Part 4 写作加分短语｜Part 5 易混短语辨析。 图例：与单词书一致——★★★ 超高频｜★★ 高频｜★ 中频。例： 给真题风格短例句；辨： 给易混对比。 和单词书怎么配合：单词书背到哪个动词（如 take），当天就把本册对应动词组过一遍——词与短语同根共背，记忆效率翻倍。

背诵方法

  1. 动词打包法：短语以动词为锚——背 take 时把 take in/on/over/up 一次拿下一串；
  2. 例句内化：每条至少念一遍例句；Part 1 的★★★条目要能默写例句；
  3. 完形逻辑：短语题的本质是"动词+副词/介词的意义引申"——记住字面义（up=完成/出现，off=离开/取消，out=向外/耗尽，over=翻转/越过）可推导大部分陌生短语；
  4. 写作输出：Part 4 的短语每周挑5个写进作文，用过才算会。

Part 5 易混短语辨析（考前必刷30组）

  1. agree with sb. / agree to sth. / agree on sth.：同意某人 / 同意某事(提议) / 就…达成一致。
  2. argue with / argue for / argue against：与某人争辩 / 为…辩护 / 反对。
  3. be made of / be made from / be made up of：由…制成(看得出原料) / 看不出原料 / 由…组成。
  4. break in / break into：不及物破门而入 / 及物闯入(房子)。
  5. call on sb. / call at a place：拜访某人 / 拜访某地。
  6. compare…to / compare…with：比作(比喻) / 与…比较。
  7. consist of / consist in：由…组成 / 在于。
  8. correspond to / correspond with：相当于 / 与…通信一致。
  9. deal with / cope with / handle：处理（cope 强调"成功应对"）。
  10. die of / die from：死于内因(疾病) / 死于外因(事故)。
  11. familiar with / familiar to：人熟悉物 / 物为人所熟悉。
  12. hear of / hear from：听说过 / 收到…来信。
  13. known as / known for / known to：被称为 / 因…出名 / 为…所知。
  14. look forward to / look up to / look down on：期待(接doing) / 尊敬 / 看不起。
  15. occur to / happen to：(想法)浮现于 / 发生在…身上（常指不幸）。
  16. put up with / keep up with / catch up with / come up with / end up with：容忍 / 跟上 / 赶上 / 想出 / 以…告终。
  17. result in / result from：导致 / 由…引起（in前因后果？不对——in前是因，后是果；from后是因。记住：lead to=result in=造成；arise from=result from=源于）。
  18. run out / run out of：某物用完(物作主语) / 人用完某物。
  19. see to / see through / see off / see into：负责照料 / 识破 / 送行 / 调查。
  20. stand for / stand by / stand out / stand up for：代表 / 支持；旁观 / 突出 / 捍卫。
  21. take place / take the place of / in place of：发生 / 代替 / 代替(介词短语)。
  22. turn out / turn up / turn down / turn to：结果是 / 出现 / 拒绝；调低 / 求助于。
  23. used to do / be used to doing / be used to do：过去常常 / 习惯于 / 被用来做。
  24. a number of / the number of：许多(+复数动词) / …的数量(+单数动词)。
  25. in case of / in case：万一(介词短语) / 以免；万一(连词，接从句)。
  26. at hand / in hand / on hand：近在手边 / 在进行中；掌握中 / 可用；在场。
  27. spend…on sth. / spend…(in) doing / cost sb. sth. / take sb. time / pay for：花法大不同，主语人/物要分清。
  28. point at / point to / point out：指着 / 指向(抽象也可) / 指出。
  29. out of question / out of the question：没问题（古旧用法） / 不可能（常考后者！）。
  30. in the way / on the way / by the way / in a way：挡道 / 在路上 / 顺便说 / 在某种程度上。
