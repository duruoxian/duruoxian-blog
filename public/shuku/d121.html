Part A · 复试快问快答 100 题

A1 数学桥梁（1-10）

  1. ML要哪些数学？——线代（矩阵/特征值/正定）、概率（贝叶斯/期望/MLE）、优化（梯度/链式/凸性）。
  2. 反向传播用什么数学？——链式法则的矩阵版。
  3. PCA用什么？——协方差矩阵特征分解，取最大特征值方向。
  4. 核函数合法性判据？——核矩阵半正定（Mercer）。
  5. 最小二乘的概率解释？——高斯噪声下的MLE。
  6. 交叉熵的出处？——伯努利/多项分布的负对数似然。
  7. 贝叶斯公式在ML的典型应用？——朴素贝叶斯；"后验=证据更新信念"。
  8. 偏差-方差分解？——误差=偏差²+方差+噪声；欠拟合偏差大、过拟合方差大。
  9. 梯度下降为什么沿负梯度？——负梯度是下降最快的方向（方向导数最小）。
  10. 大数定律对ML的意义？——样本均值收敛于期望：经验风险逼近期望风险，训练才有效。

A2 机器学习（11-35）

  1. 监督/无监督/强化区别？——有标签分类回归/无标签聚类降维/奖励驱动交互。
  2. 过拟合定义与五对策？——训练好测试差；增数据、正则化、降复杂度、早停、Dropout。
  3. 欠拟合对策？——加特征、加复杂度、减正则。
  4. 线性回归解析解？——w=(XᵀX)⁻¹Xᵀy（正规方程）。
  5. XᵀX不可逆怎么办？——去相关特征/L2正则/伪逆。
  6. 逻辑回归是回归吗？——不是，是线性模型+sigmoid的分类器。
  7. 逻辑回归损失？——交叉熵=负对数似然。
  8. 为什么不用MSE训逻辑回归？——非凸且饱和区梯度趋零。
  9. L1与L2？——L1稀疏选特征（菱形顶点）、L2平滑防过拟合。
  10. L1为什么稀疏？——菱形约束尖角落在坐标轴上，其他系数被压成0。
  11. L2的先验解释？——高斯先验；L1是拉普拉斯先验。
  12. KNN三要点？——惰性无训练、K交叉验证选、特征要归一化。
  13. K太小/太大？——小→过拟合；大→平滑欠拟合（K=N退化多数类）。
  14. 朴素贝叶斯"朴素"在哪？——条件独立假设（给定类，特征独立）。
  15. 拉普拉斯平滑干嘛？——防零概率，计数加1。
  16. 决策树分裂准则？——信息增益（ID3）/增益率（C4.5）/基尼（CART）。
  17. 信息增益公式？——H(D)−H(D|A)，熵=−Σp log₂p。
  18. C4.5为什么改进ID3？——治"偏爱取值多的特征"，除以固有值。
  19. 树怎么防过拟合？——预剪枝/后剪枝。
  20. Bagging与Boosting方向？——并行降方差/串行降偏差。
  21. 随机森林双随机？——样本bootstrap+特征随机（每次分裂抽√p个）。
  22. GBDT思想？——每轮新树拟合前面模型的残差。
  23. SVM核心思想？——最大间隔超平面，解只由支持向量决定。
  24. 核技巧解决什么？——低维线性不可分→隐式高维映射，免显式计算。
  25. SVM vs 逻辑回归？——都线性分类器；SVM间隔最大重支持向量适合小样本，LR输出概率。

A3 无监督与评估（36-50）

  1. K-means流程？——最近中心分派→均值更新→收敛。
  2. K-means缺陷？——K要预设、对初值/离群点敏感、只适合凸簇。
  3. K怎么选？——肘部法/轮廓系数。
  4. PCA步骤？——去中心化→协方差→特征分解→取前k特征向量投影。
  5. PCA保留信息怎么算？——前k特征值之和/全部特征值之和。
  6. 混淆矩阵四格？——TP/FP/FN/TN。
  7. 精确率与召回率公式？——TP/(TP+FP)；TP/(TP+FN)。
  8. 癌症筛查看哪个指标？——召回率（漏诊代价大）。
  9. 垃圾邮件看哪个？——精确率（误杀代价大）。
  10. F1是什么平均？——P与R的调和平均（惩罚短板）。
  11. AUC含义？——ROC曲线下面积，衡量排序能力；0.5随机、1完美。
  12. 类别不平衡为什么不能看准确率？——全预测多数类也有高准确率（99:1时99%）。
  13. K折交叉验证？——轮流K−1训练1验证取平均，小数据调参稳。
  14. 数据泄露？——测试信息（如全量归一化统计）混入训练；pipeline必须在折内拟合。
  15. 训练/验证/测试集分工？——训练学参数、验证调超参、测试只看一次。

A4 深度学习（51-75）

  1. 为什么需要激活函数？——否则多层线性=一层；深度=非线性层数。
  2. sigmoid缺点？——饱和区梯度≈0、非零中心。
  3. ReLU与死亡神经元？——负区梯度0致死亡；LeakyReLU治。
  4. softmax用途？——多分类输出层，输出和为1的概率分布。
  5. 反向传播四公式？——δᴸ=∂L/∂a⊙σ′；δˡ=(Wˡ⁺¹)ᵀδˡ⁺¹⊙σ′；∂L/∂W=δ(aˡ⁻¹)ᵀ；∂L/∂b=δ。
  6. 梯度消失原因与对策？——导数连乘<1；ReLU/残差/BN/好初始化。
  7. 梯度爆炸对策？——梯度裁剪、改结构、初始化。
  8. CNN两大特性？——局部连接+权值共享。
  9. 卷积输出尺寸？——O=⌊(H−K+2P)/S⌋+1。
  10. 卷积参数量？——(K×K×Cᵢₙ+1)×Cₒᵤₜ。
  11. 池化作用？——降尺寸、扩感受野、小平移不变；无参数。
  12. 为什么深网络用小核堆叠？——两个3×3=一个5×5感受野，参数更少且多一次非线性。
  13. 感受野？——顶层一个像素对应底层输入的区域，层层堆叠变大。
  14. RNN缺陷？——长序列梯度消失，记不住长依赖。
  15. LSTM三门？——遗忘/输入/输出；细胞状态加法更新=梯度直通。
  16. LSTM为什么治梯度消失？——Cₜ=f⊙Cₜ₋₁+i⊙C̃ 有恒等式通道，不是连乘。
  17. GRU与LSTM？——两门简化版，效果相当更快。
  18. 自注意力公式？——softmax(QKᵀ/√dₖ)V。
  19. Q/K/V直觉？——Q查询找什么、K键有什么、V值给内容；加权V。
  20. 为什么除√dₖ？——防点积方差大→softmax饱和→梯度小。
  21. 多头注意力？——h组QKV并行再拼接，各关注不同模式。
  22. 为什么需要位置编码？——注意力本身无序，打乱输入结果不变。
  23. Transformer vs RNN？——全并行训练+任意位置O(1)直连；代价O(n²)。
  24. ResNet为什么能训深？——y=F(x)+x恒等路径保梯度（∂y/∂x=∂F/∂x+1）。
  25. Dropout原理？——训练随机失活=隐式集成；测试全开并缩放。

A5 LLM与Agent（76-95）

  1. GPT训练三阶段？——预训练（next token）→SFT（指令）→RLHF/DPO（对齐）。
  2. 温度是什么？——softmax前logit除T；低T确定保守、高T多样发散。
  3. top-p采样？——只在累积概率p内采样，截断长尾。
  4. KV缓存？——自回归生成缓存已算的K/V避免重算。
  5. 幻觉成因？——按词的似然生成而非查证事实；缓解：RAG/引用/校验/低温。
  6. In-context learning？——不动权重，上下文给示例即可会任务。
  7. CoT为什么有效？——推理外化成草稿纸，复合错误不再一步犯。
  8. Chatbot vs Agent？——单轮应答 vs 感知-规划-行动多步闭环作用于环境。
  9. ReAct？——Reason与Act交替：Thought→Action→Observation循环。
  10. Function calling谁执行？——模型只输出结构化调用意图，应用侧执行后回填。
  11. 工具描述用什么写？——JSON schema（名称/功能/参数）。
  12. MCP是什么？——工具/数据源接入的标准化协议，Agent生态即插即用。
  13. Agent记忆三层？——短期上下文/长期向量库/任务内草稿外写。
  14. 上下文塞不下怎么办？——摘要压缩+重要事实写长期记忆。
  15. RAG两大管线？——离线：切分→embedding→向量库；在线：查询向量→检索top-k→重排→带引用生成。
  16. chunk为什么是第一超参？——太小丢上下文、太大稀释相关性。
  17. 混合检索？——向量（语义）+BM25（关键词）互补。
  18. RAG vs 微调？——RAG改知识（即时可溯源）、微调改行为（风格格式）；常组合。
  19. Agent失败模式与对策？——死循环/幻觉参数/过早完成；步数上限+校验+反思+人审。
  20. Agent评测为什么难？——成功≠过程对、轨迹长、环境非确定、基准污染——开放问题。

B2 NumPy（ML的C语言）

import numpy as np
a = np.array([[1,2],[3,4]])        # 2×2矩阵
b = np.zeros((3,4)); c = np.ones(5); d = np.arange(0,1,0.1)

a.shape; a.T                        # 形状；转置
a @ b                               # 矩阵乘（等价 np.matmul；* 是逐元素！）
np.dot(a, b)                        # 内积/矩阵乘
a.sum(axis=0)                       # 按列求和（axis=1按行）——理解axis=沿哪个维度压扁
a.max(axis=1); a.mean()

# 广播 broadcasting：形状不同的数组自动对齐运算
a = np.ones((3,4)); a + np.array([1,2,3,4])   # (3,4)+(4,)→每行加同一向量——ML里加偏置全靠它

x = np.random.randn(100, 10)        # 标准正态样本矩阵（100样本×10特征）

【对照C】NumPy数组≈C数组，但向量化运算代替循环：a*a 一行=C里一个for；速度快百倍（底层C实现）。 【核心三概念】shape、axis、broadcasting——90%的NumPy报错是这三者没对齐。

B3 最小PyTorch（研0第一周能看懂训练循环）

import torch
x = torch.tensor([[1.],[2.]], requires_grad=True)   # 张量+追踪梯度
y = (x**2).sum()
y.backward()                                         # 自动微分（反向传播一行）
print(x.grad)                                        # dy/dx = 2x → [[2.],[4.]]

# 训练循环模板（所有深度学习框架同构）
for epoch in range(100):
    pred = model(x_train)          # 前向
    loss = loss_fn(pred, y_train)  # 算损失
    optimizer.zero_grad()          # 清旧梯度
    loss.backward()                # 反传
    optimizer.step()               # 更新参数
