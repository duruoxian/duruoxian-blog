一、单项选择题（10题）

C1. 在OSI参考模型中，实现相邻结点间流量控制的是： A. 物理层 B. 数据链路层 C. 网络层 D. 传输层

B。链路层管"相邻结点"，传输层管"端到端"。

C2. 交换机工作在： A. 物理层 B. 数据链路层 C. 网络层 D. 传输层

B。路由器→网络层；集线器→物理层。

C3. 某链路带宽8kb/s，传播时延250ms，时延带宽积为： A. 1000bit B. 2000bit C. 4000bit D. 16000bit

8kb/s × 0.25s = 8000b/s × 0.25s = 2000bit，选 A。

C4. 用电话线传送数据，信道带宽4kHz，信噪比30dB，最大数据率（香农）： A. 8kb/s B. 16kb/s C. 32kb/s D. 40kb/s

30dB → S/N=1000；C=4k×log₂(1001)≈4k×9.97≈D. 40kb/s。

C5. 以太网采用曼彻斯特编码，100BASE-TX数据率100Mb/s，波特率为： A. 50M Baud B. 100M Baud C. 200M Baud D. 无法确定

C。曼彻斯特每比特2个信号变化：波特率=2×数据率=200MBaud。

C6. 16位序号的GBN协议，发送窗口最大为： A. 8 B. 16 C. 32767 D. 65535

C。W≤2ⁿ−1=65535。

C7. ARP协议的功能是： A. MAC→IP B. IP→MAC C. 域名→IP D. IP→域名

B。（C是DNS，D是反向DNS/PTR）

C8. DHCP客户端与服务器交互使用的传输层协议和端口： A. TCP 67/68 B. UDP 67/68 C. UDP 53 D. TCP 21

B。服务器67、客户端68，全用UDP广播。

C9. TCP建立连接过程中，第二次握手的报文标志为： A. SYN B. ACK C. SYN+ACK D. FIN+ACK

C。服务端回 SYN+ACK。

C10. 下列不属于网络层协议的是： A. IP B. ICMP C. ARP D. TCP

D。TCP是传输层。

二、综合计算题（10题）

A1.★★ 主机A经链路发1MB文件给B（中间无缓存延迟），速率10Mb/s，传播时延10ms，分组大小1KB（含头部忽略）。求：全部比特到达的总时间（从首个比特发送起）。

发送时延=8×10⁶bit/10⁷b/s=0.8s；传播=10ms。流水线：总时间≈发送0.8s+最后1组的传播0.01s≈0.81s（分组化使传播与发送重叠）。

A2.★★ 停止-等待协议：帧长1000B，速率1Mb/s，RTT=10ms，忽略确认帧发送时间。信道利用率？

T_D=1000×8/10⁶=8ms；U=T_D/(T_D+RTT)=8/(8+10)=44.4%。

A3.★★ 连续ARQ：信道利用率为1时需要发送窗口多大？帧长同A2、RTT同上。

需 W≥(T_D+RTT)/T_D=18/8=2.25 → W=3。若序号3位，GBN可行（3≤7）。

A4.★★★ IP地址192.168.10.0/24，划分成至少5个子网，每个子网至少容纳25台主机。给出掩码、每子网可用主机数、前3个子网的网络地址。

k=⌈log₂(25+2)⌉=5位主机位 → 前缀/27，掩码255.255.255.224；块大小32，可用主机30台。 子网：192.168.10.0/27, .32/27, .64/27（共8个子网≥5 ✓）。

A5.★★★ 将192.168.32.0/24、192.168.33.0/24、192.168.34.0/24、192.168.35.0/24 聚合成一条路由。

32-35 = 二进制 00100000~00100011 → 公共前缀22位 → 192.168.32.0/22（掩码255.255.252.0）。

A6.★★ 主机IP=192.168.44.137/26，求其所在子网的网络地址、广播地址、可用主机范围。

/26 → 块64；44.137：137=128+9 → 在 128~191 块 → 网络=192.168.44.128，广播=192.168.44.191，可用 .129~.190（62台）。

A7.★★★ 主机A向主机B建立TCP连接与断开：说明三次握手与四次挥手的报文序号变化（初始seq=100，B初始seq=300）。

握手：A→SYN seq=100；B→SYN+ACK seq=300 ack=101；A→ACK seq=101 ack=301。 挥手（数据后）：A→FIN seq=x ack=y；B→ACK ack=x+1；B→FIN seq=y ack=x+1；A→ACK ack=y+1，A等2MSL后CLOSED。

A8.★★★ TCP拥塞控制：ssthresh=8MSS，从cwnd=1开始，第6个RTT发生超时。逐RTT列出cwnd并写出超时后的变化。

RTT1:1→RTT2:2→RTT3:4→RTT4:8（达阈值转线性）→RTT5:9→RTT6:10（超时）→ ssthresh=10/2=5，cwnd=1 重新慢启动：RTT7:1→2→4→5（到阈值）→6,7…线性。 表格：1,2,4,8,9,10 | 超时后 1,2,4,5,6…（若第6RTT收到3冗余ACK则快恢复：ssthresh=5, cwnd=5）。

A9.★★ HTTP1.0与HTTP1.1（持续连接）各请求3个对象（每次TCP握手1×RTT，每对象传输1×RTT/2+ε 忽略），页面1个HTML+3图片，比较所需RTT数。

1.0非持续：4个对象×(握手1+请求响应1)=8×RTT；1.1持续非流水线：握手1+逐对象4=5×RTT；持续+流水线：握手1+1=2×RTT。

A10.★★ 某网络拓扑：PC—交换机—路由器—服务器。PC用DHCP获取IP时，Discover报文的目的MAC/IP各是什么？为什么用广播？

目的MAC=FF:FF:FF:FF:FF:FF，目的IP=255.255.255.255（源IP=0.0.0.0）；因为此时PC尚无IP、不知服务器位置，必须广播发现。

A14.★★ TCP 连接：A 的初始序号=100。A 连续向 B 发送两个 500B 的报文段。写第二个报文段的序号、若 B 正确收到两个报文后回送的确认号。

A15.★★ TCP 慢启动 ssthresh=16MSS：从 cwnd=1 开始，第几个 RTT 后 cwnd 首次达到 16？之后转入什么阶段？

A16.★★★ 卫星链路：速率2Mb/s，RTT=600ms，帧长8KB。求"信道利用率达1"所需发送窗口 W；GBN与SR各需几位序号？

T_D=65536bit/2Mb/s≈32.8ms；W≥(T_D+RTT)/T_D≈(32.8+600)/32.8≈20。 GBN：W≤2ⁿ−1 → n=5（31≥20）；SR：W≤2ⁿ⁻¹ → n=6（16<20≤32）。

A17.★★ 路由表：192.168.4.0/24→eth0；192.168.0.0/16→eth1；0.0.0.0/0→eth2。目的地址 192.168.4.5 与 10.1.2.3 各走哪个口？依据什么原则？

A18.★★★ ISP 拥有 200.0.64.0/20，分给4个组织各 /22。写出4个组织的网络地址，并验证它们能聚合回 /20。

A19.★★ 路由表：192.4.132.0/24→R1；192.4.128.0/20→R2；默认→R3。目的地址 192.4.132.65 与 192.4.140.1 各转发到哪？依据？

132.65 同时匹配 /24 与 /20 → 最长前缀匹配选 R1；140.1 只匹配 /20 → R2。

A20.★★★ 信息位 1101，生成多项式 G=1011（x³+x+1）。求 CRC 校验码与发送帧。

补3个0：1101000 ÷ 1011（模2除）： 1101⊕1011=0110 → 1100⊕1011=0111 → 1110⊕1011=0101 → 1010⊕1011=0001 → 余数 001。 发送帧 = 1101 001。

A21.★★ 停等协议：速率1Mb/s，帧4000bit，RTT=120ms。求利用率；若要利用率达1需窗口多大？GBN/SR 各需几位序号？

T_D=4ms：U=4/(4+120)≈3.2%；W≥(T_D+RTT)/T_D=31；GBN：2ⁿ−1≥31 → n=5；SR：2ⁿ⁻¹≥31 → n=6。

A22.★★ TCP 窗口通告：A 发 2000B（seq=1001~3000）。B 正确接收后回 ACK 的确认号；若 B 回告 rwnd=2000，A 连续再发 2000B，B 收满后回 ack=5001 且 rwnd=1000。此刻 A 允许再发送多少？

第一次 ACK=3001；B 端接收缓冲已用尽后释放了1000 → A 的发送窗口=min(1000, cwnd)=1000B，可再发 1000B（seq=5001~6000）。

A23.★★★ ssthresh=12：cwnd=10 时收到3个冗余ACK（快重传+快恢复）。写出随后各 RTT 的 cwnd。

快重传：立即重传丢失段；快恢复：ssthresh=10/2=5，cwnd=5（不是回到1）→ 之后线性：5→6→7→…（每RTT+1）。

A24.★★ 两条主机 IP：192.168.20.5/26 与 192.168.20.70/26。判断是否同一子网，若不是它们通信要经过什么？

大题板书精讲（408真题风格·8道）

B1.★★★ VLSM 综合划分：将 192.168.72.0/24 分给四个部门——A 100台、B 50台、C 20台、D 两条点对点链路（各2个地址）。按需分配并尽量节省地址。

A：/25（126台）→ 192.168.72.0/25； B：/26（62台）→ 192.168.72.128/26； C：/27（30台）→ 192.168.72.192/27； D：/30（2台）→ 192.168.72.224/30 与 192.168.72.228/30； 剩余 192.168.72.232 起备用。

B2.★★ IP 分片：数据报总长 3820B（首部20B，数据3800B），链路 MTU=1420B。写出各分片的长度、MF 与片偏移。

每片数据 ≤ 1400B 且为8的倍数 ⇒ 取1400。 片1：1420B，MF=1，偏移 0；片2：1420B，MF=1，偏移 175（1400/8）；片3：20+1000=1020B，MF=0，偏移 350。 （重组在目的主机进行；各片标识字段相同。）

B3.★★ 最长前缀匹配：路由表含 172.18.64.0/24→R1、172.18.64.0/22→R2、默认→R3。目的地址 172.18.65.2 与 172.18.64.7 各转发到哪？

65.2：不匹配 /24（第四段65≠64），匹配 /22（64~67 段）⇒ R2； 64.7：同时匹配 /24 与 /22 ⇒ 取最长前缀 ⇒ R1。

B4.★★★ TCP 丢包确认推演：A（seq 从1000起）连续发送三个500B报文段 S1(1000~1499)、S2(1500~1999)、S3(2000~2499)，S2 丢失，S1、S3 依次到达。写出每次事件后 B 回送的确认号，并说明 A 如何得知丢包。

S1 到达：ACK=1500； S3 到达（S2 缺口）：仍 ACK=1500（累积确认，S3 缓存等待）——此为冗余ACK； S3、后续冗余达到3个 ⇒ 快重传：A 立即重传 S2（不必等超时）； S2 重传到达，B 补齐缺口 ⇒ ACK=2500（一次性确认到2499）。

B5.★★★ TCP 拥塞窗口：ssthresh=16，cwnd 从1开始；RTT5 时 cwnd=17，此时收到3个冗余ACK。写出其后5个RTT的 cwnd。

快重传+快恢复：ssthresh=⌊17/2⌋=8，cwnd=8（不回到1）； 随后拥塞避免线性：RTT6=9，RTT7=10，RTT8=11，RTT9=12，RTT10=13。 （若发生的是超时：ssthresh=8、cwnd=1，慢启动重新爬升——两种事件处理不同，答题先辨事件。）

B6.★★ HTTP 版本时延对比：页面含1个HTML与3张图片，RTT=50ms，忽略传输时延。求 HTTP1.0、HTTP1.1（持续非流水线）、HTTP1.1（流水线）各自获取全部对象的时间（均需新建TCP连接时含握手1×RTT）。

HTTP1.0（每对象一个连接）：(1+1)×4×50 = 400ms； HTTP1.1 持续连接（串行请求）：握手1×RTT + 4次请求响应 4×RTT = 250ms； HTTP1.1 流水线：握手1×RTT + 一次发出全部请求后依次返回 1×RTT = 100ms。

B7.★★ CSMA/CD 参数计算：以太网段长2km，信号速率2×10⁸m/s，带宽100Mb/s。求争用期与最小帧长；若主机发出128B的帧是否满足要求？

单程 τ = 2000/(2×10⁸) = 10μs ⇒ 争用期 2τ = 20μs。 最小帧长 = 20μs×100Mb/s = 2000bit = 250B。 128B < 250B ⇒ 不满足：发完时冲突信号尚未返回，无法检测 ⇒ 必须填充至250B或缩短距离。

B8.★★ 用户 user1@aa.com 给 user2@bb.com 发邮件，写出完整协议流程（含DNS）。

①user1 的用户代理写好邮件，交给 aa.com 的邮件服务器缓存； ②aa.com 服务器作为 SMTP 客户端：先向 DNS 查询 bb.com 的 MX 记录（邮件交换服务器地址）； ③与 bb.com 的25端口建立 TCP 连接，用 SMTP 推送邮件（推给服务器，不是推给用户）； ④bb.com 服务器把邮件放入 user2 的邮箱； ⑤user2 方便时用 POP3（110）/IMAP 从 bb.com 拉取邮件到自己的设备。 要点：发送侧是"推"（SMTP），接收侧是"拉"（POP3/IMAP）；服务器之间也是 SMTP。
