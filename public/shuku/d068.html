第6章 总线

一、总线概念精讲

B1 总线：连接多个部件的公共信息传输干线，分时、共享。 【两大特性】分时（一时刻只允许一个部件发送）+共享（多部件可同时接收）。 B2 分类：数据总线（双向）、地址总线（单向、位数=n决定寻址范围）、控制总线（对每根线单向、整体双向）；片内/系统/通信总线。 B3 性能指标（计算核心）： - 总线宽度：数据线根数（位）； - 标准传输率（带宽）=总线工作频率×(宽度/8)——DDR（上下沿各传一次）要×2； - 时钟频率。 【推导】带宽单位换算：32位=4B，200MHz双沿=4×10⁸次传输/s → 4B×4×10⁸=1.6GB/s。

考题1（DDR带宽计算） 32位数据总线，工作频率200MHz，采用DDR（时钟上升沿与下降沿各传一次数据）。求总线带宽。 【解】带宽=4B×2×200×10⁶=1.6GB/s。∎ （审题三看：数据线宽度、工作频率还是有效频率、是否双沿——三个数错一个全错。）

二、总线仲裁

A1 集中仲裁三方式（对比表）： | 方式 | 机制 | 优先级 | 优缺点 | |---|---|---|---| | 链式查询 | BG信号串行逐设备传递，先收到者获得 | 固定：离总线控制部件近者高 | 线少（3根）；对电路故障敏感；优先级不可变 | | 计数器定时查询 | 计数器发设备号，命中者置忙 | 可从0计（等同循环）也可从上次（循环优先） | 灵活适中；线多（log₂n+2） | | 独立请求 | 每设备独立BRi/BGi | 可编程改变 | 速度最快；控制复杂、线最多（2n+1） | A2 分布式仲裁：无中央仲裁器，各设备自行比较优先号（自持仲裁）。

三、总线操作定时

T1 同步定时：统一时钟定宽——快、规整；但强制同步、不能容纳速度差异大的设备。 T2 异步定时：应答方式（握手）——不互锁、半互锁、全互锁：可靠灵活但慢（每传一次握手多轮）。 【选择】高速设备同步、速度差异大或长距离异步。

第7章 输入/输出系统

一、I/O接口与端口编址

P1 接口=端口+控制逻辑：端口（可读写的寄存器）按数据/状态/控制分三类。 P2 编址两法： - 统一编址：端口占内存地址空间，用访存指令访问——省专用指令、但占内存空间、译码慢； - 独立编址：端口独立空间，需专用I/O指令（特权）——不占内存、译码快、控制复杂。

二、中断系统（屏蔽字设计是精华）

I1 中断请求标记：每个中断源置 INTR 触发器；可屏蔽中断INTR vs 不可屏蔽NMI（紧急事件优先响应）。 I2 中断判优：硬件排队器（链式）或软件查询。 I3 中断处理过程（硬件/软件分工·必背）： - 中断隐指令（硬件自动）：关中断、保存断点、引出中断服务程序（三件事全硬件）； - 中断服务程序（软件）：保存现场和屏蔽字 → 开中断 → 服务 → 关中断 → 恢复现场和屏蔽字 → 开中断 → 中断返回。 【要点】多重中断的精髓：服务程序"保存现场和屏蔽字"之后、开中断期间才能被更高优先级打断；单重中断全程关中断。 I4 中断屏蔽字设计（大题模板）： 规则：屏蔽字每位置1=屏蔽该源；每个源屏蔽"自己+处理优先级低于自己的所有源"（保证高者可打断低者、低者打不断高者）。 【两优先级】响应优先级由硬件排队器固定（不可改）；处理优先级由屏蔽字设置（可改）——屏蔽字的全部意义=改变处理次序。

考题1（屏蔽字设计·408大题模板） 四设备A、B、C、D，硬件响应优先级 A>B>C>D。现要求处理次序改为 C→A→B→D，写出各设备的屏蔽字（位序A、B、C、D）。 【解】新处理次序：C最高，其次A、B，D最低。每个源屏蔽"自己+处理次序低于自己的源"： - A（第2位）：屏蔽自己+B、D（B、D比A低），不屏蔽C → 1101 - B（第3位）：屏蔽自己+D → 0101 - C（最高）：屏蔽自己+全部 → 1111 - D（最低）：只屏蔽自己 → 0001 【验证】A执行时（屏蔽字1101）：C位=0 → C可打断A ✓；B、D被屏蔽 ✓。C执行时（1111）：谁都打不断 ✓。D执行时（0001）：A、B、C均可打断 ✓。处理次序=C→A→B→D ✓。∎ （原次序（不改屏蔽字）时各屏蔽字：A=1111，B=0111，C=0011，D=0001——对比记忆：屏蔽字=自己位起、低位全1。）

三、DMA 方式（大题区）

M1 DMA组成：DMA控制器含——主存地址计数器、传送长度计数器、数据缓冲、DMA请求/响应逻辑、控制逻辑。 M2 DMA传输三阶段： ① 预处理（CPU执行程序初始化：主存起始地址、传送字数、方向）； ② 数据传送（DMAC掌管总线，硬件完成，CPU并行执行程序——不干预数据传送）； ③ 后处理（字数计到0，DMA发中断通知CPU：校验、是否继续）。 M3 DMA与主存争用的三种方式： - 停止CPU访问（最简单、并行性最差）； - 周期挪用（周期窃取）——最常用（DMA挪一个存取周期，CPU延迟一个周期）； - DMA与CPU交替访问（最高效但硬件复杂）。 M4 DMA vs 中断（对比表·必背）： | | 中断方式 | DMA方式 | |---|---|---| | 数据传送 | 经CPU（外设↔CPU寄存器↔内存） | 外设↔内存直达 | | 响应时机 | 指令周期结束 | 存取周期结束（总线周期级） | | 中断次数 | 每传一个字中断一次 | 一批数据结束才中断一次 | | 适用 | 低速设备 | 高速块设备 | 【两大易混】①对总线使用权的竞争：DMA请求优先于CPU访存；②DMA结束仍用中断通知CPU——"DMA与中断不是对立关系"（选择题钉子）。

四、本章考题补遗（2题）

题1（端口编址） 统一编址与独立编址的优缺点各两条？ 【答】统一编址：优点=访存指令即可访问I/O、指令丰富；缺点=占内存地址空间、全字长译码慢。独立编址：优点=不占内存空间、I/O指令短译码快；缺点=需专用I/O指令（特权）、控制复杂。∎

题2（程序查询vs中断vs DMA的CPU利用率阶梯） 从磁盘读1KB到内存：三种方式下CPU分别"忙"多久（每次寄存器操作1μs，磁盘传输率1MB/s? 简化：每字中断处理5μs）？ 【解】程序查询：CPU全程轮询等待（≈传输全程忙）；中断：1KB按2B/字=512次中断×5μs=2560μs忙；DMA：仅预处理+后处理≈10μs级。CPU负担：查询≫中断≫DMA——这就是高速设备必用DMA的原因。∎
