离散数学精讲 · 图论（第3/4批）

与《数据结构精讲_图》互补定位：DS册管"算法怎么跑"（DFS/Prim/Dijkstra），本册管"图有什么数学性质"（一笔画/哈密顿/平面性/着色）。408直接考算法、复试常问性质——两册合璧才是完整的图。

一、基本概念与度序列（可图化判定）

D1 握手定理（推广）：无向图 Σd(v)=2m；有向图 Σd⁺=Σd⁻=m。 【推论】奇度顶点个数为偶数。 D2 度序列可图化/可简单图化（计算题主战场）： - 可图化（允许重边环）：Σdᵢ 为偶数； - 可简单图化（无重边无环）：Σ偶数 且 每项 ≤ n−1，再用 Havel–Hakimi 递减判定：取最大度d，删去它并让其余d个最大的各减1，递归；出现负数或不够减 → 不可。 考题1（度序列判定） 判定序列 (5,5,3,3,2,2,1)？(4,4,3,3,2,2)？（简单图） 【解】①n=7，最大度5≤6✓。H-H：删5，其余6个中取5个减1→(4,2,2,1,1,2)排序(4,2,2,2,1,1)；删4→5个数减1：(1,1,1,0,1)排序(1,1,1,1,0)；删1→(0,1,1,1)→(1,1,1,0)? 删1对其余1个减1：(1,1,0,0)；继续……全程无负 → 可简单图化。 ②Σ=18偶✓，最大4≤5✓。删4→(3,2,2,1,1)；删3→(1,1,0,1)排序(1,1,1,0)；删1→(0,1,0)→(1,0,0)；删1→(−1,0)出现负数 → 不可简单图化。∎ （应试技巧：小序列直接试画；判断题优先用"Σ奇偶+最大度≤n−1+H-H"三板斧。）

二、通路回路与连通性

D3 通路/回路：顶点边交替序列；简单通路（顶点不重复）/初级通路（边不重复）。 【定理】n阶图中，存在通路长 ≥ n ⇒ 必存在回路；最短通路必是简单通路。 D4 连通性三度： - 无向：连通；点割集/割点、边割集/割边（桥）；点连通度 κ、边连通度 λ：κ ≤ λ ≤ δ（最小度）——不等式链必背； - 有向：强连通（互达）/单向连通/弱连通；强连通判定：存在经过每个顶点至少一次的回路。

三、欧拉图（一笔画·必考判定）

T1 欧拉回路存在定理（无向）：G 有欧拉回路（从一点出发每边恰一次回到起点）⇔ G 连通 且 每个顶点度数均为偶数。 T2 欧拉通路（不回起点）：⇔ 连通 且 恰有 0 个或 2 个奇度顶点（0个时是回路；2个时从一奇点出发到另一奇点结束）。 【有向版】欧拉回路：连通（弱）+ 每点入度=出度；欧拉通路：恰一个点出度−入度=1（起点）、一个点入度−出度=1（终点）、其余平衡。 【历史谈资】哥尼斯堡七桥问题（欧拉1736）=图论诞生：四块陆地度数3,3,3,5全是奇度 → 无解。

考题2（一笔画判定） ①各顶点度数为 (2,2,4,4,2)：能否一笔画？②(3,3,2,2)？ 【解】①全偶连通 → 有欧拉回路（任意起点一圈回来）。 ②恰两个奇度(3,3) → 有欧拉通路但无回路（从一个奇度点出发到另一个结束）。∎ 【AI/工程连接】"一笔画"=中国邮递员问题/DFS遍历边的基础；欧拉判定是线性时间的，与哈密顿形成鲜明对照。

四、哈密顿图（环球旅行·与欧拉对照）

D5 哈密顿回路：经过每个顶点恰一次的回路（对比欧拉：每条边恰一次）。 【关键认知】哈密顿判定没有充要条件，判定问题是NP完全的——这是它与欧拉的本质区别（复试必考谈点）。 T3 必要条件（用来判"不是"）：G有哈密顿回路 ⇒ ①对任意 V′⊂V，p(G−V′) ≤ |V′|（删k个点，连通分支数≤k）；②无割点。 【用法】找一个V′破坏不等式 → 无哈密顿回路。 T4 充分条件（用来判"是"，记两条）： - Dirac（狄拉克）：n≥3 简单图，若每个顶点 δ(G) ≥ n/2 ⇒ 哈密顿图； - 权边数版：n≥3，若 m ≥ C(n−1,2)+2 ⇒ 哈密顿图。 【注意方向】充分≠必要：满足不了Dirac也可能是哈密顿图（如Cₙ环本身δ=2）。

考题3（充分必要双打） ①n=6，每个顶点度数≥3：是否哈密顿？②彼得森图（3-正则，n=10）呢？ 【解】①Dirac：δ=3=n/2 ✓ → 是哈密顿图。 ②彼得森图 δ=3 < 10/2=5，Dirac不满足（不能下结论）；用必要条件试：删去某个3点集可使分支数=4>3（已知构造）→ 违反 p(G−V′)≤|V′| → 无哈密顿回路（彼得森图是经典的"非哈密顿"3-正则图）。∎

五、树与生成树（回扣DS）

T5 树的等价定义六连（复试可任答）：①无回路连通图；②连通且 m=n−1；③无回路但加任一新边得且仅得一个回路；④连通但删任一边不连通；⑤任意两点恰一条路径；⑥无回路且每条边都是桥。 【回扣DS】生成树存在性（连通图必有）；最小生成树↔Prim/Kruskal（DS册已演算W=11）；最优二元树↔哈夫曼树（DS册WPL=35例）；根树↔树的存储与遍历。 D6 根树术语：r元树/满r元树；前缀码↔二叉树叶子（哈夫曼合法性）；最优树=WPL最小的满二元树。

六、平面图（欧拉公式是核心）

T6 欧拉公式：连通平面图：n − m + r = 2（点−边+面=2）。 【推广】p个连通分支：n−m+r=1+p。 T7 平面图边数上界（推导要会）：简单连通平面图（n≥3）：每个面至少3条边 → 2m≥3r，代入欧拉公式消r：m ≤ 3n−6。 【K₅不可平面】K₅：n=5, m=10 > 3×5−6=9 → 违反上界 → 不可平面。 T8 度≤2的面版：若平面图每个面度数≥k → m ≤ k(n−1)/(k−2)。 【K₃,₃不可平面】K₃,₃是二部图无奇圈→无三角形→每个面度≥4→2m≥4r，代入欧拉公式消r得 m≤2n−4。K₃,₃：m=9 > 2×6−4=8 → 不可平面 ✓ （经典坑：只用 m≤3n−6 判不动 K₃,₃（9≤12 不违反）——必须用"无三角形"的更强界 2n−4。） T9 库拉托夫斯基定理：G 平面 ⇔ 不含与K₅或K₃,₃同胚（细分）的子图——平面性的充要刻画（判定用，证明超纲）。 D7 对偶图：平面图每个面→对偶图一个点、每条边→对偶一条边；对偶图的着色=原图的面着色。

考题4（欧拉公式计算） 连通平面图 n=8，m=14。求面数 r，并验证边数上界。 【解】r=2−n+m=2−8+14=8。上界验证：14 ≤ 3×8−6=18 ✓ 不矛盾（是平面图的必要条件，满足不保证平面——上界只能证"非平面"，不能证平面）。∎

七、图着色与匹配

D8 点着色：相邻异色；色数 χ(G)=最少色数。二部图 ⇔ χ=2（无奇圈）；四色定理：平面图 χ≤4（面着色）；五色定理（χ≤5）是可证版。 【连接】χ=2的判定=二部图判定=无奇圈（BFS染色的原理，DS双向奔赴）；考试排程/寄存器分配=着色应用（谈资）。 D9 匹配：边互不相邻；完美匹配：覆盖所有顶点；Hall婚配定理：二部图 X到Y有饱和X的匹配 ⇔ 对任意S⊆X，|N(S)|≥|S|（"任意k个男孩认识的女孩总数≥k"）。 【连接】增广路求最大匹配（匈牙利算法思想）=DS"找增广路换配对"——任务分配问题的理论根基。
