408综合题的算法要用C手写——本速查只覆盖"写算法题够用"的C：指针、结构体、动态内存、链表惯用套路、常见编译坑。半天过完，配合《数据结构_代码题》《算法代码题精练》练习。 答题口径：408代码题允许 C 或 C++（甚至良好伪代码）；王道解析用 C++ 的引用（SqList &L），你考场上用哪种都行，但全文风格要统一。

01 变量、指针基础

int a = 5;
int *p = &a;      // p 存 a 的地址；& 取地址，* 解引用
*p = 10;          // 通过指针改 a → a 变 10
int b[5] = {1,2,3,4,5};
int *q = b;       // 数组名即首元素地址；q+1 指向 b[1]（移动4字节）
*(q+2) 等价于 q[2] 等价于 b[2]     // 三种写法同一回事
  • 指针就是地址变量。看到 LNode *p，读作"p 是一个指向结点的指针"。
  • p->data 等价于 (*p).data——箭头 = 先解引用再取成员（链表题天天用）。

02 结构体与 typedef（408 全部代码题的地基）

/* 顺序表（王道标准写法） */
#define MaxSize 50
typedef struct {
    int data[MaxSize];
    int length;
} SqList;

/* 单链表结点（带头结点） */
typedef struct LNode {
    int data;
    struct LNode *next;    /* 结构体内部引用自身必须写全 struct LNode */
} LNode, *LinkList;        /* LNode=结点；LinkList=头指针类型（等价 LNode*） */
  • typedef 的意思："给这个类型起个别名"。typedef struct {...} LNode, *LinkList; 之后就能直接写 LNode *p; LinkList L;。
  • 带头结点：L->next 才是第一个数据结点；空表判 L->next == NULL（不是 L==NULL）。
  • 双链表/栈/队列/树都是同一套：结构体包数据+指针，typedef 起名。
typedef struct BiTNode {
    int data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;

03 动态内存 malloc / free

LNode *s = (LNode *)malloc(sizeof(LNode));  /* 申请一个结点 */
s->data = x; s->next = NULL;
free(s);                                    /* 用完释放，防内存泄漏 */
  • malloc(sizeof(类型)) 是固定搭配；返回 void*，强转成目标类型。
  • 判空习惯：if (s == NULL) return 0;（考场上可省略，但写出更稳）。
  • 删除结点两步：摘链 + free——先 pre->next = p->next; 再 free(p);（顺序不能反）。

04 链表三大惯用套路（背熟=代码题半壁江山）

套路一：pre/p 双指针遍历（删除/插入必用）

LNode *pre = L, *p = L->next;
while (p != NULL) {
    if (要删(p)) { pre->next = p->next; free(p); p = pre->next; }
    else         { pre = p; p = p->next; }
}

套路二：头插法（逆序重建）

L->next = NULL;                    /* 断开成空表 */
while (工作指针非空) {
    t = p; p = p->next;            /* 摘下 t */
    t->next = L->next;             /* t 头插 */
    L->next = t;
}

头插一次=逆置一次——"递增表变递减表""原地逆置"全是它。

套路三：快慢指针（中点/判环/倒数第k个）

LNode *slow = L, *fast = L;
while (fast->next && fast->next->next) { slow = slow->next; fast = fast->next->next; }
/* fast 到尾时 slow 在中点 */

05 递归写法模板（树题通用）

/* 三行模板：空返回 → 叶特殊 → 左右合并 */
int f(BiTree T) {
    if (T == NULL) return 0;              /* 1) 递归出口 */
    if (!T->lchild && !T->rchild) return 1;  /* 2) 叶子特判（按题意） */
    return f(T->lchild) + f(T->rchild);   /* 3) 左右结果合并 */
}
  • 递归=信任"子调用已经算对"，只管当前结点怎么由左右拼出来。
  • 终止条件永远先写；忘写=段错误（Stack Overflow）。

06 常见编译坑（考场上丢分的暗坑）

坑 正确写法
= 与 == 混用 if (p->data == x)（判断用双等号）
数组越界 下标范围 [0, n-1]；循环条件 i < n
free 后继续用 free(p) 后立即 p = p->next 是错的——先存 nxt
字符串结尾 C 串以 '\0' 结尾，长度手动数或 strlen()
缺头文件 abs() 需要 stdlib.h；INT_MIN 需要 limits.h（或自设 0x80000000）
结构体自引用 内部必须写 struct LNode *next（不能只写 LNode）
指针未初始化 局部指针先置 NULL 或指向有效地址

07 复杂度速判口诀

  • 单层循环 n 次 → O(n)；双层嵌套 → O(n²)；每次规模减半（折半/二叉）→ O(log n)；一层循环里套二分 → O(n log n)
  • 递归：递归深度 × 每层工作量（树遍历：深度O(n)? 深度O(h)，每层O(1) → O(n) 时间）
  • 空间：辅助数组 O(n)；递归栈深度 O(h)；原地两指针 O(1)
  • 写大题必须附一句："该算法时间复杂度 O(n)，空间复杂度 O(1)。"

08 十分钟自测

  1. p->next->next = p; 做了什么？p 指向自身吗？
  2. 带头结点空表的判断条件？
  3. malloc 之后必须配对什么？删除结点的两步顺序？
  4. 头插法 n 个结点后，链表顺序与插入顺序什么关系？
  5. 递归函数缺终止条件会怎样？

答案：1. 把 p 的后继的后继指向 p（逆置/成环常用，p 自己不动）；2. L->next == NULL；3. free；先摘链再 free；4. 相反；5. 栈溢出（无限递归）。
