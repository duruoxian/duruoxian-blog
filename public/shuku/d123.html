AI方向 · 深度学习基础精讲（第3/4批）

深度学习复试问答的地毯：反向传播完整推导、CNN参数计算、Transformer自注意力三大计算点全部展开；每个模块配"复试一句话答法"。数学仍然只用你考研学过的（链式法则、矩阵乘、softmax=归一化指数）。

一、从感知机到多层网络

1.1 感知机（1957）：y=sign(wᵀx+b)，单层只能分线性可分数据（异或都解不了——历史上的"AI寒冬"导火索，复试爱当故事考）。 1.2 多层感知机MLP：线性层叠加非线性激活→万能逼近。 【为什么必须非线性】没有激活函数，多层线性=一层线性：W₂(W₁x)=Wx——深度就白堆了。"深度学习的深度=非线性变换的层数"。 1.3 激活函数族（必背对比表）： | 激活 | 公式 | 优 / 缺 | |---|---|---| | Sigmoid | 1/(1+e⁻ˣ) | 输出(0,1)可当概率 / 饱和区梯度≈0（梯度消失）、非零中心 | | Tanh | (eˣ−e⁻ˣ)/(eˣ+e⁻ˣ) | 零中心 / 同样饱和 | | ReLU | max(0,x) | 计算便宜、正区不饱和 / 神经元死亡（负区梯度0） | | LeakyReLU | max(αx,x) | 治死亡 / 略增计算 | | Softmax | e^{zᵢ}/Σe^{zⱼ} | 多分类输出层专用（输出和=1的概率分布） |

二、反向传播完整推导（复试王牌：能白板写出就是强信号）

记号：L层网络，zˡ=Wˡaˡ⁻¹+bˡ（预激活），aˡ=σ(zˡ)（激活）；损失L。 四个核心量（四行公式）： ① 误差信号（输出层）：δᴸ = ∂L/∂zᴸ = ∂L/∂aᴸ ⊙ σ′(zᴸ) ② 误差回传（隐藏层）：δˡ = (Wˡ⁺¹)ᵀ δˡ⁺¹ ⊙ σ′(zˡ) ③ 权重梯度：∂L/∂Wˡ = δˡ (aˡ⁻¹)ᵀ ④ 偏置梯度：∂L/∂bˡ = δˡ 【灵魂】②就是链式法则穿层（第1批桥3的两层版推广）；③是"误差×输入"的外积——转置来自分块矩阵求导的形状对齐（你线代桥1）。 考题1（两层网络反传·手算） y=σ(w₂h)，h=σ(w₁x)，损失L=½(y−t)²，输入x=1，w₁=w₂=0.5，t=1，y=σ(0.5σ(0.5))=σ(0.2449)=0.5610。求 ∂L/∂w₁、∂L/∂w₂。 【解】σ(0.2449)=0.5610，σ′(z₂)=0.5610×0.4390=0.2463；σ(0.5)=0.6225，σ′(z₁)=0.6225×0.3775=0.2350。 ∂L/∂y=y−t=−0.4390。 ∂L/∂w₂=∂L/∂y·σ′(z₂)·h=−0.4390×0.2463×0.6225=−0.0673。 ∂L/∂w₁=∂L/∂y·σ′(z₂)·w₂·σ′(z₁)·x=−0.4390×0.2463×0.5×0.2350×1=−0.0127。 【观察】越往前的层梯度越小（连乘两个<1的因子）——梯度消失的现场演示：这就是sigmoid深网训不动、ReLU上台的原因。∎ 梯度消失/爆炸：反传=连乘导数；|导数|<1连乘→消失，>1→爆炸。对策：ReLU、残差连接（梯度有"高速公路"直通）、BatchNorm、合理初始化（Xavier/He）。

三、CNN 卷积神经网络（计算题主战场：输出尺寸+参数量）

3.1 三大件： - 卷积层：卷积核在输入上滑动做局部加权求和——局部连接+权值共享（一个核扫全图）→参数暴降+平移等变； - 池化层：max/avg池化降尺寸、扩大感受野、小平移不变； - 全连接层：末端分类。 3.2 输出尺寸公式（必背）： O = ⌊(H − K + 2P)/S⌋ + 1（H输入、K核、P填充、S步长）。 参数量公式：每层 = (K×K×Cᵢₙ+1)×Cₒᵤₜ（+1是偏置）。 考题2（CNN双计算） 输入224×224×3，卷积核5×5、64个、padding=2、stride=2。求输出尺寸与该层参数量。 【解】O=(224−5+4)/2+1=111.5→⌊111.5⌋+1=112？——精确：(224−5+2×2)/2+1=(223)/2+1=111+1=112（223/2=111.5向下取整111）。 参数=(5×5×3+1)×64=4864。 对比全连接224×224×3→同样输出通道：参数≈千万级——权值共享省了三个数量级。∎ 3.3 感受野：层层堆叠，顶层一个像素"看见"底层的范围越来越大（VGG两个3×3=一个5×5感受野、参数更少还多一次非线性——为什么深层用小核）。

四、RNN / LSTM（序列建模）

4.1 RNN：hₜ=tanh(W_hh hₜ₋₁+W_xh xₜ+b)，隐状态=记忆。 缺陷：长序列梯度消失→记不住长依赖（"cat...was"能接，隔100词接不上）。 4.2 LSTM三门一槽（结构会画是加分项）： - 遗忘门 f：丢弃多少旧记忆； - 输入门 i：写入多少新信息； - 细胞状态 Cₜ=f⊙Cₜ₋₁+i⊙C̃ₜ（加法更新=梯度的直通车道，治RNN的连乘消失）； - 输出门 o：决定隐状态暴露多少。 复试一句话："LSTM用门控控制信息的遗忘、写入与输出，细胞状态的加法更新让梯度可以长程传播——解决RNN长依赖。" 4.3 GRU：LSTM简化版（两门、合并细胞与隐状态），效果相当、更快。

五、Transformer 与注意力（近年复试第一热词）

5.1 自注意力（Scaled Dot-Product Attention）： Attention(Q,K,V)=softmax(QKᵀ/√dₖ)V - 每个token生成三向量：Q（查询：我在找什么）、K（键：我有什么）、V（值：我的内容）； - 注意力权重=Q与K的相似度（点积）softmax归一化，对V加权求和； - 除以√dₖ：点积随维度增大方差变大→softmax饱和→梯度小；缩放稳住分布（复试追问率极高）。 5.2 多头注意力：h组独立QKV并行做注意力再拼接——不同头关注不同模式（语法头/位置头）。 5.3 为什么取代RNN：①完全并行（RNN必须逐时间步）；②任意两位置直接相连（路径O(1)，长依赖不再衰减）；③代价O(n²)（序列长度的平方）。 5.4 位置编码：注意力本身无序（打乱输入结果不变）→加位置编码注入顺序信息。 考题3（注意力手算·复试级） Q=[1,0]，K₁=[1,0]，K₂=[0,1]，V₁=[1,0]，V₂=[0,1]，dₖ=2。求注意力输出。 【解】分数：QK₁ᵀ=1，QK₂ᵀ=0；缩放：1/√2、0。 softmax(0.707,0)≈(0.67,0.33)。 输出=0.67×[1,0]+0.33×[0,1]=[0.67, 0.33]——查询"像谁"，输出就偏向谁的值：这就是"注意力"的全部直觉。∎ 5.5 Transformer块=多头注意力+前馈网络+残差连接+LayerNorm（×N层）；编码器-解码器或仅解码器（GPT系：自回归，预测下一个词）。

六、优化器与训练技巧

6.1 优化器进化线： - SGD：w←w−ηg；噪声大但泛化常好； - 动量：累积历史梯度（惯性冲过震荡与浅谷）； - Adam：动量（一阶）+自适应步长（二阶梯度平方滑动平均）——默认首选，"开箱即用"；调参口诀：学习率是第一超参（太大发散、太小慢）。 6.2 过拟合全家桶（与ML篇对策呼应）： | 手段 | 机理 | 一句话 | |---|---|---| | Dropout | 训练时随机失活神经元 | 每次训练不同子网→集成视角；测试全开按比例缩放 | | BatchNorm | 对每个mini-batch标准化 | 稳定分布、允许大学习率、轻微正则 | | 数据增强 | 翻转/裁剪/噪声 | 最便宜的"增数据" | | 早停 | 验证误差回升即停 | 别训过头 | | 权重衰减 | L2正则 | 桥接ML篇2.3 | 6.3 损失函数配对：多分类=softmax+交叉熵（数值稳定要log-sum-exp技巧）；回归=MSE；二者都是MLE（桥2）。

七、考题补遗（3题）

题4（结构对比压轴） CNN、RNN、Transformer各自适合什么数据？一句话原因。 【答】CNN=网格数据（图像）：局部相关+平移等变；RNN/LSTM=序列（早期NLP/语音）：逐步递归带记忆；Transformer=长序列并行（现代NLP/多模态）：自注意力任意位置直连+全并行。趋势：Transformer一统（ViT把图像切块当序列）。∎

题5（残差连接） ResNet的残差结构为什么能训极深网络？ 【答】y=F(x)+x：梯度对x的路径有一条"+1"直通项（∂y/∂x=∂F/∂x+1）——梯度永不消失于恒等路径，深层也可训；且网络只需学"增量"F(x)，比直接学映射容易。∎

题6（BatchNorm追问） 训练与推理时BatchNorm行为差异？ 【答】训练用当前batch统计量（均值/方差）并更新滑动平均；推理用累积的滑动平均（不再依赖batch大小）——所以BN模型推理时batch可为1。∎
