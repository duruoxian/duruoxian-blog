卷一答案与详解

选择：1B 2A 3B 4B 5B 6C 7B 8B 9B 10B

  1. 1-cosx~x²/2，x·tanx~x²，比值=1/2。
  2. x→0左右极限均为0（有界×无穷小），极限存在但不等于函数值（无定义）→可去。
  3. y''=6x-6=0得x=1，两侧y''变号，y(1)=1-3+1=-1，拐点(1,-1)。
  4. ∫₀^∞ e^{-2x}dx = [-e^{-2x}/2]₀^∞ = 1/2。
  5. Σ1/√n 发散（p=1/2<1），故非绝对收敛；交错级数由莱布尼茨判别收敛→条件收敛。
  6. zₓ=2x/(1+x²+y²)，z_y=2y/(1+x²+y²)；(1+x²+y²)在(1,1)处=3，故zₓ+z_y=(2+2)/3=4/3，选C。
  7. |2A⁻¹|=2³·|A⁻¹|=8·(1/2)=4。
  8. λ₁=1+2=3，λ₂=1-2=-1（对角a非对角b：a±b）。
  9. σ=2，P(|X-1|<2)=P(|Z|<1)=2Φ(1)-1=0.6826。
  10. 0.4+0.5-0.4×0.5=0.7。

填空： 11. tanx-sinx~x³/2 → 1/2。 12. (x-1)eˣ+C。 13. 特征根r=2（二重），通解 (C₁+C₂x)e^{2x}。 14. 交点x=0,2，∫₀²(2x-x²)dx=4-8/3=4/3。 15. |A|=|A|ⁿ⁻¹=2²=4。 16. (5/8)×(4/7)=5/14*。

17. 泰勒：eˣ+e⁻ˣ = (1+x+x²/2+o(x²))+(1-x+x²/2+o(x²)) = 2+x²+o(x²)，极限=1。

18. 记u=xy，v=x/y。zₓ = y·f₁′ + (1/y)·f₂′。 再对y求导（f₁′=f₁′(u,v)，f₁′的偏导：∂f₁′/∂y = x·f₁₁′′ + (-x/y²)·f₁₂′′）： z_xy = f₁′ + y(x f₁₁′′ - (x/y²)f₁₂′′) + [(-1/y²)f₂′ + (1/y)(x f₂₁′′ - (x/y²)f₂₂′′)] = f₁′ - (1/y²)f₂′ + xy f₁₁′′ - (x/y³)f₂₂′（利用f₁₂′′=f₂₁′′，交叉项相消）。

19. 极坐标：区域 r=2cosθ，θ∈[-π/2,π/2]。I=∫_{-π/2}^{π/2}dθ∫₀^{2cosθ} r³dr = ∫4cos⁴θdθ = 4×2∫₀^{π/2}cos⁴θdθ = 8×(3/4·1/2·π/2)=3π/2。

20. 特征根1,2；eˣ对应单根1，设y=Ax eˣ。代入得 -A eˣ = 2eˣ → A=-2（代入验证：y=Ax eˣ时 y''-3y'+2y = -Aeˣ）。 通解 y=C₁eˣ+C₂e^{2x}-2xeˣ。y(0)=C₁+C₂=1；y'(0)=C₁+2C₂-2=0 → C₁=0? 解：C₂=1，C₁=0。 特解 y = e^{2x} - 2x eˣ*。

21. 二次型矩阵 A=[[2,1,1],[1,2,1],[1,1,2]]。求特征多项式：由"对角a、非对角b"结构（a=2,b=1，n=3）：λ₁=a+2b=4（对应(1,1,1)ᵀ），λ₂=λ₃=a-b=1。 正交变换 x=Qy 下标准形 f=4y₁²+y₂²+y₃²。特征值全为正 → 正定。
