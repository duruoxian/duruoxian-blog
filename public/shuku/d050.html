综合题解析

综合1：思想——B的第一公共结点之后与A完全重合，故两链表长度差只在头部。先让长链表走 |lenA−lenB| 步，再同步前进，首个相同结点即答案。

LNode* FindFirst(LinkList A, LinkList B){
    int la=0, lb=0; LNode *p=A, *q=B;
    while(p){ la++; p=p->next; }
    while(q){ lb++; q=q->next; }
    p=A; q=B;
    for(int i=0;i<la-lb;i++) p=p->next;   /* 长者先走 */
    for(int i=0;i<lb-la;i++) q=q->next;
    while(p && p!=q){ p=p->next; q=q->next; }
    return p;                              /* 相遇点或NULL */
}   /* O(lenA+lenB), O(1) */

综合2：(1) 合并：1+2=3 → 3+4=7 → 7+8=15。深度：d=1、c=2、b=3、a=3。 编码（左0右1）：d=0，c=10，b=110，a=111；WPL=8×1+4×2+2×3+1×3=25。 (2) 串 101100011：10→c? 按上述编码：10→c(4)？注意 c 的权值4编码10、b权值2编码110、a权值1编码111、d权值8编码0。 逐位译码：10→c；110→b；0→d；111→a ⇒ 译出 c b d a。

综合3： ①对阶：x阶1 < y阶2，小阶向大阶：x 尾数右移1位 → x = 2²×0.0101。 ②尾数和：0.1001+0.0101 = 0.1110 ⇒ 和 = 2²×0.1110。 ③规格化：0.1110 符号位0、最高数值位1，已规格化，无需处理。 ④舍入：无截断。 结果 x+y = 2²×0.1110（=3.5）。

综合4： (1) A：中断频率=1/(30μs)≈33333次/s，占用=33333×5μs≈16.7%。 B：中断频率=512KB/512B=1024次/s，占用=1024×10μs≈1.02%。 (2) 两设备占用率都不高；若高频小粒度设备（如A改造为更高数据率）可改DMA： B改DMA：512KB/4KB=128次/s，每次1000周期=10μs ⇒ 占用=128×10μs/1s≈0.13%，且CPU完全不参与传送阶段。
