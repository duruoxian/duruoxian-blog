01 矩阵运算与逆

模板

  1. 求 Aⁿ：找 A=kE+B 且 B 的低次幂为 O（二项式展开）；或相似对角化 Aⁿ=PDⁿP⁻¹；
  2. 求 A⁻¹：初等行变换 (A|E)→(E|A⁻¹)；二阶用口诀；伴随法 A⁻¹=A*/|A|；
  3. 解矩阵方程 AX=B：先判断 A 是否可逆；AX+XB 型考虑转置/待定；
  4. 伴随矩阵性质链：A⁻¹=A/|A|，AA=|A|E，r(A)=n/1/0（对应r=n/n-1/≤n-2），(A)*=|A|ⁿ⁻²A。

例题

例1 A=[[1,1],[0,1]]，求 Aⁿ。 A=E+B，B=[[0,1],[0,0]]，B²=O → Aⁿ=E+nB=[[1,n],[0,1]]。

例2 已知 A 为3阶方阵，特征值 1,2,3，求 |A⁻¹+2E|。 A⁻¹ 特征值 1, 1/2, 1/3 → A⁻¹+2E 特征值 3, 5/2, 7/3 → 行列式 = 3×5/2×7/3 = 35/2。

例3 解方程 AX=B，A=[[1,2],[2,5]]? 用 A=[[2,1],[1,1]]，B=[[1,0],[0,1]]? 直接：求 A⁻¹=[[1,-1],[-1,2]]，则 X=A⁻¹B。

练习（带答案）

  1. A=[[2,1],[0,2]]，求 Aⁿ。→ A=2E+B，B²=O：Aⁿ=2ⁿE+n·2ⁿ⁻¹B=[[2ⁿ, n·2ⁿ⁻¹],[0, 2ⁿ]]。
  2. 设 A 为 n 阶方阵，AAᵀ=E 且 |A|<0，求 |A+E|。→ |A|=-1；|A+E|=|A|·|Aᵀ+E|=|A|·|(A+E)ᵀ|? 计算：|A+E|=|A(Aᵀ+E)|? |A+E|=|A||E+Aᵀ|=|A|·|A+E| → (1-|A|)|A+E|=0 → |A+E|=0。
  3. 已知 A=[[1,0,0],[0,0,1],[0,1,0]]? 求 Aⁿ。→ 对换矩阵，周期2：n偶为E，n奇为A。
  4. 设 A⁻¹ 的特征值为 1,2,3? 设 A 的特征值 1,2,3，求 |A+2E|。→ A 特征值 |A|/λ = 6,3,2 → +2 得 8,5,4 → |A*+2E|=160。

02 线性方程组（含参数讨论）

模板（参数题必走流程）

  1. 写增广矩阵 → 行变换化行阶梯（含参数除法禁用，用"减法消参"）；
  2. 按参数分类讨论：r(A)<r(Ā) 无解；r(A)=r(Ā)<n 无穷解；r(A)=r(Ā)=n 唯一解；
  3. 无穷解时：自由变量取标准值 → 基础解系 → 通解=特解+k·基础解系；
  4. 两个方程组同解/公共解：同解⇒r相等且互为解；公共解⇒联立或由通解匹配。

例题

例 讨论参数 a、b 取何值时，方程组 { x₁+x₂+x₃=1；2x₁+x₂+3x₃=0；x₁+2x₂+ax₃=b } 无解/唯一解/无穷多解：

按设计稿执行：R2-2R1：x₂+x₃=-2；R3-R1：x₂+(a-1)x₃=b-1；再 R3-R2：(a-2)x₃=b+1。 - a≠2：唯一解 x₁=3，x₂=-2-(b+1)/(a-2)，x₃=(b+1)/(a-2)； - a=2 且 b=-1：无穷解 (3, -2-t, t)ᵀ = (3,-2,0)ᵀ + t(0,-1,1)ᵀ； - a=2 且 b≠-1：0=(b+1) 矛盾 → 无解。

练习（带答案）

  1. 讨论方程组 {x₁+x₂+x₃=1; x₁+2x₂+3x₃=? } 改做：设 A 为 4×3 矩阵且 r(A)=2? 练习：A 是4×3矩阵，r(A)=2，已知 η₁,η₂,η₃ 是 AX=b 的三个解且 η₁+η₂=(1,2,1)ᵀ? 设 η₁=(1,2,3)ᵀ? 简化：已知 AX=b 有解 η₁,η₂，r(A)=2（n=3），η₁-η₂=(1,1,1)ᵀ，η₁=(2,1,0)ᵀ，求通解。→ 对应齐次基础解系 η₁-η₂ → 通解 = (2,1,0)ᵀ + k(1,1,1)ᵀ。
  2. 求方程组 {x₁+x₂+x₃+x₄=0; x₂+2x₃+2x₄=1? 做齐次版本：{x₁+x₂+x₃+x₄=0; x₂+x₃+x₄=0; x₁+2x₂+2x₃+2x₄=0} 的通解。→ R3-R12? R3-R1: x₂+x₃+x₄=0（与R2同）→ 有效两行：x₁+x₂+x₃+x₄=0, x₂+x₃+x₄=0 → x₁=0，x₂+x₃+x₄=0 → 基础解系 (0,-1,1,0)ᵀ,(0,-1,0,1)ᵀ，通解 k₁(0,-1,1,0)ᵀ+k₂(0,-1,0,1)ᵀ*。
  3. 设方程组 {x₁+x₂=1? 同解题：已知两个方程组 Ⅰ{x₁+x₂=0, x₂-x₃? } 简化：求 {x₁+x₂+x₃=0} 与 {x₁+2x₂+3x₃=0} 的公共解。→ 联立：x₁+x₂+x₃=0，x₁+2x₂+3x₃=0 → 消元：x₂+2x₃=0 → 基础解系 (1,-2,1)ᵀ，公共解 k(1,-2,1)ᵀ。
  4. a 取何值时 {x₁+2x₂+x₃=1; 2x₁+x₂+? } 做：{x₁+x₂+x₃=0; x₁+ax₂+x₃=0; x₁+x₂+ax₃=0} 有非零解的条件。→ 行列式=(a-1)²(a+2)=0 → a=1 或 a=-2。

03 向量组的线性相关性

模板

  1. 判断相关性：齐次方程组有无非零解 / 行列式是否为零 / 秩是否等于个数；
  2. 求极大无关组：列向量拼矩阵行变换→主元列；其余向量用主元列线性表示（解对应方程组）；
  3. 线性表示：AX=β 有解判定；
  4. 常用结论：部分相关⇒整体相关；n+1个n维向量必相关；α₁,α₂线性无关而α₁+β,α₂+β相关⇒β可用α₁,α₂唯一表示? （β = c₁α₁+c₂α₂，c₁+c₂=1? careful——若 β 与它们…skip）。

例题

例1 α₁=(1,1,1)ᵀ, α₂=(1,2,3)ᵀ, α₃=(1,3,a)ᵀ，a 为何值时线性相关？并把它们用极大无关组表示。 det[[1,1,1],[1,2,3],[1,3,a]] = 1(2a-9) -1(a-6) +1(3-4) = a-4。 a=4 时相关（此时秩2），极大无关组 α₁,α₂；解 x₁α₁+x₂α₂=α₃ → x₁=-1, x₂=2 → α₃ = -α₁ + 2α₂。

例2 证明：若 β 可由 α₁,…,αₛ 线性表示但表示式不唯一，则 α₁,…,αₛ 线性相关。 设两种表示 β=Σkᵢαᵢ=Σlᵢαᵢ，相减 Σ(kᵢ-lᵢ)αᵢ=O，至少一个系数非零 → 有非零组合 → 线性相关。∎

练习（带答案）

  1. 判断 α₁=(1,0,2)ᵀ, α₂=(2,1,1)ᵀ? 组合：α₁=(1,1,0)ᵀ, α₂=(0,1,1)ᵀ, α₃=(1,2,1)ᵀ 是否相关。→ α₃=α₁+α₂ → 相关。
  2. 求向量组 (1,1,1),(1,2,3),(1,3,6),(1,4,10) 的秩与一个极大无关组。→ 前3个行列式=1≠0 → 秩3，任取前三个（如 α₁,α₂,α₃）为极大无关组。
  3. β=(4,2,? ) 设 α₁=(1,2,3)ᵀ, α₂=(1,0,1)ᵀ，β=(3,2,5)ᵀ 能否由 α₁,α₂ 表示？→ 解 x₁α₁+x₂α₂=β：x₁+x₂=3? 系数：x₁+x₂=3, 2x₁=2, 3x₁+x₂=5 → x₁=1, x₂=2 → β=α₁+2α₂。
  4. 证明：n+1 个 n 维向量必线性相关。→ 以其为列的 n×(n+1) 矩阵秩 ≤ n < n+1。∎

04 特征值与相似对角化

模板

  1. 求 λ：|A-λE|=0；求 ξ：(A-λE)x=0（重根要解出两个无关向量）；
  2. 可对角化条件：每个 λᵢ 的几何重数=代数重数（n阶有n个无关特征向量）；
  3. 求正交矩阵：先求ξ，同一特征值的多个ξ要施密特正交化，再单位化；
  4. 反求参数：用 Σλᵢ=tr(A)、Πλᵢ=|A|；
  5. 由特征值/向量反求 A：A=P D P⁻¹（实对称时 A=Σλᵢ ξᵢξᵢᵀ/ξᵢᵀξᵢ）；
  6. 已知 A 的特征值求 f(A)：f(λᵢ)（矩阵函数 Aⁿ=A P Dⁿ P⁻¹）。

例题

例1 A=[[1,-1,1],[2,4,-2],[-3,-3,5]]，求特征值与特征向量，并判断可否对角化。 |A-λE|：tr=10=2+2+6，det=24=2·2·6 → 特征值 2,2,6（由特征多项式验证 (λ-2)²(λ-6)）。 λ=2：x₁+x₂-x₃=0 → ξ₁=(1,-1,0)ᵀ, ξ₂=(1,0,1)ᵀ（两个无关）； λ=6：ξ₃=(1,-2,3)ᵀ。三个无关向量 → 可对角化，P=(ξ₁,ξ₂,ξ₃)，P⁻¹AP=diag(2,2,6)。

例2 设 A=[[2,0,0],[0,3,a],[0,a,3]]，已知 A 有特征值 5。求 a，并将 A 正交对角化。 块对角：λ=2 与 [[3,a],[a,3]] 的 3±a。5=3+a → a=2，特征值 1,2,5。 ξ_{5}=(0,1,1)ᵀ，ξ₁=(0,1,-1)ᵀ，ξ₂=(1,0,0)ᵀ（两两正交，单位化即可）→ Q=(ξ₂,ξ₁,ξ₅) → QᵀAQ=diag(2,1,5)。

练习（带答案）

  1. 求 A=[[4,1],[−2,1]] 的特征值与特征向量。

    答案：tr=5，det=6 → 特征值 2,3；ξ₂=(1,−2)ᵀ，ξ₃=(1,−1)ᵀ。

  2. 求 A=[[1,-1],[2,4]] 的特征值并求 Aⁿ。→ tr=5，det=6 → 特征值 2,3；ξ₂=(1,-1)ᵀ，ξ₃=(1,-2)ᵀ。P=[[1,1],[-1,-2]]，P⁻¹=[[2,1],[-1,-1]]，Aⁿ=PDⁿP⁻¹=[[2^{n+1}-3ⁿ, 2ⁿ-3ⁿ],[2·3ⁿ-2^{n+1}, 2·3ⁿ-2ⁿ]]（n=1 时还原为 A，可自验）。
  3. 设 A 满足 A² - 3A + 2E = O，证明 A 的特征值只能是 1 或 2。→ λ²-3λ+2=0。∎
  4. 设 ξ=(1,1,1)ᵀ 是 A=[[a,1,1],[1,a,1],[1,1,a]] 的特征向量，求 a 与对应特征值。→ Aξ=(a+2)ξ → 特征值 a+2（a 任意，ξ 恒为特征向量——由对称性）。

05 二次型

模板

  1. 写出二次型矩阵（必须对称，交叉项系数一分为二）；
  2. 正定判定三选一：顺序主子式全>0 / 特征值全>0 / 配方后平方项系数全>0；
  3. 正交变换法：实对称矩阵正交对角化 → 标准形系数=特征值；
  4. 配方法：化标准形（系数不一定是特征值——两种方法结果不同但惯性指数相同）；
  5. 规范形与惯性定理：正负惯性指数 (p,q) 唯一；合同⇔同 p,q。

例题

例1 判断 f = x₁²+2x₂²+3x₃²+2x₁x₂ 的正定性并化为标准形（配方）。 A=[[1,1,0],[1,2,0],[0,0,3]]：Δ₁=1>0，Δ₂=1>0，Δ₃=3>0 → 正定。 配方：f=(x₁+x₂)²+x₂²+3x₃² → 标准形 y₁²+y₂²+3y₃²（也可除以3得规范形）。

例2 用正交变换化 f=2x₁²+2x₂²+2x₃²+2x₁x₂+2x₁x₃+2x₂x₃。 A：对角2、非对角1 → 特征值 4,1,1 → 标准形 4y₁²+y₂²+y₃²；ξ₄=(1,1,1)ᵀ/√3，λ=1 的两个正交向量如 (1,-1,0)ᵀ/√2 与 (1,1,-2)ᵀ/√6。

练习（带答案）

  1. 判断 f = x₁²+x₂²+5x₃²+2x₁x₂-2x₁x₃+2x₂x₃ 是否正定。→ Δ₂=det[[1,1],[1,1]]=0 → 不正定（半正定讨论超纲，答不正定即可）。
  2. 求 f = 2x₁²+3x₂²? 求 f=x₁²+x₂²+x₃²+2x₁x₂+2x₁x₃+2x₂x₃ 的特征值与正负惯性指数。→ A=[[1,1,1],[1,1,1],[1,1,1]]：λ=3,0,0 → 惯性指数 (1,0)，半正定。
  3. t 为何值时 f=2x₁²+x₂²+3x₃²+2tx₁x₂+2x₁x₃ 正定？→ Δ₂=det[[2,t],[t,1]]=2-t²>0 → |t|<√2；Δ₃：det A = 2(3)-t²(3-? ) 算：A=[[2,t,1],[t,1,0],[1,0,3]]，det=2·3-t²·3+1·(t·0-1·1)=6-3t²-1=5-3t²>0 → t²<5/3。取交集：t²<5/3 即 |t|<√15/3? √(5/3)=√15/3≈1.29 → |t|<√(5/3)。
  4. 设 A 正定，证明 A⁻¹ 正定。→ A⁻¹=(A⁻¹)ᵀ 对称；对任意 x≠0，xA⁻¹xᵀ? 用 xᵀA⁻¹x = (A⁻¹x)ᵀ A (A⁻¹x) > 0（令 y=A⁻¹x≠0，yᵀAy>0）。∎

06 秩与抽象证明

模板

  1. 基本不等式链：r(Aᵀ)=r(A)，r(AB)≤min(r(A),r(B))，r(A+B)≤r(A)+r(B)，AB=O⇒r(A)+r(B)≤n；
  2. r(AᵀA)=r(A)（证明：AᵀAx=0 与 Ax=0 同解——xᵀAᵀAx=0⇒|Ax|²=0）；
  3. 满秩分解、分块秩：r([[A,O],[O,B]])=r(A)+r(B)；
  4. r(A*)：r=n→n；r=n-1→1；r≤n-2→0；
  5. 证明题三板斧：定义（Ax=0 找非零解）、秩的不等式、方程组同解传递。

例题

例 证明 r(AᵀA)=r(A)。 Ax=0 ⇒ AᵀAx=0（显然）。反之 AᵀAx=0 ⇒ xᵀAᵀAx=0 ⇒ (Ax)ᵀ(Ax)=0 ⇒ ‖Ax‖²=0 ⇒ Ax=0。两齐次方程组同解 → 解空间维数相等 → n-r(AᵀA)=n-r(A) → r(AᵀA)=r(A)。∎

练习（带答案）

  1. A 是 m×n 矩阵，B 是 n×s 矩阵，AB=O，证明 r(A)+r(B)≤n。→ B 的列都是 Ax=0 的解 → r(B)≤n-r(A)。∎
  2. 证明 r(A+B)≤r(A)+r(B)。→ A+B 的列可由 (A|B) 的列线性表示 → r(A+B)≤r(A|B)=r(A)+r(B)。∎
  3. 设 A 为 n 阶方阵且 A²=A（幂等），证明 r(A)+r(A-E)=n。→ A(A-E)=O → r(A)+r(A-E)≤n；又 r(A)+r(E-A)≥r(A+E-A)=r(E)=n。∎
  4. 设 Aᵀ=-A（反对称），n 为奇数，证明 |A|=0。→ |A|=|Aᵀ|=|-A|=(-1)ⁿ|A|=-|A| → |A|=0。∎

大题答题规范（阅卷得分点）

  1. 先写"设/令/由"：矩阵题第一步写清对哪个矩阵做什么变换；
  2. 行变换用箭头标注，别跳步太多（参数讨论题每步依据是采分点）；
  3. 求出特征向量后立即回代验证（Ax=λx），10秒防大错；
  4. 结论句单独成行："故当 a≠2 时方程组有唯一解……"；
  5. 证明题最后写 ∎ 或"证毕"。
