第4章 文件管理

一、文件的逻辑结构与物理结构精讲

L1 逻辑结构：顺序文件（批量存取高效、随机查找慢）、索引文件（变长记录+索引表）、索引顺序文件（分块索引，查找效率 log 型提升）。

L2 物理结构（文件在磁盘上怎么放）： | 结构 | 原理 | 随机存取 | 扩展 | 碎片 | |---|---|---|---|---| | 连续分配 | 起始块+长度 | O(1) 直接算 | 难（需搬移） | 外部碎片 | | 隐式链接 | 每块含下一块指针 | O(n) 逐块读 | 易 | 无（块级） | | 显式链接FAT | FAT表常驻内存，表项=下一块号 | O(1)查内存表 | 易 | 无 | | 索引分配 | 索引块集中放块号 | O(1)（查索引块） | 大文件需多级/链接索引块 | 索引块开销 |

FAT体积计算模板：磁盘容量÷块大小=块数 n → FAT表项 ⌈log₂n⌉ 位（标记下一块号）→ FAT总大小 = n×表项位数。

考题1（FAT体积） 磁盘容量512GB，块大小4KB。求FAT表项最少位数与FAT总大小。 【解】块数=512GB/4KB=2³⁷/2¹²=2²⁵=33,554,432个 → 表项至少 25位（标记下一块号）；实际按字节对齐常取4B。 FAT总大小=2²⁵×25bit≈100MB（取4B/项则为 128MB）。 【要点】FAT开机调入内存常驻——查FAT不需要额外访存磁盘，这是显式链接相对隐式链接的最大优势。∎

L3 索引结点（inode）与UNIX混合索引： FCB瘦身：只留文件名+inode号 → inode存元数据+磁盘地址块。UNIX混合索引：直接地址（如10/12个）+一次间接+二次间接+三次间接。 【推导】块4KB、地址项4B → 每个间接块装 4096/4=1024 个地址。

考题2（混合索引·最大文件与访存次数） inode含10个直接地址块、一次/二次/三次间接各1个。求最大文件大小；访问文件偏移 X=26MB+520B 处的字节需要几次访存磁盘？ 【解】最大文件 = 10×4KB + 1024×4KB + 1024²×4KB + 1024³×4KB = 40KB + 4MB + 4GB + 4TB。 偏移X：逻辑块号 = X/4KB = 6656 + 0.127 → 块号6656（块内偏移520）。 块号6656 ≥ 10+1024=1034 → 二次间接：二级索引号 = (6656−1034)÷1024 = 5，二级内偏移 = (6656−1034) mod 1024 = 244。 访存：读二次间接块 → 读二级指向的间接块 → 读数据块 = 3次访存磁盘（inode已调入内存）。∎ （访存次数口诀：直接0次额外、一次间接+1、二次间接+2、三次间接+3——前提inode已在内存。）

二、目录与链接

D1 FCB与索引结点：目录=FCB的有序集合；inode瘦身使目录项变小→检索更快。 D2 硬链接 vs 软（符号）链接： - 硬链接：多个目录项指向同一inode，引用计数+1；删除原文件→计数−1，减到0才真删；改名/移动后硬链接依然有效； - 软链接：独立的新文件，内容是路径字符串；原文件删除/改名 → 软链接悬空失效；可跨文件系统。

考题3（链接辨析） 文件F建立硬链接H和软链接S后删除F。访问H、S各如何？两个链接各占多少inode？ 【解】H：inode引用计数从2→1，访问H仍正常（数据未删）；S：指向的路径不存在 → 访问S失效。H与F共享inode（不占新inode）；S占独立inode（存路径字符串）。∎

三、位示图（盘块管理计算模板）

B1 换算公式（0基编号）：盘块号 b → 字号 ⌊b/字长⌋，位号 b mod 字长；反向：盘块号 = 字号×字长+位号。 考题4 位示图每字32位。①盘块号1000在哪个字号哪一位？②字号28、位17对应盘块号？ 【解】①1000÷32=31余8 → 字31位8。②28×32+17=913。∎ （看清题目是"从0编号"还是"从1编号"——从1编号时整体±1，408高频陷阱。）

第5章 输入/输出管理

一、I/O软件层次（自上而下）

用户层I/O软件 → 设备独立性软件（命名映射、保护、缓冲、分配）→ 设备驱动程序（把抽象命令转为设备操作）→ 中断处理程序 → 硬件。 【要点】驱动程序之上是"与硬件无关"的；read()系统调用产生两次数据拷贝（设备→内核缓冲→用户区）。

二、I/O控制方式（CPU介入程度递减）

方式 数据流 CPU介入 应用
程序直接控制 外设→CPU→内存 全程轮询忙等 早期低速
中断 每个字经CPU 每字中断一次 键盘等低速
DMA 外设↔内存（块级直达） 仅预处理/后处理（块结束中断） 磁盘等块设备
通道 一组数据块，通道程序 仅启动/结束 大型机
【要点】DMA结束时以中断通知CPU做后处理；通道是"弱CPU"，有自己的指令系统。

三、缓冲区（公式推导）

B1 单缓冲：每块耗时 max(C,T)+M。 【推导】设备输入缓冲(T)与CPU从缓冲搬用户区并处理(M+C)：输入块i+1可与"搬移+处理块i"并行 → 稳态周期=max(T, M+C)+M = max(C,T)+M。∎ B2 双缓冲：每块耗时 max(C+M, T)。 【推导】两个缓冲交替，设备输入下一块可与"搬移+处理当前块"完全并行 → 周期=max(T, M+C)。 B3 循环缓冲n个：类比生产者消费者；缓冲池=系统公用（输入/输出/空闲队列）。

考题5（缓冲计算） 块输入T=100μs，缓冲→用户区搬移M=10μs，处理C=50μs。求单缓冲、双缓冲下处理4块的总时间。 【解】单缓冲：首块 T+M+C=160μs；后续每块 max(C,T)+M=110μs → 总=160+3×110=490μs。 双缓冲：首块 T+M+C=160μs；后续每块 max(C+M,T)=max(60,100)=100μs → 总=160+3×100=460μs。∎ （若C>T很多（处理是瓶颈），双缓冲收益消失——瓶颈转移给了CPU。）

四、SPOOLing（假脱机）

结构：磁盘上的输入井/输出井+输入/输出缓冲区+预输入程序/井管理程序/缓输出程序。 意义：用共享设备（磁盘井）模拟独占设备（打印机）→ 把独占设备改造为共享设备；用户进程的打印请求排队进输出井，缓输出程序依次打印。 【要点】SPOOLing必须有磁盘作井；提高了设备利用率与进程推进速度。

五、磁盘（调度演算）

K1 磁盘时间 = 寻道时间 + 旋转延迟（平均半圈）+ 传输时间。 考题6 转速7200rpm，每道63扇区（512B/扇区），寻道8ms。读一个扇区总时间？ 【解】旋转一圈=60/7200=8.33ms → 平均旋转延迟=4.17ms；传输=8.33/63≈0.13ms。 总=8+4.17+0.13≈12.3ms。∎

K2 磁盘调度演算：请求柱号 98,183,37,122,14,124,65,67，磁头在53。 | 算法 | 服务序列 | 总移动道数 | |---|---|---| | FCFS | 98,183,37,122,14,124,65,67 | 45+85+146+85+108+110+59+2=640 | | SSTF | 65,67,37,14,98,122,124,183 | 236 | | SCAN（向大，扫到199端折返） | 65,67,98,122,124,183,199,14? ——折返后14,37 | (199−53)+(199−14)=331 | | LOOK（向大，到最远请求183即折返） | 65,67,98,122,124,183,37,14 | (183−53)+(183−14)=299 | 【辨析】SCAN扫到物理端点；LOOK到最远请求即折返；C-SCAN单向服务+快速返回起点（对称扫描，等待时间更均匀）。 【调度目标】寻道时间通常占比最大——减少总寻道距离是调度核心；SSTF可能饥饿（远端请求无限延后），SCAN/C-SCAN无饥饿。

六、本章考题补遗（2题）

题7（设备独立性） 什么是设备独立性？带来什么好处？ 【答】应用程序独立于具体物理设备（用逻辑设备名申请）。好处：①设备分配灵活（可换同类设备）；②易于实现I/O重定向；③提高系统可靠性与适应性。∎

题8（SSD与传统磁盘） 固态硬盘（闪存）为什么没有寻道与旋转延迟？磨损均衡解决什么问题？ 【答】闪存是纯电子存储，无机械运动 → 随机访问快（无寻道/旋转）。但闪存块擦写次数有限且必须整块擦除→ 磨损均衡算法把擦写摊到所有块上，延长寿命；SSD上"随机读写"反而优于顺序覆盖写（无需先擦除的优化由FTL层处理）。∎ （SSD特性是近年408新考点：读快写慢于读、写前擦除、磨损均衡。）
