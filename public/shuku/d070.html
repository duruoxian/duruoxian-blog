第1章 计算机系统概述

一、定义精讲

D1 层次结构（从上到下）：高级语言机器（编译/解释）→ 汇编语言机器（汇编）→ 操作系统机器 → 机器语言机器 → 微程序机器。 【要点】软硬件在逻辑功能上等价（任何功能可硬件实现也可软件实现——成本/速度/灵活性的权衡）；编译=一次性生成目标程序，解释=逐句翻译执行（解释程序本身是软件）。

D2 冯·诺依曼结构（必背五条）： ① 计算机由运算器、存储器、控制器、输入设备、输出设备五大部件组成； ② 指令和数据以同等地位存储于存储器，可按地址寻访； ③ 指令和数据均用二进制表示； ④ 指令由操作码+地址码组成； ⑤ 存储程序：指令预先存入存储器，机器自动按地址顺序取指执行——这是冯·诺依曼机最根本的特征。 【发展辨析】早期冯·诺依曼机以运算器为中心（I/O都要经过运算器，瓶颈）→ 现代以存储器为中心 → 进一步发展出三总线结构。

D3 计算机工作过程：取指令（PC→MAR→存储器→MDR→IR，PC自动+1）→ 分析指令（操作码译码）→ 执行指令 → 下一循环。 【要点】(PC)→MAR→M(MAR)→MDR→(MDR)→IR 这条取指通路要能默写；PC自动加"1"是加一条指令的长度。

D4 性能指标（计算三件套）： - 主频 f（时钟频率）、时钟周期=1/f； - CPI：执行一条指令所需的平均时钟周期数； - CPU执行时间 = 指令条数 × CPI × 时钟周期 = 指令条数 × CPI ÷ 主频； - MIPS = 主频(Hz) ÷ (CPI×10⁶)——每秒百万条指令；FLOPS（浮点运算次数/秒，超算指标）。 【辨析】主频高≠机器快（CPI不同）；比较机器性能要看同一程序的总执行时间（"主频4GHz必快于2GHz"是错误说法——985面试陷阱）。

二、本章考题（3题）

题1（CPI/MIPS/CPU时间全套） 某机主频2GHz，某程序含 10⁹ 条指令，平均CPI=2。求CPU执行时间与MIPS。 【解】CPU时间 = 10⁹×2/(2×10⁹) = 1s；MIPS = 2×10⁹/(2×10⁶) = 1000 MIPS。∎ （变式：若程序中40%指令CPI=1、60%指令CPI=3 → 平均CPI=0.4+1.8=2.2，CPU时间=1.1s——按指令类型加权是必考变式。）

题2（冯·诺依曼辨析） 判断：①冯·诺依曼机中指令按内容访问存储器；②现代计算机以存储器为中心；③"存储程序"指指令预先存入存储器并由机器自动按地址顺序执行。 【答】①错（按地址访问，内容访问是相联存储器/TLB的事）；②对（缓解运算器瓶颈）；③对（存储程序=冯·诺依曼最根本特征）。∎

题3（翻译vs解释） 高级语言程序转换为机器可执行形式的两种方式？各自特点？ 【答】编译：由编译程序一次性翻译为目标程序再执行（执行快、可优化、C/Java前半）；解释：解释程序逐句翻译并立即执行（不生成完整目标程序、便于人机交互、效率低，如Python/Shell）。∎

第2章 数据的表示和运算

一、数制定点表示精讲

N1 原码/反码/补码/移码（n+1位含符号）： | 码制 | 表示范围 | 特点 | |---|---|---| | 原码 | −(2ⁿ−1) ~ 2ⁿ−1（有±0） | 乘除直观 | | 反码 | 同原码（有±0） | 过渡用 | | 补码 | −2ⁿ ~ 2ⁿ−1（无±0，多表示一个最小负数） | 加减统一、符号位参与运算 | | 移码 | 同补码 | 补码符号位取反；用于浮点阶码（保真值大→移码大，便于比较） | 【推导】补码定义 [x]补 = 2^{n+1}+x (mod 2^{n+1})——"模运算"视角：钟表拨快3小时=拨慢9小时。

N2 移位运算： - 算术左移：低位补0（补码下相当于×2，可能溢出）；算术右移：高位补符号位（÷2，符号不变）； - 逻辑右移：高位补0（无符号数用）； - 循环移位：带进位位/不带进位位（大小端存储交换用）。

N3 补码加减与溢出判断： 补码加减：符号位参加运算，超出模的进位丢弃。 溢出判断两法： ① 单符号位：符号位进位 ⊕ 最高数值位进位 = 1 → 溢出； ② 双符号位（变形补码）：结果双符号位 01=正溢、10=负溢、00/11 无溢出。 【本质】溢出=运算结果超出表示范围（只有同号相加/异号相减才可能溢出——异号相加绝不溢出，必考）。

N4 乘除法（概念级）：原码一位乘（符号异或+绝对值乘）；补码一位乘（Booth算法，附加位Yₙ₊₁）；除法：恢复余数法/加减交替法（不恢复余数）。408考演算频率低，考"移位与加法实现乘除"的思想。

三、C语言整数类型与类型转换（985高频陷阱区）

C1 符号扩展与截断： - 短→长：符号扩展（补码高位补符号位，值不变）； - 长→短：截断（保留低位，值可能变）； - 有符号↔无符号：位模式不变，解释改变。

考题1（类型转换·经典陷阱） 32位机器上：①int i = −1; unsigned u = i; u=? ②signed char c = 250; c的值？③unsigned char uc = −6; uc的值？ 【解】①−1 补码全1 → 无符号解释 = 4294967295（2³²−1）。 ②250 = 1111 1010₂ → 符号位1 → 负数：−(00000101+1) = −6。 ③−6 补码 1111 1010 → 无符号解释 = 250。∎ （口诀：位模式不变、解释方式变——②③互为镜像。）

四、浮点数精讲（IEEE 754）

F1 IEEE 754 单精度（32位）：1符号+8阶码（偏置127）+23尾数（隐含首位1）。 真值 = (−1)^s × 1.M × 2^{E−127}。 双精度：1+11（偏置1023）+52。 【要点】①尾数隐含"1."——精度实际24位；②阶码全0=非规格化数/±0（渐进下溢）；全1=±∞（尾数=0）或NaN（尾数≠0）；③移码偏置让阶码无符号比较即可比大小。

考题2（十进制→IEEE754） 将 75.25 表示为单精度IEEE 754（十六进制机器码）。 【解】75.25 = 1001011.01₂ = 1.00101101×2⁶。 符号0；阶码=6+127=133=10000101；尾数=0010110100…0。 机器码：0 10000101 00101101000000000000000 = 0x42968000。∎ （反向也要会：0x42968000 → 阶133−127=6、尾数1.00101101 → +75.25。）

考题3（浮点加减五步·手算） 设 x=2¹×0.1101，y=2³×0.1011（尾数6位，规格化、舍0舍1入）。求 x+y。 【解】①对阶（小阶向大阶）：x尾数右移2位 → 2³×0.001101； ②尾数相加：0.1011+0.001101 = 0.111001； ③规格化：0.111001 首位为1，已规格化； ④舍入：尾数6位内精确； ⑤阶码未溢出。 结果 = 2³×0.111001 = 0.111001₂×8 = 7.125（验证 1.625+5.5=7.125 ✓）。∎ （五步口诀：对阶—求和—规格化—舍入—判溢出；对阶必须"小阶向大阶"——右移损失的是小阶的低位精度。）

考题4（溢出判断·双符号位） 8位补码运算：①(−100)+(−50)；②(−45)+(−50)。用双符号位判断溢出。 【解】①[−100]变形补=11 10011100，[−50]=11 0011110。相加=10 1101010：双符号位10 → 负溢出（实际−150超出−128下限）。 ②11 01010011? [−45]=11 1010011? 8位[−45]=11010011 → 变形 11 1010011? 用8位结果：11010011+11001110=1 10100001 → 丢进位后 10100001，双符号位11 → 无溢出（结果−95）。∎ （规律：同号相加得异号必溢出；双符号位01=正溢、10=负溢。）

五、运算器组织（概念）

A1 加法器：串行进位（行波，慢）→ 超前进位加法器（进位生成Gi=AiBi、传递Pi=Ai⊕Bi，并行算进位，快）。 A2 定点运算器：ALU+通用寄存器+暂存器+移位器；补码加减直接做，乘除用移位+加法。 A3 标志位：ZF（零）、CF（无符号进位/借位）、OF（有符号溢出）、SF（符号）——CF看无符号、OF看有符号（同一运算两个标志独立置位）。

考题5（标志位辨析） 8位运算 1111 1111 + 0000 0001 = 0000 0000。CF与OF分别是什么？ 【解】有符号视角：(−1)+1=0 无溢出 → OF=0；无符号视角：255+1=256 超出 → CF=1。 同一运算，CF与OF各自独立置位——判断哪个标志取决于你把操作数当有符号还是无符号。∎
