第6章 图

一、定义与存储精讲

D1 图的基本概念：G=(V,E)；有向图弧有向、无向边(vi,vj)对称；完全图：无向任意两顶点有边（n(n−1)/2条），有向任意两顶点双向有弧（n(n−1)条）。 D2 度与连通： - 无向：度 TD(v)=关联边数；握手定理 ΣTD=2e（每边贡献两个度——推导一切度数题）； - 有向：入度ID+出度OD=TD；ΣID=ΣOD=e； - 无向连通：任意两顶点有路径；连通分量=极大连通子图；生成树=含全部n个顶点的极小连通子图（n−1条边，加边有环、去边不连通）； - 有向强连通：任意两顶点互达；强连通图最少n条边（有向环）；非强连通图的强连通分量用两次DFS求。 【推导】n个顶点e条边的无向图：连通⇒e≥n−1；n−1条边且连通⇔恰是树。

D3 四种存储（对比表）： | 存储 | 适用 | 空间 | 求度 | |---|---|---|---| | 邻接矩阵 | 稠密图 | O(n²)（对称矩阵可压缩） | 无向：行和；有向：行=出度、列=入度 | | 邻接表 | 稀疏图 | O(n+e)（无向2e个边结点） | 出度=边结点数；入度需遍历或逆表 | | 十字链表 | 有向图 | O(n+e) | 出入度都易 | | 邻接多重表 | 无向图 | O(n+e) | 每边只存一次，便于"对边"操作 |

二、遍历精讲

B1 DFS：递归（栈）；邻接表 O(n+e)，邻接矩阵 O(n²)；空间 O(n)（递归栈最深）。 B2 BFS：队列；同上复杂度；无权图单源最短路径（按层扩展，首达即最短）。 B3 序列唯一性（高频辨析）： - 邻接矩阵存储：邻居次序固定 → DFS/BFS序列唯一； - 邻接表存储：取决于建表时边结点的插入次序 → 序列不唯一； - 非连通图：一次遍历只能访问一个连通分量，调用遍历的次数=连通分量数。 B4 遍历应用：连通分量计数、判断是否有环（无向图DFS遇已访问的非双亲结点→有环）、路径存在性。

三、最小生成树（MST）

M1 Prim：从某顶点出发，每次选择"树内↔树外"的最小权边把一个新顶点并入；O(n²)——与边数无关，适合稠密图。 M2 Kruskal：边按权排序，从小到大试选，并查集判环（不成环才要）；O(elog₂e)——适合稀疏图。 M3 正确性直觉（985面试）：割性质——把顶点集分成树内/树外两半，跨越割的最小权边必属于某棵MST（若不选它而选别的跨割边，把那条换成它总权更小且仍连通——与最小矛盾）。Prim与Kruskal都是这条性质的不同实现。 M4 唯一性：权值互异⇒MST唯一；否则MST不唯一但总权值唯一且最小。

图G1（无向带权，本批演算主图）：V={A,B,C,D,E}，边：A-C=1，B-C=2，D-E=3，A-B=4，B-D=5，C-D=8，C-E=10。

考题1（Prim从A出发演算） | 步 | 并入顶点 | 选的边 | 树内集合 | |---|---|---|---| | 1 | C | A-C=1 | {A,C} | | 2 | B | C-B=2 | {A,C,B} | | 3 | D | B-D=5 | {A,C,B,D} | | 4 | E | D-E=3 | {A,C,B,D,E} | MST={AC,BC,BD,DE}，W=1+2+5+3=11。∎

考题2（Kruskal演算） 排序：AC1，BC2，DE3，AB4，BD5，CD8，CE10。 选AC✓、BC✓、DE✓；AB：A、B已连通（并查集find同根）弃；BD：B与D已连通（经AC-BC-DE）弃；CD、CE同样弃——已有4条边，停止。 结果与Prim一致：W=11。∎

四、最短路径

S1 Dijkstra（单源，禁负权边）：贪心——每轮把"当前 dist 最小的未定顶点"定为永久最短，再松弛其邻边。O(n²)。 图G2（有向带权）：A→B=2，A→C=5，B→C=1，B→D=6，C→D=2，D→E=1，C→E=7。

考题3（Dijkstra逐步表·从A） | 轮 | 选出 | dist[A,B,C,D,E] | 更新说明 | |---|---|---|---| | 初始 | — | 0, 2, 5, ∞, ∞ | A的邻边 | | 1 | B(2) | 0, 2, 3, 8, ∞ | 经B松弛C：2+1=3<5；D：2+6=8 | | 2 | C(3) | 0, 2, 3, 5, 10 | 经C松弛D：3+2=5<8；E：3+7=10 | | 3 | D(5) | 0, 2, 3, 5, 6 | 经D松弛E：5+1=6<10 | | 4 | E(6) | 结束 | | 最短路径：A→B(2)、A→B→C(3)、A→B→C→D(5)、A→B→C→D→E(6)。∎ 【负权禁区·反例】A→B=1，A→C=2，C→B=−2：Dijkstra第1轮后选B(1)并永久确定，但真实最短是经C的0——"永久确定"的前提（当前最小者不会再被改进）被负权破坏。负权用Floyd或SPFA。 S2 Floyd（多源）：动态规划，依次允许经过顶点1..n 中转：d⁽ᵏ⁾(i,j)=min(d⁽ᵏ⁻¹⁾, d⁽ᵏ⁻¹⁾(i,k)+d⁽ᵏ⁻¹⁾(k,j))，三重循环 O(n³)；可处理负权边（禁负权回路）。

五、拓扑排序与关键路径

P1 拓扑排序（AOV网）：每次取入度为0的顶点输出并删除其出边（栈/队列均可）；输出顶点数<n ⇒ 有环；拓扑序列不唯一；DFS按完成时间逆序也是拓扑序。O(n+e)。

P2 关键路径（AOE网）：源→汇；事件最早发生 ve(源)=0，ve(j)=max{ve(i)+w}（按拓扑序）；最迟 vl(汇)=ve(汇)，vl(i)=min{vl(j)−w}（按逆拓扑序）。 活动四大参数（活动a=，时长w）： 最早开始 e(a)=ve(i)；最迟开始 l(a)=vl(j)−w；时间余量=l−e；余量=0 → 关键活动。 【要点】①关键路径=最长路径，可有多条；②缩短某一关键活动不一定缩短工期（关键路径可能转移）；③只有"所有关键路径都经过"的活动被缩短才有效。

图G3（AOE网）：活动与时长：1→2=3，1→3=2，2→4=2，2→5=3，3→5=3，4→5=1。

考题4（关键路径四大参数完整演算） 【拓扑序】1,2,3,4,5；【逆拓扑序】5,4,2,3,1。 ve：ve1=0；ve2=ve1+3=3；ve3=ve1+2=2；ve4=ve2+2=5；ve5=max(ve2+3, ve3+3, ve4+1)=max(6,5,6)=6。 vl：vl5=6；vl4=vl5−1=5；vl3=vl5−3=3；vl2=min(vl4−2, vl5−3)=min(3,3)=3；vl1=min(vl2−3, vl3−2)=0。 | 活动 | w | e=ve(尾) | l=vl(头)−w | 余量 | 关键? | |---|---|---|---|---|---| | 1→2 | 3 | 0 | 3−3=0 | 0 | ✓ | | 1→3 | 2 | 0 | 3−2=1 | 1 | | | 2→4 | 2 | 3 | 5−2=3 | 0 | ✓ | | 2→5 | 3 | 3 | 6−3=3 | 0 | ✓ | | 3→5 | 3 | 2 | 6−3=3 | 1 | | | 4→5 | 1 | 5 | 6−1=5 | 0 | ✓ | 工期=ve5=6；关键路径两条：1→2→5 与 1→2→4→5。∎ （验证：ve=max 分支里两条路径同为6——"多条关键路径"的活例。）

考题5（拓扑排序演算·栈与队列结果不同） 对G3的AOV图（同G3顶点与有向边）分别用队列与栈做拓扑排序。 【解】初始入度：1:0，2:1，3:1，4:1，5:3。 队列：出1→入度2,3归零 → {2,3}；出2→4入队 → {3,4}；出3→5剩1（来自4）；出4→5入队；出5。序列 1,2,3,4,5。 栈：出1→压2,3；弹3（5还差2的入度）；弹2→4、5就绪压栈；弹5、弹4。序列 1,3,2,5,4。 两个都是合法拓扑序列——数据结构（栈/队列）的选择改变输出序列，但不改变合法性。∎

六、本章考题补遗（3题）

题6（度数与边数） 无向图有16条边，度为3的顶点有4个、度为4的顶点有3个，其余顶点度均≤2? 求最少顶点数。 【解】ΣTD=2e=32。已知贡献 3×4+4×3=24，剩余度数=8，其余每个顶点至少1度（若连通）? 题设"度≤2"的顶点至少0度——最少顶点=让剩余度数尽量集中：每个≤2 → 至少 8/2=4 个顶点。总最少 4+4+3=11个顶点。∎ （握手定理 ΣTD=2e 是一切度数计算的入口。）

题7（BFS最短路应用） 无权图 G1 中求 A 到 E 的最短路径（边数最少）。 【解】BFS从A：层0={A}，层1={C,B,D}，层2={E}（经C或D）→ 最短2条边，路径 A→C→E? G1中C-E=10存在边 ✓ 或 A→D→E。∎

题8（概念钉子） 判断：①强连通有向图最少n条边；②权互异的无向图MST唯一；③Dijkstra可处理负权边只要无负权回路；④缩短任一关键活动必缩短工期。 【答】①对（有向环）；②对；③错（负权边即破坏贪心前提，反例见S1）；④错（多条关键路径时，只缩短一条上的活动，工期不变——G3中缩短1→2超过1个单位前，工期仍由两条关键路径的max决定）。∎
