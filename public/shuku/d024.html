卷三答案与详解

选择：1A 2B 3B 4B 5A 6A 7C 8C 9A 10A

  1. x-arcsinx~x³/6。
  2. 左极限1，右极限2，均存在但不等 → 跳跃。
  3. x=1垂直渐近；x²/(x-1)=(x+1)+1/(x-1) → 斜渐近y=x+1；x→∞极限不存在（发散），无水平 → 2条。
  4. [f(a+h)-f(a)]-[f(a)-f(a-h)] over h = 两半之差→2f'(a)。
  5. 半径2的四分之一圆=π。
  6. dy/y=cotx dx → lny=lnsinx+C。
  7. 一般项→(-1)ⁿ不趋于0 → 发散。
  8. r(A)≤n-2 → r(A*)=0。
  9. X+Y~N(0,2) 对称 → 0.5。
  10. E(X²)=λ+λ²；E(X²-3X+2)=λ+λ²-3λ+2=λ²-2λ+2。

填空：11. 定积分定义：∫₀¹√(1+x)dx = (2/3)(2√2-1)。 12. f'=2xlnx+x，f''=2lnx+3，f'''=2/x → 2。 13. y'=3x²-3=0 → x=±1；y''=6x：x=-1处极大 → y(-1)=4。 14. ∫₀¹ u du = 1/2（u=lnx）。 15. A²=[[7,10],[15,22]]；A²-5A=[[2,0],[0,2]]=2E（凯莱-哈密顿：λ²-5λ-2=0）。 16. 两奇或两偶：C(5,2)·2!/10·9? 有序：5·4+5·4=40，总 10·9=90 → 4/9。

17. xˣ=e^{xlnx}，x→0⁺时 xlnx→0 → xˣ-1 ~ xlnx → 极限=1。

18. fₓ=3x²-3y=0→y=x²；f_y=3y²-3x=0→x=y²。联立：x⁴=x → x=0或1 → 驻点(0,0),(1,1)。 A=f_xx=6x，B=f_xy=-3，C=f_yy=6y。 (0,0)：AC-B²=-9<0 → 非极值；(1,1)：AC-B²=36-9=27>0 且 A=6>0 → 极小值 f(1,1)=-1。

19. 外层y=2x，内层y=x²：V=π∫₀²[(2x)²-(x²)²]dx = π(32/3-32/5) = 64π/15。

20. 极坐标：I=∫₀^{2π}dθ∫₁² r·r dr = 2π·(r³/3)|₁² = 14π/3。

21. 特征多项式 (1-λ)[(1-λ)²-1] = (1-λ)·λ(λ-2) → 特征值 0,1,2。 λ=0：x₁+x₃=0 → ξ₁=(1,0,-1)ᵀ；λ=1：x₁=0,x₃=0 → ξ₂=(0,1,0)ᵀ；λ=2：x₁=x₃ → ξ₃=(1,0,1)ᵀ。 三个互异特征值 → 可对角化：P=(ξ₁,ξ₂,ξ₃) → P⁻¹AP=diag(0,1,2)。

22. E(X)=(1+2+3+4)/10=1；E(X²)=(1+4+9+16)/10=3；D(X)=3-1=2。

三、解答题

22.（12分）设 (X,Y) 的联合密度 f(x,y)=2e^{-(2x+y)}（x>0,y>0），否则为0。求：(1) 边缘密度并判断独立性；(2) P(X<1, Y<1)；(3) E(XY)。

卷四答案与详解

选择：1A 2C 3A 4A 5A 6C 7B 8C 9C 10A

  1. e^{2x}-e^{-3x}~(2+3)x。
  2. f'=3x|x|，f''=6|x|（x≠0），f''(0)=lim3|x|=0 存在；f'''(0)=lim 6|x|/x 不存在 → C。
  3. arctanx|₀^∞=π/2。
  4. y'=e^{-x}x(2-x)=0 → x=2，二阶判负 → 极大值 4e^{-2}。
  5. |A|=1·(-1)·2=-2 → |A²|=4。
  6. λ²=1 → λ=±1。
  7. R=1；x=0：Σ(-1)ⁿ/n 收敛；x=2：Σ1/n 发散 → [0,2)。
  8. D(2X-3)=4·4=16。
  9. 1-(0.4)²=0.84。
  10. 抽签原理：与第一次相同 = 2/5。

填空：11. ln3-ln2（3^x-2^x=(e^{xln3}-e^{xln2})~x(ln3-ln2)）。 12. 两边求导：e^y y'+y+xy'=0；x=0时 e^y=e→y=1 → y'(0)=-1/e。 13. y=e^{-x}+Ce^{-2x}。 14. 裂项 Σ(1/n-1/(n+1))=1。 15. A=αβᵀ：特征值 0,0,βᵀα=6 → 6。 16. F(0.75)-F(0.25)=0.5625-0.0625=0.5。

17. 取对数：lim lnx/(1-x) = lim(1/x)/(-1) = -1 → 原式=e^{-1}。

18. 柱壳法：V=2π∫₀² x(2x-x²)dx = 2π(16/3-4) = 8π/3。

19. (1) 令 g(x)=f(x)+x-1：g 在[0,1]连续，g(0)=-1<0，g(1)=1>0，由零点定理存在 ξ∈(0,1) 使 g(ξ)=0，即 f(ξ)=1-ξ。∎ (2) f 在 [0,1] 上满足拉格朗日中值定理条件 → 存在 η∈(0,1)：f(1)-f(0)=f'(η)·(1-0)，即 f'(η)=1。∎

20. D 为圆心(0,1)、半径1的圆。∬2y=2·ȳ·面积=2·1·π=2π；∬3x²=3·∬x²=(3/2)∬(x²+y²)dσ（对称轮换）=（3/2)∫₀^πdθ∫₀^{2sinθ}r³dr = (3/2)∫₀^π4sin⁴θdθ = (3/2)·4·(3π/8)=9π/4。 I = 9π/4 + 2π = 17π/4。

21. (1) A 的特征值=2 与 [[3,a],[a,3]] 的 3±a → 5=3+a → a=2（另一特征值1）。 (2) λ=5：ξ₅=(0,1,1)ᵀ；λ=1：ξ₁=(0,1,-1)ᵀ；λ=2：ξ₂=(1,0,0)ᵀ（两两正交）。单位化后 Q=[[1,0,0],[0,1/√2,1/√2],[0,-1/√2,1/√2]] → Q⁻¹AQ=diag(2,1,5)。 (3) 特征值 2,1,5 全正 → 正定。

22. (1) f_X=2e^{-2x}(x>0)，f_Y=e^{-y}(y>0)；f_X·f_Y=f → 独立。 (2) (1-e^{-2})(1-e^{-1})。 (3) E(XY)=E(X)E(Y)=(1/2)·1=1/2。
