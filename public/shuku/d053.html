408 全真模拟卷（自编·第七套）

结构同真题：40×2' 选择 + 7道综合题共70分 = 150分，180分钟。答案解析在卷末（选择题答案随题给出）。

一、单项选择题（每题2分）

数据结构（1~11）

1. 若线性表最常用的操作是存取第 i 个元素及其前驱的值，则宜采用： A. 顺序表　B. 带头结点单链表　C. 循环单链表　D. 双链表

A。随机访问是顺序表的独门优势，链表按位存取 O(n)。

2. 中缀表达式 A+BC 的后缀表达式为： A. ABC+*　B. AB+C　C. ABC+　D. ABC+

A。乘法优先级高：先 B C *，再 A +。

3. 循环队列用数组 A[0..5]（容量6）实现，front=3、rear=0（牺牲单元法），队列中元素个数为： A. 2　B. 3　C. 4　D. 6

B。(rear−front+M) mod M = (0−3+6) mod 6 = 3。

4. n=100 的完全二叉树的树高（根为第1层）为： A. 6　B. 7　C. 8　D. 50

B。⌈log₂(n+1)⌉ = ⌈log₂101⌉ = 7（2⁶=64 < 101 ≤ 128=2⁷）。

5. 森林的后根遍历序列对应其二叉树表示的： A. 先序序列　B. 中序序列　C. 后序序列　D. 层次序列

B。树的先根→二叉树先序；树的后根→二叉树中序（森林同理）。

6. 用邻接表存储含 n 个顶点、e 条边的无向图，边表结点总数为： A. e　B. 2e　C. n+e　D. e²

B。每条边在两个端点的边表中各出现一次。

7. 在 AOE 网中，关键活动的特征是： A. 最早开始时间最大　B. 最早开始时间等于最迟开始时间（时间余量为0）　C. 一定是入度为0的顶点发出的活动　D. 工期一定最短

B。e=l 的活动为关键活动，其延误将推迟整个工程。

8. 对含 8 个元素的序列做 2 路归并排序，第一趟归并后有序段的个数为： A. 1　B. 2　C. 4　D. 8

C。第一趟两两归并：8→4个长度为2的有序段。

9. 序列 (90, 70, 60, 40, 50, 30) 满足： A. 小根堆　B. 大根堆　C. 二叉排序树的先序　D. 都不是

B。90≥(70,60)；70≥(40,50)；60≥(30)。

10. 以权值 {1,2,3,4} 构造哈夫曼树，其带权路径长度 WPL 为： A. 17　B. 18　C. 19　D. 20

C。合并：1+2=3；3+3=6；4+6=10。WPL=4×1+3×2+(1+2)×3 = 4+6+9 = 19。

11. 用链地址法处理冲突的散列表，其平均查找长度： A. 与表长成正比　B. 与装填因子α有关　C. 与关键字个数无关　D. 恒为1

B。ASL 是 α 的函数，与表长本身无关（这是散列表的核心性质）。

计算机组成原理（12~22）

12. 16 位补码定点整数的表示范围是： A. −32767 ~ 32767　B. −32768 ~ 32767　C. −32768 ~ 32768　D. 0 ~ 65535

B。n=15 数值位：−2¹⁵ ~ 2¹⁵−1。

13. 超前进位加法器比行波进位加法器快，原因是： A. 位数更少　B. 各级进位并行产生，无需逐级等待　C. 使用补码运算　D. 时钟频率更高

B。进位生成/传递函数并行算出所有进位。

14. 下列补码尾数中，已规格化的是： A. 0.0101　B. 1.0110　C. 0.1111　D. 1.1111

B。补码规格化规则：符号位与最高数值位相反——正数形如 0.1xx，负数形如 1.0xx。A、C（正数最高数值位为0）、D（负数最高数值位为1）均未规格化。

15. DRAM 需要定期刷新的根本原因是： A. 读出后数据被破坏　B. 存储用电容，电荷会泄漏　C. 地址线有噪声　D. 电源波动

B。电容漏电 → 需集中/分散刷新；"读出破坏"是破坏性读出问题，靠读后重写解决。

16. 2 路组相联 Cache 共 8 行，主存块号 13 应映射到的组号是： A. 1　B. 1（13 mod 4）　C. 5　D. 2

B。8行2路 → 4组；组号 = 13 mod 4 = 1。

17. 访问 TLB 需 10ns，访问主存需 100ns，TLB 命中率 90%（未命中需先查页表再取数），则有效访存时间约为： A. 110ns　B. 120ns　C. 210ns　D. 100ns

B。0.9×(10+100) + 0.1×(10+100+100) = 99+21 = 120ns。

18. 一地址指令中，另一个隐含的操作数通常存放在： A. 程序计数器PC　B. 状态寄存器　C. 累加器ACC　D. 堆栈

C。一地址指令约定 ACC 为隐含操作数与结果存放处。

19. 微程序控制器中，一条机器指令对应： A. 一条微指令　B. 一段微程序　C. 一个微命令　D. 一条机器周期

B。指令→微程序（若干条微指令），微指令→若干微命令。

20. 中断屏蔽字的作用是： A. 永久禁止中断　B. 动态调整中断处理次序（改变响应处理优先级）　C. 记录中断源　D. 保存断点

B。屏蔽字让每个中断源可屏蔽部分其他中断源，从而重排处理次序；响应优先级由硬件固定。

21. DMA 方式传送数据期间，数据传送路径为： A. 外设→CPU→主存　B. 外设↔主存（不经过CPU）　C. 外设→Cache→主存　D. 必须经过CPU寄存器

B。DMA 控制器直接掌管总线，数据在外设与主存间直达。

22. 键盘与主机间信息交换宜采用的 I/O 方式是： A. DMA　B. 通道　C. 程序中断　D. 程序查询（CPU循环等待）

C。键盘数据率低且随机，中断方式兼顾实时与效率；查询方式浪费CPU。

操作系统（23~32）

23. 下列功能中，不属于处理机管理的是： A. 进程控制　B. 进程同步　C. 存储保护　D. 进程调度

C。存储保护属存储器管理。

24. 用户程序通过系统调用请求 I/O，执行过程中会发生： A. 用户态→用户态　B. 用户态→核心态　C. 核心态→用户态　D. 不发生态转换

B。陷入(trap)指令切换到核心态执行内核代码。

25. 进程切换（保存当前进程上下文、恢复新进程）必定发生在： A. 用户态　B. 核心态　C. 任何态均可　D. 中断关闭时

B。切换由内核完成，必须处于核心态。

26. 以"快速响应交互用户"为主要目标的调度算法是： A. 先来先服务　B. 短作业优先　C. 时间片轮转　D. 高响应比优先

C。RR 面向交互式系统，保证响应时间上限。

27. 临界区管理四原则中，"让权等待"的含义是： A. 等待时占用CPU空转　B. 进程不能进入临界区时应释放CPU并阻塞自己　C. 临界区尽量短　D. 先到先服务

B。避免忙等；与"有限时间内可以进入"配合。

28. 用于实现互斥的信号量 mutex 初值通常为： A. 0　B. 1　C. −1　D. n

B。1表示临界区空闲；0表示被占；负值绝对值=等待进程数。

29. 通过"允许高优先级进程剥夺低优先级进程的CPU"来破坏死锁必要条件，破坏的是： A. 互斥条件　B. 请求并保持　C. 不可剥夺　D. 循环等待

C。可剥夺调度破坏"不可剥夺"条件。

30. 页大小 2KB，逻辑地址 4500（十进制），页号2对应物理块号5，则物理地址为： A. 9404　B. 10644　C. 4500　D. 11252

B。4500 = 2×2048+404 → 物理地址 = 5×2048+404 = 10644。

31. 页式虚拟存储中，"缺页中断"属于： A. 外中断　B. 内中断（程序性异常）　C. 时钟中断　D. I/O中断

B。缺页由当前指令执行引发，属内中断；且一条指令执行期间可产生并处理。

32. 文件连续分配方式的突出优点是： A. 文件易于动态增长　B. 支持随机（直接）存取　C. 无外部碎片　D. 目录简单无需FCB

B。由起始块号+长度即可直接定位任意块；缺点是不易扩展、有外部碎片。

计算机网络（33~40）

33. 网络协议三要素中，规定"需要发出何种控制信息、完成何种动作、做出何种应答"的是： A. 语法　B. 语义　C. 时序　D. 结构

B。语法=格式结构；语义=动作与应答；时序=顺序与速度匹配。

34. 对实时性要求高（如语音通话）的场景，传统上首选的交换方式是： A. 电路交换　B. 报文交换　C. 分组交换　D. 信元交换

A。电路交换建立专用通路，通信时延小且稳定。

35. 采用曼彻斯特编码传输 10Mbps 的数据，其波特率为： A. 10Mbaud　B. 20Mbaud　C. 5Mbaud　D. 40Mbaud

B。每比特两个信号周期 → 波特率=2×数据率。

36. 以太网交换机收到帧后查 MAC 表无表项时，将： A. 丢弃该帧　B. 向除入端口外的所有端口转发（洪泛）　C. 只发往网关　D. 返回NAK

B。洪泛同时完成自学习（记源MAC）；目的站回应后表项补全。

37. 网络 192.168.1.0/24 不划分子网时，可用主机地址数为： A. 256　B. 254　C. 255　D. 128

B。8位主机位 → 2⁸−2 = 254（去掉网络地址与广播地址）。

38. 测试到目标主机连通性所使用的 ping 程序基于的报文是： A. TCP SYN　B. ICMP 回送请求与回送回答　C. ARP 请求　D. UDP 广播

B。ping 用 ICMP 类型8/0；traceroute 用 ICMP 超时/终点不可达。

39. TCP 拥塞控制，初始 ssthresh=8（单位：MSS），cwnd 从1开始慢启动并线性增长（无丢包），则第 6 轮传输结束时 cwnd 为： A. 6　B. 8　C. 10　D. 12

C。慢启动：轮1=1,2,4,8（轮4达门限）；轮5=9、轮6=10（拥塞避免线性+1）。

40. 本地域名服务器向根域名服务器查询域名时，通常采用： A. 迭代查询　B. 递归查询　C. 反向查询　D. 组播查询

A。主机→本地服务器是递归；本地→根/顶级/权限通常是迭代。

二、综合应用题（共70分）

41.（13分）设计算法判断一个带头结点的单链表（结点值为字符）是否中心对称（如 xyx、xyzyx），要求时间 O(n)。可借助辅助栈，说明思路并写出代码。

答案：快慢指针找中点，前半入栈，再与后半逐一比较。 c int IsSymmetric(LinkList L) { // 有头结点 LNode *slow = L->next, *fast = L->next; char stack[MAXSIZE]; int top = -1; while (fast && fast->next) { // fast走两步、slow走一步 stack[++top] = slow->data; // 前半部分入栈 slow = slow->next; fast = fast->next->next; } if (fast != NULL) slow = slow->next; // 奇数长度时跳过中心结点 while (slow != NULL) { // 后半与栈顶（前半逆序）比较 if (stack[top--] != slow->data) return 0; slow = slow->next; } return 1; } 时间 O(n)，空间 O(n)。（若要求 O(1) 空间：找中点后逆转后半链再比较，最后还原。）

42.（10分）对序列 (49, 38, 65, 97, 76, 13, 27) 进行一趟快速排序（以第一个元素 49 为枢轴），写出每一轮交换后的序列与最终结果，并说明枢轴的最终位置及其含义。

答案（low=0, high=6，枢轴 49，标准"挖坑填数"过程）： 初始：49, 38, 65, 97, 76, 13, 27 ① high 找到 27<49 → 填入low位：27, 38, 65, 97, 76, 13, [ ] ② low 前进，65>49 → 填入high位：27, 38, [ ], 97, 76, 13, 65 ③ high 前进，13<49 → 填入low位：27, 38, 13, 97, 76, [ ], 65 ④ low 前进至 high 相遇：枢轴 49 填入位置3。 一趟结果：(27, 38, 13, 49, 76, 97, 65)。 枢轴 49 落在其最终位置（第4个）：左侧全部≤49，右侧全部≥49——这正是快排"每趟确定一个元素最终位置"的性质。

43.（13分）将十进制数 −0.75 表示为 IEEE 754 单精度浮点数（写出三个字段与十六进制机器码），并说明 IEEE 754 中阶码全0、全1的两种特殊含义。

答案：−0.75 = −(0.11)₂ = −1.1×2⁻¹。 符号位 = 1；阶码 = −1+127 = 126 = 0111 1110；尾数 = 100 0000 0000 0000 0000 0000（隐含首位1）。 机器码：1 01111110 10000000000000000000000 = BF40 0000H。 特殊阶码：全0 表示非规格化数（含±0，用于极小值渐进下溢）；全1 表示无穷大（尾数=0）或 NaN（尾数≠0）。

44.（10分）某流水线分5段，每段耗时100ns（段间锁存延迟忽略）。(1) 连续执行10条指令的总时间；(2) 与串行执行相比的加速比；(3) 若第3条指令与第4条指令存在"先写后读"数据相关且无转发技术，需要插入几个等待周期？重新计算总时间。

答案： (1) (5+10−1)×100 = 1400ns。 (2) 串行 = 10×5×100 = 5000ns；加速比 = 5000/1400 ≈ 3.57。 (3) RAW 相关：后一条指令需等前一条写回 → 插入2个等待周期（第4条在译码后停顿，直至第3条写回）： 总时间 = 1400 + 2×100 = 1600ns。（有转发技术时通常无需停顿或仅停1拍——这正是设计转发硬件的意义。）

45.（8分）某系统有 A、B、C 三类资源各 10、5、7 个，当前分配如下（Allocation / Max）： P0: A0 B1 C0 / 7,5,3　P1: 2,0,0 / 3,2,2　P2: 3,0,2 / 9,0,2　P3: 2,1,1 / 2,2,2　P4: 0,0,2 / 4,3,3 当前 Available = (3,3,2)。用银行家算法判断系统是否处于安全状态；若安全，给出一个安全序列。

答案：Need = Max−Allocation：P0(7,4,3) P1(1,2,2) P2(6,0,0) P3(0,1,1) P4(4,3,1)。 Work=(3,3,2)：P1 Need(1,2,2)≤Work → 运行完释放 → Work=(5,3,2)； P3 Need(0,1,1)≤ → Work=(7,4,3)；P4 Need(4,3,1)≤ → Work=(7,4,5)； P0 Need(7,4,3)≤ → Work=(7,5,5)；P2 Need(6,0,0)≤ → Work=(10,5,7)。 存在安全序列 ⟨P1, P3, P4, P0, P2⟩ → 系统处于安全状态。

46.（7分）磁盘请求柱号序列：98, 183, 37, 122, 14, 124, 65, 67，磁头当前在 53 号柱面。分别求 SSTF（最短寻道时间优先）与 LOOK（向柱号增大方向，到最远请求即折返）的寻道序列与总移动道数。

答案： SSTF：53→65(12)→67(2)→37(30)→14(23)→98(84)→122(24)→124(2)→183(59)。 总移动 = 12+2+30+23+84+24+2+59 = 236 道。 LOOK（向大）：53→65→67→98→122→124→183（最远请求，不扫到199端点）→37→14。 总移动 = (183−53) + (183−14) = 130 + 169 = 299 道。 （注意区分：SCAN 需扫到物理端点才折返；LOOK 到最远请求即返回。）

47.（9分）某 IP 数据报总长 1500B（含 20B 首部），经过 MTU=576B 的链路传输。求：(1) 每个分片携带的数据长度（要求片偏移为8B的整数倍）；(2) 各分片的片偏移字段值与 MF 标志；(3) 各分片的总长度。
