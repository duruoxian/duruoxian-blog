卷七答案与详解

选择：1B 2B 3A 4B 5B 6B 7A 8A 9B 10A

  1. eˣ−1−x ~ x²/2，x·sinx ~ x² ⇒ 1/2。
  2. f(h)/h：h>0 时 = h²−1 → −1；h<0 时 = −(h²−1) → 1。左右不等 ⇒ 连续但不可导。
  3. y = x³−2x²+x，y″ = 6x−4 = 0 ⇒ x=2/3，y = (2/3)(1/9) = 2/27，且 y″ 两侧变号 ✓。
  4. 分部：= ½x²arctanx |₀¹ − ½∫₀¹ x²/(1+x²) = π/8 − ½(1−π/4) = π/4 − 1/2。
  5. 绝对值级数为 p-级数：p>1 绝对收敛；p≤1 时原级数由莱布尼茨收敛而绝对值发散 ⇒ 0<p≤1 条件收敛（p≤0 通项不趋0发散）。
  6. dz = e^{xy}(y dx + x dy)，代入 (1,0)：e⁰(0·dx + 1·dy) = dy。
  7. |−2A⁻¹| = (−2)³·|A⁻¹| = −8·(1/3) = −8/3。
  8. det = −ac（按第一列展开）⇒ 无关 ⟺ ac≠0 ⇒ a≠0 且 c≠0。
  9. P(X≥1) = 1−(2/3)⁴ = 1−16/81 = 65/81。
  10. D(2X−Y) = 4·4 + 9 = 25（减号不减方差）。
