综合题解析

综合1：后序末位 A 为根 → 中序分左{D,B,E}右{F,C}；左后序 DEB → 根 B（D 左、E 右）；右后序 FC → 根 C（中序 F 在前 → F 左、C 根）。 先序：A B D E C F。

综合2：快慢指针：slow每次1步、fast每次2步；fast到尾时slow即中间（偶数个时 slow 停在前一个中间——判 fast->next->next）。

LNode* Mid(LinkList L){          /* 带头结点 */
    LNode *p=L->next, *q=p;
    if(!p) return NULL;
    while(q->next && q->next->next){
        p=p->next; q=q->next->next;
    }
    return p;
}   /* O(n), O(1) */

综合3：位扩2片/组（16K×16→16K×32），字扩4组（16K字→64K字）⇒ 8片。 地址16位：低14位接芯片，A15A14 → 2:4译码产生4个组片选：

A15A14 组 字地址范围
00 1 0~16K−1
01 2 16K~32K−1
10 3 32K~48K−1
11 4 48K~64K−1

（组内两片：一片供低16位数据、一片供高16位数据，共用片选。）

综合4：35.625=100011.101₂=1.00011101×2⁵。 S=0；E=5+127=132=10000100；M=00011101后补0（23位）。 二进制：0 10000100 00011101000000000000000；十六进制 0x420E8000。

综合5：0-7 P1（到达序列中无人更短）；7时刻就绪 P2(4),P3(1),P4(4) → P3 先（7-8）；再 P2（8-12，FCFS先到）；P4（12-16）。 周转：P1=7，P2=10，P3=4，P4=11；平均周转 = (7+10+4+11)/4 = 8。 （等待：0,6,3,7；平均4。）

综合6：(1) 每块地址数=256。 最大 = (10 + 256 + 256²)×4KB = 65802×4KB = 269,484,032B ≈ 257MiB。 (2) 1,000,000÷4096=244.14 → 数据在第244块；244>10 → 位于一级间接范围（块10~265）：先读一级间接块得数据块地址，再读数据块 ⇒ 2次访盘。

综合7：A 120台→/25（126台）：192.168.100.0/25；B 60→/26（62台）：192.168.100.128/26；C 30→/27（30台）：192.168.100.192/27（可用30，恰好满足）；D 两条点对点→/30（2可用）：192.168.100.224/30、192.168.100.228/30；剩余 .232 以后留用。 公司整体聚合：192.168.100.0/24。
