§1 一阶方程（F1–F30）

F1.★ 解 y′ = x/y（y>0）。

分离变量：y dy = x dx ⇒ y² = x² + C。

F2.★ 解 y′ = y/(1+x)。

dy/y = dx/(1+x) ⇒ ln|y| = ln|1+x| + C₁ ⇒ y = C(1+x)。

F3.★ 解 y′ = y/x。

齐次方程：dy/y = dx/x ⇒ y = Cx（过原点的直线族）。

F4.★★ 解 y′ = y/x + tan(y/x)。

令 u=y/x：x·u′ = tanu ⇒ cotu du = dx/x ⇒ lnsinu = lnx + C。 sin(y/x) = Cx。

F5.★★ 解 (x+y)dx − x dy = 0。

y′ = 1 + y/x（齐次）：x·u′ = 1 ⇒ u = lnx + C。 y = x(C + lnx)。

F6.★ 解 y′ + y/x = x。

一阶线性，积分因子 e^{∫dx/x} = x：(xy)′ = x² ⇒ xy = x³/3 + C。

F7.★ 解 y′ − 2y = eˣ。

积分因子 e^{−2x}：(ye^{−2x})′ = e^{−x} ⇒ ye^{−2x} = −e^{−x} + C ⇒ y = Ce^{2x} − eˣ。

F8.★ 解 y′ + y = e^{−x}。

(yeˣ)′ = 1 ⇒ y = (x+C)e^{−x}（特解 xe^{−x}，λ=−1 恰为特征根，典型共振）。

F9.★★ 解 y′ + y·tanx = secx。

积分因子 e^{∫tanx} = secx：(y·secx)′ = sec²x ⇒ y·secx = tanx + C。 y = sinx + C·cosx。

F10.★★ 解 x·y′ + y = lnx（x>0）。

化标准形 y′ + y/x = lnx/x，积分因子 x：(xy)′ = lnx。 xy = x·lnx − x + C（∫lnx = xlnx − x）。

F11.★ 默写一阶线性方程的通解结构。

y = e^{−∫P}·[∫Q·e^{∫P}dx + C]。通解 = 齐次通解 + 非齐次一个特解，与二阶同构。

F12.★ 解 y′ = e^{x+y}。

e^{−y}dy = eˣdx ⇒ −e^{−y} = eˣ + C ⇒ e^{−y} = −eˣ + C。

F13.★★ 解 x²y′ + xy = 1。

y′ + y/x = 1/x²：(xy)′ = 1/x² ⇒ xy = −1/x + C ⇒ y = C/x − 1/x²。

F14.★★ 解 (x²−1)y′ + 2xy = cosx。

注意左边正是 [(x²−1)y]′！直接积分：(x²−1)y = sinx + C ⇒ y = (sinx+C)/(x²−1)。 看到"导数乘系数"先观察是否恰为某乘积的导数。

F15.★★ 解 y′ − y = x·y²（伯努利方程）。

两边除 y²、令 z=1/y：z′ + z = −x。 z = Ce^{−x} − x + 1 ⇒ y = 1/(1 − x + Ce^{−x})。

F16.★★★ 解 y′ = (x²+y²)/(xy)。

令 u=y/x：x·u′ = (1+u²)/u − u = 1/u ⇒ u du = dx/x。 u²/2 = lnx + C ⇒ y² = 2x²·lnx + Cx²。

F17.★★ 验证 (3x²+2xy)dx + (x²+2y)dy = 0 是全微分方程并求解。

∂M/∂y = 2x = ∂N/∂x ✓。 u = x³ + x²y + y² ⇒ x³ + x²y + y² = C。

F18.★ 全微分方程的判定条件？

单连通域上 ∂M/∂y = ∂N/∂x（恰当方程）；此时存在 u 使 du = Mdx+Ndy。

F19.★★ 解 y′ + y/x = sinx。

(xy)′ = x·sinx ⇒ xy = sinx − x·cosx + C ⇒ y = (sinx − x·cosx)/x + C/x。

F20.★ 曲线任一点切线斜率等于 2y/x，求曲线族。

y′ = 2y/x ⇒ dy/y = 2dx/x ⇒ y = Cx²（抛物线族）。

F21.★ 解 y′ = y²。

dy/y² = dx ⇒ −1/y = x + C ⇒ y = −1/(x+C)。

F22.★ 解 (1+x)y′ = y。

dy/y = dx/(1+x) ⇒ y = C(1+x)。

F23.★ 解 y′ = (1+y²)/(1+x²)。

dy/(1+y²) = dx/(1+x²) ⇒ arctany = arctanx + C ⇒ y = tan(arctanx + C)。

F24.★ 解 y′ = 2x，y(0)=1。

y = x² + C，代入得 y = x² + 1。

F25.★ 默写一阶线性方程的积分因子。

y′+P(x)y=Q(x) 的积分因子 = e^{∫P dx}；两边乘它后左边恰为 [y·e^{∫P}]′。

F26.★ 解 y′ + 2y = 4x。

特解尝试 y=ax+b：2+(2ax+2b)·? 按待定系数：2a=4 ⇒ a=2；2a+2b=0? 代入：a + 2(ax+b) = 4x ⇒ 2a=4, a+2b=0 ⇒ b=−1。 y = Ce^{−2x} + 2x − 1*。

F27.★ 解 y′ = −x/y。

y dy = −x dx ⇒ x² + y² = C（同心圆族，半径 √C）。

F28.★★ 解 y′ + y·cosx = e^{−sinx}。

积分因子 e^{sinx}：(ye^{sinx})′ = 1 ⇒ y = (x+C)e^{−sinx}。

F29.★★ 由通解 y = C₁eˣ + C₂e^{2x} 反求微分方程。

特征根 1、2 ⇒ (r−1)(r−2) = r²−3r+2 ⇒ y″ − 3y′ + 2y = 0。

F30.★★ 下列方程中是线性方程的：①y′=x²y ②y′=y²+x ③y′+xy=eˣ ④y·y′=x。 A. ①③ B. ①② C. ②④ D. ③④

A。线性=关于 y 与 y′ 都是一次。②含 y²、④含 y·y′，都非线性。

§2 可降阶的高阶方程（F31–F45）

F31.★ 解 y″ = x。

积分两次：y = x³/6 + C₁x + C₂。

F32.★ 解 y″ = y′（缺 y）。

令 p=y′：p′=p ⇒ p = C₁eˣ ⇒ y = C₁eˣ + C₂。

F33.★★ 解 y″ = (y′)²。

p=y′：dp/dx = p² ⇒ −1/p = x + C₁ ⇒ y′ = −1/(x+C₁)。 y = −ln|x+C₁| + C₂。

F34.★★ 解 y″ + (y′)² = 1。

缺 x：p·dp/dy = 1−p² ⇒ 令 w=1−p²：dw/dy = −2p·dp/dy = −2w ⇒ w = C₁e^{−2y}。 p² = 1−C₁e^{−2y}；取 C₁=1 代入分离变量（令 u=e^y）得 u=cosh(x+C₁)。 y = ln|cosh(x+C₁)| + C₂（验证：y′=tanh(x+C₁)，y″=sech²(x+C₁)，相加=1 ✓）。

F35.★ 解 y‴ = x。

积分三次：y = x⁴/24 + C₁x²/2 + C₂x + C₃。

F36.★ 解 y″ = e^{2x}。

y = e^{2x}/4 + C₁x + C₂。

F37.★★ 解 (1+x²)y″ = 2xy′。

p=y′：dp/p = 2x/(1+x²)dx ⇒ p = C₁(1+x²)。 y = C₁(x + x³/3) + C₂。

F38.★ 缺 y 的方程（y″=f(x,y′)）与缺 x 的方程（y″=f(y,y′)）分别怎么降阶？

缺 y：令 p=y′，得 p 关于 x 的一阶方程；缺 x：令 p=y′ 且 y″=p·dp/dy，得 p 关于 y 的一阶方程。

F39.★★ 解 y″ + y′ = x。

对 p=y′：p′+p = x（一阶线性）⇒ p = x − 1 + Ce^{−x}。 y = x²/2 − x − Ce^{−x} + C₂。

F40.★★ 解 y·y″ = (y′)²。

缺 x：y·p·dp/dy = p² ⇒ dp/p = dy/y ⇒ p = C₁y ⇒ dy/y = C₁dx。 y = C₂e^{C₁x}（指数族）。

F41.★ 解边值问题 y″=0，y(0)=0，y(1)=1。

y = C₁x+C₂：C₂=0，C₁=1 ⇒ y=x。

F42.★ 解 y″ = −y。

y = C₁cosx + C₂sinx（特征根 ±i，简谐振动）。

F43.★★ 解 x·y″ + y′ = 0（x>0）。

观察 (xy′)′ = 0 ⇒ xy′ = C₁ ⇒ y = C₁lnx + C₂。

F44.★★ 解 y″ = y′/x。

(ln p)′ = 1/x ⇒ p = C₁x ⇒ y = C₁x²/2 + C₂。

F45.★★ 求满足 y″=y′，y(0)=0，y′(0)=1 的解。

y = C₁eˣ+C₂：y(0)=0 ⇒ C₂=−C₁；y′(0)=C₁=1。 y = eˣ − 1。

§3 二阶常系数线性方程（F46–F75）

F46.★ 默写 y″+py′+qy=0 特征根的三种情形与通解。

判别式 Δ=p²−4q： 两不同实根 r₁≠r₂：y=C₁e^{r₁x}+C₂e^{r₂x}；二重根 r：y=(C₁+C₂x)e^{rx}； 共轭复根 α±βi：y=e^{αx}(C₁cosβx+C₂sinβx)。

F47.★ 解 y″ − 5y′ + 6y = 0。

r²−5r+6 = (r−2)(r−3) ⇒ y = C₁e^{2x} + C₂e^{3x}。

F48.★ 解 y″ + 2y′ + y = 0。

(r+1)² = 0 二重根 −1 ⇒ y = (C₁+C₂x)e^{−x}。

F49.★ 解 y″ + y = 0。

r = ±i ⇒ y = C₁cosx + C₂sinx。

F50.★ 解 y″ − 2y′ + 5y = 0。

r = 1±2i ⇒ y = eˣ(C₁cos2x + C₂sin2x)。

F51.★★ 解 y″−4y′=0，y(0)=1，y′(0)=2。

r=0、4 ⇒ y=C₁+C₂e^{4x}；C₁+C₂=1，4C₂=2 ⇒ C₂=1/2，C₁=1/2。 y = (1+e^{4x})/2。

F52.★★ 解 y″ − y = eˣ。

特征根 ±1，λ=1 是单根 ⇒ 特解形如 a·x·eˣ。代入得 2a=1。 y = C₁eˣ + C₂e^{−x} + (x/2)eˣ。

F53.★ 解 y″ + y = eˣ。

λ=1 非根：特解 aeˣ，2a=1 ⇒ y = C₁cosx+C₂sinx + eˣ/2。

F54.★★ 解 y″ + y = sinx。

λ=±i 是根 ⇒ 特解 x(a cosx + b sinx)。代入解得 a=−1/2。 y = C₁cosx + C₂sinx − (x/2)cosx。

F55.★★★ 解 y″ − 3y′ + 2y = x·eˣ。

λ=1 单根 ⇒ 特解 x(ax+b)eˣ。逐项求导代入： 系数匹配得 a=−1/2，b=−1（利用 (D−1)(D−2) 作用于 x(ax+b)eˣ = −2a·x·eˣ+(2a−b)eˣ）。 y = C₁eˣ + C₂e^{2x} − (x²/2 + x)eˣ。

F56.★ 叠加原理：右端 f = f₁+f₂ 时特解怎么取？

特解 = f₁ 的一个特解 + f₂ 的一个特解（分别按各自类型设，互不影响）。

F57.★★ 解 y″ + 4y = cos2x。

λ=2i 是根 ⇒ 特解 x·(a cos2x + b sin2x)，代入得 a=0，b=1/4。 y = C₁cos2x + C₂sin2x + (x/4)sin2x。

F58.★★ 解 y″ − 2y′ + y = eˣ。

λ=1 二重根 ⇒ 特解 ax²eˣ，代入得 2a=1 ⇒ a=1/2。 y = (C₁+C₂x)eˣ + (x²/2)eˣ。

F59.★★ 由通解 y = C₁e^{−x} + C₂e^{2x} 反求方程。

特征根 −1、2 ⇒ (r+1)(r−2) = r²−r−2 ⇒ y″ − y′ − 2y = 0。

F60.★ 通解中出现 cosβx 的条件？

特征方程有共轭复根 ⟺ 判别式 p²−4q < 0。

F61.★ 解 y″ + y = x。

特解 y=ax+b：0+(ax+b) = x ⇒ a=1，b=0。 y = C₁cosx + C₂sinx + x*。

F62.★ 解 y″ − y = x。

特解 ax+b：−(ax+b) = x ⇒ a=−1，b=0。 y = C₁eˣ + C₂e^{−x} − x。

F63.★★ 解 y″ + y = x·e^{2x}。

λ=2 非根：特解 (ax+b)e^{2x}。代入：y″+y = (5ax + 5b + 4a)e^{2x} = xe^{2x}。 a=1/5，b=−4/25 ⇒ y = C₁cosx+C₂sinx + (x/5 − 4/25)e^{2x}。

F64.★★ 解 y″ − y = eˣ + 1。

分项：eˣ 的特解 xeˣ/2（F52）；1 的特解 −1（F62 同理：0−c=1）。 y = C₁eˣ + C₂e^{−x} + (x/2)eˣ − 1。

F65.★ 二阶非齐次线性方程解的结构定理默写。

通解 = 对应齐次通解 + 非齐次任一特解；两个非齐次解之差是对应齐次的解。

F66.★★ y₁、y₂ 是 y″+py′+qy=f(x) 的两个解，(y₁+y₂)/2 是什么？

A[(y₁+y₂)/2] = f ⇒ 也是原方程的解；而 y₁−y₂ 是齐次方程的解。

F67.★★ 解 y″ − y = sin2x。

特解 a·sin2x + b·cos2x：y″−y = −5a·sin2x − 5b·cos2x = sin2x ⇒ a=−1/5，b=0。 y = C₁eˣ + C₂e^{−x} − (1/5)sin2x。

F68.★ 解 y″+y=0，y(0)=1，y′(0)=0。

y = C₁cosx+C₂sinx：C₁=1，C₂=0 ⇒ y = cosx。

F69.★ 特解设 form 中"乘 xᵏ"的规则？

e^{λx} 型右端：λ 是特征方程的 k 重根 ⇒ 特解设为 xᵏ·Q(x)·e^{λx}（k=0,1,2）。

F70.★ 解 y″ + y′ + y = 0。

r = (−1±√3 i)/2 ⇒ y = e^{−x/2}[C₁cos(√3x/2) + C₂sin(√3x/2)]。

F71.★★ y″+2y′+3y=0 的所有解是否随 x→+∞ 趋于 0？

特征根实部 −1 < 0 ⇒ e^{−x} 因子压住三角函数 ⇒ 是，全部解趋 0（渐近稳定）。

F72.★★ 解 y‴ + y′ = 0。

特征 r³+r = r(r²+1) ⇒ r=0, ±i。 y = C₁ + C₂cosx + C₃sinx。

F73.★★ 解 y″ + y′ − 2y = 2x²。

特征根 1、−2；特解 ax²+bx+c。代入：2a + (2ax+b) − 2(ax²+bx+c) = 2x²。 −2a=2 ⇒ a=−1；2a−2b=0 ⇒ b=−1；2a+b−2c=0 ⇒ c=−3/2。 y = C₁eˣ + C₂e^{−2x} − x² − x − 3/2。

F74.★★★ 解 y″+4y=8x，y(0)=0，y′(0)=0。

特解 y=2x。通解 y = C₁cos2x + C₂sin2x + 2x。 y(0)=0 ⇒ C₁=0；y′(0)=2C₂+2=0 ⇒ C₂=−1。 y = −sin2x + 2x*。

F75.★★★ 已知某二阶常系数齐次方程有解 eˣ·cosx，写出该方程。

复根 1±i ⇒ 特征方程 (r−1)²+4·? = r²−2r+2 ⇒ y″ − 2y′ + 2y = 0。

§4 欧拉方程与变系数（F76–F85）

F76.★ 默写欧拉方程的形式与解法。

x²y″ + axy′ + by = f(x)。令 x=e^t 化为常系数（记 D=d/dt：x²y″→D(D−1)y，xy′→Dy）。

F77.★★ 解 x²y″ − 2y = 0。

试 y=x^r：r(r−1)−2 = r²−r−2 = (r−2)(r+1) ⇒ r=2,−1。 y = C₁x² + C₂/x。

F78.★★ 解 x²y″ + 2xy′ − 2y = 0。

r(r−1)+2r−2 = r²+r−2 = (r−1)(r+2) ⇒ y = C₁x + C₂/x²。

F79.★ 欧拉方程为何总能化成常系数？

系数 xᵏy⁽ᵏ⁾ 在 x=e^t 变换下每项都变成常数系数的 Dy 组合——欧拉方程是"伪变系数"。

F80.★ 解 x²y″ + xy′ − y = 0。

r²−1=0 ⇒ y = C₁x + C₂/x。

F81.★★★ 解 x²y″ − xy′ + y = x（x>0）。

齐次：r²−2r+1=(r−1)² ⇒ y=C₁x+C₂x·lnx。 化常系数后右端 e^t，特征根 1（二重）⇒ 特解 t²e^t/2。 y = C₁x + C₂x·lnx + (x/2)·(lnx)²。

F82.★★★ 已知 y₁=x 是 y″ − (2/x)y′ + (2/x²)y = 0 的解，用降阶法求通解。

刘维尔公式：y₂ = y₁·∫e^{−∫P}/y₁² dx = x·∫x²/x² dx = x²。 y = C₁x + C₂x²。

F83.★ n 阶线性齐次方程通解的结构？

n 个线性无关的解 y₁,…,yₙ 的线性组合即通解（解空间维数=n）。

F84.★ 可降阶三种类型分别缺什么？

①y⁽ⁿ⁾=f(x)：直接积分；②缺 y：令 p=y′；③缺 x：令 p=y′，y″=p·dp/dy。

F85.★ 欧拉方程解的形式猜想：

齐次欧拉方程必有 y=x^r 型解（幂函数是它的"e^{λx}"）。

§5 应用题（F86–F100）

F86.★★ 物体温度 T 满足 dT/dt = −k(T−20)（环境 20℃），T(0)=100。求 T(t)。

令 u=T−20：u′=−ku ⇒ T = 20 + 80e^{−kt}（牛顿冷却定律标准形）。

F87.★★ 放射性衰变 dN/dt = −λN。求半衰期。

N = N₀e^{−λt}；N₀/2 ⇒ t = ln2/λ。

F88.★ 人口按 dP/dt = kP 增长，求倍增时间。

P = P₀e^{kt}；2P₀ ⇒ t = ln2/k。

F89.★ 曲线任一点切线斜率等于该点与原点连线斜率，求曲线族。

y′ = y/x ⇒ y = Cx（过原点直线族）。

F90.★ 曲线过 (1,1) 且满足 y′ = x/y（y>0）。

y² = x² + C；代入 (1,1)：C=0 ⇒ y = x（第一象限取正支）。

F91.★★ RC 电路：R·q′ + q/C = E，q(0)=0。求电荷量。

q′ + q/(RC) = E/(RC)：特解 q=CE，通解 q = CE(1−e^{−t/(RC)})。 q = CE(1−e^{−t/RC})*（充电曲线）。

F92.★★ 跳伞员 m·v′ = mg − kv（v(0)=0）。求极限速度。

v = (mg/k)(1−e^{−kt/m}) ⇒ v→mg/k（收尾速度，e 项消失）。

F93.★★ 水箱 V 升盐水含盐 S₀，清水以 r 升/分流入、同速流出（均匀混合）。求含盐量。

dS/dt = −r·(S/V) ⇒ S = S₀e^{−rt/V}（指数稀释）。

F94.★★★ Logistic 模型 dP/dt = kP(1−P/M)。写出通解形状。

分离变量部分分式：P = M/(1+Ce^{−kt})（S 形曲线，P→M 环境容纳量）。

F95.★ 满足 y″ = a·√(1+(y′)²) 的曲线叫什么？

悬链线（链条自重下垂的形状；双曲余弦的变体）。

F96.★ 解 f′ = f + 1，f(0)=0。

特解 f=−1：f = Ceˣ − 1；f(0)=0 ⇒ C=1 ⇒ f = eˣ − 1*。

F97.★★ 由通解 y = (C₁+C₂x)e^{2x} 反求方程。

特征根 2 二重 ⇒ (r−2)² = r²−4r+4 ⇒ y″ − 4y′ + 4y = 0。

F98.★★★ 解积分方程：∫₀ˣ f(t)dt = x² + f(x)。

求导：f(x) = 2x + f′(x) ⇒ f′ − f = −2x。 通解 f = 2(x+1) + Ceˣ；原式令 x=0：0 = f(0) ⇒ C=−2。 f = 2x + 2 − 2eˣ。

F99.★ 弹簧无阻尼振动 y″ + ω²y = 0 的解与周期？

y = A·cos(ωt+φ)，周期 T = 2π/ω（简谐振动）。

F100.★★★ 曲线过原点，且任一点处切线斜率等于"横坐标与纵坐标之和"。求曲线。

y′ = x + y，y(0)=0。通解 y = Ce^{−x} + x − 1；y(0)=0 ⇒ C=1。 y = e^{−x} + x − 1（验证：y′ = 1−e^{−x} = x + y ✓）。
