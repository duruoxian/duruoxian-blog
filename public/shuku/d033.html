概率论与数理统计 · 大题套路精讲

数一概率大题（1-2道，约11-22分）考的就是五个套路。每个套路给"标准解题流程→例题详解→练习（带答案）"。配合《概率统计_知识点与难点》。 📑 五个套路：01 一维随机变量及其函数｜02 二维随机变量｜03 数字特征｜04 大数定律与中心极限定理｜05 数理统计（估计与检验）

套路一 一维随机变量及其函数

标准流程

  1. 求常数：连续型用 ∫f=1；离散型用 Σp=1；
  2. 求分布函数 F(x)：分段写（x<左端为0，中间积分，右端为1）；
  3. 求概率：P(a<X≤b)=F(b)-F(a)；连续型单点概率为0；
  4. 函数分布（Y=g(X)）两法：分布函数法（先写 F_Y(y)=P{g(X)≤y} 再求导）／公式法（g 单调时 f_Y(y)=f_X(h(y))|h'(y)|）。

例题

例 设 X 的密度 f(x)=3x²（0≤x<1），否则为0。求 (1) F(x)；(2) P(X>1/2)；(3) Y=X² 的密度。 (1) F(x)=0（x<0）；x³（0≤x<1）；1（x≥1）。 (2) 1-F(1/2)=1-1/8=7/8。 (3) F_Y(y)=P(X²≤y)=P(X≤√y)=y^{3/2}（0≤y<1）→ f_Y(y)=（3/2)√y（0<y<1）。

练习（带答案）

  1. f(x)=ke^{-x}（x>0）：求 k、P(X≤1)、E(X)。→ k=1；1-e^{-1}；1。
  2. X~U(0,5)，求方程 4t²+4Xt+X+2=0 有实根的概率。→ 判别式 16X²-16(X+2)≥0 → X²-X-2≥0 → X≥2（X≤-1舍）→ P=3/5。
  3. X~N(2,4)? X~N(1,4)，求 P(X≤3) 与 P(|X-1|<1)。→ σ=2：P(X≤3)=P(Z≤1)=0.8413；P(|Z|<0.5)=2Φ(0.5)-1=0.3830。
  4. 证明指数分布无记忆性：P(X>s+t|X>s)=P(X>t)。→ 条件概率展开 = e^{-λt}。∎

套路二 二维随机变量

标准流程

  1. 求常数 ∫∫f=1；边缘密度 f_X=∫f dy；
  2. 独立判定：f(x,y)=f_X·f_Y 处处成立（或 P(AB)=P(A)P(B)）；
  3. 条件密度 f_{X|Y}=f/f_Y（注意 y 使 f_Y>0 的范围）；
  4. Z=X+Y（连续）：f_Z(z)=∫f(x,z-x)dx（卷积，画图定积分限——最容易丢分的一步）；
  5. M=max(X,Y)、N=min(X,Y)（独立时）：F_M=F²，F_N=1-(1-F)²；一般情形直接按定义算。

例题

例 f(x,y)=k(x+y)（0≤x,y≤1），否则0。求 (1) k；(2) 边缘密度与独立性；(3) P(X<1/2, Y<1/2)。 (1) ∫∫(x+y)=1 → k=1。 (2) f_X=x+1/2，f_Y=y+1/2；乘积≠f → 不独立。 (3) ∫₀^{1/2}∫₀^{1/2}(x+y)dxdy = 1/8。

例 X,Y 独立同服从 U(0,1)，求 Z=X+Y 的密度。 f_Z(z)=∫f(x,z-x)dx：0<z<1 时 ∫₀^z dx=z；1≤z<2 时 ∫_{z-1}^1 dx=2-z。 f_Z(z)=z（0<z<1），2-z（1≤z<2），否则0（三角形分布）。

练习（带答案）

  1. 离散：P(X=i,Y=j)=k·ij? 设 P(X=i,Y=j)=k(2i+j)，i,j=0,1? 太繁，改：X,Y 独立，P(X=0)=P(X=1)=1/2，Y 同分布，求 Z=X+Y 的分布。→ Z~B(2,1/2)：P(Z=0)=1/4，P(Z=1)=1/2，P(Z=2)=1/4。
  2. (X,Y) 在由 x轴、y轴、x+y=1 围成的三角形上均匀分布，求 f_X(x)。→ f_X(x)=2x? 密度=2（三角形面积1/2）；f_X(x)=∫₀^{1-x}2dy=2(1-x)（0<x<1）。
  3. X,Y 独立同 N(0,1)，求 P(max(X,Y)>1)。→ 1-P(both≤1)=1-Φ(1)²=1-0.8413²≈0.2923。
  4. 上题求 Z=X+Y 的分布。→ Z~N(0,2)。

套路三 数字特征

标准流程

  1. E 直接算（离散 Σ；连续 ∫）；先化简再算（E(aX+b)=aE(X)+b，E(X±Y)=EX±EY 恒成立）；
  2. D(X)=E(X²)-E²(X)；D(aX+b)=a²DX；D(X±Y)=DX+DY±2Cov（独立时=Cov为0）；
  3. Cov(X,Y)=E(XY)-EXEY；双线性；ρ=Cov/√(DX·DY)；
  4. 常见分布背表（见《选择填空技巧与易错点》04节）；
  5. 题型：给定 f 求 E、D；二项/泊松应用题；最大最小值的期望。

例题

例 X~U(-1,2)，Y=X²，求 E(Y) 与 Cov(X,Y)。 E(Y)=∫{-1}^2 x²·(1/3)dx = [x³/9]{-1}^2 = 9/9 = 1。 E(XY)=E(X³)=∫x³/3 dx = [x⁴/12]_{-1}^2 = 15/12 = 5/4；EX=(−1+2)/2=1/2。 Cov = 5/4 - 1/2·1 = 3/4。

练习（带答案）

  1. X~P(2)，求 E[(X-1)(X-2)]。→ E(X²-3X+2)=(6-6+2)-? E(X²)=λ+λ²=6 → 6-6+2=2。
  2. X 与 Y 独立同 N(1,4)? X~N(1,1)，Y~N(2,4) 独立，求 D(2X-3Y+1)。→ 4·1+9·4=40。
  3. 袋中10球4红，不放回取3个，X为红球数，求E(X)。→ 超几何：E=np=3·4/10=1.2（不放回与放回期望相同）。
  4. X~U(0,1)? 设 X 的密度 f(x)=2x（0<x<1），求 E(X) 与 D(X)。→ E=∫2x²=2/3；E(X²)=∫2x⁴=1/2 → D=1/2-4/9=1/18。

套路四 大数定律与中心极限定理

标准流程

  1. 设 X₁,…,Xₙ 独立同分布（EX=μ，DX=σ²），S=ΣXᵢ： S ≈ N(nμ, nσ²)（列维-林德伯格）； 标准化：P(a<S<b) = Φ((b-nμ)/√(n)σ) - Φ((a-nμ)/√n σ)；
  2. 二项 B(n,p) 用棣莫弗-拉普拉斯（μ=np，σ²=np(1-p)）；
  3. 答题句式："由列维-林德伯格中心极限定理，(S-nμ)/(√nσ) 近似服从 N(0,1)"。

例题

例 掷骰子100次，记点数之和为S，求 P(320<S<380)。 μ=3.5×100=350，σ²=(35/12)×100≈291.67，σ≈17.08。 P = Φ(30/17.08)-Φ(-30/17.08) = 2Φ(1.76)-1 ≈ 2×0.9608-1 = 0.9216。

练习（带答案）

  1. 某厂产品合格率0.9? 独立生产100件，合格数X~B(100,0.9)，求 P(85≤X≤95)。→ μ=90，σ=3 → P(|X-90|≤5)=2Φ(5/3)-1=2Φ(1.67)-1≈0.905。
  2. 用中心极限定理估计：需多少个部件（每个寿命均值1000h，标准差100h）串联? 改：需要至少 n 个部件才使总寿命超过 100 个? 简单版：每袋糖重 X~N(100,4)（g），100袋总重超过10050g的概率? μ=10000，σ=√(100·4)=20 → P(S>10050)=1-Φ(2.5)=0.0062。
  3. 说明为什么可用正态近似：条件是独立同分布且方差有限（n 大时）。陈述即可。

套路五 数理统计

标准流程

  1. 抽样分布三件套（正态总体）： X̄~N(μ,σ²/n)；(n-1)S²/σ²~χ²(n-1)；X̄⊥S²；√n(X̄-μ)/S~t(n-1)；
  2. 矩估计：令 E(X)=X̄（一阶）；
  3. 最大似然：L(θ)=∏f(xᵢ;θ) → lnL → 求导=0；均匀分布 U(0,θ) 的 MLE= max xᵢ（导数法失效，用"L 随 θ 增大而减小、θ≥max xᵢ"论证）；
  4. 区间估计：σ²已知 μ∈X̄±z_{α/2}·σ/√n；σ²未知用 t 分位数；σ²的区间用 χ²；
  5. 假设检验【数一】：写 H₀/H₁ → 选统计量 → 定拒绝域 → 计算 → 结论（两类错误概念）。

例题

例 X₁,…,Xₙ 来自 U(0,θ)。求 θ 的矩估计与最大似然估计。 矩估计：EX=θ/2=X̄ → θ̂₁=2X̄。 MLE：L(θ)=θ^{-n}（θ≥max xᵢ 时；否则为0），L 关于 θ 递减 → 取最小允许值 θ̂₂=max(x₁,…,xₙ)。

例 总体 X~N(μ,σ²)，n=9，X̄=10，S=3。求 μ 的95%置信区间（t₀.₀₂₅(8)=2.306）。 10 ± 2.306×3/3 = 10±2.306 → (7.69, 12.31)。

练习（带答案）

  1. X₁,…,Xₙ 来自 N(μ,σ²)，证明 E(S²)=σ²。→ (n-1)S²/σ²~χ²(n-1)，E(χ²(n-1))=n-1 → E(S²)=σ²。∎
  2. X~E(λ)（指数），求 λ 的矩估计与MLE。→ 均为 1/X̄。
  3. n=25，X̄=150，σ=5（已知），求 μ 的95%区间（z_{0.025}=1.96）。→ 150±1.96×1=(148.04, 151.96)。
  4. 检验 H₀:μ=100（σ²=25 已知，n=16，X̄=102.5，z_{0.025}=1.96），是否拒绝？→ z=(102.5-100)/(5/4)=2>1.96 → 拒绝 H₀。

大题答题规范

  1. 定义新记号要声明（"记 X̄=…"）；
  2. 求密度/分布函数分段写全（含端点外的0），漏段直接扣分；
  3. 卷积积分画图定限，答案后写"（x<0及x>2时 f_Z=0）"补全；
  4. 统计题结论句完整："由于…落在拒绝域内，故在显著性水平0.05下拒绝H₀"。
