第1章 行列式

一、定义精讲

D1 排列与逆序数：n元排列 p₁p₂…pₙ 中逆序的总数记 τ(p₁…pₙ)。逆序数为奇数称奇排列。 【要点】对换改变排列的奇偶性（一次对换必改变奇偶性——交换律的代数根源）；n≥2 时奇偶排列各占 n!/2 个。

D2 n阶行列式的定义（逆序数版）： |A| = Σ_{p₁…pₙ} (−1)^{τ(p₁p₂…pₙ)} a_{1p₁}a_{2p₂}…a_{npₙ} 即：所有"不同行不同列"的 n 个元素乘积的代数和，符号由列标排列的逆序数决定。 【要点】① n=2,3 的对角线法则只是特例（n≥4 没有对角线法则）；② 由此定义立得：某行全为0 → 行列式为0；两行相同 → 为0（成对抵消）。

D3 余子式与代数余子式：Mᵢⱼ（划去第i行第j列的 n−1 阶行列式）；Aᵢⱼ=(−1)^{i+j}Mᵢⱼ。 【要点】代数余子式与 aᵢⱼ 本身的取值无关（后面"异乘变零"的根源）；Aᵢⱼ 带符号。

二、定理精讲

T1 六大性质：①|Aᵀ|=|A|；②互换两行变号；③某行公因子可提出；④两行相同/成比例→0；⑤某行=两组数之和→可拆成两个行列式之和（其余行不变）；⑥某行加上另一行的k倍，不变。 【要点】性质⑤"单行可拆"是拆分法的依据（求导/求极限型行列式的工具）；性质①说明行列式对行、列地位对等。

T2 按行（列）展开定理（拉普拉斯展开）：Σ_{j=1}^n aᵢⱼAᵢⱼ=|A|；Σ_{j=1}^n a_{kj}Aᵢⱼ=0（i≠k）。 【要点】"自身乘代数余子式求和=行列式；异行乘代数余子式求和=0"（异乘变零）。证明思路：把第 i 行换成第 k 行，得到两行相同的行列式=0，再按第 i 行展开。 【应用】求伴随矩阵、证明 |A*| 公式、抽象行列式计算的核心武器。

T3 范德蒙德行列式： |1 x₁ … x₁^{n−1}; 1 x₂ …; …; 1 xₙ … xₙ^{n−1}| = Π_{1≤i<j≤n}(xⱼ−xᵢ)。 【证明思路（归纳法，要会）】第 n 行减去第 n−1 行的 x₁ 倍（自下而上），按第一列展开，提出公因子，得到 n−1 阶范德蒙德。

T4 克莱姆法则：n个方程n个未知量、系数行列式 D≠0 → 解唯一：xⱼ=Dⱼ/D。 【推论】n×n 齐次方程组有非零解 ⇔ D=0。 【要点】克莱姆只适用于"方阵+满秩"；一般方程组用第4章的秩理论。

三、985强度考题（4题）

题1（对角占优结构·箭头法） 计算 n 阶行列式：对角线全为 a，其余元素全为 b。 【解】各列加到第一列：第一列全为 a+(n−1)b，提出；第 i 行(i≥2)减去第一行：上三角，对角线 a−b。 D=a+(n−1)b^{n−1}。∎ （取 a=2,b=1,n=4：D=5。）

题2（异乘变零·抽象计算） 设 A 为 n 阶矩阵，A 为伴随矩阵。证明 Σ_{j=1}^n aᵢⱼA_{kj} 组成的矩阵（第i行换成A的第k行的代数余子式）的行列式为0；并由此证明 (A) = |A|^{n−2}A。 【证】前者即"把 |A| 的第 i 行元素替换为第 k 行元素"的行列式=0（两行相同）。 (A)：由 AA=|A|E 得（A 可逆时）(A)⁻¹=A/|A|；又 |A|=|A|^{n−1}。 (A)=|A|(A)⁻¹=|A|^{n−1}·A/|A|=|A|^{n−2}A。A 不可逆时用连续性论证或直接验证。∎

题3（范德蒙德应用） 已知 a,b,c 互不相等，证明方程组 x₁+x₂+x₃=1；ax₁+bx₂+cx₃=1? 系数行列式=（b−a)(c−a)(c−b)≠0 → 对任意右端有唯一解。 【证】系数行列式是范德蒙德行列式（转置），= (b−a)(c−a)(c−b)≠0。由克莱姆法则，解存在唯一。∎ （插值多项式的存在唯一性即源于此——985跨科联问点。）

题4（特征值法求行列式） 设 A 为3阶矩阵，A²−3A+2E=O? 证明 |A−2E|=0? 改：设 A 满足 A²=A（幂等）且 A≠E，证明 |A|=0。 【证】由 A²=A 得 A(A−E)=O。若 |A|≠0，则 A 可逆，两边左乘 A⁻¹ 得 A−E=O，即 A=E，矛盾。故 |A|=0。∎ （反证+可逆性——抽象行列式的标准武器。）

四、本章必会证明清单

① 对换改变排列奇偶性；② 异乘变零（构造两行相同）；③ 范德蒙德归纳证明；④ 行列式性质⑤（单行可拆）的验证。

第2章 矩阵

一、定义精讲

D1 矩阵运算：加法（同型）；数乘；乘法 A_{m×n}B_{n×s}（内标相等，结果 m×s）。 【要点】① 乘法不交换（AB≠BA 一般成立——线代一切非交换现象之源）；② AB=O ⇏ A=O 或 B=O（存在零因子，如 [[1,0],[0,0]]·[[0,0],[0,1]]=O）；③ 消去律失效：AB=AC 且 A 可逆才有 B=C；④ |AB|=|A||B|（方阵）；但 A+B 的行列式没有公式。

D2 可逆矩阵：若存在 B 使 AB=BA=E，称 A 可逆。逆矩阵唯一。 【要点】① 定义中 AB=E 与 BA=E 只需验证一个（n阶方阵时另一个自动成立——用行列式或秩可证）；② A 可逆 ⇔ |A|≠0 ⇔ r(A)=n。

D3 伴随矩阵 A：A 的 (i,j) 元 = A_{ji}（转置放置的代数余子式）。核心恒等式 AA=AA=|A|E。 【性质链】|A|=|A|^{n−1}；(A)⁻¹=A/|A|（A可逆）；(A)=|A|^{n−2}A；r(A*)=n（r(A)=n）、1（r(A)=n−1）、0（r(A)≤n−2）。

D4 初等矩阵：单位阵经一次初等（行/列）变换得到的矩阵。左乘=行变换，右乘=列变换。 【要点】① 初等矩阵皆可逆，逆仍是同类初等矩阵；② A可逆 ⇔ A=若干初等矩阵之积；③ (A|E)→(E|A⁻¹) 行变换求逆的原理。

D5 分块矩阵：以子块为元素的矩阵。常用分块求逆：[[A,O],[O,B]]⁻¹=[[A⁻¹,O],[O,B⁻¹]]；[[A,O],[C,B]]⁻¹=[[A⁻¹,O],[−B⁻¹CA⁻¹,B⁻¹]]（用乘法验证）。

二、定理精讲

T1 逆的运算律：(AB)⁻¹=B⁻¹A⁻¹；(Aᵀ)⁻¹=(A⁻¹)ᵀ；(kA)⁻¹=(1/k)A⁻¹；|A⁻¹|=|A|⁻¹。(AB)=BA；(Aᵀ)=(A)ᵀ。 T2 转置性质：(AB)ᵀ=BᵀAᵀ；(A+B)ᵀ=Aᵀ+Bᵀ；r(Aᵀ)=r(A)。 T3 乘积的秩：r(AB)≤min(r(A),r(B))；r(AB)≥r(A)+r(B)−n（Sylvester不等式）。 【Sylvester证明思路（必会）】齐次方程 ABx=0 的解空间包含 Bx=0 的解空间（维数 n−r(B)），且在 B 的像空间上受限：解空间维数 n−r(AB) ≤ (n−r(B))+(n−r(A))。整理即得。∎ T4 矩阵方程与秩：r([A|B])=r(A) ⇔ AX=B 有解；AB=O ⇒ r(A)+r(B)≤n（B 的列都是 Ax=0 的解）。 T5 分块对角行列式/秩*：r([[A,O],[O,B]])=r(A)+r(B)；|diag(A,B)|=|A||B|。

三、985强度考题（5题）

题1（伴随+逆+行列式综合） 设 A 为 n 阶可逆矩阵（n≥2），交换 A 的第1、2行得 B。证明 AB 与 BA 满足：AB=−BA? 验证 AB 与 BA 的伴随关系：求 |B|。 【解】B=P₁₂A（P₁₂ 为交换1、2行的初等矩阵），|B|=−|A|。 |B|=|B|^{n−1}=(−1)^{n−1}|A|^{n−1}=(−1)^{n−1}|A|。 即 B 与 A 的行列式相差 (−1)^{n−1} 倍（n偶时相等、n奇时相反）。∎ （配套：B = (P₁₂A) = A(P₁₂) = AP₁₂（因 (P₁₂)=(P₁₂)⁻¹=P₁₂）→ B=A*P₁₂，伴随被"右乘"初等矩阵。）

题2（分块求逆·乘法验证） 设 A、B 可逆，求 M=[[A,O],[C,B]] 的逆，并用分块乘法验证。 【解】设 M⁻¹=[[X,Y],[Z,W]]。MM⁻¹=[[AX,AY],[CX+BZ,CY+BW]]=E： AX=E→X=A⁻¹；AY=O→Y=O；CY+BW=BW=E→W=B⁻¹；CX+BZ=O→Z=−B⁻¹CA⁻¹。 M⁻¹=[[A⁻¹,O],[−B⁻¹CA⁻¹,B⁻¹]]。∎（验证：乘回去成立。）

题3（Sylvester秩不等式·完整证明） 证明 r(AB)≥r(A)+r(B)−n。 【证】记 N(M) 为 MX=0 的解空间。N(B)⊆N(AB)，故 dim N(AB)−dim N(B)=dim N(AB)/N(B)≤dim N(A)=n−r(A)（N(AB)/N(B) 中的向量 x 满足 Bx≠0 但 ABx=0，即 Bx∈N(A)，映射 x↦Bx 的像空间维数≤dim N(A)）。 代入维数：[n−r(AB)]−[n−r(B)]≤n−r(A) → r(AB)≥r(A)+r(B)−n。∎

题4（矩阵方程解的存在性） 证明正规方程 AᵀAx=Aᵀb 恒有解。 【证】增广矩阵秩：r([AᵀA | Aᵀb])=r(Aᵀ[A | b])≤r(Aᵀ)=r(A)。 另一方面 r(AᵀA)=r(A)≤r([AᵀA|Aᵀb])。 两个不等式夹住 → 增广秩=系数秩 → 有解。∎ （意义：最小二乘拟合的数学基础——"方程组无解，但离它最近的解永远存在"。）

题5（矩阵高次幂·对角化预处理） 设 A=[[1,2],[0,? ]]? 设 A=[[3,1],[0,3]]? 求 Aⁿ。 【解】A=3E+N，N=[[0,1],[0,0]]，N²=O → Aⁿ=3ⁿE+n·3^{n−1}N=[[3ⁿ, n·3^{n−1}],[0, 3ⁿ]]。∎ （一般范式：A=kE+B 且 B 的低次幂为零→二项式展开；否则相似对角化。）

四、本章必会证明清单

① AA=|A|E（按行展开+异乘变零）；② (A)=|A|^{n−2}A；③ r(A) 三分结论；④ Sylvester不等式；⑤ AB=O⇒r(A)+r(B)≤n；⑥ 可逆⇔初等矩阵之积。

第3章 向量组

一、定义精讲

D1 线性组合与表示：β=k₁α₁+…+kₛαₛ 称 β 可由 α₁,…,αₛ 线性表示。 【要点】β 可由 α 组表示 ⇔ 方程组 (α₁,…,αₛ)X=β 有解 ⇔ r(α组)=r(α组,β)。

D2 线性相关/无关：k₁α₁+…+kₛαₛ=0 有非零解 ⇔ 相关；只有零解 ⇔ 无关。 【要点】① 含零向量的向量组必相关；② 单个向量 α：相关 ⇔ α=0；③ 部分相关⇒整体相关（逆否：整体无关⇒部分无关）；④ 以向量组为列拼矩阵，相关 ⇔ r<向量个数。

D3 极大无关组：向量组的最大线性无关部分组（①本身无关 ②再加任一原向量即相关）。所含向量个数=秩。 【要点】极大无关组不唯一（但所含个数唯一）；任意两个极大无关组等价（可互相线性表示）。

D4 向量组等价：两组能互相线性表示。等价⇒秩相等；秩相等⇏等价（还要看能否互相表示——例：(1,0) 与 (0,1) 秩都是1但不等价）。

二、定理精讲

T1 线性相关判定定理：s 个 n 维向量相关 ⇔ 以其为列的矩阵秩 < s。 【推论】① n+1 个 n 维向量必相关（解空间维数观点：n个方程约束不了 n+1 个未知数）；② 向量个数>维数必相关。 T2 表示与相关性：α₁,…,αₛ 无关，而 α₁,…,αₛ,β 相关 ⇒ β 可由 α 组唯一线性表示。 【证明思路】相关给出 k₀β+Σkᵢαᵢ=0，k₀≠0（否则α组相关，矛盾）→β=−(1/k₀)Σkᵢαᵢ；唯一性：两种表示相减得 α 组的零组合，由无关性系数全零。∎ T3 表示传递保秩：若 α 组可由 β 组线性表示，则 r(α组)≤r(β组)。 【证明思路】取 α 组的极大无关组（r个），它们可由 β 组表示 → 联合后 β 组的极大无关组也能表示它们 → r(β组)≥r。∎（"表示→秩不大"：被表示者的秩不超过表示者。） T4 三秩相等：r(A)=A 的行秩=A 的列秩。 【证明思路】初等行变换不改变列向量组的线性关系（AX=O 与 BX=O 同解）→行变换后的列秩=原列秩；而行变换后的行秩显然=行阶梯非零行数=r(A)。∎

三、985强度考题（4题）

题1（无关性的系数行列式判定） 设 α₁,α₂,α₃ 线性无关，讨论 β₁=α₁+α₂，β₂=α₂+α₃，β₃=α₃+α₁ 的相关性；若改为 β₃=α₂+α₃? 再讨论 β₁=α₁+2α₂，β₂=2α₂+3α₃，β₃=3α₃+α₁。 【解】设 Σkᵢβᵢ=0，整理成 α 组的组合，由 α 组无关得系数方程组，其系数行列式： 情形一：C=[[1,0,1],[1,1,0],[0,1,1]]，|C|=1(1)−0+1(1)=2≠0 → 只有零解 → β 组无关。 情形二：C=[[1,0,1],[2,1,0],[0,1,1]]? 对应 β₁=α₁+2α₂, β₂=2α₂+3α₃? 系数矩阵 [[1,0,3],[2,1,0],[0,3,1]]? 行列式=1(1)−0+3(6)=19? 计算：|1 0 3; 2 1 0; 0 3 1| = 1(1−0)−0(2−0)+3(6−0)=1+18=19≠0 → 无关。 【另解框架】过渡矩阵 C 可逆 ⇔ 两向量组等秩。∎ （规范方法：把"β 组是否相关"转化为"过渡矩阵行列式是否为零"。）

题2（极大无关组+表示·具体计算） 已知 α₁=(1,1,1)ᵀ，α₂=(1,2,3)ᵀ，α₃=(1,3,t)ᵀ。①t 为何值时 α₁,α₂,α₃ 线性相关？②相关时求极大无关组并把其余向量表出。 【解】系数行列式 |1 1 1; 1 2 3; 1 3 t| = (t−3)（按三阶计算：1(2t−9)−1(t−3)+1(3−2)=2t−9−t+3+1=t−3）。 t=3 时相关。此时行变换：[[1,1,1],[1,2,3],[1,3,3]]→[[1,1,1],[0,1,2],[0,2,2]]→[[1,1,1],[0,1,2],[0,0,0]]。 秩2，极大无关组 {α₁,α₂}；解 x₁α₁+x₂α₂=α₃：x₂=2，x₁=−1 → α₃=−α₁+2α₂。∎

题3（Schmidt正交化·具体计算） 将 α₁=(1,1,1)ᵀ，α₂=(1,2,3)ᵀ，α₃=(1,4,9)ᵀ 正交化。 【解】β₁=α₁=(1,1,1)ᵀ。 β₂=α₂−[(α₂,β₁)/3]β₁=(1,2,3)ᵀ−2(1,1,1)ᵀ=(−1,0,1)ᵀ。 β₃=α₃−[(α₃,β₁)/3]β₁−[(α₃,β₂)/2]β₂=(1,4,9)ᵀ−(14/3)(1,1,1)ᵀ−4(−1,0,1)ᵀ=(1/3,−2/3,1/3)ᵀ。 （可整体×3：(1,−2,1)ᵀ。）∎

题4（抽象·无关组的构造） 设 α₁,α₂ 线性无关，β₁,β₂ 线性无关，且 α₁,α₂ 都可由 β₁,β₂ 线性表示。证明存在 2×2 可逆矩阵 K 使 (α₁,α₂)=(β₁,β₂)K? 并证明存在非零向量 γ 同时可由两组表示。 【证】表示式 α₁=k₁₁β₁+k₂₁β₂? 写 (α₁,α₂)=(β₁,β₂)K，K 的列是表示系数。因 r(α组)=2=r(α₁,α₂)=r((β₁,β₂)K)≤r(K)≤2 → r(K)=2 → K 可逆。 取 γ=α₁+α₂? 不够——要证存在非零向量同时属于两个生成空间：考虑线性组合 x₁α₁+x₂α₂−(y₁β₁+y₂β₂)=0，即 (β₁,β₂)KX−(β₁,β₂)Y=0 → KX=Y。取任意 X≠0，令 Y=KX≠0（K可逆），则 γ=α组合≠0 且可由 β 组表示。∎ （本质：两个秩为2的子空间相交非零——维数公式 dim U+dim V−dim(U∩V)≤dim 全空间。）

四、本章必会证明清单

① 部分相关⇒整体相关；② 无关组+β相关⇒β唯一表示；③ 表示⇒秩不增；④ 三秩相等；⑤ 过渡矩阵可逆⇔两组等价且秩相同。

第4章 线性方程组

一、定义精讲

D1 基础解系：齐次方程组 AX=O 解空间的一个极大无关组。 【要点】① 存在条件：r(A)=r<n 时基础解系含 n−r 个向量；② 基础解系不唯一（但个数唯一、生成的解空间唯一）；③ 通解=基础解系的全部线性组合。

D2 非齐次通解结构：X=η+k₁ξ₁+…+k_{n−r}ξₙ₋ᵣ（η 为任一特解）。 【要点】两个特解之差是齐次解；c₁η₁+c₂η₂ 为 AX=b 的解 ⇔ c₁+c₂=1；为 AX=O 的解 ⇔ c₁+c₂=0。

二、定理精讲

T1 齐次有非零解判定：AX=O 有非零解 ⇔ r(A)<n（未知数个数）。方阵情形 ⇔ |A|=0。 【证明思路】自由变量个数=n−r；r=n 时唯一零解。 T2 非齐次有解判定：AX=b 有解 ⇔ r(A)=r([A|b])；唯一解 ⇔ =n；无穷解 ⇔ =r<n。 【要点】无解的代数表现：行变换后出现 0=d（d≠0）。含参数题的全部逻辑都来自这三分支。 T3 解空间维数定理：r(A)=r 时，AX=O 的解空间维数=n−r。 【证明思路】自由变量取标准值 (0,…,1,…,0) 得 n−r 个无关解（下三角结构保证无关），且任何解可由它们表出（用自由变量表达主变量）。∎ T4 解的结构定理：非齐次通解=特解+对应齐次通解。 【证明思路】η+ξ 满足方程；反之任何解 η=(η−η)+η，而 η−η 是齐次解。∎ T5 同解与公共解：两方程组同解 ⇔ 互相可导出（增广秩与解完全一致）；公共解=联立求解，或由一方通解代入另一方定参数。

三、985强度考题（4题）

题1（双参数三分支讨论·规范流程） 讨论方程组 {x₁+x₂+x₃=1；2x₁+x₂+4x₃=2；3x₁+2x₂+λx₃=3} 解的情况。 【解】增广矩阵行变换：R2−2R1：−x₂+2x₃=0；R3−3R1：−x₂+(λ−3)x₃=0；再消：[(λ−3)−(−1)·2]? 两式相减：(λ−5)x₃=0。 ① λ≠5：r(A)=r(Ā)=3 → 唯一解：x₃=0，x₂=0，x₁=1，即 X=(1,0,0)ᵀ。 ② λ=5：r=2<n=3 → 无穷解：x₂=2t，x₃=t，x₁=1−3t → X=(1,−2,0)ᵀ+t(−3,2,1)ᵀ。 （无解情形在本题结构中不出现——但若右端第二分量不是2，则会出现 0=非零。）∎

题2（解的结构·抽象证明） 设 η₁,η₂ 是 AX=b 的两个不同解（A 可逆性不论），ξ 是 AX=O 的解。证明：①η₁+ξ 是 AX=b 的解；②c₁η₁+c₂η₂ 是 AX=b 的解 ⇔ c₁+c₂=1。 【证】①A(η₁+ξ)=b+O=b。∎ ②A(c₁η₁+c₂η₂)=(c₁+c₂)b。等于 b ⇔ (c₁+c₂−1)b=O；b≠0 时 ⇔ c₁+c₂=1。∎

题3（公共解·通解代入法） 求 Ⅰ：{x₁+x₂=0，x₂−x₄=0} 与 Ⅱ：{x₁+x₃=0} 的公共解。 【解】Ⅰ 的通解：x₁=−x₂，x₄=x₂，x₃ 自由 → X=(−t, t, s, t)ᵀ。 代入 Ⅱ：−t+s=0 → s=t → 公共解 X=k(−1,1,1,1)ᵀ。∎ （方法：把Ⅰ的通解代入Ⅱ，解出参数约束。）

题4（正规方程·抽象存在性） 设 A 为 m×n 实矩阵，b 为 m 维实向量。证明方程组 AᵀAx=Aᵀb 必有解（最小二乘解存在性）。 【证】r(AᵀA | Aᵀb)=r(Aᵀ[A | b])≤min(r(Aᵀ), r(A|b))=r(A)（实矩阵 r(Aᵀ)=r(A)，且 r(A|b)≤m? 需 r(A|b) 可能超过 r(A)——修正：r(Aᵀ[A|b])≤r(Aᵀ)=r(A)；另一方面系数部分：r(AᵀA)=r(A)≤r(AᵀA|Aᵀb)。两式夹住 → 增广秩=r(AᵀA) → 有解。∎ （第二个不等号方向：增广秩≥系数秩恒成立。此题综合第2、3章秩的性质，是985级综合证明题。）

第5章 特征值与特征向量 · 相似对角化

一、定义精讲

D1 特征值与特征向量：Aξ=λξ（ξ≠0）。λ 称特征值，ξ 称属于 λ 的特征向量。 【要点】① 特征向量非零；② 一个特征值对应无穷多特征向量（解空间的非零元），但属于不同特征值的特征向量线性无关；③ 特征向量只对确定的 λ 而言——同一个向量不能同时是两个不同特征值的特征向量。 D2 特征多项式与特征方程：|A−λE|=0（λ 的 n 次多项式，必有 n 个复根——代数基本定理）。数一在实数范围内讨论；实矩阵的特征值可以是复数（如旋转矩阵），此时在实数范围内不可对角化。 D3 相似：存在可逆 P 使 P⁻¹AP=B，称 A 与 B 相似（A∼B）。 【要点】相似=同一线性变换在不同基下的矩阵——这是相似的本质（985面试的概念题）。 D4 可对角化：A 与对角阵相似。

二、定理精讲

T1 特征值三公式：Σλᵢ=tr(A)；Πλᵢ=|A|；f(A) 的特征值=f(λᵢ)（f 为多项式）。 【推论】A⁻¹→1/λ；A→|A|/λ；Aᵀ 与 A 特征值相同（特征多项式相同）。 T2 不同特征值的特征向量线性无关。 【证明思路（必会）】归纳法：设 k 个不同特征值 λ₁,…,λₖ 的特征向量相关，取最小相关组；用 A 乘减去 λₖ 乘，得 k−1 个向量的相关组合（系数 (λᵢ−λₖ)cᵢ≠0），矛盾。∎ 【推论】k 重特征值至多有 k 个线性无关的特征向量（几何重数≤代数重数）。 T3 可对角化充要条件：n 阶矩阵 A 可对角化 ⇔ A 有 n 个线性无关的特征向量 ⇔ 每个特征值的几何重数=代数重数。 【充分性证明思路】把 n 个无关特征向量拼成 P，则 AP=PD（按列分块乘法）→ P⁻¹AP=D。 【推论】① n 个互异特征值 ⇒ 可对角化；② A 有 n−1 重特征值 λ 且对应 r=n−1 个无关向量+单根 → 可对角化。 T4 相似的必要条件：A∼B ⇒ 特征多项式相同（特征值、迹、行列式相同）、秩相同（对可对角化的秩才可比——一般相似秩必相同：P⁻¹AP=B，秩不变）。 【警示】以上都是必要条件，满足也不一定相似（反例：[[1,1],[0,1]] 与 E 特征值全同但不相似——E 只与自己相似）。判定相似的实路：找 P 或借助实对称理论。 T5 实对称矩阵必可正交对角化*：实对称 A 必存在正交阵 Q 使 Q⁻¹AQ=diag(λᵢ)。 【证明思路（985面试）】① 实对称的特征值全为实数（λ|ξ|²=(Aξ,ξ)=(ξ,Aξ)=λ̄|ξ|²）；② 实对称不同特征值的特征向量正交：λ₁(ξ₁,ξ₂)=(Aξ₁,ξ₂)=(ξ₁,Aξ₂)=λ₂(ξ₁,ξ₂) → (λ₁−λ₂)(ξ₁,ξ₂)=0；③ 重特征值的无关特征向量施密特正交化。三条拼出正交基。∎

第6章 二次型

一、定义精讲

D1 二次型与矩阵：f(x)=xᵀAx（A 对称，Aᵢⱼ=Aⱼᵢ=交叉项系数的一半）。 【要点】二次型与对称矩阵一一对应；f 的秩=r(A)。 D2 标准形与规范形：标准形=只含平方项（系数任意）；规范形=系数为 1、−1、0。 【要点】标准形不唯一（配方法与正交变换结果不同）；规范形唯一（惯性定理）。 D3 合同：B=CᵀAC（C 可逆），记 A≃B。 【要点】① 合同保持对称性与正负惯性指数；② 实对称矩阵：相似⇒合同（特征值全同→惯性指数同）；合同⇏相似（惯性指数同但特征值可以不同）；③ 两实对称矩阵合同 ⇔ 正负惯性指数相同 ⇔ 秩与正惯性指数相同。 D4 正定：∀x≠0，xᵀAx>0。 【要点】正定⇒A 对称（定义即要求）；正定二次型的规范形是 y₁²+…+yₙ²。

二、定理精讲

T1 惯性定理：实二次型的标准形中正（负）系数的个数是不变量（与所用可逆线性变换无关）。 【证明思路（要会）】设两个规范形正惯性指数 p≠p′（不妨 p>p′）：由 x=Cy（C 可逆）将 y₁²+…+y_p′² 型解出一组非零 y 使 x=Cy≠0 且 y_{p′+1}=…=0 → 代入另一标准形得负值，但由 x=Cᵀ? 推导矛盾（在该 x 下第一个标准形≥0? 严格写出需两组变换互逆——985面试要求能讲清大意：同一个 x 在两个规范形下的符号矛盾）。 T2 正定的充要条件（A 对称）： ① 顺序主子式全 >0；② 特征值全 >0；③ 正惯性指数=n；④ 存在可逆 C 使 A=CᵀC；⑤ ∀x≠0，xᵀAx>0（定义）。 【证明思路】①⇒④：对 A 做对称的初等变换（成对行列表变换）化为单位阵；④⇒⑤：xᵀAx=xᵀCᵀCx=(Cx)ᵀ(Cx)>0。主子式链条是计算主力。 T3 必要条件：正定 ⇒ aᵢᵢ>0（取 x=eᵢ）⇒ |A|>0（特征值全正）。 【警示】aᵢᵢ>0 与 |A|>0 都只是必要条件，不能单独作判据。 T4 具体判定流程：给具体二次型 → 首选顺序主子式；抽象矩阵 → 特征值/定义/已有正定矩阵的运算封闭性（正定阵之和正定、AᵀA 正定、A⁻¹ 正定、kA(k>0) 正定、正定阵的合同像正定）。

题5（正定综合证明·985强度） 设 A 为 n 阶正定矩阵，证明：①A⁻¹ 正定；②A+kE（k>0? 当 k≥0 时 A+kE 正定）；③|A+E|>1。 【证】①A⁻¹=(A⁻¹)ᵀ 对称；对任意 x≠0，xᵀA⁻¹x=(A⁻¹x)ᵀA(A⁻¹x)（令 y=A⁻¹x≠0，=yᵀAy>0）。∎ ②xᵀ(A+kE)x=xᵀAx+kxᵀx>0。∎ ③A 的特征值 λᵢ>0 → A+E 的特征值 λᵢ+1>1 → |A+E|=Π(λᵢ+1)>1。∎ （正定性的"运算封闭性"+特征值桥接——抽象证明题的两个主力套路。）
