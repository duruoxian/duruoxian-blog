§1 不定积分技巧（J1–J45）

J1.★ ∫x³dx。

幂法则 ∫xᵘdx = x^{u+1}/(u+1)：= x⁴/4 + C。C 永远不能丢，考试扣分重灾区。

J2.★ ∫(1/x)dx。

ln|x| + C。绝对值别丢——负区间内 ln(−x) 才有意义。

J3.★ ∫eˣdx 与 ∫aˣdx。

eˣ + C；aˣ/lna + C（a>0，a≠1）。

J4.★ ∫sinx dx 与 ∫cosx dx。

−cosx + C；sinx + C。sin 的导是 cos，反着积出来带负号。

J5.★ ∫sec²x dx、∫csc²x dx。

tanx + C；−cotx + C。它们分别就是 tanx、cotx 的导数。

J6.★ ∫dx/(1+x²) 与 ∫dx/√(1−x²)。

arctanx + C；arcsinx + C。两个基本反三角原型，出现 a²+x²、a²−x² 时先想着它们。

J7.★ ∫(√x + 1/√x)dx。

= ∫(x^{1/2} + x^{−1/2})dx = (2/3)x^{3/2} + 2√x + C。

J8.★ ∫tan²x dx。

tan²x = sec²x − 1 ⇒ tanx − x + C。"三角平方降次"是固定起手。

J9.★ ∫sin²(x/2)dx。

降幂：sin²(x/2) = (1−cosx)/2 ⇒ x/2 − sinx/2 + C。

J10.★ ∫x·e^{x²}dx。

凑微分：x dx = d(x²)/2 ⇒ (1/2)e^{x²} + C。

J11.★ ∫x/(1+x⁴)dx。

xdx = d(x²)/2 ⇒ (1/2)∫d(x²)/(1+x⁴) = (1/2)arctan(x²) + C。

J12.★ ∫(lnx)/x dx（x>0）。

(lnx)/x dx = lnx·d(lnx) ⇒ (1/2)ln²x + C。

J13.★ ∫e^{eˣ}·eˣ dx。

eˣdx = d(eˣ) ⇒ e^{eˣ} + C。看到"指数的指数"配它自己的导数。

J14.★ ∫sin³x dx。

拆 sin³ = (1−cos²x)sinx，令 u=cosx： ∫(u²−1)du = u³/3 − u = cos³x/3 − cosx + C。

J15.★★ ∫sin²x·cos²x dx。

sinxcosx = sin2x/2 ⇒ 被积函数 = sin²2x/4 = (1−cos4x)/8。 = x/8 − sin4x/32 + C。

J16.★★ 默写 ∫tanx dx 与 ∫cotx dx。

∫tanx dx = −ln|cosx| = ln|secx| + C；∫cotx dx = ln|sinx| + C。

J17.★★ 默写 ∫secx dx 与 ∫cscx dx。

∫secx dx = ln|secx + tanx| + C；∫cscx dx = ln|cscx − cotx| + C。 sec 型凑 (sec+tan) 的导数；csc 型结果里是减号。

J18.★★ ∫dx/(x²+2x+3)。

配方：(x+1)²+2 ⇒ ∫d(x+1)/[(x+1)²+(√2)²] = (1/√2)arctan[(x+1)/√2] + C。

J19.★★ ∫dx/√(4−x²)。

套 a=2：= arcsin(x/2) + C。

J20.★★ ∫x²/(x²+1)dx。

假分式先拆：x²/(x²+1) = 1 − 1/(x²+1) ⇒ x − arctanx + C。

J21.★★ ∫dx/(1+sinx)。

分子分母乘 (1−sinx)：= ∫(1−sinx)/cos²x dx = ∫(sec²x − tanx·secx)dx = tanx − secx + C。

J22.★★ ∫dx/(sinx·cosx)。

= ∫(sec²x/tanx)dx（上下同除 cos²x）= ∫d(tanx)/tanx = ln|tanx| + C。

J23.★★ ∫dx/√(x²+1)。

结论：ln(x + √(x²+1)) + C（三角换元 x=tanθ 可推；这也是反双曲正弦 arsinhx）。 与它成对的：∫dx/√(x²−1) = ln|x+√(x²−1)| + C（见 J24）。

J24.★★ ∫dx/√(x²−1)（x>1）。

ln|x + √(x²−1)| + C。与 J23 只差一个符号，结果结构相同，成对背。

J25.★★ ∫√(a²−x²)dx（a>0）。

三角换元 x=asinθ：= ∫a²cos²θdθ = a²(θ/2 + sin2θ/4)。 = (x/2)√(a²−x²) + (a²/2)arcsin(x/a) + C。 几何理解：半圆 x 从 0 到 x 的面积 = 扇形 + 三角形，公式不用死背也能现场拼出来。

J26.★ ∫x/√(1−x²)dx。

d(1−x²) = −2xdx ⇒ = −½∫(1−x²)^{−1/2}d(1−x²) = −√(1−x²) + C。

J27.★★ ∫dx/(1+√x)。

令 t=√x，dx=2tdt：2∫t/(1+t)dt = 2∫(1 − 1/(1+t))dt = 2t − 2ln(1+t)。 = 2√x − 2ln(1+√x) + C。

J28.★★ ∫dx/(1+³√x)。

令 t=³√x，dx=3t²dt：3∫t²/(1+t)dt = 3∫(t−1 + 1/(1+t))dt。 = 3[t²/2 − t + ln(1+t)] + C，t=³√x。根号次数 n 就设 t=x^{1/n}。

J29.★★ ∫x/(1+x)²dx。

拆分子：x = (1+x)−1 ⇒ = ∫[1/(1+x) − 1/(1+x)²]dx = ln(1+x) + 1/(1+x) + C。

J30.★ ∫x·eˣdx。

分部（幂函数留作 u，指数进 dv）：= xeˣ − ∫eˣdx = xeˣ − eˣ + C。

J31.★ ∫x·lnx dx。

分部（对数留作 u）：= (x²/2)lnx − ∫x/2 dx = (x²/2)lnx − x²/4 + C。

J32.★★ ∫x²eˣdx。

两次分部：= x²eˣ − 2∫xeˣ = x²eˣ − 2(xeˣ−eˣ) = eˣ(x²−2x+2) + C。 幂次每分部一次降一阶，到 0 为止。

J33.★ ∫x·sinx dx。

= −xcosx + ∫cosx = −xcosx + sinx + C。

J34.★★ ∫lnx dx。

把 1 当 x⁰ 分部：= xlnx − ∫1 dx = xlnx − x + C。"∫lnx 不用换元，直接分部"。

J35.★★ ∫arctanx dx。

= x·arctanx − ∫x/(1+x²)dx = x·arctanx − ½ln(1+x²) + C。

J36.★★ ∫eˣ·sinx dx。

分部两次出现循环：设 I=∫eˣsinx，得 I = eˣsinx − eˣcosx − I。 I = (eˣ/2)(sinx − cosx) + C。e^{ax}sinbx 一族都用这招解方程。

J37.★★ ∫e^{√x}dx。

t=√x：2∫te^t dt = 2e^t(t−1) = 2e^{√x}(√x − 1) + C（换元套分部的复合套路）。

J38.★★ ∫x·arctanx dx。

= ½∫arctanx·d(x²) = ½x²arctanx − ½∫x²/(1+x²)dx = ½x²arctanx − ½x + ½arctanx + C。

J39.★★ ∫(lnx)²/x² dx。

u=(lnx)²，dv=dx/x²：= −(lnx)²/x + 2∫(lnx)/x² dx = −(lnx)²/x − 2lnx/x − 2/x。 = −[(lnx)² + 2lnx + 2]/x + C。

J40.★★★ ∫ln(1+x)/(1+x)² dx。

u=ln(1+x)，dv=dx/(1+x)²（dv = −d[1/(1+x)]）： = −ln(1+x)/(1+x) + ∫dx/(1+x)² = −[ln(1+x)+1]/(1+x) + C。

J41.★★ ∫(x+1)/[(x−1)(x+2)]dx。

待定系数：(x+1) = A(x+2)+B(x−1)。x=1 ⇒ A=2/3；x=−2 ⇒ B=1/3。 = (2/3)ln|x−1| + (1/3)ln|x+2| + C。

J42.★★ ∫dx/[x(x²+1)]。

拆：1/[x(x²+1)] = 1/x − x/(x²+1)。 = ln|x| − ½ln(1+x²) + C。

J43.★★ ∫dx/(x²+2x+5)。

配方：(x+1)²+4 ⇒ (1/2)arctan[(x+1)/2] + C。

J44.★★ ∫dx/(1+cosx)。

半角：1+cosx = 2cos²(x/2) ⇒ = ½∫sec²(x/2)dx = tan(x/2) + C。

J45.★★ ∫dx/(eˣ+1)。

分子分母乘 e^{−x}：= ∫e^{−x}/(1+e^{−x})dx = −ln(1+e^{−x}) + C。 也可写成 x − ln(1+eˣ) + C（两者只差常数）。

§2 定积分计算与性质（J46–J80）

J46.★ 用几何意义求 ∫₋₁¹ |x|dx。

两块三角形，每块 ½ ⇒ 1。简单绝对值函数先画图，比算快。

J47.★ ∫₀^π sinx dx。

= [−cosx]₀^π = 2（半周期正弦的面积，常用值）。

J48.★ ∫₋₁¹ (x² + x³)dx。

x³ 奇函数积分为 0；∫x² = 2/3 ⇒ 2/3。对称区间先扫奇偶。

J49.★ ∫₋ₐᵃ (x³cosx + x²)dx。

x³cosx 是奇函数（奇×偶=奇）⇒ 归零。= 2a³/3。

J50.★★ ∫₀^π x·sinx dx。

分部：= [−xcosx]₀^π + ∫₀^π cosx = π + 0 = π。 推广 ∫₀^π x·f(sinx)dx = (π/2)∫₀^π f(sinx)dx，见 J80。

J51.★★ ∫₀¹ x·e^{−x}dx。

分部：= [−xe^{−x}]₀¹ + ∫₀¹e^{−x} = −1/e + (1−1/e) = 1 − 2/e。

J52.★★ ∫₁ᵉ ln x dx。

分部：= [xlnx − x]₁ᵉ = (e−e) − (0−1) = 1。

J53.★★ ∫₀^{π/2} sin²x dx 与 ∫₀^{π/2} cos²x dx。

降幂各为 π/4（两者相等且和为 π/2）。图形对称，直接背。

J54.★★ 用华里士公式求 ∫₀^{π/2} sin⁴x dx 与 ∫₀^{π/2} sin³x dx。

公式：∫₀^{π/2}sinⁿ = [(n−1)!!/n!!]·(π/2 若 n 偶；1 若 n 奇)。 sin⁴：(3·1)/(4·2)·π/2 = 3π/16；sin³：(2/3)·1 = 2/3。

J55.★★ ∫₀¹ √(1−x²)dx。

单位圆第一象限四分之一圆盘 ⇒ π/4（几何意义秒杀，别硬算）。

J56.★★ ∫₀¹ x·√(1−x²)dx。

令 u=1−x²：= ½∫₀¹ u^{1/2}du = 1/3。

J57.★★ ∫₀^{2π} |sinx| dx。

四个拱，每拱面积 2 ⇒ 4。绝对值必须拆段或用对称。

J58.★★ ∫₀^{2π} sin²x·cos²x dx。

= ¼∫₀^{2π}sin²2x dx = ¼·(平均½×周期2π) = ¼·π = π/4。

J59.★★ ∫₁ᵉ (lnx)/x dx。

= ∫₀¹ u du（u=lnx）= 1/2。

J60.★★ ∫₀¹ dx/(1+eˣ)。

分子分母乘 e^{−x} 或拆 1/(1+eˣ) = 1 − eˣ/(1+eˣ)： = [x − ln(1+eˣ)]₀¹ = 1 + ln2 − ln(1+e)。

J61.★★ ∫₀^{ln2} √(eˣ−1) dx。

令 t=√(eˣ−1)：x=ln(1+t²)，dx=2t/(1+t²)dt，积分限 0→1： 2∫₀¹ t²/(1+t²)dt = 2[t − arctant]₀¹ = 2 − π/2。

J62.★ ∫₀² |x−1|dx。

拆 [0,1] 与 [1,2]：½ + ½ = 1。

J63.★★ ∫₀^π √(1+cos2x) dx。

1+cos2x = 2cos²x ⇒ 被积函数 = √2|cosx|。 √2[∫₀^{π/2}cosx − ∫_{π/2}^π cosx] = √2(1+1) = 2√2。开根号必须加绝对值！

J64.★★★ ∫₀^{π/4} ln(1+tanx) dx。

区间再现 x→π/4−x：tan(π/4−x)=(1−tanx)/(1+tanx)，1+tan(⋯)=2/(1+tanx)。 I = ∫₀^{π/4}ln2·dx − I ⇒ 2I = (π/4)ln2 ⇒ I = (π/8)ln2。

J65.★★ ∫₋₁¹ (x² + 2x + √(1−x²))dx。

三项分开：∫x²=2/3；∫2x=0（奇）；∫√(1−x²)=π/2（半圆）。 = 2/3 + π/2。

J66.★★ ∫₀¹ (eˣ−1)/(eˣ+1) dx。

= ∫₀¹ [1 − 2/(eˣ+1)]dx = 1 − 2·J60 = 1 − 2[1+ln2−ln(1+e)] = 2ln[(1+e)/2] − 1。

J67.★★ ∫₀¹ x·arctanx dx。

分部：= ½x²arctanx |₀¹ − ½∫₀¹ x²/(1+x²)dx = π/8 − ½(1−π/4) = π/4 − 1/2。

J68.★★ ∫₀^{π/2} eˣ·sinx dx。

由 J36 的原函数：[eˣ(sinx−cosx)/2]₀^{π/2} = e^{π/2}(1−0)/2 − (0−1)/2 = (e^{π/2}+1)/2。

J69.★★ 不计算，比较 ∫₀^{π/2} sinx dx 与 ∫₀^{π/2} sin²x dx 的大小。

0≤x≤π/2 时 sinx ∈ [0,1] ⇒ sinx ≥ sin²x（等号仅在端点）。 严格不等 ⇒ 前者大（1 > π/4，验证一致）。保序性是积分不等式的根基。

J70.★★ 用积分中值定理，对 ∫₀¹ eˣdx 找出 ξ。

(1/(1−0))∫₀¹eˣ = e−1 = e^ξ ⇒ ξ = ln(e−1) ≈ 0.54 ∈ [0,1] ✓。 中值定理的 ξ 是具体存在的，验证题就这么算。

J71.★★ 求 lim(x→0) [∫₀ˣ (sint/t)dt] / x²。

变限求导 + 洛必达：lim (sinx/x)/(2x) = lim (sinx)/(2x²) = 1/2。

J72.★ 求 lim(x→0) [∫₀ˣ cost² dt] / x。

= lim cosx² = 1（F′(0)=cos0）。变限积分求导后直接代。

J73.★★ ∫₀^{2π} x·sin²x dx。

sin²x = (1−cos2x)/2：∫x/2 = π²；∫xcos2x 分部后 = 0（周期对消）。 = π²。

J74.★★ ∫₀^{π/2} sinx/(sinx+cosx) dx。

对偶换元 x→π/2−x，得 I = ∫cosx/(sinx+cosx)。 I+I′ = ∫₀^{π/2}1 dx = π/2 ⇒ I = π/4。

J75.★★★ 求 ∫₋₁¹ x²/(1+eˣ) dx。

区间再现 x→−x：I = ∫₋₁¹ x²·eˣ/(1+eˣ)dx。 两式相加：2I = ∫₋₁¹ x²dx = 2/3 ⇒ I = 1/3。 1/(1+eˣ) 型在对称区间上"加它自己的倒影等于 1"，经典结构。

J76.★★ ∫₀^π sin⁶(x/2) dx。

sin⁶(x/2) = [(1−cosx)/2]³ = (1/8)(1 − 3cosx + 3cos²x − cos³x)。 ∫₀^π：cosx 与 cos³x 归零，∫cos²x = π/2 ⇒ (1/8)(π + 3π/2) = 5π/16。

J77.★★ ∫₁⁴ x/√(x+1) dx。

令 t=√(x+1)：x=t²−1，dx=2tdt，限 √2→√5： ∫2(t²−1)dt = [2t³/3 − 2t] = (4√5 + 2√2)/3。 （√5 处：10√5/3−2√5=4√5/3；√2 处：4√2/3−2√2=−2√2/3；相减即得。）

J78.★★ 求 lim(n→∞) Σ_{k=1}^n 1/(n+k)。

= lim (1/n)Σ 1/(1+k/n) = ∫₀¹ dx/(1+x) = ln2。 定积分定义求极限的识别标志：Σ 里出现 k/n 或 1/n 因子。

J79.★★ 求 lim(n→∞) n²·∫₀^{1/n} x·eˣ dx。

∫₀^{1/n}xeˣ = e^{1/n}(1/n−1) + 1（分部）。 泰勒展开：e^{1/n}(1/n−1)+1 = 1/(2n²) + O(1/n³)。 n² 倍 ⇒ 1/2。

J80.★★★ 证明 ∫₀^π x·f(sinx)dx = (π/2)∫₀^π f(sinx)dx，并用它求 ∫₀^π x·sinx/(1+cos²x) dx。

x→π−x：sin(π−x)=sinx，I = ∫₀^π (π−x)f(sinx)dx；相加得 2I = π∫₀^π f(sinx)。∎ 应用：∫₀^π sinx/(1+cos²x) = [−arctan(cosx)]₀^π = π/4+π/4 = π/2。 原式 = (π/2)(π/2) = π²/4。

§3 变限积分与积分方程（J81–J105）

J81.★ 默写变限积分求导定理。

f 连续 ⇒ F(x)=∫ₐˣ f(t)dt 可导且 F′=f；f 只可积 ⇒ F 连续。 "原函数存在定理"：连续函数必有原函数。

J82.★ 求 d/dx ∫ₓᵃ f(t)dt。

= −f(x)（上下限反了差个负号）。

J83.★★ 求 d/dx ∫₀^{x²} sint² dt。

链式：F′ = sin(x²)² · (x²)′ = 2x·sinx⁴。

J84.★★ 求 d/dx ∫_{x²}^{eˣ} t dt。

先算出被积：= d/dx [e^{2x}/2 − x⁴/2] = e^{2x} − 2x³。 验证通式：F′ = eˣ·f(eˣ) − 2x·f(x²)，f(t)=t ⇒ e^{2x}−2x³ ✓。

J85.★★ 求 d/dx [x·∫₀ˣ f(t)dt]。

乘积法则：∫₀ˣ f(t)dt + x·f(x)（x 同时是因子和上限，两处都要动）。

J86.★★ 求 d/dx ∫₀ˣ (x−t)f(t)dt。

先拆：= x∫₀ˣf − ∫₀ˣ t·f(t)dt，再求导：∫₀ˣf + xf(x) − x·f(x) = ∫₀ˣ f(t)dt。 陷阱：被积函数里的 x 是参数，直接对它求导是经典错误。

J87.★★ 求 lim(x→0) [∫₀^{x²} sin√t dt] / x³。

F′ = 2x·sinx ⇒ F ≈ 2∫₀ˣ tsin t dt ≈ 2·x³/3。 或洛必达：lim (2x·sinx)/(3x²) = 2/3。

J88.★★★ 求 d/dx ∫₀ˣ t·f(x²−t²)dt（f 连续）。

令 u=x²−t²，du=−2tdt（x 固定时对 t）：t 从 0→x 对应 u 从 x²→0。 原式 = ½∫₀^{x²}f(u)du ⇒ 求导 = ½·2x·f(x²) = x·f(x²)。

J89.★★ 已知 ∫₀ˣ f(t)dt = x·sinx，求 f(x)。

两边求导：f(x) = sinx + x·cosx（乘积法则）。

J90.★★ 解积分方程：f(x) = x + λ∫₀¹ f(t)dt（λ≠1，f 连续）。

两边在 [0,1] 积分：∫₀¹f = ½ + λ∫₀¹f ⇒ ∫₀¹f = 1/[2(1−λ)]。 f(x) = x + λ/[2(1−λ)]。"未知数是一个数"型积分方程，整体积分一次就解出。

J91.★★ 默写原函数奇偶性结论。

f 奇 ⇒ F(x)=∫₀ˣf 为偶函数；f 偶 ⇒ F 为奇函数（对任意下限的变限积分，奇偶看的是"从0积"）。 例：f=t³ 奇，∫₀ˣt³ = x⁴/4 偶 ✓。

J92.★★ f 以 T 为周期，∫ₐ^{a+T} f(t)dt 与 a 有关吗？

无关（=∫₀^T f）。推论：F(x)=∫₀ˣf 以 T 为周期 ⟺ ∫₀^T f = 0（如 |sinx| 的原函数不周期，sinx 的原函数 −cosx 周期）。

J93.★★ 求 ∫₀^{100π} |cosx| dx。

|cosx| 周期 π，共 100 个周期，每周期 ∫₀^π|cosx| = 2 ⇒ 200。

J94.★★ 设 f(x)=x(1−x)，讨论 F(x)=∫₀ˣ f(t)dt 的单调性与极值。

F′=f=x(1−x)：(0,1) 上正，x>1 负。 F 在 (0,1) 增、x>1 减 ⇒ x=1 处取极大 F(1)=1/6（F′=0 且变号）。极值点由 f 的变号点决定。

J95.★★★ 求 F(x)=∫₀ˣ (x−t)²·f(t)dt 的三阶导数（f 连续）。

F′ = 2∫₀ˣ(x−t)f(t)dt；F″ = 2∫₀ˣ f(t)dt；F‴ = 2f(x)。 每求一次导，(x−t) 的幂次降一阶（对 x 求导时 t 是常数）。

J96.★★ 求 lim(x→0) [∫₀ˣ sint³ dt] / x⁴。

sint³ ~ t³ ⇒ ∫₀ˣ sint³dt ~ ∫₀ˣ t³dt = x⁴/4 ⇒ 极限 = 1/4。（洛必达验证：分子导 sinx³ ~ x³，分母 4x³ ⇒ 1/4 ✓）

J97.★★ 设 x = ∫₀^y √(1+t³) dt，求 dy/dx。

对 x 求导：1 = √(1+y³)·y′ ⇒ dy/dx = 1/√(1+y³)（反函数思想的变限版）。

J98.★★ f 连续，∫₀¹ f = 1，∫₀¹ x·f(x)dx = 2。求 ∫₀¹ (2x+1)f(x)dx。

线性组合：2·2 + 1·1 = 5。积分对被积函数是线性的，已知两个矩就够。

J99.★★★ 设 f 在 x₀ 连续，F(x)=∫₀ˣ f(t)dt。证明 F′(x₀)=f(x₀)。

F(x₀+h)−F(x₀) = ∫_{x₀}^{x₀+h} f(t)dt = h·f(ξ)（积分中值定理，ξ 在 x₀ 与 x₀+h 之间）。 h→0 时 ξ→x₀，f 连续 ⇒ 差商 → f(x₀)。∎

J100.★★★ f 连续，且 f(x) = f′(x) + 2x 对所有 x 成立。求 f 的通解。

移项 f′ − f = 2x（一阶线性）：积分因子 e^{−x}：(fe^{−x})′ = 2xe^{−x}。 ∫2xe^{−x} = −2(x+1)e^{−x} ⇒ f·e^{−x} = −2(x+1)e^{−x} + C。 f(x) = Ceˣ − 2x − 2。变限积分与微分方程的桥：F′=f 这一条随时能用。

J101.★★ f 在 [0,a] 递增。证明：(1/a)∫₀ᵃ f(x)dx ≤ f(a)。

f 递增 ⇒ x≤a 时 f(x)≤f(a) ⇒ ∫₀ᵃ f ≤ ∫₀ᵃ f(a)dx = a·f(a)。∎

J102.★★★ 证明柯西—施瓦茨积分不等式：[∫₀¹ f(x)dx]² ≤ ∫₀¹ f²(x)dx。

对任意实 λ：0 ≤ ∫₀¹ (f − λ)² = ∫f² − 2λ∫f + λ²。 右端是 λ 的二次函数恒非负 ⇒ 判别式 ≤ 0：4(∫f)² − 4∫f² ≤ 0。∎

J103.★ f 连续且 f(0)=3，求 lim(x→0) [∫₀ˣ f(t)dt] / x。

= F′(0) = f(0) = 3。

J104.★★★ 已知 lim(x→0) [∫₀ˣ f(t)dt] / x² = 2（f 连续），求 f(0) 与 f′(0)。

∫₀ˣf ~ 2x² ⇒ 差商 F′=f 满足 f(x) ~ 4x ⇒ f(0)=0，f′(0)=4。 逻辑：F(x)/x² → 2 ⇒ F(x)=2x²+o(x²) ⇒ F′=f = 4x+o(x)。

J105.★★★ F(x)=∫₀ˣ (t²−3t+2)dt，求 F 的极值。

F′=(x−1)(x−2)：(0,1) 正、(1,2) 负、x>2 正。 极大 F(1)=5/6；极小 F(2)=2/3（F(1)=1/3−3/2+2；F(2)=8/3−6+4）。

§4 反常积分（J106–J130）

J106.★ 计算 ∫₁^{+∞} x^{−2}dx，并说明 ∫₁^{+∞} dx/x 为何发散。

∫₁^{+∞}x^{−2} = [−1/x]₁^{+∞} = 1。 ∫₁^{+∞}dx/x = ln(+∞) 发散。p=1 是无穷区间积分的临界线：p>1 收敛，p≤1 发散。

J107.★ 计算 ∫₀¹ dx/√x，并默写瑕积分 p 判别法。

= [2√x]₀¹ = 2。 ∫₀¹ dx/xᵖ：p<1 收敛，p≥1 发散（与无穷区间方向相反，别背反）。

J108.★★ ∫₀^{+∞} e^{−x}dx 与 ∫₀^{+∞} x·e^{−x}dx。

第一个 = 1。第二个分部：[−xe^{−x}]₀^{+∞} + ∫₀^{+∞}e^{−x} = 0 + 1 = 1。

J109.★★ 求 ∫₀^{+∞} x²e^{−x}dx，并给出 Γ(n+1)。

两次分部：x²e^{−x} 型逐次降幂 = 2·1 = 2。 Γ(n+1)=n!，Γ(s+1)=sΓ(s)，Γ(1)=1。

J110.★ ∫_{−∞}^{+∞} dx/(1+x²)。

拆成 (−∞,0] 与 [0,+∞)，各收敛：π/2 + π/2 = π。两侧必须都收敛，定义不允许"取中间极限凑"。

J111.★★ ∫₀^{+∞} dx/(1+x²)^{3/2}。

x=tanθ：dx=sec²θdθ，分母 = sec³θ ⇒ ∫₀^{π/2}cosθdθ = 1。

J112.★★ ∫₀^{+∞} e^{−x}sinx dx 与 ∫₀^{+∞} e^{−x}cosx dx。

由 J36 原函数代入 0 与 +∞： sin 版 = [e^{−x}(−sinx−cosx)/2]₀^{+∞} = 1/2；cos 版同为 1/2（[e^{−x}(sinx−cosx)/2] 型）。

J113.★★ 计算 ∫₁^{+∞} dx/[x·√(1+x²)]。

令 x=1/t：dx = −dt/t²，x 从 1→∞ 对应 t 从 1→0。 被积函数 = 1/[ (1/t)·√(1+t²)/t ]·(dt/t²) 化简后 = ∫₀¹ dt/√(1+t²) = ln(1+√2)。

J114.★★ 计算 ∫₀¹ dx/√(x(1−x))。

令 x=sin²t（0→π/2）：dx=2sint·cost dt，分母 = sint·cost。 = 2∫₀^{π/2}dt = π。两个瑕点同时处理，此换元一次全消。

J115.★ ∫₀^{+∞} dx/(1+x)³。

= [−1/(2(1+x)²)]₀^{+∞} = 1/2。

J116.★ ∫₀^{+∞} x/(1+x²)² dx。

u=1+x²：= ½∫₁^{+∞}u^{−2}du = 1/2。

J117.★★ 只判敛不计算：∫₁^{+∞} dx/(x²·√x) 与 ∫₀¹ dx/x^{0.9}。

第一个 p=5/2>1 ⇒ 收敛；第二个 p=0.9<1 ⇒ 收敛。两道都是"背口诀"题，考的就是临界方向。

J118.★★ ∫₀¹ lnx dx。

瑕点在 0。分部：[xlnx − x]₀¹ = (0−1) − lim(xlnx−x)|_{x→0⁺} = −1 − 0 = −1。 xlnx→0 是 ∞×0 的经典极限，这里必须交代。

J119.★ ∫₀¹ x·lnx dx。

分部：= ½∫₀¹ lnx·d(x²) = ½[lnx·x²]₀¹ − ½∫₀¹ x dx = 0 − ¼ = −1/4。

J120.★★★ 求 ∫₀^{+∞} lnx/(1+x²) dx。

区间再现 x→1/x：lnx/(1+x²) dx → ln(1/x)/(1+1/t²)·(−dt/t²)… 化简后新积分 = −I（x 与 1/x 换位，分母不变分子变号）。 I = −I ⇒ I = 0。对称结构直接判零，不用算出收敛速度。

J121.★ ∫₀^{+∞} e^{−ax}dx（a>0）的值与敛散条件。

= 1/a，当且仅当 a>0 收敛；a≤0 时被积函数不衰减，发散。参数积分先问参数范围。

J122.★ ∫_{−∞}^0 x·eˣ dx。

分部：[xeˣ − eˣ]_{−∞}^0 = (0−1) − 0 = −1。

J123.★★ 判断 ∫₂^{+∞} dx/(x·lnx) 的敛散。

= ∫ d(lnx)/lnx = lnlnx |₂^{+∞} → +∞ ⇒ 发散。 陷阱：看起来像 1/(x·something) 该收敛，实际 ln lnx 无界。对照 ∫₂^{+∞}dx/(x·ln²x) = 1/ln2 收敛。

J124.★★ 比较敛散：∫₁^{+∞} dx/(x²+1) 与 ∫₁^{+∞} dx/√(x²+1)。

前者 ~1/x² 收敛（值 = π/2 − π/4）；后者 ~1/x 发散。 大 O 比较是反常积分判敛的第一工具：看无穷远处等价主部。

J125.★★★ 证明 Γ(½)=√π。

Γ(½) = ∫₀^{+∞} t^{−1/2}e^{−t}dt，令 t=u²：= 2∫₀^{+∞}e^{−u²}du = 2·(√π/2) = √π。 （用到概率论里的高斯积分 ∫_{−∞}^{+∞}e^{−u²}du=√π，两边平方用极坐标可证。）

J126.★★ 求 ∫₀^{+∞} t^{3/2}e^{−t}dt。

= Γ(5/2) = (3/2)Γ(3/2) = (3/2)(1/2)Γ(½) = 3√π/4。

J127.★★★ 求 I = ∫₀^{π/2} ln(sinx) dx。

由对称性 I = ∫₀^{π/2}ln(cosx)dx。相加：2I = ∫ln(sinx·cosx) = ∫ln(sin2x)dx − (π/2)ln2。 ∫₀^{π/2}ln(sin2x)dx = ½∫₀^π ln(sinu)du = ½·2I = I（半角换元+对称）。 2I = I − (π/2)ln2 ⇒ I = −(π/2)ln2。瑕积分收敛但原函数初等写不出——对称法是唯一通路。

J128.★★ 判断 ∫₁^{+∞} (sinx)/x² dx 的绝对收敛性。

|sinx/x²| ≤ 1/x²，而 ∫₁^{+∞}x^{−2} 收敛 ⇒ 绝对收敛。

J129.★★★ 说明 ∫₁^{+∞} (sinx)/x dx 收敛但不绝对收敛。

收敛：分部 ∫₁^{∞}sinx/x = [−cosx/x]₁^{∞} − ∫₁^{∞}cosx/x² dx，两项都收敛。 不绝对：|sinx|/x ≥ sin²x/x = (1−cos2x)/(2x)，∫(1/(2x)) 部分发散 ⇒ ∫|sinx|/x 发散。∎ 条件收敛的教科书例子，考研选择常考"收敛但不绝对收敛"。

J130.★★★ 讨论 p 为何值时 ∫₀^{+∞} dx/[x^p·(1+x²)] 收敛。

0 处（若 p>0）：被积 ~ 1/x^p，需 p<1；p≤0 时 0 处无瑕点。 +∞ 处：被积 ~ 1/x^{p+2}，需 p+2>1 即 p>−1，恒成立（p<1 时自动满足）。 收敛 ⟺ p<1。

§5 定积分应用（J131–J150）

J131.★ 求 y=x² 与 y=x 围成图形的面积。

交点 (0,0)、(1,1)，直线在上：∫₀¹(x−x²)dx = ½−⅓ = 1/6。

J132.★ 求 y=eˣ、y=e^{−x} 与 x=1 围成的面积。

eˣ ≥ e^{−x}（x≥0）：∫₀¹(eˣ−e^{−x})dx = (e−1) − (1−1/e) = e + 1/e − 2。

J133.★★ 求 y²=2x 与 x²=2y 围成的面积。

交点 (0,0)、(2,2)。上支 y=√(2x)： ∫₀²[√(2x) − x²/2]dx = [2√2·x^{3/2}/3 − x³/6]₀² = 8/3 − 4/3 = 4/3。

J134.★★ 求 y=√x 与 y=x³ 围成的面积。

0≤x≤1 上 √x ≥ x³：∫₀¹(√x−x³) = 2/3 − 1/4 = 5/12。

J135.★★ 用极坐标面积公式求 r=2acosθ 的面积。

S = ½∫_{−π/2}^{π/2} 4a²cos²θdθ = 2a²·(π/2) = πa²（就是半径 a 的圆，验算一致）。

J136.★★ 求心形线 r=a(1+cosθ)（a>0）围成的面积。

S = ½∫₀^{2π} a²(1+cosθ)²dθ = (a²/2)∫(1 + 2cosθ + cos²θ) ∫1=2π，∫cosθ=0，∫cos²θ=π ⇒ S = (a²/2)(3π) = 3πa²/2。

J137.★ 求 y=x²（0≤x≤1）绕 x 轴旋转一周的体积。

圆盘法：V = π∫₀¹x⁴dx = π/5。

J138.★★ 求 y=√x 与 y=x 在 [0,1] 之间区域绕 x 轴的旋转体体积。

垫圈法：π∫₀¹[(√x)² − x²]dx = π(½−⅓) = π/6。

J139.★★ 求 y=1/x（1≤x≤2）与 x 轴之间区域绕 y 轴的旋转体体积。

柱壳法：V = 2π∫₁² x·(1/x)dx = 2π·1 = 2π。 （垫圈法要解出 x=1/y 且分两段，麻烦得多——外径内径嵌套时优先柱壳。）

J140.★★ 用定积分推导球体积公式。

y=√(R²−x²) 绕 x 轴：V = π∫_{−R}^R (R²−x²)dx = π[2R³ − 2R³/3] = 4πR³/3。∎

J141.★ 求 y=eˣ（0≤x≤1）绕 x 轴的旋转体体积。

V = π∫₀¹e^{2x}dx = π(e²−1)/2。

J142.★★ 求 y=x²（0≤x≤1）绕 y 轴的旋转体体积。

解出 x=√y（0≤y≤1）：V = π∫₀¹ y·dy = π/2（垫圈：外径 √y 内径 0）。

J143.★★ 求曲线 y=(2/3)x^{3/2} 在 [0,3] 上的弧长。

y′=√x：L = ∫₀³√(1+x)dx = (2/3)(1+x)^{3/2}|₀³ = (2/3)(8−1) = 14/3。

J144.★★ 求 y=lncosx 在 [0,π/4] 上的弧长。

y′=−tanx，√(1+y′²)=secx： L = ∫₀^{π/4}secx dx = [ln(secx+tanx)]₀^{π/4} = ln(1+√2)。

J145.★★★ 求渐开线 x=a(cost+tsint)，y=a(sint−tcost) 在 [0,2π] 上的弧长。

x′=at·cost，y′=at·sint ⇒ √(x′²+y′²) = at。 L = ∫₀^{2π}at·dt = 2aπ²。"参数方程弧长的题，√ 里经常天生是完全平方"。

J146.★★ 用定积分推导球面（旋转曲面）面积公式。

y=√(R²−x²)：y′=−x/y，√(1+y′²) = R/y。 S = 2π∫_{−R}^R y·(R/y)dx = 2πR·2R = 4πR²。∎（"y 与 √ 恰好约掉"是球面的特殊恩赐）

J147.★ 弹簧劲度 k=100 N/m，从平衡位置拉长 0.1 m，求做的功。

W = ∫₀^{0.1}100x dx = 100·(0.1)²/2 = 0.5 J。变力做功 = 力对位移积分。

J148.★ 质点速度 v(t)=3t²，求 0≤t≤2 的位移。

s = ∫₀² 3t²dt = 8（v 是位移的导数，反着积回去）。

J149.★★ 宽 2 m、高 3 m 的矩形闸门竖直放置、上沿与水面齐，求单侧水压力。

深度 x 处压强 ρgx，面积微元 2dx： P = ρg∫₀³2x dx = ρg·9 = 9800×9 = 88200 N ≈ 88.2 kN。

J150.★★★ 直线 y=cx（c>0）与 y=x² 围成面积 S(c)，求 c 使 S=2/3。

交点 x=0 与 x=c，直线上方：S(c)=∫₀^c(cx−x²)dx = c³/2 − c³/3 = c³/6。 c³/6 = 2/3 ⇒ c³ = 4 ⇒ c = ∛4 = 2^{2/3}（2026-10-29复审订正：原版根指数误写为4次方根，应为立方根）。
