01 函数极限与连续【数一·数二】

知识点摘要

  • 函数有界性、单调性、奇偶性、周期性；复合函数与反函数。
  • 极限定义（ε-δ语言理解即可，重点在计算）；单侧极限；极限存在充要条件=左右极限存在且相等。
  • 无穷小与无穷大：无穷小阶的比较（高阶/同阶/等价/阶数）；等价无穷小替换。
  • 极限存在准则：夹逼准则、单调有界必有极限。
  • 两个重要极限。
  • 连续：f在点连续 ⇔ 极限值=函数值；间断点分类（第一类：可去/跳跃；第二类：无穷/振荡）。
  • 闭区间连续函数性质：有界性、最值定理、介值定理、零点定理。

公式定理

  • 等价无穷小（x→0）：sinx~x, tanx~x, arcsinx~x, arctanx~x, 1-cosx~x²/2, eˣ-1~x, ln(1+x)~x, (1+x)^α-1~αx, aˣ-1~x·lna。
  • 重要极限：lim(sinx/x)=1 (x→0)；lim(1+1/x)ˣ=e (x→∞)。
  • 极限四则与复合运算成立条件；洛必达适用于 0/0、∞/∞ 且导数比极限存在。
  • 幂指函数极限：lim u^v = e^(lim v·ln u)。

常见题型

  1. 用等价替换+洛必达+泰勒求 0/0 型极限（泰勒展开到"足够阶"是速度最快的通用解法）。
  2. ∞-∞ 型：通分或提出最高次因子。
  3. 1^∞ 型：凑 (1+□)^(1/□) 或取对数。
  4. n项和求极限：夹逼 or 定积分定义（识别 1/n·Σf(i/n)）。
  5. 已知极限反求参数（先化简，用"分母不为零/分子趋于零"定参数）。
  6. 间断点判别：找无定义点→算左右极限→分类。

易错点

  • 等价无穷小只能整体替换乘除因子，加减慎用（除非展开泰勒保证精度）。
  • x→∞ 时 "存在极限" 与 "有界" 不是一回事；有界×无穷小=无穷小，但无穷大×有界未必无穷大。
  • 洛必达失效情形：导数比振荡不存在（如 lim x²sin(1/x)/x），改用夹逼。
  • 分段函数在分段点：必须分别算左、右极限。
  • 可去间断点改定义后"连续"是新的函数，别混淆。

自测题（3道，答案见底部）

  1. 求 lim(x→0) (eˣ - 1 - x)/x²。
  2. 求 lim(x→0⁺) xˣ。
  3. 讨论 f(x)=e^(1/x)（x≠0），f(0)=0 在 x=0 处的间断类型。

答案 1. 1/2（泰勒：eˣ=1+x+x²/2+o(x²)）。 2. 1（取对数 x·lnx→0）。 3. x→0⁻ 时 e^(1/x)→0=f(0)（左连续），x→0⁺ 时 →+∞：第二类无穷间断点。

02 导数与微分【数一·数二】

知识点摘要

  • 导数定义：f'(x₀)=lim [f(x₀+Δx)-f(x₀)]/Δx（定义法求导是高频考点）；左右导数与可导关系。
  • 可导⇒连续；连续⇏可导（|x|在0处）。可导与可微等价（一元）。
  • 求导法则：四则、复合（链式）、反函数、隐函数、参数方程、对数求导法。
  • 高阶导数：莱布尼茨公式；常见函数n阶导。
  • 微分：dy=f'(x)dx；一阶微分形式不变性；近似计算。

公式定理

  • 基本导数表（sin→cos, tan→sec², sec→sec·tan, ln→1/x, aˣ→aˣlna 等）。
  • (uv)'=u'v+uv'；(u/v)'=(u'v-uv')/v²。
  • 参数方程：dy/dx=(dy/dt)/(dx/dt)；二阶 d²y/dx² = d(dy/dx)/dt ÷ dx/dt。
  • 常用n阶导：(e^(ax))⁽ⁿ⁾=aⁿe^(ax)；sin(ax+b)⁽ⁿ⁾=aⁿsin(ax+b+nπ/2)；1/(x-a)⁽ⁿ⁾=(-1)ⁿn!/(x-a)^(n+1)。
  • 莱布尼茨：(uv)⁽ⁿ⁾=ΣC(n,k)u⁽ⁿ⁻ᵏ⁾v⁽ᵏ⁾。

常见题型

  1. 用定义讨论分段函数在分段点的可导性（拆 f(x₀+Δx)-f(x₀)）。
  2. 绝对值/取整函数的可导性（左右导数）。
  3. 隐函数求一阶、二阶导数。
  4. 参数方程求二阶导（易错重灾区）。
  5. n阶导：先拆分/降幂再用公式。
  6. 相关变化率（几何/物理背景的速率问题）。

易错点

  • f'(x₀) 存在 ⇔ 左右导数存在且相等；"f在x₀处可导"与"f'在x₀处连续"（导函数连续）完全不同。
  • 参数方程二阶导：分子是对 t 求导后除以 dx/dt，不是再对 x 商一次。
  • 复合函数求导漏乘内层导数；多层复合建议从外往里逐层写。
  • 对数求导法适用于幂指函数 u^v 与多项连乘除。
  • 微分近似 dy≈Δy 只在 |Δx| 小时成立，别把近似当等式。

自测题（3道）

  1. f(x)=x²·D(x)（D为狄利克雷函数）在 x=0 是否可导？
  2. 设 y=y(x) 由 x²+xy+y²=1 确定，求 y'(1)。
  3. y=x²e^(3x)，求 y⁽ⁿ⁾。

答案 1. 可导且 f'(0)=0（|f(Δx)/Δx|≤|Δx|→0，夹逼）。 2. 对x求导：2x+y+xy'+2yy'=0。x=1 时由原方程得 y=0 或 y=-1：y=0 ⇒ y'=-2；y=-1 ⇒ y'=-1/3。双值都要写清分支。 3. y⁽ⁿ⁾=e^(3x)·3ⁿ·x² + n·e^(3x)·3^(n-1)·2x + C(n,2)e^(3x)·3^(n-2)·2（莱布尼茨）。

03 微分中值定理与导数应用【数一·数二】

知识点摘要

  • 三大中值定理：罗尔、拉格朗日、柯西（条件与结论要能默写，几何意义清楚）。
  • 费马引理（极值点可导则导数为零）。
  • 洛必达法则；泰勒公式（带皮亚诺余项/拉格朗日余项）与麦克劳林公式。
  • 单调性判别、极值（第一/第二充分条件）、最值。
  • 凹凸性与拐点（注意用二阶导符号定义凹凸的教材口径）。
  • 渐近线：水平、垂直、斜渐近线（三条都要查）。
  • 方程根的个数讨论、不等式证明。

公式定理

  • 罗尔：f(a)=f(b) ⇒ ∃ξ∈(a,b), f'(ξ)=0。
  • 拉格朗日：f(b)-f(a)=f'(ξ)(b-a)。
  • 柯西：[f(b)-f(a)]/[g(b)-g(a)]=f'(ξ)/g'(ξ)。
  • 泰勒（拉格朗日余项）：f(x)=Σ(f⁽ᵏ⁾(x₀)/k!)(x-x₀)ᵏ + f⁽ⁿ⁺¹⁾(ξ)/(n+1)!·(x-x₀)ⁿ⁺¹。
  • 常用麦克劳林：eˣ, sinx, cosx, ln(1+x), (1+x)^α, 1/(1-x)（背到常用阶数）。
  • 极值第二充分条件：f'(x₀)=0 且 f''(x₀)≠0（<0极大，>0极小）。

常见题型

  1. 构造辅助函数证明中值等式：看到 f'ξ·g(ξ)+… 就想"乘积求导=两项"逆推（如 (f·e^x)'=e^x(f'+f)）。
  2. 两个中值 ξ、η 的证明：分区间用两次罗尔/拉格朗日。
  3. 用泰勒展开证明含 f'' 或高阶的不等式/中值问题（在极值点/端点展开）。
  4. 单调性+极值+凹凸+拐点+渐近线全套函数性态分析。
  5. 方程 f(x)=0 根的个数：单调性分段+零点定理+极值符号。
  6. 证明不等式：构造 F(x) 求导判单调，或拉格朗日/泰勒放缩。

易错点

  • 罗尔定理三条件缺一不可（连续、可导、端点值相等），答题先验证条件。
  • 拐点判定：f''=0 的点两侧二阶导变号才是拐点（f''=0 不一定是拐点，如 y=x⁴ 在0）。
  • 极值点可以不在驻点（如 |x| 的极值点不可导）；驻点不一定是极值点。
  • 斜渐近线：k=lim f(x)/x (x→∞)，b=lim[f(x)-kx]；x→+∞ 与 x→-∞ 要分别查，可能有两条不同渐近线。
  • 泰勒展开的余项阶数要"够"：展开到比分子分母低阶项高一阶为止。
  • 用洛必达前必须验证是未定式，否则错（如 lim (x+1)/x 用洛必达=错）。

自测题（3道）

  1. f 在[0,1]连续，(0,1)可导，f(1)=0，证明：∃ξ∈(0,1) 使 f'(ξ)=-f(ξ)/ξ。
  2. 求 y=x·e^(-x) 的单调区间、极值、凹凸区间、拐点。
  3. 证明：当 x>0 时，ln(1+x) > x/(1+x)。

答案 1. 构造 F(x)=x·f(x)：F在[0,1]满足罗尔（F(0)=0=F(1)=1·f(1)=0）⇒ F'(ξ)=f(ξ)+ξf'(ξ)=0。 2. y'=e^(-x)(1-x)：增(-∞,1)减(1,+∞)，极大值 f(1)=1/e；y''=e^(-x)(x-2)：凸(x<2)凹(x>2)【按凹凸口径】，拐点(2, 2/e²)。 3. 构造 F(x)=ln(1+x)-x/(1+x)：F(0)=0，F'(x)=x/(1+x)²>0 (x>0) ⇒ F增 ⇒ F(x)>0。

04 不定积分与定积分【数一·数二】

知识点摘要

  • 原函数与不定积分概念；基本积分表。
  • 换元法：第一类（凑微分）、第二类（三角换元、根式换元、倒代换）。
  • 分部积分：u 的选取优先级"反、对、幂、三、指"（谁排前谁设 u）。
  • 有理函数积分：部分分式分解。
  • 定积分定义（和式极限）、几何意义；变限积分求导（高频）。
  • 定积分性质：区间可加、绝对可积性、比较定理、估值定理、积分中值定理。
  • 牛顿-莱布尼茨公式；定积分换元（换元必换限）与分部（"定限分部"边界相减）。
  • 反常积分（无穷区间、无界函数）敛散性判定与计算。
  • 定积分应用：面积、旋转体体积、弧长（数一数二都考）、物理应用（数一侧重）。

公式定理

  • 凑微分常用：x dx→(1/2)dx², (1/x)dx→d(lnx), eˣdx→d(eˣ), cosx dx→d(sinx), (1/√x)dx→2d(√x)。
  • 三角换元：√(a²-x²)→x=a·sin t；√(a²+x²)→x=a·tan t；√(x²-a²)→x=a·sec t。
  • 变限求导：d/dx ∫[a,φ(x)] f(t)dt = f(φ(x))·φ'(x)。
  • 华里士公式（Wallis）：∫₀^(π/2) sinⁿx dx 递推，n偶=…·(n-1)/n·π/2，n奇=…·(n-2)/(n-1)。
  • 对称性：∫_{-a}^{a} f = ∫₀^a [f(x)+f(-x)]dx（奇函数=0；偶函数加倍）。
  • ∫₀^(π/2) f(sinx)dx = ∫₀^(π/2) f(cosx)dx；区间再现：x→(a+b-x)。

常见题型

  1. 复合/分段/抽象函数的不定积分与定积分。
  2. 变限积分：求导、求极限、判断奇偶性、方程（∫f=…求f）。
  3. 对称性+区间再现化简三角定积分（先化简再计算，能省一半时间）。
  4. 反常积分敛散判别（比较判别法 p 积分/1/(x lnp x) 基准）。
  5. 旋转体体积（圆盘法/柱壳法）与平面面积（交点先求准）。
  6. 积分等式证明（中值定理、分部、换元构造）。

易错点

  • 连续函数才有变限求导那一套；被积含 x 时先把 x 提出积分号或换元。
  • 分段/含绝对值的积分必须拆区间。
  • 反常积分：瑕点在内部的要拆开分别判敛，一部分发散则整体发散。
  • 换元后忘换限；第二类换元回代时别丢定义域（t 范围与主值分支）。
  • 分部积分循环型（∫eˣsinx）解出方程移项，别丢等号。
  • 面积/体积题：先画草图定交点，别凭想象。

自测题（3道）

  1. 求 ∫ x·eˣ dx。
  2. 求 ∫₀^π x·sinx dx。
  3. 求 ∫₁^{+∞} dx/x² 与 ∫₁^{+∞} dx/x 的敛散性。

答案 1. (x-1)eˣ+C。 2. π（定限分部：[-x cosx]₀^π + ∫₀^π cosx dx = π+0）。 3. 1/x² 收敛（=1），1/x 发散（p≤1）。结论记忆：p-积分 ∫₁^∞ dx/xᵖ，p>1收敛，p≤1发散。

05 多元函数微分学【数一·数二（数二要求较低：不含方向导数/梯度/几何应用）】

知识点摘要

  • 多元函数极限与连续（沿不同路径极限不同⇒极限不存在，常用判别法）。
  • 偏导数定义与计算；可微定义：Δz=A·Δx+B·Δy+o(ρ)。
  • 关系链：偏导连续 ⇒ 可微 ⇒ 连续 且 偏导存在；反向均不成立（必背逻辑图）。
  • 复合函数链式法则（树状图，"连线相乘、分线相加"）。
  • 隐函数求导：一个方程 F=0 ⇒ ∂z/∂x=-F_x/F_z；方程组用隐函数组求导。
  • 全微分；二阶偏导与混合偏导（连续则相等）。
  • 【数一】方向导数与梯度：方向导数=grad·单位向量；梯度的意义（增长最快方向）。
  • 多元极值：无条件极值（AC-B²判别法）；条件极值（拉格朗日乘数法）；最值应用题。

公式定理

  • 链式法则：z=f(u,v), u=u(x,y), v=v(x,y) ⇒ z_x=f_u·u_x+f_v·v_x。
  • 无条件极值判别：f_xx=A, f_xy=B, f_yy=C；AC-B²>0 且 A<0极大 / A>0极小；<0非极值；=0失效（另判）。
  • 拉格朗日：L=f+λg，解 ∇(f+λg)=0。
  • 【数一】方向导数：D_l f = f_x·cosα+f_y·cosβ(+f_z·cosγ)；grad f=(f_x, f_y[, f_z])。

常见题型

  1. 用定义判可微性（先算 f_x(0,0)=lim f(Δx,0)/Δx，再验证 Δz-…=o(ρ)）。
  2. 复合函数（含抽象函数 f₁', f₂' 记号）一阶、二阶偏导。
  3. 隐函数（单方程/方程组）偏导与全微分。
  4. 求闭区域上的最值（内部驻点+边界代入化一元）。
  5. 条件极值应用题（拉格朗日）。

易错点

  • "偏导存在"推不出"连续"更推不出"可微"——经典反例：xy/(x²+y²) 在原点。
  • 二阶混合偏导若不连续可能不相等；计算时先算清 f_x 再对 y 求导。
  • 隐函数存在定理要求 F_z≠0（在该点），条件要写。
  • 拉格朗日乘数法解出的点是候选极值点，应用题里要结合实际意义（或比较函数值）确认最值。
  • 区域边界最值：参数化或代入约束化为一元，别漏端点。

自测题（3道）

  1. f(x,y)=√(x²+y²)，问 f 在 (0,0) 处偏导是否存在？是否连续？是否可微？
  2. z=z(x,y) 由 x²+y²+z²=4 确定，求 ∂z/∂x。
  3. 求 f(x,y)=x²+y² 在约束 x+y=1 下的最小值。

答案 1. f_x(0,0)=lim |Δx|/Δx 不存在 ⇒ 偏导不存在 ⇒ 不可微；但 f 连续（显然）。考点：连续↛偏导存在。 2. 2x+2z·z_x=0 ⇒ z_x=-x/z（z≠0）。 3. L=x²+y²+λ(1-x-y)：x=y=(1-λ)/2=1/2，最小值 1/4（圆上最近点，实际意义确认）。

06 重积分【数二仅二重积分；数一含三重积分】

知识点摘要

  • 二重积分概念、几何意义（曲顶柱体体积）、性质（可比性、中值定理）。
  • 直角坐标：X型/Y型确定积分限（先对谁积分看"穿线"）。
  • 极坐标：x=r·cosθ, y=r·sinθ，面积元 dxdy = r·dr·dθ（勿丢 r）。
  • 交换积分次序：由积分限还原区域图再重写。
  • 对称性与奇偶性：区域对称+被积函数奇偶 → 化简（必考技巧）。
  • 轮换对称性：∫∫f(x,y)=∫∫f(y,x)（区域关于 y=x 对称时）。
  • 【数一】三重积分：投影法/截面法（先二后一）、柱坐标、球坐标。
  • 【数一】曲线曲面积分（与本章关联，另行成笔记时补充——2027年确认考数一后再补全）。

公式定理

  • ∫∫D f dσ：X型 ∫_a^b dx ∫{y₁(x)}^{y₂(x)} f dy。
  • 极坐标：∫∫ f(r cosθ, r sinθ)·r dr dθ。
  • 奇偶对称：D 关于 y 轴对称 ⇒ 若 f 关于 x 为奇函数则积分为0；为偶函数则=2倍半区域。
  • 球坐标【数一】：dV=r²·sinφ·dr·dφ·dθ。

常见题型

  1. 直角坐标计算（定限是关键：画图穿线）。
  2. 交换次序（给出 ∫∫ 的累次积分，换序再算）。
  3. 极坐标计算（圆域、环域、扇形区域优先）。
  4. 对称性/奇偶性化简后再算（判断题里的陷阱也在这）。
  5. 分段函数的二重积分（按函数分段切分区域）。
  6. 【数一】三重积分选坐标系与"先二后一"。

易错点

  • 极坐标变换忘乘 r（最常见错误，没有之一）。
  • 交换次序时积分限"内限是外变量的函数"，先画图再写，别凭代数硬换。
  • 被积函数含 max/min/|·|/√(r²) 等必须分区讨论。
  • 对称性使用前提是"区域对称+函数奇偶"两个条件同时成立。
  • 无界区域上的二重积分（数一偶考）用先算后取极限。

自测题（3道）

  1. 交换次序：∫₀¹ dx ∫_x^1 e^(-y²) dy 并求值。
  2. 求 ∫∫_D (x+y) dσ，D: x²+y²≤1（用对称性）。
  3. 求 ∫∫_D √(x²+y²) dσ，D: 1≤x²+y²≤4。

答案 1. 原区域 {0≤x≤y≤1}，换序 ∫₀¹ dy ∫₀^y e^(-y²) dx = ∫₀¹ y·e^(-y²) dy = (1-e^(-1))/2。 2. 区域对称：x 项、y 项均为奇函数积分为 0 ⇒ 结果 0。 3. 极坐标：∫₀^{2π}dθ∫₁² r·r dr = 2π·(8-1)/3 = 14π/3（注意被积函数√(r²)=r，面积元 r，共 r²）。

07 微分方程【数一·数二（数二不考欧拉方程；数一含伯努利/全微分方程等）】

知识点摘要

  • 可分离变量方程；齐次方程 y'=φ(y/x)（换元 u=y/x）。
  • 一阶线性方程 y'+P(x)y=Q(x)：公式法或常数变易法；Q=0 时为齐次线性。
  • 伯努利方程【数一】：y'+P y=Q yⁿ，令 z=y^(1-n)。
  • 全微分方程【数一】：P dx+Q dy=0 且 ∂P/∂y=∂Q/∂x。
  • 可降阶二阶：y⁽ⁿ⁾=f(x)；y''=f(x,y')；y''=f(y,y')（令 p=y'，注意后者 p 看成 y 的函数）。
  • 二阶常系数齐次：特征方程法。
  • 二阶常系数非齐次：特解形式（待定系数法）+ 通解=齐次通解+特解。
  • 欧拉方程【数一】：x²y''+pxy'+qy=f(x)，令 x=eᵗ。
  • 高阶线性解的结构：叠加原理。

公式定理

  • 一阶线性通解：y=e^(-∫P dx)[∫Q·e^(∫P dx)dx + C]。
  • 特征方程 r²+pr+q=0：两不同实根 r₁,r₂ → y=C₁e^(r₁x)+C₂e^(r₂x)；重根 r → C₁e^(rx)+C₂x·e^(rx)；共轭复根 α±βi → e^(αx)(C₁cosβx+C₂sinβx)。
  • 非齐次特解：f(x)=Pₘ(x)e^(λx) → y*=xᵏQₘ(x)e^(λx)（k=λ作为特征根的重数）；f=e^(λx)[A cosωx+B sinωx] → 同理 k 按 λ±ωi 是否为特征根。

常见题型

  1. 识别类型→选方法（拿到方程先判：可分离？齐次？一阶线性？）。
  2. y''=f(y,y') 降阶时令 p(y)=y'，y''=p·dp/dy（易错点）。
  3. 二阶常系数：写通解；由初始条件定常数。
  4. 已知解反求方程/参数（解的结构定理：非齐通=非齐特+齐次通）。
  5. f(x) 两个不同特解 ⇒ 差为齐次解，构造齐次方程。
  6. 综合应用题（几何/变化率建立微分方程）。

易错点

  • y''=f(y,y')：设 p=y' 后 y''=p(dp/dy)，不是 dp/dx。
  • 特解的 k（修正因子）判断：λ 是特征单根 k=1，重根 k=2，不是根 k=0。
  • 共轭复根情形 ω 与 β 的对应别写错。
  • 一阶线性公式里 e^(∫P dx) 的符号方向（除以 vs 乘以），代回验算一次。
  • 应用题设变量时明确"谁是谁的变化率"，单位一致性。

自测题（3道）

  1. 解 y'+y·tanx=secx。
  2. 解 y''-4y'+4y=e^(2x)。
  3. y=e^(2x)+(1+x)e^x 是 y''+ay'+by=ce^x 的特解，求 a,b,c。

答案 1. 一阶线性，P=tanx，∫P dx=-ln|cosx| ⇒ 通解 y=sinx·(x+C)。（代回可验） 2. 特征根 r=2（二重）；齐次通解 (C₁+C₂x)e^(2x)；λ=2为二重根 k=2 ⇒ y*=x²/2·e^(2x)；通解 y=(C₁+C₂x)e^(2x)+(x²/2)e^(2x)。 3. 代入解的叠加：两个"部分"相减得齐次解 e^(2x)-x·e^x ⇒ 特征根 2 和 1 ⇒ a=-3, b=2；代入原方程比较 e^x 系数 ⇒ c=-1。

08 无穷级数【仅数学一；报专硕（数二）可跳过本文件】

知识点摘要

  • 常数项级数：部分和、收敛定义；收敛必要条件 lim aₙ=0（逆命题不成立！p级数反例之外还有调和级数）。
  • 正项级数判别法：比较（及极限形式）、比值（达朗贝尔）、根值（柯西）、积分判别。
  • 交错级数：莱布尼茨判别法（单调递减+趋于0⇒收敛）。
  • 绝对收敛与条件收敛：绝对收敛必收敛；条件收敛=原收敛但绝对值级数发散。
  • 幂级数：收敛半径 R（比值/根值法求）、收敛区间、收敛域（端点单独判）。
  • 幂级数性质：和函数连续、可逐项求导/积分（收敛域内部）。
  • 函数展开为幂级数（泰勒/麦克劳林展开，直接法与间接法）。
  • 傅里叶级数【数一】：系数公式、狄利克雷收敛定理、正弦/余弦级数（延拓）。

公式定理

  • 几何级数：Σaqⁿ，|q|<1 收敛于 a/(1-q)。
  • p-级数：Σ1/nᵖ，p>1 收敛，p≤1 发散；调和级数发散。
  • eˣ=Σxⁿ/n!；1/(1-x)=Σxⁿ (|x|<1)；ln(1+x)=Σ(-1)^(n-1)xⁿ/n (-1<x≤1)；sinx、cosx、(1+x)^α 展开。
  • 收敛半径：R=lim |aₙ/aₙ₊₁|（或 1/lim ⁿ√|aₙ|）。
  • 傅里叶：aₙ=(1/π)∫_{-π}^{π}f(x)cosnx dx，bₙ=(1/π)∫ f(x)·sinnx dx；收敛定理：间断点收敛于 [f(x₋)+f(x₊)]/2。

常见题型

  1. 判定具体级数敛散（先看必要条件→判正项/交错→选判别法）。
  2. 判断绝对收敛/条件收敛（对 Σ|aₙ| 再判一次）。
  3. 含参数级数（讨论参数取值）。
  4. 求幂级数收敛域与和函数（逐项求导/积分把陌生化成 1/(1-x) 型）。
  5. 函数展开为 x-x₀ 的幂级数并注明收敛域。
  6. 数项级数求和（借幂级数和函数）。

易错点

  • lim aₙ=0 推不出收敛（调和级数是标准反例，判断题最爱）。
  • 比值/根值判别法失效时（比值为1）改用比较判别法。
  • 逐项求导/积分后收敛半径不变，但端点收敛性可能改变，收敛域要重新判端点。
  • 和函数定义域 vs 收敛域：求和函数时写明 x 范围。
  • 傅里叶展开：间断点处的和=左右极限平均值；周期与延拓方式（奇/偶延拓）决定正弦/余弦级数。

自测题（3道）

  1. 判断 Σ(-1)ⁿ·n/(n+1) 的敛散性。
  2. 求幂级数 Σxⁿ/n 的收敛域与和函数。
  3. 判断 Σ(-1)ⁿ/√n 的绝对收敛/条件收敛。

答案 1. 发散（必要条件失败：lim n/(n+1)=1≠0）。 2. R=1，端点 x=1 时交错调和收敛、x=-1 时调和发散 ⇒ 收敛域 (-1,1]；S(x)=-ln(1-x)。 3. |Σ|为 p=1/2 发散；原级数满足莱布尼茨 ⇒ 收敛 ⇒ 条件收敛。

09 向量代数与空间解析几何【仅数一】

知识点摘要

  • 向量运算：点积 a·b=|a||b|cosθ（判垂直）；叉积 a×b（模=|a||b|sinθ，方向右手，判平行、求法向量/面积）；混合积 [a b c]=(a×b)·c（判共面，绝对值=平行六面体体积）。
  • 平面方程：点法式 A(x−x₀)+B(y−y₀)+C(z−z₀)=0；一般式 Ax+By+Cz+D=0（法向量 n=(A,B,C)）；截距式。
  • 直线方程：点向式（对称式）(x−x₀)/m=(y−y₀)/n=(z−z₀)/p；参数式；一般式（两平面交线，方向 s=n₁×n₂）。
  • 位置关系：两平面夹角=法向量夹角；两直线共面 ⇔ 混合积=0；点到平面距离 d=|Ax₀+By₀+Cz₀+D|/√(A²+B²+C²)。
  • 曲面：旋转面（坐标面上的曲线绕轴旋转：绕哪个轴哪个变量不动，另一变量换成 ±√(另两变量平方和)）；柱面（缺哪个变量母线平行哪个轴）；二次曲面八标准形（椭球面/椭圆抛物面/双曲抛物面（马鞍面）/单叶双曲面/双叶双曲面/锥面/圆柱面/抛物柱面）。
  • 空间曲线：参数式；投影柱面（消去z）与在坐标面上的投影。

常见题型

  1. 求平面方程（点法式：先找法向量——两向量叉积或垂直条件）。
  2. 求直线方程与两直线/直线与平面的位置关系（夹角、平行垂直）。
  3. 距离计算：点到平面、点到直线（投影法）、异面直线间距离（数一低频）。
  4. 旋转面方程（绕 x 轴：y、z 换成 ±√(y²+z²)）。
  5. 二次曲面识别与草图（标准形对照）。
  6. 空间曲线在坐标面上的投影（后面重积分/曲面积分定域要用）。

易错点

  • 叉积方向用右手定则，a×b ≠ b×a。
  • 旋转面"绕 x 轴"时 x 保持不变，别把不动的变量也换掉。
  • 平面束方程（过直线的所有平面）设式后用附加条件定参数。
  • 点到直线距离：投影点法（P₀+ (v·(P−P₀)/|v|²)v）别算错符号。

自测题（3道，答案见底部）

  1. 求过点 (1,2,3) 且与平面 2x−y+3z=5 平行的平面方程。
  2. 求点 (1,2,3) 到平面 x+2y+2z−9=0 的距离。
  3. 指出曲面 z=x²+y² 与 x²+y²−z²=1 分别是什么曲面。

答案 1. 法向量 n=(2,−1,3)：2(x−1)−(y−2)+3(z−3)=0，即 2x−y+3z−9=0。 2. d=|1+4+6−9|/√(1+4+4)=2/3。 3. 旋转抛物面（绕z轴）；单叶双曲面（绕z轴旋转双曲线）。

10 曲线积分与曲面积分【仅数一】

知识点摘要

  • 第一类曲线积分（对弧长，物理=线质量）：∫_L f ds，ds=√(1+y′²)dx（y=y(x)）；与方向无关。
  • 第二类曲线积分（对坐标，物理=变力做功）：∫_L Pdx+Qdy+Rdz，与方向有关，改向变号。
  • 格林公式：∮_L Pdx+Qdy = ∬_D (∂Q/∂x−∂P/∂y)dσ（L 取正向边界=沿它走区域在左手）。
  • 路径无关四等价：单连通域内 ∮=0 ⇔ 路径无关 ⇔ Pdx+Qdy 为某 u 的全微分 ⇔ ∂P/∂y=∂Q/∂x；原函数 u=∫(变起点折线)。
  • 第一类曲面积分（对面积）：∬_Σ f dS，dS=√(1+z_x²+z_y²)dxdy；有对称性简化。
  • 第二类曲面积分（对坐标，流量）：∬_Σ Pdydz+Qdzdx+Rdxdy，与侧有关（外侧/内侧）。
  • 高斯公式：∬_Σ（外侧）Pdydz+Qdzdx+Rdxdy = ∭_Ω (∂P/∂x+∂Q/∂y+∂R/∂z)dV。
  • 斯托克斯公式：∮_L Pdx+Qdy+Rdz = ∬_Σ (curl F)·dS（L 与 Σ 侧成右手）。
  • 两类联系：∫_L Pdx+Qdy = ∫_L (Pcosα+Qcosβ)ds。

常见题型

  1. 第一类曲线积分直接算（参数化+ds）或用对称性（轮换对称：曲线方程关于 x,y 轮换不变时 ∮x²ds=∮y²ds）。
  2. 第二类曲线积分：参数直接算；不闭合→补线用格林；有奇点（如分母 x²+y²）→挖小圆洞。
  3. 路径无关判别+求原函数（折线法：u(x,y)=∫ₓ₀ˣP(x,y₀)dx+∫_{y₀}^y Q(x,y)dy+C）。
  4. 第一类曲面积分：投影+对称性（Σ 关于 yOz 对称且 f 含 x 奇次 → 0）。
  5. 第二类曲面积分：直接投影（各面分开算）；不闭合→补面用高斯（注意补面侧的方向，减去补面积分）。
  6. 斯托克斯：空间闭曲线化为曲面积分（常再转高斯/直接投影）。

易错点

  • 格林/高斯公式前提：闭曲线（外侧闭曲面）+ 被积函数在区域内有一阶连续偏导；不闭补线/补面、有奇点挖洞——补上的要减掉。
  • 第二类曲面积分投影时符号：取上侧 dxdy 前为正、下侧为负；三个坐标面投影分别判。
  • 第一类对称性"奇零偶倍"适用于 ds 与 dS；第二类的对称性结论相反（还与侧有关），别混用。
  • 斯托克斯公式方向：右手法则，L 方向与 Σ 侧不匹配时差一个负号。

自测题（3道，答案见底部）

  1. 求 ∮_L (x²+y²)dS，L 为圆 x²+y²=a²。
  2. 用格林公式求 ∮_L (x−y)dx+(x+y)dy，L 为 x²+y²=1 沿正向。
  3. 用高斯公式求 ∬_Σ xdydz+ydzdx+zdxdy，Σ 为球面 x²+y²+z²=a² 外侧。

答案 1. 在 L 上 x²+y²=a²，∮=a²·(周长)=2πa³（第一类可直接代入曲线方程！这是第一类独有技巧）。 2. ∂Q/∂x−∂P/∂y=1−(−1)=2 ⇒ =∬2dσ=2π。 3. div=(1+1+1)=3 ⇒ =3·(4/3)πa³=4πa³。

高数 · 难点专攻（拉开分差的地方）

1. 中值定理：辅助函数构造对照表（背）

  • 见 f′+λf → 构造 e^{λx}·f(x)（其导数=e^{λx}(f′+λf)）
  • 见 xf′+f → 构造 x·f(x)；见 xf′−f → 构造 f(x)/x
  • 见 f′/f → 构造 ln f（先说明 f>0，或对 |f| 讨论）
  • 见 f′g−fg′ → 构造 f/g；见 f′g+fg′ → 构造 f·g
  • 要 ξ∈(a,b) 且含两端函数值 → 先想罗尔（构造后验证两端相等）

2. 泰勒展开怎么“定阶”

  • 原则：展开到比分母最低阶高一次；展开点选“信息最多的点”（极值点、f(a)=0、对称点）。
  • 典型：已知 f″ 在 U(0) 存在、f(0)=f′(0)=0，求 lim f(x)/x² → 用带拉格朗日余项泰勒 f(x)=f″(ξ)x²/2，极限=f″(0)/2（ξ→0 由连续性）。
  • 只给一阶可导时别硬泰勒，改洛必达+导数定义拼接。

3. 幂级数求和套路链

识别类型 → 逐项求导（分子有 xⁿ⁻¹ 倾向）或逐项积分（分母有 n 倾向）→ 化成 Σxⁿ=1/(1-x) → 反解出 S(x) → 端点单独判敛，写清收敛域。缺项级数（如 Σx²ⁿ/n）先令 t=x²。

4. 变限积分三件套

被积函数含 x → 先把 x 从积分号里拿出来（换元 t/x 或提取）；求导对象是“上限函数的复合”；∫₀ˣ f(t)dt=f(x)-1 这类方程 → 两边求导后代 x=0 定常数。

5. 反常积分敛散：三个基准

∫₁^∞ dx/xᵖ（p>1 收）；∫₀¹ dx/xᵖ（p<1 收）；∫₂^∞ dx/(x·lnᵖx)（p>1 收）。判敛先化简被积函数找等价基准，瑕点在内部必须拆开分别判。

6. 多元可微验证固定流程

①用定义算 f_x(x₀,y₀)、f_y(x₀,y₀)；②算极限 lim [Δz−f_xΔx−f_yΔy]/ρ；③为 0 ⇒ 可微，否则不可微。三步缺一不可，判断题专考“偏导存在但不可微”。
