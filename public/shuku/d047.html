综合题解析

综合1：合并次序 2+4=6 → 6+5=11 → 11+9=20。树：9 在深度1，5 深度2，2、4 深度3。编码（左0右1一种）：9=0，5=10，2=110，4=111。WPL=9×1+5×2+2×3+4×3=37。无歧义原因：字符只出现在叶结点 ⇒ 任何编码不是另一编码的前缀（前缀码），译码走到叶即输出。

综合2：思想：扫描一遍，写指针维护“已保留的不重复前缀”；O(1) 空间下重复判定依赖有序性（重复必相邻）——答题先声明前提："若表无序，先排序，否则退化为 O(n²)"：

int Del(int a[], int n){          /* 有序表：重复必相邻 */
    int w=1;                       /* 写指针（保留a[0]） */
    for(int r=1;r<n;r++)
        if(a[r]!=a[w-1]) a[w++]=a[r];
    return w;                      /* 新长度 */
}

时间O(n)、空间O(1)。若题目为无序表，则需 O(n²) 或改用排序预处理——答题时先声明前提。

综合3：块内地址 5 位（32B）；Cache行=64KB/32B=2048，4路 → 组数=512 → 组号 9 位；标记=30−9−5=16位。 0x00123456=1193046：块内偏移=低5位=22（0x16）；组号=(1193046>>5)&511=418；标记=1193046>>14=72。 （校验：组号418×32B=13376，位于Cache第418组。）

综合4（逐格画表可得）： - FIFO：缺页9次（4先出，序列 1,2,3,4,5,1,2 …按装入顺序淘汰）。 - LRU：缺页10次。 - OPT：缺页7次（淘汰"将来最久不用"：4淘汰3? 每步淘汰3/4/1/2）。 - Belady 异常仅属 FIFO（本题若把页框增到4帧，FIFO缺页反例可见；3帧时9次）。

综合7（MSS为单位）：

依据：RTT1~4 慢启动指数增长到 ssthresh=8；RTT5起转拥塞避免线性+1；RTT6 内发生超时（cwnd=10 时）→ ssthresh=10/2=5，cwnd 重置1 重新慢启动：RTT7=1、8=2、9=4，RTT10 达到新阈值5 转拥塞避免。 （若把事件改为"3个冗余ACK"则走快恢复：ssthresh=5、cwnd=5 继续线性——注意区分。）
