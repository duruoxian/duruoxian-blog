第一部分 高等数学（28题）

§1 极限与连续

T1.★ 求 lim(x→0) [1/x² − 1/(x·tanx)]。

通分 = (tanx−x)/(x²tanx)。tanx−x ~ x³/3，tanx~x ⇒ 极限 = (x³/3)/x³ = 1/3。

T2.★★ 求 lim(x→0⁺) (tanx)^{1/lnx}。

取对数：lim ln(tanx)/lnx。x→0⁺ 时 tanx 与 x 等价（ln(tanx)/lnx = 1 + ln(1+o(x))/lnx → 1），故原式 = e¹ = e。

T3.★★ 求 lim(n→∞) Σᵢ₌₁ⁿ 1/√(n²+i)。

夹逼：n/√(n²+n) ≤ 和 ≤ n/√(n²+1)，两端 →1 ⇒ 1。

T4.★★ 已知 lim(x→0) (x − a·sinx)/x³ = b（存在且不为0），求 a、b。

若 a≠1，分子 ~ (1−a)x，极限为∞或0阶不符；故 a=1。此时 x−sinx ~ x³/6 ⇒ a=1, b=1/6。

T5.★★ 讨论 f(x)=(e^{1/x}−2)/(e^{1/x}+1)（x≠0），f(0)=1 的间断点。

x→0⁻：e^{1/x}→0，f→(−2)/1=−2；x→0⁺：f→(1−2e⁻…)/(1+…)→1。左右极限都存在但不等 ⇒ x=0 是跳跃间断点（第一类）；且与 f(0)=1 比较仅右侧相等。

§2 导数与微分

T6.★★★ f 在 x=0 可导且 f(0)=0，F(x)=f(x)(1+|sinx|)。证明 F 在 0 可导。

F(0)=0。F′(0)=lim F(h)/h = lim f(h)(1+|sinh|)/h = lim f(h)/h · lim(1+|sinh|) = f′(0)·1。左同右同 ⇒ F′(0)=f′(0) 存在。（f(0)=0 吸收了不可导因子）

T7.★★ x=arctan t，y=ln(1+t²)，求 d²y/dx²。

dy/dx = [2t/(1+t²)]/[1/(1+t²)] = 2t。d²y/dx² = [d(2t)/dt]/(dx/dt) = 2·(1+t²) = 2(1+t²)。

T8.★★ 求 y=x²e^{−x} 的极值与拐点。

y′=e^{−x}x(2−x)：极大 f(2)=4e^{−2}，极小 f(0)=0。y″=e^{−x}(x²−4x+2)=0 ⇒ x=2±√2，两侧变号 ⇒ 拐点 (2±√2, y(x))。

§3 中值定理与导数应用

T9.★★★ f∈C[a,b]、(a,b)可导，f(a)=f(b)=0。证明：∃ξ∈(a,b) 使 f′(ξ)=f(ξ)。

构造 F(x)=e^{−x}f(x)：F(a)=F(b)=0，F∈C、可导。罗尔 ⇒ F′(ξ)=e^{−ξ}(f′(ξ)−f(ξ))=0 ⇒ f′(ξ)=f(ξ)。

T10.★★ 证明 x∈(0,1) 时 eˣ(1−x) < 1。

令 F(x)=eˣ(1−x)，F′=−x·eˣ<0 (x>0)，F(0)=1 ⇒ F(x)<F(0)=1。∎

T11.★ 求 y=2x³−9x²+12x−1 的单调区间与极值。

y′=6(x−1)(x−2)：增 (−∞,1)∪(2,+∞)，减 (1,2)；极大 f(1)=4，极小 f(2)=3。

§4 不定积分与定积分

T13.★★ 求 ∫ dx/(1+sinx)。

分子分母同乘 (1−sinx)：∫(1−sinx)/cos²x dx = ∫(sec²x − secx·tanx)dx = tanx − secx + C。

T14.★ 求 ∫ x·arctanx dx。

分部：= (x²/2)arctanx − (1/2)∫ x²/(1+x²)dx = (x²+1)/2·arctanx − x/2 + C。

T15.★★ 求 ∫₀^{ln2} √(eˣ−1) dx。

令 t=√(eˣ−1)：x=ln(1+t²)，dx=2t/(1+t²)dt，限 0→1。积分 =2∫₀¹ t²/(1+t²)dt = 2[t−arctan t]₀¹ = 2−π/2。

T16.★★ 求 ∫_{−π/2}^{π/2} (x³+cos²x)·sin²x dx。

T17.★★★ f 连续，f(x)=x²+∫₀ˣ f(t)dt，求 f(x)。

T18.★★ 求 ∫₁^{+∞} dx/(x√(x²−1))。

令 x=secθ（θ:0→π/2）：被积 = secθtanθdθ/(secθ·tanθ)=dθ ⇒ 积分 = π/2。

T19.★★ 求 y=eˣ、y=e^{−x} 与 x=1 围成图形面积。

T20.★ 求 y=√x（0≤x≤1）绕 x 轴旋转一周体积。

§5 多元函数微分学

T21.★★★ f(x,y)=xy/√(x²+y²)（(x,y)≠0），f(0,0)=0。证明在(0,0)偏导存在但不可微。

f_x(0,0)=lim f(h,0)/h = 0；同理 f_y=0。可微需 [Δz−0]/ρ→0：= xy/(x²+y²)，沿 y=kx 得 k/(1+k²) 随 k 变 ⇒ 极限不存在 ⇒ 不可微（偏导存在的反例经典）。

T22.★★★ z=f(xy, x/y)，f 有二阶连续偏导，求 ∂z/∂x 与 ∂²z/∂x∂y。

z_x = y·f₁′ + (1/y)·f₂′。 ∂z_x/∂y = f₁′ + y(xf₁₁″ − x/y²·f₁₂″) + [(xf₂₁″ − x/y²·f₂₂″)/y − f₂′/y²]。 （按 f₁′、f₂′ 分块逐项求，f₁₂″=f₂₁″）

T23.★★ z=z(x,y) 由 F(x−z, y−z)=0 确定，求 ∂z/∂x。

令 u=x−z, v=y−z：F_u(1−z_x)+F_v(−z_x)=0 ⇒ z_x = F₁′/(F₁′+F₂′)；同理 z_y=F₂′/(F₁′+F₂′)。

T24.★★ 在椭圆 x²/4+y²=1 内作内接矩形（边平行坐标轴），求最大面积。

顶点 (x,y)，A=4xy，约束 x²/4+y²=1。拉格朗日：∇(xy)=λ∇(x²/4+y²) ⇒ y=x²/2·? 解得 x=√2, y=1/√2 ⇒ A=4（此时 x²/4=1/2）。比较边界（A=0）知为最大。

T25.★★★ 交换次序并计算 ∫₀¹dx ∫ₓ^√x sin(y²)dy。

A=|A|A⁻¹=A⁻¹/2；(2A)⁻¹=A⁻¹/2。差 = A⁻¹/2 − 5A⁻¹/2 = −2A⁻¹。 |−2A⁻¹| = (−2)³/|A| = −8·2 = −16*。

T32.★★ 解矩阵方程 AX = X + A，A=[[3,1],[1,3]]。

(A−E)X=A，A−E=[[2,1],[1,2]] 可逆：X=(A−E)⁻¹A = (1/3)[[2,−1],[−1,2]]·[[3,1],[1,3]] = (1/3)[[5,−1],[−1,5]]。

T34.★★ α₁=(1,1,2), α₂=(1,a,3), α₃=(2,4,7) 线性相关，求 a。

相关 ⇔ |α₁ α₂ α₃|=0：= 3a−5 = 0 ⇒ a=5/3。

T35.★★★ 讨论解：x+y+z=1；x+2y+az=2；x+4y+a²z=4。

系数行列式=(a−1)(a−2)。a≠1,2：唯一解。a=1：r(A)=r(A|b)=2 → 无穷多解（y=1, x+z=0）。a=2：同理 r=2 → 无穷多解。不存在无解情形（本题专防"套路化答题"）。

T36.★★★ 证明 r(AᵀA)=r(A)。

证 Ax=0 与 AᵀAx=0 同解：Ax=0 ⇒ AᵀAx=0 显然。反之 xᵀAᵀAx=0 ⇒ ‖Ax‖²=0 ⇒ Ax=0。同解 ⇒ 解空间同 ⇒ n−r 相等 ⇒ r 相等。∎

T37.★★ A=[[2,0,0],[0,3,1],[0,1,3]]，求全部特征值与特征向量。

T39.★★ 判定 f=2x₁²+2x₂²+2x₃²+2x₁x₂+2x₁x₃+2x₂x₃ 的正定性。

矩阵=E+全1阵：顺序主子式 2、3、4 全正 ⇒ 正定（特征值 4,1,1 亦可）。

T40.★★★ A=[[1,0],[0,−1]]，B=[[0,1],[1,0]]。判断 A 与 B 的相似性与合同性并说明。

特征值都为 1,−1 ⇒ 相似（都实对称且特征值相同必相似）。正负惯性指数都为(1,1) ⇒ 合同。既相似又合同（正交变换矩阵 [1/2?] 可具体构造 Q=[[1,1],[1,−1]]/√2）。

T41.★★ 用配方法化 f=x₁²+2x₂²+5x₃²+2x₁x₂+2x₁x₃+6x₂x₃ 为标准形。

f=(x₁+x₂+x₃)²+(x₂+2x₃)²（展开恰好消尽）。令 y₁=x₁+x₂+x₃，y₂=x₂+2x₃ ⇒ f=y₁²+y₂²，正惯性指数2。

T42.★★ 设 Aξ=2ξ（ξ≠0），求 A²−3A+2E 的特征值，并判断 A 可逆吗？

f(2)=4−6+2=0 ⇒ 0 是 f(A) 的特征值。又 A²−3A+2E=(A−E)(A−2E)；若 A 不可逆则 |A|=0 ⇒ 0 是 A 的特征值。本题：0 是 f(A) 特征值，说明 A²−3A+2E 不可逆；对 A 本身由已知无法断定（需另一信息：若 2 是唯一特征值且 A 可对角化则 |A|=2²≠0）。答出"f(A) 不可逆"即得分点。
