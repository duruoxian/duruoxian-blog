一、单项选择题（12题）

C1. 某机主频2GHz，平均CPI=2.5，则MIPS为： A. 500 B. 800 C. 1000 D. 1250

MIPS = 2000MHz/(2.5×10⁶? ) = 2×10⁹/(2.5)条/秒 = 8×10⁸条/秒 = B. 800 MIPS。

C2. 8位补码可表示的整数范围： A. −127~127 B. −128~127 C. −128~128 D. −255~255

B。补码多表示一个最小负数 −2⁷=−128。

C3. 两补码数相加，采用双符号位，结果符号位为10表示： A. 正溢出 B. 负溢出 C. 正确（负数） D. 错误

B。双符号位01=正溢出，10=负溢出；最高符号位是真符号。

C4. 海明码信息位 n=8 时，至少需要校验位： A. 3 B. 4 C. 5 D. 6

2ᵏ≥8+k+1：k=4 → 16≥13 ✓；k=3 → 8<12 ✗。选 B。

C5. float（IEEE754）中，阶码字段全0且尾数字段全0，表示： A. 0 B. 无穷大 C. NaN D. 最小规格化数

A。E全0且M全0=±0；E全0且M≠0=非规格化数；E全1、M=0=±∞；E全1、M≠0=NaN。

C6. 某机主存4GB按字节编址，Cache数据区32KB，块大小64B，2路组相联，标记字段位数为： A. 15 B. 16 C. 17 D. 18

块内6位；32KB/64B=512块→256组→组号8位；主存32位（4GB）；标记=32−8−6=D. 18位。

C7. 低位交叉存储器4体，存取周期T=50ns，总线传送周期τ=12.5ns，连续读取4个字的时间约为： A. 200ns B. 87.5ns C. 50ns D. 100ns

T+(m−1)τ = 50+3×12.5 = B. 87.5ns。

C8. 采用变址寻址，指令中地址码A=100H，变址寄存器IX内容=0400H，操作数有效地址为： A. 100H B. 0400H C. 0500H D. 由主存单元100H内容决定

C。变址：EA=(IX)+A=0500H。（若是间接寻址才取主存内容）

C9. 相对寻址的转移指令占2个字节，存于地址1000H处，位移量A=−2（补码），取指后转移目标地址为： A. 0FFEH B. 1000H C. 1002H D. 0FFCH

取指后PC=1000H+2=1002H；目标=PC+A=1002H−2=B. 1000H。（相对寻址基准是"下一条指令地址"）

C10. 五段流水线（IF ID EX MEM WB）各1拍，连续执行10条指令（无冒险），第5条指令执行完是在第几拍： A. 5 B. 8 C. 9 D. 10

第n条完成于第 n+k−1 拍 = 5+5−1 = C. 9拍。

C11. 下列关于中断的说法正确的是： A. DMA结束不需要中断 B. 自陷是外部中断 C. 缺页属于故障（内中断） D. NMI可被屏蔽

C。缺页是内部异常中的"故障"；DMA结束需中断告知；自陷是内部异常；NMI不可屏蔽。

C12. 32位数据总线、100MHz、每个时钟周期传送一次数据，总线带宽为： A. 100MB/s B. 200MB/s C. 400MB/s D. 800MB/s

4B×100M=C. 400MB/s。（若为DDR每周期2次则800）

A1.★★ 求十进制数 −96.75 的 IEEE754 单精度表示。

96.75 = 1100000.11B = 1.10000011×2⁶。S=1；E=6+127=133=10000101；M=10000011000000000000000。 结果：1 10000101 10000011000000000000000。

A2.★★ 已知IEEE754单精度编码 0x428C8000，求真值。

0x428C8000 = 0100 0010 1000 1100 1000 …0：S=0；E=10000101=133 → e=6；M=0001100…→尾数=1.0001100₂=1+0.09375=1.09375? 精确：0.0001100₂=1/16+1/32+1/64=0.09375。 真值 = +1.09375×2⁶ = 70。

A3.★★ 主存按字节编址，容量1MB；Cache 4KB，块大小16B，直接映射。求主存地址各字段位数；主存地址 8A657H 映射到Cache哪一行？

块内4位；Cache行数=4KB/16B=256行→行号8位；主存20位；标记=20−8−4=8位。 8A657H=1000 1010 0110 0101 0111：块内=0111；行号=10 0110 01（取中间8位）=269? 精确拆分：低4位=7；中间8位=0A65H的低段…按位拆：20位地址 10001010011001010111 → 标记[19:12]=10001010=8AH，行号[11:4]=01100101=65H=101行，块内[3:0]=0111。 映射到第 101 行（0x65）。

A4.★★★ Cache采用LRU，2路组相联，共4组（8行），块大小1字。访问主存块地址序列：0,1,2,4,2,0,3,5。写出每组内容变化并求命中率。

组号=块地址 mod 4：0→组0，1→组1，2→组2，4→组0，3→组3，5→组1。 组0：0【缺】→ {0}；4【缺】→ {0,4}；0【命中】→ LRU换序 {4,0}。 组1：1【缺】→ {1}；5【缺】→ {1,5}。 组2：2【缺，缺两次】→ 第一次缺、第5次访问2【命中】。 组3：3【缺】。 访问8次：缺 0,1,2,4,3,5 共6次，命中 2次（第5次访问2、第6次访问0）→ 命中率 2/8=25%。

A5.★★ 用64K×8位的SRAM芯片设计 256K×16位存储器，需要多少片？写出字/位扩展方案与片选逻辑（高位地址如何接）。

A6.★★★ 五段流水线（IF ID EX MEM WB 各1拍）执行：

I1: add R1,R2,R3
I2: sub R4,R1,R5
I3: and R6,R1,R7
I4: or  R8,R1,R9

(1) 无转发机制需插几个气泡？(2) 有转发（EX→EX）呢？

(1) I1 的 R1 第5拍（WB）才写回；I2 的 ID 原在第3拍 → 按“WB前半写、ID后半读”口径推迟到第5拍 ⇒ 停2拍；I3 顺延到第6拍读 ⇒ 停1拍；I4 停0拍。共3个气泡。 (2) 有 EX→EX 转发：I2 第4拍直接取 I1 第3拍的结果，全部0个气泡。

A7.★★ 中断系统4级：D>A>C>B？设实际优先级 D>A>C>B，写出各级中断服务程序的屏蔽字（1=屏蔽）。

规则：屏蔽自身及更低者，放行更高者。 D级（最高）：1111（屏蔽D,A,C,B? 自身D置1，其余更低全1 → D:1111） A级：1101（屏蔽A及更低C,B，放行D → A=1,D=0,C=1,B=1 → 位序D A C B：1101） C级：1100? 位序D A C B：放行D,A，屏蔽C,B → 0011? 按位序（D,A,C,B）：C级屏蔽字 = D:0, A:0, C:1, B:1 → 0011 B级：D:0,A:0,C:0,B:1 → 0001 答案：D=1111，A=0111，C=0011，B=0001（位序D,A,C,B）。

A8.★★ 磁盘? 不属计组。改：某总线时钟100MHz，每个总线事务传输32位数据需2个时钟周期，求最大带宽；若改为64位总线每周期传1次呢？

每2拍传4B → 4B×50M次/秒=200MB/s；64位每周期1次：8B×100M=800MB/s。

A17.★★ 写出信息位 1010（n=4）的海明码（偶校验，校验位在 1,2,4 位）。

校验位 p1 管 1,3,5,7 位；p2 管 2,3,6,7；p4 管 4,5,6,7。信息放 3,5,6,7 位：1,0,1,0。 p1：b3⊕b5⊕b7=1⊕0⊕0=1；p2：b3⊕b6⊕b7=1⊕1⊕0=0；p4：b5⊕b6⊕b7=0⊕1⊕0=1。 海明码（位1→7）：1 0 1 1 0 1 0。

A18.★★ 求 −2.5 的 IEEE754 双精度表示。

A19.★★ 2路组相联 Cache 共4组、块大小8B。访问块地址序列 0,1,0,2,1,3，求命中率（LRU）。

组号=块%4：0→组0【缺】，1→组1【缺】，0→组0【命中】，2→组2【缺】，1→组1【命中】，3→组3【缺】。 命中率 = 2/6=1/3。

A20.★★ 五段流水线（含转发）执行：

I1: lw  R1, 0(R2)
I2: add R3, R1, R4
I3: sub R5, R3, R6
I4: or  R7, R5, R8
I5: and R9, R7, R1
I6: xor R10, R9, R2

求总拍数。

I2 依赖 I1 的 load 结果（MEM后才有数据）→ load-use 冒险，即使有转发也需停1拍；其余依赖可转发。总拍数 = 6+5−1+1 = 11拍。

A21.★★★ 磁盘数据率 4MB/s，DMA 每次传送 8KB，DMA 预处理+后处理共需 1000 个时钟周期，CPU 主频 100MHz。求 DMA 方式下 CPU 为该设备耗费的时间占比。

每秒传送次数 = 4MB/8KB = 512 次；CPU周期占用 = 512×1000 = 5.12×10⁵ /秒； 占比 = 5.12×10⁵/10⁸ = 0.512%（对比中断方式的数百%，体现 DMA 优势）。

A22.★★ 虚地址 24 位、页 4KB；TLB 共 16 项、2路组相联。虚地址 0x3ABCD 的虚页号、页内偏移、TLB 组号各是多少？

页内偏移12位=0xBCD；虚页号=0x3A；TLB组数=8 → 组号=0x3A mod 8 = 58 mod 8 = 2。

A23.★★ 求真值：[x₁]补=0.1110、[x₂]补=1.0011，并求 x₁−x₂ 的补码结果（判溢出）。

x₁=14/16，x₂=−13/16；x₁−x₂=27/16 溢出（超出(−1,1)）。 计算：[x₂]补→[−x₂]补=0.1101；[x₁]补+[−x₂]补=0.1110+0.1101=1.1011（双符号判断：两正数得负→正溢出）。

A24.★★ 磁盘组：4盘片（8记录面），每面1000磁道，每道200扇区，每扇区512B。求总容量；按 CHTS→LBA 规则（柱面优先）求 (C=2, H=3, S=5) 的 LBA（S从1计）。

A25.★ 简答：中断服务程序执行前为何必须先"关中断"？何时再"开中断"？

保存断点与现场的过程必须原子完成，若被新中断打断会丢失现场；故响应后立即关中断，现场保存完毕（若是多重中断则保存后开中断允许更高级打断）、服务结束时恢复现场后开中断返回。

大题板书精讲（408真题风格·8道）

B1.★★★ 海明码完整链路：信息位 1010 编码 → 传输第5位翻转 → 接收端定位并纠正。

发送端（k=3，校验位在1,2,4位）：码字 1011010（见计组考题集A17）。 设传输后收到 1001010（第3位由1→0）。 接收端校验：s₁=b1⊕b3⊕b5⊕b7=1⊕0⊕0⊕0=1；s₂=b2⊕b3⊕b6⊕b7=0⊕0⊕1⊕0=1；s₄=b4⊕b5⊕b6⊕b7=1⊕0⊕1⊕0=0。 故障字 (s₄s₂s₁)=011₂=3 ⇒ 第3位错，翻转恢复 1011010 → 信息位(3,5,6,7)=1010 ✓。

B2.★★ 求 −77.75 的 IEEE754 双精度表示。

77.75 = 1001101.11₂ = 1.00110111×2⁶。 S=1；E=6+1023=1029=10000000101（11位）；M=00110111 后补0至52位。 编码：1 10000000101 0011011100…0（共64位）。 验算：1.00110111₂ = 1+0.25+0.03125+0.015625+0.0078125? 直接验证 1.00110111×64 = 77.75 ✓。

B3.★★★ 虚存-Cache 综合三查：虚地址16位、页4KB；TLB 共4组、2路组相联；页式虚存，页表部分：页2→页框7（有效）；Cache 直接映射64行、块16B。求虚地址 0x2F6A 的物理地址与 Cache 行号。

①虚页号=0x2F6A>>12=2；页内偏移=0xF6A。 ②TLB组号=2 mod 4=2（假设TLB命中且页2→页框7）。 ③物理地址=页框7×4KB+0xF6A=0x7F6A。 ④Cache：块号=0x7F6A>>4=2038；行号=2038 mod 64=54；标记=32618>>10=31。

B4.★★ 用 16K×4 位的芯片构成 64K×8 位的存储器。求芯片数、分组与连接说明。

位扩：2片并成16K×8；字扩：64K/16K=4组 ⇒ 共8片。 CPU地址16位：低14位接所有芯片的地址端；高2位 A15A14 → 2:4译码器产生4个组片选。 数据：每组两片分别接数据总线低4位与高4位。 地址范围：组1：0000H~3FFFH；组2：4000H~7FFFH；组3：8000H~BFFFH；组4：C000H~FFFFH。

B5.★★ 五段流水线（IF ID EX MEM WB 各1拍）连续执行7条指令，其中第3条为转移成功的分支指令（在EX段末解析，其后2条作废）。求总拍数并画时空表。

理想：7+5−1=11拍；分支成功作废2条指令的已用时序 ⇒ +2拍 ⇒ 13拍。 时空表要点：第3条在EX（第5拍）解析出转移；第4、5条已进入流水线的部分作废（标×）；第6、7条（即新目标及其后）从第6拍起重新取指 → 尾部顺延2拍。

B6.★★ 总线带宽与 DMA 占比综合：总线宽32位、频率133MHz；某磁盘数据率66MB/s，DMA每次传送8KB，预处理+后处理共500个时钟周期（CPU主频200MHz）。求总线带宽与DMA方式下CPU占用率。

带宽 = 4B×133M = 532MB/s。 DMA次数 = 66MB/8KB = 8448次/s；每次CPU耗时 = 500/200MHz = 2.5μs。 占用率 = 8448×2.5μs ≈ 2.1%（对比中断方式的不可行，体现DMA优势）。

B7.★★ 磁盘：12000转/分，平均寻道6ms，每道125个扇区、每扇区512B。求读一个扇区、读一整道的平均时间与持续数据率。

平均旋转延迟 = 60000ms/12000/2 = 2.5ms；单扇区传输 = 60000/12000/125 = 0.04ms。 读一个扇区 = 6+2.5+0.04 ≈ 8.54ms。 读一整道 = 6+2.5+125×0.04=5ms ⇒ 13.5ms。 持续数据率 = 125×512B/6ms ≈ 10.7MB/s。

B8.★ 简述CPU响应中断的条件与处理流程，并说明多重中断与单重中断在"开中断时机"上的差异。

响应条件：①有中断请求且未被屏蔽；②CPU允许中断（EINT=1）；③一条指令执行完毕。 流程：关中断→保存断点（PC、PSW）→引出服务程序→（多重中断此时开中断，允许更高级打断）→执行服务→恢复现场→开中断→返回断点。 差异：单重中断全程关中断直到服务结束；多重中断在保存完现场/屏蔽字后即开中断，允许优先级更高的中断嵌套。
