## 标题

用 `#` 的个数表示层级，一个 `#` 是一级标题（正文里一般从 `##` 开始用）。

## 强调

**加粗**、*斜体*、~~删除线~~、`行内代码`。

## 列表

无序列表：

- 苹果
- 香蕉
- 橘子

有序列表：

1. 打开编辑器
2. 写内容
3. 保存

任务列表：

- [x] 已完成的事
- [ ] 待办的事

## 链接与图片

```markdown
[链接文字](https://example.com)
![图片说明](/covers/hello.svg)
```

## 表格

| 语法 | 效果 |
| --- | --- |
| `**粗体**` | **粗体** |
| `` `代码` `` | `代码` |

## 代码块

写出语言名可以自动高亮：

```javascript
function greet(name) {
  return `Hello, ${name}!`;
}
console.log(greet("World"));
```

## 引用

> 简洁是可靠的朋友，复杂是不可靠的敌人。
