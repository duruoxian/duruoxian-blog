## 为什么开这个博客

笔记散在各处：手机备忘录、聊天记录、收藏夹、各种平台。
它们各自都能用，但合在一起就成了一团乱麻。

我想要一个地方：

- 由我自己掌控，不会因为某个平台关停而消失
- 能按我自己的方式组织，而不是被算法决定
- 写的时候只需要专注于内容本身

于是就有了这个站点。

## 会写些什么

大概会围绕这几类：

- **技术**：学习笔记、踩坑记录、工具使用
- **项目**：我做过、或者正在做的东西
- **生活**：一些零散的想法与记录

不追求更新频率，只写真正想留下来的东西。

## 关于这个网站

本站用 **Next.js + TypeScript + Tailwind CSS** 搭建，文章以 Markdown 编写，
托管在 Cloudflare Pages 上，源码在 GitHub 上开源（见页脚）。
