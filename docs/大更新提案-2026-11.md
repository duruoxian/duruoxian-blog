# 博客大更新提案(2026-11-01)

> 基于线上站点实测 + 本地代码审计 + 标杆调研(antfu.me / leerob.com / IndieWeb / 中文博客圈)得出。
> 原则:零花费、免费渠道、每项标注是否需要你本人参与。

---

## 一、现状总评:先说清楚已经很好的部分(不用再做的)

你的博客工程底座已经是个人博客第一梯队,以下能力**全部已具备**,任何"大更新"都不该重复投入:

| 类别 | 已有 |
|---|---|
| 阅读体验 | 明暗色(无闪白)、6 套背景主题+自定义背景图、TOC(桌面+移动)、阅读进度条、返回顶部、代码复制、图片缩放、相关文章、上/下一篇、分享按钮 |
| 内容组织 | 分类/标签/系列三维导航、归档页(按年)、全文搜索(Ctrl+K, fuse.js)、阅读时长+字数 |
| SEO/分发 | sitemap、robots、RSS 全文、canonical、首页 WebSite JSON-LD、**文章页 BlogPosting JSON-LD(已做)**、每篇动态 OG 分享卡(satori) |
| 工程 | Next.js 16 + React 19 静态导出、GitHub Actions 自动部署、安全头+精细缓存策略(_headers)、PWA、跳到正文、构建时抓 GitHub 贡献图(带失败降级) |
| 评论 | Giscus 已配置已激活(Repo Id/Category Id 都填了) |
| 子系统 | 刷题库 920 题、书库 124 份、单词听力、图形化 admin 后台、资源页(带图标自动抓取) |

**结论:不缺功能,缺的是三样东西 —— ①"名片"属性(别人 30 秒内看你是谁、做过什么);②传播(收录/友链/统计,目前约等于零);③内容策略(只有一种文体)。**

## 二、标杆调研:人家是怎么做的

**antfu.me**(Vue/Vite 核心团队):
- 首页不放文章列表,放**按角色分组的项目索引**:"Creator of(Vitest/Slidev…)、Maintaining(Shiki…)、Core team of(Vue…)"
- 文末 Creative Commons 许可协议;有 /uses 装备页;RSS 显眼
- 纯文本、链接密集、零图片 → 性能与无障碍极好

**leerob.com**(前 Vercel):
- **Notes 与 Blogs 分离**:短想法(话题式小短文)与长文分开,两种文体
- 文章列表极简:一行"标题 + 年月",无卡片无缩略图
- Bio 就是职业名片,内链 /cursor、/vercel;有 "Things I believe" 页

**IndieWeb "slash pages" 文化**(/now、/uses、/colophon):
- /now:我现在在做什么(每几月更新一次)——nownownow.com 收录
- /uses:我的装备与工具链(折腾人圈的社交名片)
- /colophon:本站用什么搭的(技术栈/字体/部署)——和你"从零到上线"那篇天然呼应

**中文博客圈**:
- 中文博客琅琊榜(GitHub)、BlogFinder:免费收录渠道,也是找友链的地方
- 共识:内容为王,但必备页面里"友链页"是中文圈的社交货币
- 数字花园理念:博客 = 持续生长的知识库,不是一次性发布流

## 三、诊断:六个缺口

1. **没有项目页。** 19 篇文章里至少 10 个真实项目(webai2api、ocs、SysMonitor、qdbaby、txt2md、教务系统×2、GRUB 主题、水彩技能、博客本身),全埋在时间流里。考研复试/实习面试甩一个链接就能看完你的全部作品——现在做不到。
2. **关于页太薄。** 只有"你好/博客介绍/联系方式"三小节,没有:现在在做什么、项目精选、技能画像。对比 leerob 的 bio 叙事差距明显。
3. **首页信息架构错位。** 黄金位置给了 24 个标签云(其中 GRUB/Canvas/X11/Manjaro 等十几个标签只有 1 篇文章,零信息量),而最值钱的 **webai2api 四篇系列没有任何首页入口**。
4. **传播为零。** 搜索引擎未验证收录、无友链页、未提交任何博客目录、Cloudflare Web Analytics token 为空(等于闭眼运营)、pages.dev 子域名 SEO 权重低。
5. **文体单一。** 全是 5-12 分钟的项目长文,没有短想法(Notes)、没有月度总结、没有"更新于"修订记录。技术文随项目演进会过时(如 webai2api 系列 v0.1.32 之后还会变)。
6. **小缺失。** 文末无版权/license 声明(footer 只写"保留所有权利");front-matter 无构建校验(漏 description/tags 不会报错);_headers 缺 CSP;RSS 入口只在 footer 小图标里。

## 四、方案(按优先级)

### P0 —— 名片化(1~2 次推送,全部我能独立完成,不需要你参与)

**P0-1 新增「项目」页 `/projects` + 导航入口**
- 数据:`src/data/projects.json`(项目名/一句话简介/仓库链接/截图可选/关联文章 slug 列表)
- 每个项目一张卡,关联文章自动链到对应文章
- 这是整个大更新里性价比最高的一项:把你已有的东西重新组织一遍,博客从"日记"变"作品集"

**P0-2 重写关于页**
- 加三块:①"现在在做"段落(2026 考研备考 + webai2api 维护 + ocs 迭代,兼 /now 作用,以后单独拆页也行);②项目精选(链到 /projects);③技能画像(一句话级别,别堆进度条)
- 联系方式保留,风格对标 leerob:用叙事,不用表单

**P0-3 首页信息架构改造**
- 撤掉标签云(标签页已有导航入口,不损失任何功能)
- 换上:①「项目精选」3 个(链 /projects);②「系列」入口卡:webai2api 四部曲(第一篇→最新篇顺序列出)
- GitHub 贡献图保留(它已经是同类站里少见的亮点)

**P0-4 文末版权行 + 修订记录**
- 每篇文章末尾自动追加:"© DuRuoxian · CC BY-NC-SA 4.0 · 转载请注明出处"+ 首发日期
- front-matter 加可选 `updated` 字段,有则显示"最后更新于"
- 涉及:`posts/[slug]/page.tsx`、`posts.ts` schema、全部 19 篇 md 补 updated(可选,我批量处理)

**P0-5 RSS 入口提升**
- 顶栏加 RSS 小图标(和搜索图标并列),footer 已有不动

### P1 —— 传播与机制(3~5 次推送)

**P1-1 开启 Cloudflare Web Analytics** ⚠️ 需要你
- CF 控制台 → Pages 项目 → Web Analytics 一键开启,不需要改代码(手机上就能点)
- 这是唯一需要你本人操作的 P1 项,做完运营才算睁眼

**P1-2 友链页 `/links` + 收录提交**
- 建页(数据 JSON 化,admin 后台可加"友链"栏目,复用工具站编辑模式)
- 提交:中文博客琅琊榜 PR、BlogFinder、各大博客聚合(均免费)
- 注意:友链交换时对方信息的展示要遵守隐私边界(不写他人真名)

**P1-3 /uses 页(装备与工具链)**
- 内容现成:Windows 终端栈、ocs/fzf 工作流、VSCode/opencode、Clash、学习工具(Anki 替代品=你自己的 quiz)、手机端远程工作流
- 这页对你的目标读者(折腾向学生)有天然吸引力,也是好素材("我的 2026 装备"本身就是一篇文章)

**P1-4 Notes 短想法机制**
- `content/notes/*.md`(每篇=一段话+日期),首页侧栏显示最近 3 条 + 独立 /notes 页
- 复用 posts 管线,工程量小;解决"想记一句但不够发文章"的场景
- 对标 leerob 的 Notes;考研期间正好用它发碎片学习记录

**P1-5 工程加固**
- 构建脚本校验 front-matter(缺 description/tags/category 时 warning,漏 title 时 error)
- _headers 加 CSP(注意白名单:giscus.app、static.cloudflareinsights.com、github.com avatar)+ HSTS
- README 首行加博客链接 + 徽章(shields.io 免费)

### P2 —— 长期打磨(考研间隙,想到再做)

- **KaTeX 数学公式 + mermaid 图表支持**(将来写 408 笔记会用到,一次配好)

- **/colophon 建站说明页**(技术栈/字体/主题机制/部署链路,"从零到上线"的续集)

## 五、内容策略(比任何功能都重要)

1. **每月一篇「月度总结」**:考研进展 + 项目进展 + 本月踩坑。这是粘性来源,也是 15 个月后回头看最值钱的记录。系列名建议"备考 408 的第 N 个月"。
2. **把子系统写成故事**:「我给自己建了个考研刷题站:920 题的来龙去脉」——quiz/shuku 是你博客最大的差异化,但目前只有功能没有故事,这篇文章同时是引流文。
3. **长青内容**:现有一半文章是"流水账长文"(质量高但有时效性),补 2~3 篇不随时间贬值的:如「Windows 上 Python+fzf 工具链从零配置」「WebP 图片管线:5.8M→0.3M 的完整方案」。
4. **webai2api 系列每篇文首加"系列导航"**(前一篇/后一篇/首篇),SeriesNav 组件已有,确认长文里显眼即可。
5. **节奏**:</b>宁少勿断,每周 ≤2 篇,质量优先;Notes 机制承接日常碎片。

## 六、明确不建议做的(劝退清单)

- ❌ **Newsletter 邮件订阅**:中文圈工具链弱、维护成本高、零花费约束下没有好方案。RSS 顶栏入口做好即可
- ❌ **自建统计(GoatCounter/Umami)**:CF Web Analytics 免费够用,自建需要服务器
- ❌ **换框架(Astro/Hugo)**:Next.js 16 静态导出没有任何瓶颈,迁移是纯风险
- ❌ **大改视觉风格**:现有明暗+六主题+贡献图已经是强个性,推倒重来不划算
- ❌ **追求百度收录**:海外托管+未备案,投入产出比趋近于零
